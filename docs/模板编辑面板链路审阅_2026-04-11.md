# 模板编辑面板链路审阅（2026-04-11）

本审阅只关注模板编辑面板，不扩展到场景面板和执行面板。

## 审阅范围

- 表格
- 页眉页脚与目录
- 参考文献
- 题注

## 当前状态

| 能力 | 配置入口 | 文档执行入口 | 当前结论 |
|------|---------|-------------|---------|
| 表格 | `template.table` | `src/modules/table/table_format.py` | 已具备真实注入能力；本轮已补齐 `border_width_pt`、右对齐、双倍行距 |
| 页眉页脚与目录 | `template.header_footer` / `template.toc` | `src/modules/basic/header_footer.py` / `src/modules/structure/toc.py` | 已具备真实注入能力；本轮已补齐 `header_mode=none` 与 `page_number_enabled=false` 的真实行为 |
| 参考文献 | `template.reference_style` + `styles["references_body"]` | `src/modules/special/reference_format.py` | 已具备真实注入能力；本轮已接上 `doc_tree` 的 references 分区兜底 |
| 题注 | `template.caption` + `styles["caption"]` | `src/modules/table/caption.py` | 已具备真实注入能力；编号、前缀、自动插入、域代码编号均已进入真实文档 |

## 已在本轮补齐的低风险链路

1. `table_format` 现在会真实消费 `border_width_pt`，并补上 `cell_alignment=right`、`line_spacing_mode=double` 的落地行为。
2. `reference_format` 不再只依赖“参考文献”标题，已接入 `doc_tree` 的 `references` 分区兜底。
3. `header_footer` 不再把 `header_mode=none` 和 `page_number_enabled=false` 停留在配置层，现已真实清空页眉/移除页码域。

## 仍未补齐的缺口

1. 表格仍缺 0.2 的隐藏策略迁移：
   `smart_levels` 尚未参与智能宽度分层。
   `compact/smart` 尚未恢复 0.2 的正文范围过滤、富内容表格跳过、单位换行纠偏、表格总宽聚类等策略。
2. 页眉页脚与目录仍缺模板面板定义：
   当前 Elements 面板只编辑结构参数，尚未承载 `styles.toc / toc_title / toc_chapter / toc_level1 / toc_level2` 的目录样式。
3. 页眉页脚仍缺 0.2 的隐藏策略迁移：
   封面不显示页眉页脚、前置部分罗马页码、正文重新起页码、分区差异化页眉策略尚未恢复到 1.0。
4. 题注仍缺细分样式入口：
   引擎已支持 `figure_caption` / `table_caption` 独立样式，但模板面板当前只暴露共享 `caption` 样式。

## 建议的下一步顺序

1. 先补 `Elements` 面板中的目录样式定义，使模板侧的 TOC 参数从“结构配置”扩展到“结构 + 样式”闭环。
2. 再迁移 `header_footer` 的封面/前置部分/正文页码策略，避免 1.0 出现“参数可配但版式策略回退”的隐性回归。
3. 最后集中补 `table_format` 的 0.2 隐藏策略迁移，因为这部分涉及范围过滤、宽度聚类和复杂表格保护，改动面相对更大。
