# Workbench 首页重新设计 V2

- 日期：2026-03-31
- 状态：Draft
- 基于：用户反馈对 master-detail-reset-design.md 的重新规划

## 1. 核心设计原则

### 1.1 第一张卡片 = 完整工作流

用户的核心诉求是：**打开首页就能完成完整的格式化任务**

第一张卡片应该包含从输入到输出的完整流程，而不是把流程拆散到多个对象里。

### 1.2 其他卡片 = 高级功能

其他卡片不是"对象"，而是"高级功能开关 + 配置入口"。

只有当用户需要精细控制某个功能时，才会点击对应的卡片进入配置。

## 2. 左侧卡片重新定义

### 2.1 卡片列表

左侧固定为以下卡片：

1. **快速执行** - 完整工作流一站式操作
2. **标题编号** - 高级功能：标题编号规则配置
3. **内容填充** - 高级功能：Quick Fill 数据源与映射
4. **模块控制** - 高级功能：模块启用/禁用与优先级
5. **输出设置** - 高级功能：输出路径、命名规则、格式选项
6. **执行历史** - 查看历史记录与报告

### 2.2 每张卡片的定位

#### 1. 快速执行（默认选中）

**定位：** 完整工作流，80% 用户只需要这一张卡片

**左侧卡片显示：**
- 标题："快速执行"
- 当前文档名（如果已选择）
- 当前场景模板（如果已选择）
- 总体就绪状态

**右侧详情区包含：**

1. **输入文档区**
   - 文档选择器（支持拖拽、浏览、最近文档）
   - 文档基础信息（路径、大小、修改时间）
   - 文档校验状态

2. **场景模板区**
   - 场景模板下拉选择
   - 模板说明（简短描述该模板的用途）
   - 快速预览：该模板启用的模块

3. **高级选项区**（可折叠）
   - 标题编号开关 + 快速跳转配置
   - 内容填充开关 + 快速跳转配置
   - 模块控制开关 + 快速跳转配置
   - Strict Mode 开关

4. **输出文档区**
   - 输出路径选择
   - 输出文件名预览
   - 输出格式选项（如果有多种）

5. **配置存储区**
   - 当前配置名称（如果已保存）
   - 保存配置按钮
   - 加载配置下拉

6. **执行区**
   - 大号执行按钮
   - 执行状态显示
   - 进度条（执行中）

7. **输出日志区**（可折叠）
   - 最近一次执行的日志摘要
   - 错误/警告提示
   - 查看完整日志按钮

#### 2. 标题编号

**定位：** 高级功能，只有需要精细控制标题编号时才进入

**左侧卡片显示：**
- 标题："标题编号"
- 当前状态：已启用/已禁用
- 当前方案摘要（如：1.1.1 / 3级）

**右侧详情区包含：**
- 启用/禁用开关
- 编号方案选择（预设方案）
- 编号深度设置
- 目录联动开关
- 自定义编号规则（高级）
- 预览效果

#### 3. 内容填充

**定位：** 高级功能，Quick Fill 数据源与映射配置

**左侧卡片显示：**
- 标题："内容填充"
- 当前状态：已启用/已禁用
- 数据源摘要（如：Excel / 5个实体）

**右侧详情区包含：**
- 启用/禁用开关
- 数据源选择（Excel/JSON/数据库）
- 实体/资产列表
- 映射规则配置
- 填充范围预览
- 映射完成度

#### 4. 模块控制

**定位：** 高级功能，精细控制哪些模块启用

**左侧卡片显示：**
- 标题："模块控制"
- 当前启用模块数量（如：5/12 已启用）

**右侧详情区包含：**
- 模块列表（可勾选启用/禁用）
- 模块执行优先级调整
- 模块依赖关系提示
- 批量操作（全选/全不选/恢复默认）

#### 5. 输出设置

**定位：** 高级功能，输出路径、命名、格式的精细配置

**左侧卡片显示：**
- 标题："输出设置"
- 当前输出路径摘要

**右侧详情区包含：**
- 输出目录设置
- 文件命名规则（模板变量）
- 输出格式选项
- 覆盖策略（覆盖/重命名/询问）
- 输出后操作（打开文件/打开目录/无操作）

#### 6. 执行历史

**定位：** 查看历史执行记录与报告

**左侧卡片显示：**
- 标题："执行历史"
- 最近执行时间
- 最近执行状态（成功/失败）

**右侧详情区包含：**
- 历史记录列表（时间、文档、状态）
- 每条记录的详情（点击展开）
- JSON 报告查看
- Markdown 报告查看
- 日志查看
- 输出文件快速打开

## 3. 右侧详情区的统一规范

### 3.1 不再强制 5 类元素

旧设计的 5 类元素（对象头部、对象详情、对象动作、与执行的关系、最近结果摘要）过于僵化。

新设计采用更灵活的分区方式：

1. **功能区** - 该卡片的核心功能配置
2. **关联区** - 与其他功能的关联（可选）
3. **操作区** - 主要操作按钮
4. **状态区** - 当前状态与反馈（可选）

### 3.2 快速执行卡片的特殊性

"快速执行"卡片是唯一包含完整流程的卡片，因此它的右侧详情区结构与其他卡片不同。

其他高级功能卡片的右侧详情区更简洁，只聚焦于该功能本身的配置。

## 4. 工作流逻辑

### 4.1 默认流程（80% 用户）

1. 打开首页，默认选中"快速执行"
2. 选择输入文档
3. 选择场景模板
4. （可选）展开高级选项，快速开关某些功能
5. 确认输出路径
6. 点击执行
7. 查看执行日志

### 4.2 高级配置流程（20% 用户）

1. 在"快速执行"中发现需要精细配置某个功能
2. 点击对应的"快速跳转配置"链接
3. 自动切换到对应的高级功能卡片
4. 完成详细配置
5. 返回"快速执行"继续流程

### 4.3 配置存储与复用

用户可以在"快速执行"中保存当前的完整配置（包括所有高级功能的设置）。

下次使用时，直接加载配置即可恢复所有设置。

## 5. 与旧设计的对比

### 5.1 旧设计的问题

| 问题 | 旧设计 | 新设计 |
|------|--------|--------|
| 对象粒度不一致 | "当前任务"是整体，"标题编号"是配置项 | 第一张卡片是完整流程，其他都是高级功能 |
| 工作流被拆散 | 文档、策略、编号分散在不同对象 | 完整流程集中在"快速执行" |
| 命名不符合心智 | "执行策略"、"当前任务"概念模糊 | "快速执行"、"标题编号"直观明确 |
| 强制统一契约 | 所有对象都要有 5 类元素 | 灵活分区，按需组织 |

### 5.2 新设计的优势

1. **降低学习成本** - 新用户只需要看第一张卡片
2. **提高操作效率** - 常用流程一站式完成
3. **保持灵活性** - 高级用户可以深入配置
4. **清晰的层级** - 基础流程 vs 高级功能，界限分明

## 6. 共享 UI 组件需求

### 6.1 必需的新组件

1. **MasterDetailLayout** - 左右布局容器
2. **NavigationCard** - 左侧导航卡片（支持选中态、状态标识）
3. **SectionGroup** - 右侧内容分组容器
4. **QuickToggle** - 高级选项的开关 + 跳转组合控件
5. **StatusBadge** - 状态标识（已启用/已禁用/警告/错误）

### 6.2 可复用的现有组件

- `Card` - 作为基础容器
- `FormRow` - 表单行
- `IconButton` - 图标按钮
- `ToggleSwitch` - 开关
- `StyledComboBox` - 下拉选择
- `ProgressIndicator` - 进度指示

### 6.3 需要升级的组件

`Card` 需要支持：
- 选中态样式
- 状态标识位置（右上角 badge）
- hover 态
- 禁用态

## 7. 实施建议

### 7.1 开发顺序

1. **Phase 1: 共享 UI 基础**
   - 实现 MasterDetailLayout
   - 实现 NavigationCard
   - 升级 Card 支持新状态

2. **Phase 2: 快速执行卡片**
   - 实现"快速执行"的完整流程
   - 确保基础工作流可用

3. **Phase 3: 高级功能卡片**
   - 按优先级实现：标题编号 → 内容填充 → 模块控制 → 输出设置
   - 实现执行历史

4. **Phase 4: 联动与优化**
   - 实现快速跳转
   - 配置存储与加载
   - 性能优化

### 7.2 迁移策略

不需要一次性删除所有旧代码，可以：

1. 新建 `workbench_v2/` 目录
2. 复用旧代码中的执行逻辑和状态管理
3. 只重写 UI 层
4. 测试稳定后替换旧首页

### 7.3 关键技术点

1. **状态管理** - 全局配置状态需要在所有卡片间共享
2. **快速跳转** - 卡片间的导航与参数传递
3. **配置序列化** - 完整配置的保存与加载
4. **实时校验** - 输入文档、输出路径的即时校验反馈

## 8. 视觉设计要点

### 8.1 左侧导航卡片

- 高度：固定或最小高度，避免参差不齐
- 选中态：明显的背景色变化 + 左侧边框强调
- 状态标识：右上角小圆点或 badge
- 间距：卡片间保持一致间距

### 8.2 右侧详情区

- 顶部留白：与左侧卡片顶部对齐
- 分区间距：使用分隔线或留白区分不同功能区
- 折叠区：默认展开常用项，折叠高级项
- 操作按钮：主操作按钮突出，次要操作按钮弱化

### 8.3 响应式考虑

- 窗口较窄时，左侧卡片可以折叠为图标 + tooltip
- 右侧详情区内容自适应宽度
- 执行按钮始终可见（固定或跟随滚动）

## 9. 非目标

本次重新设计不包括：

1. 执行引擎的重构
2. 配置文件格式的变更
3. 模块系统的改造
4. 主题系统的完整重做

## 10. 总结

新设计的核心理念：

> **第一张卡片 = 完整工作流，其他卡片 = 按需配置**

这样的设计：
- 符合用户的心智模型
- 降低学习成本
- 提高操作效率
- 保持高级功能的可访问性

与旧设计相比，新设计不再纠结于"对象"的定义，而是回归到用户的实际使用场景：快速完成任务 + 按需深入配置。
