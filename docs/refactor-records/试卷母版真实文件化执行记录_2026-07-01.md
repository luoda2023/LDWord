# 试卷母版真实文件化执行记录

## 本次结论

试卷场景里的“试卷母版”已经从“点击时临时生成的展示文件”改为“真实存在的 `.docx` 母版文件”。

最终边界如下：

| 对象 | 责任 |
|---|---|
| 场景配置 | 选择空白试卷样式、题目装配方式、答案处理方式 |
| 试卷母版 | 保存长期复用的卷面外框、题目插入点、答题区、页脚 |
| 工作台 | 每次填写标题、科目、年级、考试时间、满分和题稿 |
| 样张 | 从当前母版读取后插入示例题，用于确认当前母版效果 |

## 文件落点

内置母版固定放在：

- `exam_masters/builtin/default_exam_v7.docx`
- `exam_masters/builtin/compact_exam_v7.docx`

用户点击“复制后修改”后，才会复制到：

- `exam_masters/user/<副本ID>.docx`

场景副本配置新增 `master_docx_path`，用于记录这个副本对应的真实 Word 文件。

## 交互变化

- `打开母版`：打开当前样式绑定的真实 `.docx` 文件。
- `复制后修改`：复制当前真实母版到用户目录，并切换到新副本。
- `生成样张`：从当前真实母版加载，再插入示例题和答案版，不再从空白 `Document()` 临时重建版式。

## 母版内容调整

内置母版改为普通 Word 卷面结构：

- 标题：`【试卷标题】`
- 副标题：`【副标题】`
- 信息栏：科目、年级、考试时间、满分
- 考生栏：姓名、班级、考号
- 注意事项
- 题目区插入点：`题目会在正式生成时从这里开始。`，以隐藏文本保存，供程序定位。
- 答题区说明：`作答区域会按题目自动延展。`，以隐藏文本保存，供程序定位。
- 页脚页码字段

不再使用灰底块、方括号占位符或异常展示文本。

## 版式参考更新

根据 `<LOCAL_PATH>` 做了版式参考，但不复制其内容。

提取到的参考特征：

- A4 页面，顶部较紧，左右边距较宽。
- 标题两行居中：第一行约 18pt 宋体加粗，第二行约 24pt 黑体加粗。
- 标题下方有 2 行 8 列总分表：`题号 / 一 / 二 / 三 / 四 / 五 / 六 / 总分`，第二行为 `分数`。
- 每个大题前有 1 行 2 列的小得分框：`得分 / 空白`。
- 正文约 12pt 宋体，1.5 倍行距，大题标题约 14pt。

内置母版已调整为同类卷面：

- 左侧密封区/装订栏改为页眉 VML 形状层承载，不再用两栏外层表格承载正文。
- 正文恢复为普通 Word 正文流：标题段落、总分表、大题得分框、题目插入点按顺序直接进入文档主体。
- 新增总分表。
- 新增大题前得分框，并让得分框与大题标题处于同一行。
- 页边距改为参考卷接近值。
- 标题层级改为两行居中。
- 正文基础字号和行距改为更接近小学测试卷。

旧的 `exam_masters/builtin/default_exam.docx` 当前可能被 WPS 占用，保留不动；程序入口已经切换到新的 `default_exam_v7.docx`。

## v4 结构修正

本次继续修正了 v3 的核心问题：v3 虽然看起来接近参考卷，但把整页正文包进了一个外层布局表，后续题目插入、分页、编辑都会变得不自然。

v4 的确认边界如下：

- 左侧装订区属于试卷母版的页眉装饰层，只负责每页重复出现的密封线、装订线和“学校 / 班级 / 姓名”标识。
- 正文区不再被装订区包裹，顶层结构恢复为普通 Word：段落标题、2 行 8 列总分表、大题得分框、题目插入点。
- 局部表格只用于真实表格对象，例如总分表和大题得分框；不再把表格当作整页排版容器。
- 测试新增结构断言：默认母版首段必须是“试卷标题”，首个顶层表格必须是 8 列总分表，页眉必须包含 `ExamSealDottedLine` 和 `ExamSealLabelBox`。

## v5 可读母版修正

根据打开母版后的截图继续修正 v4 的可用性问题。

v4 暴露的问题：

- 左侧装订区没有显示，原因是页眉 VML 使用负坐标，部分 Word/WPS 预览会把它裁到页面外。
- 卷面上出现 `默认试卷 · 空白母版`，这是系统样式名，不应该成为用户看到的试卷内容。
- 缺少考试信息栏，用户无法确认科目、年级、考试时间和满分最终落在哪里。
- `题目会在正式生成时从这里开始。`、`作答区域会按题目自动延展。` 这类工程提示直接显示在卷面上，不像真实母版。
- 顶部分数表偏窄，大题得分框和大题标题之间关系松散。

v5 修正结果：

- 内置入口切换到 `exam_masters/builtin/default_exam_v5.docx` 和 `exam_masters/builtin/compact_exam_v5.docx`。
- 左侧装订区继续放在页眉形状层，但改为相对页面的正坐标定位，并增加 `mso-position-horizontal-relative:page` / `mso-position-vertical-relative:page`，避免被裁掉。
- 标题区改为可理解占位：`【试卷标题】`、`【副标题】`。
- 增加考试信息栏：`科目`、`年级`、`考试时间`、`满分`。
- 插入点标记仍保留在 docx 结构中，供程序定位，但改成隐藏文本，不再作为卷面正文显示。
- 顶部分数表扩展到接近正文宽度，大题标题向得分框靠拢。

新增结构断言：

- 默认母版文件名必须是 `default_exam_v5.docx`。
- 母版正文必须包含 `【试卷标题】`、`【副标题】` 和考试信息栏。
- 母版正文不能再包含 `默认试卷 · 空白母版`。
- 页眉装订区必须包含页面相对定位，并且不能再出现负 `margin-left`。

## v6 定位修正

根据 v5 截图继续修正三个位置问题：

1. 考试信息栏
   - v5 使用单段文本承载 `科目 / 年级 / 考试时间 / 满分`，在 Word/WPS 里容易因为行宽和字体差异让 `满分` 下划线换行。
   - v6 改为 1 行 4 列无边框表格，每个字段占一个固定列宽：`科目`、`年级`、`考试时间`、`满分`。
   - 这样字段不会互相挤压，也不会把最后一个下划线挤到下一行。

2. 大题标题
   - v5 的“大题得分框 + 一、题目区”虽然在同一行，但外层表格没有完整写入 `tblGrid`，不同渲染器会重新分配列宽，导致标题跑到页面中间。
   - v6 为该行写入固定 `tblW / tblGrid / tcW`，得分框和标题的相对位置由明确列宽控制。

3. 左侧装订区
   - v5 的标签显示在正文区内，说明“全部正坐标”会把形状推入正文区域。
   - v6 允许小幅负偏移，把装订区放回正文左侧；同时避免 v4 的大幅负偏移。
   - 继续保留 VML 线条，并新增 `ExamSealDottedTextGuide` 点列作为兼容兜底，防止某些 Word/WPS 对 `<v:line>` 渲染不稳定。

新增结构断言：

- 默认母版文件名必须是 `default_exam_v6.docx`。
- 第一张表必须是 4 列考试信息栏，第二张表必须是 8 列分数表。
- 页眉必须包含 `ExamSealDottedLine`、`ExamSealDottedTextGuide` 和 `ExamSealLabelBox`。
- 程序定位文本仍存在，但必须是隐藏文本。

## v7 首页装订区修正

根据边界重新确认：装订线和密封信息不是正文元素，也不应该每页重复。它们只属于首页页眉。

v7 修正规则：

- 开启 Word 的 `首页不同`。
- 装订线、虚线兜底点列、学校/班级/姓名只写入 `first_page_header`。
- 普通 `header` 保持空，不包含任何 `ExamSeal*` 对象。
- 页码同时写入 `first_page_footer` 和普通 `footer`，避免开启首页不同后第一页页码丢失。
- 正文区继续保持普通 Word 正文流，不参与装订区定位。

新增结构断言：

- 默认母版文件名必须是 `default_exam_v7.docx`。
- `different_first_page_header_footer` 必须为 `True`。
- `first_page_header` 必须包含 `ExamSealDottedLine`、`ExamSealDottedTextGuide` 和 `ExamSealLabelBox`。
- 普通 `header` 不能包含任何装订区对象。

## v9 顶部信息栏减法与一级标题回退

根据 2026-07-02 的边界确认，顶部的“科目 / 年级 / 考试时间 / 满分”不再放在正文区域。该信息由首页左侧装订区承担，母版正文只保留真正属于卷面主体的结构。

v9 修正规则：
- 保留 v7 的首首页眉装订区规则：装订线、学校 / 班级 / 姓名只存在于 `first_page_header`，普通页眉保持空。
- 删除正文顶部的 4 列考试信息栏，避免“左侧装订区”和“正文信息栏”重复承担同一任务。
- 回退到上一版确认合理的“大题得分框 + 一级标题”结构：得分框和“一、题目区”位于同一行，左侧为嵌套 1x2 得分小表，右侧为一级标题。
- 第一张顶层表必须是 2 行 8 列的总分表；第二张顶层表必须是 1 行 2 列的大题标题行。
- 题目插入点和作答区标记继续保留为隐藏文本，只供程序定位，不作为卷面说明展示。

新增结构断言：
- 内置默认母版文件名为 `default_exam_v9.docx`。
- 正文可见文本不能包含 `科目：`、`年级：`、`考试时间：`、`满分：`。
- 第二张顶层表的左单元格必须包含嵌套得分表，右单元格必须包含 `一、题目区`。

## v10 得分框与一级标题垂直对齐

根据截图继续修正 v9 的细节问题：`得分` 小表和右侧 `一、题目区` 虽然处于同一行，但右侧标题受 `Exam Section Heading` 段前间距影响，视觉上会比得分框偏下。

v10 修正规则：
- 内置默认母版切换到 `default_exam_v10.docx`，紧凑母版切换到 `compact_exam_v10.docx`。
- 大题标题行的外层左、右单元格都设置为垂直居中。
- 仅对“得分框同一行里的一级标题”清零段前和段后，并设置行距为 `1.0`。
- 不修改普通题目正文里的 `Exam Section Heading` 样式，避免影响正式题目生成时的大题标题段落间距。

新增结构断言：
- 第二张顶层表左右单元格必须都是垂直居中。
- 右侧标题段落的 `space_before`、`space_after` 必须为 0，`line_spacing` 必须为 1.0。

## v12 回退 v11 的页眉过度简化

继续审阅用户手工修改后的 `default_exam_v10.docx` 后确认：v10 中新增的两条对象不是普通横向文本，也不是正文左侧布局块，而是故意放在 `first_page_header` 中的旋转 VML 文本框。v11 将它们改写成简化 VML shape，并删除旧装订线对象，属于过度抽象，容易改变 Word/WPS 的定位和旋转行为。

v12 修正规则：
- 内置默认母版切换到 `default_exam_v12.docx`，紧凑母版切换到 `compact_exam_v12.docx`。
- 大题标题行列宽继续固化为 `1846 / 7083` DXA。
- 首页装订区以 v10 的页眉对象为准：保留两个旋转文本块，以及 `ExamSealDottedLine`、`ExamSealDottedTextGuide`、`ExamSealSolidLineTop`、`ExamSealSolidLineBottom`、`ExamSealLabelBox`。
- 这些对象只写入 `first_page_header`，普通 `header` 必须为空，正文区域不承担装订区定位。
- 生成器优先从 `default_exam_v10.docx` 复用已人工确认的页眉对象；参考文件不存在时才使用简化 fallback。

新增结构断言：
- 默认母版文件名为 `default_exam_v12.docx`。
- 首页页眉必须包含两个 `rotation:-5898240f` 的 V10 旋转文本块，并保留 `margin-left:-451.1pt` 与 `margin-left:-343.2pt`。
- 首页页眉必须包含旧的 `ExamSeal*` 装订区对象；普通页眉不能包含装订区对象。

## v13 完整保留 v10 页眉兼容结构

用户打开 v12 后反馈看不到装订块。继续对比 `default_exam_v10.docx` 和 `default_exam_v12.docx` 后确认：v12 虽然复制了 VML `shape/line`，但把它们压进了一个新的 `w:pict`；v10 中真正能稳定显示的结构是 `mc:AlternateContent -> mc:Fallback -> w:pict -> v:shape`，并且同一首页页眉内有多个独立 `w:pict`。

v13 修正规则：
- 内置默认母版切换到 `default_exam_v13.docx`，紧凑母版切换到 `compact_exam_v13.docx`。
- 保存母版后，直接定位 `w:type="first"` 的页眉关系，把对应 `word/header*.xml` 替换为 v10 的原始首页页眉 XML。
- 因此 `AlternateContent`、`mc:Choice`、`mc:Fallback`、`w:pict`、VML 对象、WPS/Word 兼容命名空间都不再被 python-docx 重组。
- 普通页眉仍保持空，装订区只存在于首页页眉。

新增结构断言：
- 默认母版文件名为 `default_exam_v13.docx`。
- 包内首页页眉必须包含 7 个 `w:pict`、4 个 `AlternateContent`、2 个 `rotation:-5898240f`。
- 包内首页页眉必须保留 `xmlns:w15` 和 `xmlns:wpsCustomData`，避免 Word/WPS 兼容层丢失。
