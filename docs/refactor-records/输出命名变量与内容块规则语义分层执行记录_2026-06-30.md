# 输出命名变量与内容块规则语义分层执行记录 2026-06-30

## 本轮结论

场景面板的输出设置已经有交付版本、目标模板、输出文件、显隐规则等能力，但此前“高级命名与报告”区仍然把实现细节直接暴露给用户：

- 命名变量下拉直接显示 `{preset_id}`、`{preset_label}`，用户需要先理解模板占位符。
- 内容显隐规则要求用户理解 `answer=remove` 和 `{{#visibility:answer}}`。
- 输出设置与模板管理的控件契约不一致：模板管理主路径是业务名和可读状态，内部 ID 只出现在 tooltip、数据层或诊断层；输出设置仍有大量内部 key 进入主路径。

本轮将输出设置继续收敛到同一套语义分层：主路径显示业务名，内部 key/占位符保留在控件数据、tooltip、文本规则和测试断言中。

## 与模板管理的比对

模板管理当前更成熟的部分有三个稳定特征：

1. 选择器显示业务名，例如模板名、资料规则名、样式分区名。
2. 内部 ID 仍可追踪，但不占据用户主路径。
3. 控件之间有明确层级：摘要看结果，表单改参数，高级入口处理细节。

输出设置此前的断点是：

1. “变量插入”把占位符当作选项名，破坏可读性。
2. “规则插入 / 显隐规则”把规则文本当作主要理解方式，缺少常用业务块选择。
3. 占位符示例同时承担“默认值、说明、输入格式”三种角色，信息边界不清。

## 本轮落地

### 命名变量

新增变量投影层：

- `{document_dir}` -> 原文所在文件夹
- `{output_dir}` -> 本次输出文件夹
- `{stem}` -> 原文件名
- `{suffix}` -> 原扩展名
- `{preset_id}` -> 交付编号
- `{preset_label}` -> 交付名称

主下拉只显示中文业务名；真实占位符仍作为 item data，并在 tooltip 中展示。插入按钮继续写入真实占位符，因此不影响已有路径渲染、校验和执行。

同时把“变量插入”改为“命名信息”，按钮从“插入目录 / 插入命名”调整为“放入目录 / 放入文件名”，让动作更贴近用户目标。

### 输出目录与文件命名

占位符示例从 placeholder 中下沉到 tooltip：

- 输出目录 placeholder 改为“默认放到当前文档旁的 output 文件夹”。
- 文件命名 placeholder 改为“默认使用原文件名加交付编号”。
- `{document_dir}/output`、`{stem}_{preset_id}` 保留在 tooltip 和真实默认值中。

这样 placeholder 只负责解释缺省行为，不再要求用户先理解模板语法。

### 内容块规则

新增常用内容块选择器：

- 答案 -> `answer`
- 解析 -> `analysis`
- 解题过程 -> `solution`
- 题目区 -> `question_only`
- 内部内容 -> `internal`
- 内部备注 -> `internal_note`
- 审阅备注 -> `review_note`

用户可以从下拉选择常用内容块，也可以在右侧输入自定义内容块名，仍支持粘贴 `{{#visibility:answer}}`。点击“添加到规则”后，写入的仍是 `answer=hide/remove/exclude` 这种现有规则文本，并继续解析为 `ContentVisibilityRule`。

原“规则插入 / 显隐规则”调整为“添加内容块 / 内容块规则”，让用户先理解“哪个内容块怎么处理”，再进入规则文本。

## 链路边界

本轮没有改运行时执行逻辑，原因是现有链路已经可用：

```mermaid
flowchart LR
  A["场景输出设置"] --> B["DeliveryPreset"]
  B --> C["content_visibility_rules"]
  C --> D["content visibility engine"]
  D --> E["执行页扫描与预览"]
  E --> F["最终交付文件"]
```

这次改的是 A 层的控件投影，不改变 B 到 F 的执行合同。这样风险较低，也能保证规划页写入的规则仍被执行页和 pipeline 识别。

## 验收证据

已补充/更新测试，覆盖以下约束：

- 输出设置表单不再出现“变量插入 / 规则插入 / 显隐规则”这些偏实现的主路径标签。
- 变量下拉显示业务名，不显示 `preset_label` 或 `{preset_label}`。
- 变量 tooltip 保留 `{preset_label}`，确保可追踪。
- 内容块下拉显示“答案”，不显示 `answer`。
- 内容块 tooltip 保留 `answer` 和 `{{#visibility:answer}}`。
- 选择“答案”后仍能写入 `answer=hide`，并更新当前交付的 `content_visibility_rules`。

## 仍需继续推进

1. 内容块词表还在 `ScenePanel` 内部，后续应抽成共享投影，供场景规划页和执行页扫描结果共同使用。
2. `QuickExecutionDetail` 扫描显隐标记时仍显示 selector 原值，可继续做“扫描结果主路径业务名化，selector 下沉 tooltip”。
3. 输出高级区仍可继续拆成 `DeliveryNamingBlock` 与 `ContentVisibilityRuleBlock`，进一步降低 `_OutputDetail` 体积。
4. 交付版本 ID 仍是主表单字段，后续可以考虑折叠到高级区，主路径只保留交付名称、业务模板和输出物开关。
