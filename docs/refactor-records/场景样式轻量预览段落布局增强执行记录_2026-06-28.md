# 场景样式轻量预览段落布局增强执行记录

日期：2026-06-28

## 1. 本轮继续推进的问题

上一轮已经在场景“样式覆盖”中加入轻量预览，让用户能看到当前分区有效样式的一段样本文字。但继续检查后发现，预览仍偏表层：

- 能表达字体、字号、粗体、斜体、对齐。
- 不能真正表达首行缩进、悬挂缩进、左右缩进。
- 不能表达段前段后。
- `line_spacing` 参数传入了，但 QLabel 级预览没有实际用它影响布局。

这会导致用户看到“样式预览”，但对论文、参考文献这类最关键的段落版式仍然判断不足。为了继续减少解释文字，本轮把轻量预览推进到段落布局层。

## 2. 设计边界

### 2.1 仍然不是完整模板预览

本轮没有把场景页变成完整纸张预览。模板页仍然负责完整页面、标题、正文、表格、页眉页脚组合效果。

场景页只展示当前分区的一小段有效样式，用来帮助用户判断“这个分区覆盖后是否大致对”。

### 2.2 单位换算必须在投影层完成

缩进和段距有多种单位：

- 字符
- pt
- cm
- lines
- auto

UI 组件不应直接理解这些业务单位。本轮继续保持分层：

```text
StyleConfig
  -> SectionStylePreviewProjection
  -> StylePreview
```

`SectionStylePreviewProjection` 输出已换算好的 pt 值，`StylePreview` 只负责绘制。

## 3. 本轮实现

### 3.1 `SectionStylePreviewProjection` 补充段落布局数据

文件：`src/config/style_variant_semantics.py`

投影新增：

- `left_indent_pt`
- `right_indent_pt`
- `first_indent_pt`
- `hanging_indent_pt`
- `space_before_pt`
- `space_after_pt`

其中：

- 缩进通过 `resolve_style_config_indents(...)` 解析。
- 行距类型通过 `normalize_line_spacing_type(...)` 规范。
- 行距值通过 `resolve_line_spacing_value(...)` 解析。
- 段前段后通过 `resolve_spacing_render_pt(...)` 按有效行高换算。

这样预览层拿到的是稳定的点值，不需要再理解“0.5 行”“2 字符”这些配置单位。

### 3.2 `StylePreview` 改为自绘轻量段落预览

文件：`src/shared/ui/style_preview.py`

`StylePreview` 仍然保持 `QLabel` 子类，保留原来的导入和调用兼容性；但内部新增自绘：

- 使用主题 token 绘制背景、边框、圆角和 padding。
- 将样本文案拆成两行。
- 根据对齐方式绘制左右/居中。
- 根据首行缩进、悬挂缩进、左右缩进调整每行起点和宽度。
- 根据行距值调整行间距。
- 根据段前段后调整文本区域的上下空间。

`update_preview(...)` 新增参数：

- `left_indent_pt`
- `right_indent_pt`
- `first_indent_pt`
- `hanging_indent_pt`
- `space_before_pt`
- `space_after_pt`

原有参数保持兼容。

### 3.3 场景页传递完整布局预览参数

文件：`src/ui/panels/scene_panel.py`

`_sync_section_style_preview(...)` 现在把投影中的缩进和段距参数一并传给 `StylePreview.update_preview(...)`。

这让当前分区预览不再只是“字体样例”，而是“段落样例”。

## 4. 对用户理解的改进

本轮后，场景样式覆盖的轻量预览能表达更多真实排版信息：

- 参考文献是否有悬挂缩进。
- 正文类分区是否有首行缩进。
- 左右缩进是否明显。
- 行距大致是紧凑还是宽松。
- 段前段后是否为内容留出空间。

这对论文、参考文献、摘要、附录这类段落型分区尤其重要。

## 6. 后续仍可继续推进

### 6.1 自绘预览还可以更接近 Word

当前预览是轻量绘制，不追求 Word 级精确。后续如果要更逼真，可以继续加入：

- 多行自动换行。
- 悬挂缩进对第二行以后更完整的模拟。
- 段前段后视觉标尺。
- 左右缩进参考线。

### 6.2 预览与模板完整预览仍可抽更深投影

当前 `TemplateStylePreview` 和 `StylePreview` 仍是两个渲染组件。后续可以继续抽：

```text
ParagraphPreviewProjection
```

让模板页完整预览和场景页轻量预览共享同一套段落布局投影。

## 7. 结论

本轮把场景样式轻量预览从“字体效果可见”推进到“段落布局也可见”。

它继续服务同一个目标：少用解释文字，多用状态、动作和即时反馈帮助用户理解场景覆盖与模板基线之间的关系。
