# 样本库动作状态投影归一执行记录

日期：2026-06-29

## 1. 本轮结论

前几轮已经把请求说法、请求筛选、请求数量、请求证据动作状态统一到共享投影层。继续审计后，场景页里“样本库”动作仍然有一组散落文案：

- `生成失败: {exc}`
- `请先选择样本文件`
- `样本文件不存在，请先生成样本库`
- `样本目录不存在，请先生成样本库`
- `已打开样本`
- `已打开样本目录`

这些文案虽然已经比 raw id 友好，但仍有两个问题：

1. 状态原因没有统一边界：未生成、未选择、打开失败、生成失败各自拼接。
2. 主文案可能混入异常或路径，和请求证据动作状态的分层不一致。

本轮将样本库动作状态也收进 `scene_summary_projection.py`，让样本库、样本文件、样本目录的操作反馈统一为“主状态 + tooltip 证据”。

## 2. 已落地调整

### 2.1 新增共享样本库状态投影

文件：`src/ui/panels/scene_summary_projection.py`

新增：

- `scene_sample_fixture_library_status_text(...)`
- `scene_sample_fixture_library_status_tooltip(...)`

当前状态：

| 状态 | 主文案 |
| --- | --- |
| `not_generated` | 尚未生成样本库 |
| `generated` | 样本库已生成 |
| `generation_failed` | 样本库生成失败 |
| `no_sample_selection` | 先选择一个样本文档 |
| `sample_missing` | 样本文件未生成 |
| `sample_opened` | 已打开样本 |
| `sample_open_failed` | 无法打开样本 |
| `directory_missing` | 样本目录未生成 |
| `directory_opened` | 已打开样本目录 |
| `directory_open_failed` | 无法打开样本目录 |

生成成功仍支持数量摘要：

```text
样本库已生成 · 42 个样本
```

路径、manifest 位置、异常详情只进入 tooltip：

```text
样本库生成失败
样本库生成过程中出现错误。
说明：permission denied
位置：C:/tmp/scene_samples
```

### 2.2 场景页接入

文件：`src/ui/panels/scene_panel.py`

调整：

- 样本库未生成：主文案“尚未生成样本库”，tooltip 解释“生成样本库后，可以打开样本文档和请求证据”。
- 生成失败：主文案“样本库生成失败”，异常详情进入 tooltip。
- 生成成功：主文案“样本库已生成 · N 个样本”，manifest 路径进入 tooltip。
- 打开样本：主文案“已打开样本”，文件路径进入 tooltip。
- 打开目录：主文案“已打开样本目录”，目录路径进入 tooltip。
- 样本文件未生成、样本目录未生成也使用共享投影。

### 2.3 按钮 tooltip 对齐

文件：`src/ui/panels/scene_panel.py`

`_sync_selected_sample_fixture_state()` 现在会为“打开样本”按钮设置同源 tooltip：

- 当前样本可打开：说明样本库已生成，并给出位置。
- 当前样本文件未生成：提示“样本文件未生成”，说明先生成样本库。
- 没有选中样本：提示“先选择一个样本文档”。

## 4. 当前边界

已归一：

- 请求说法显示名、tooltip。
- 请求筛选项与匹配逻辑。
- 请求数量/空态。
- 请求证据动作状态。
- 样本库动作状态。
- 样本文件/样本目录打开状态。

仍需继续：

1. 抽 `SampleEvidenceBlock`，把样本库动作、请求筛选、数量、列表、打开证据组织成一个共享组合块。
2. 将路径、manifest、fixture id、sample id 从 tooltip 升级到可展开证据面板。
3. 把样本库生成失败的异常类型进一步转成用户可执行建议，例如权限、路径不存在、docx 生成失败。
4. 做一次视觉层审计：样本库动作区是否还像表单堆叠，是否需要更接近模板管理的“摘要 + 动作条 + 明细浏览”结构。

## 5. 设计判断

这轮继续强化一个原则：

```text
主文案只讲状态；
tooltip 讲原因和位置；
技术证据不占用主阅读路径。
```

样本库动作现在和请求证据动作使用同样的反馈模型。用户看到的是“样本文件未生成”“已打开样本目录”，而不是路径、异常、manifest 或工程判断。
