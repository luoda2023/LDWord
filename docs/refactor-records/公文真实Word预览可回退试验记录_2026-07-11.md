# 公文真实 Word 预览可回退试验记录（2026-07-11）

## 试验目标

把公文方案页原有的 HTML“结构示意”升级为接近最终交付物的预览：使用当前公文 DOCX 母版和当前资料数据完成真实装配，再由 Microsoft Word 导出 PDF，最后在应用内显示逐页 PNG。

这是一项可回退试验，不替换、不删除原快速预览。

## 当前实现

- 方案概览提供“真实 Word / 快速结构”切换，默认尝试真实 Word。
- Word 页面按卡片宽度完整展开高度，不再嵌套第二层滚动区；滚动统一交给工作台外层页面。
- 真实预览使用当前选中的 DOCX 母版；字号、段落、页边距、表格、分页等均来自 Word 实际排版。
- 无完整资料时会用确定性的示例资料补足，仅用于展示版式，界面会明确提示。
- DOCX、PDF 和分页 PNG 按“文种 + 资料 + 母版版本”缓存；同一输入再次查看不重复启动 Word。
- 渲染在后台串行执行，并有 700ms 防抖；连续切换文种或资料时只接收最新结果。
- PDF 分页优先使用应用依赖 `pypdfium2`，系统 `pdftoppm` 仅作为后备。
- Word、PDF 或 PNG 任一环节失败时，自动切回原“快速结构”预览，不阻断方案配置和文档生成。
- 方案卡片不再展示文种、内部模板 ID、资料契约、字段槽位和交付版本等重复技术说明。

## 回退方式

### 用户即时回退

在方案预览右上角选择“快速结构”。真实渲染代码仍在，但当前页面不再请求渲染。

### 整体关闭试验

启动应用前设置环境变量：

```powershell
$env:ALAVETTE_REAL_WORD_PREVIEW='0'
```

关闭后，界面不创建真实预览控件和后台渲染器，行为恢复为原快速结构预览。删除该环境变量或设为 `1` 即可重新开启。

### 代码级彻底撤回

本试验被隔离在以下新增文件及少量接入点中：

- `src/shared/engine/official_word_preview.py`
- `src/shared/engine/pdf_page_renderer.py`
- `src/shared/ui/document_page_preview.py`
- `src/ui/panels/official_word_preview_controller.py`
- `src/ui/panels/scene_panel.py` 中 `official_word_preview` / `official_preview_mode` 相关接入
- `requirements.txt`、`pyproject.toml` 和 `THIRD_PARTY_NOTICES.md` 中的 `pypdfium2` 条目

撤回这些接入后，原 `_official_preview_canvas` 及其 HTML 结构预览仍完整保留，无需重新实现旧功能。

## 缓存与清理

缓存位于系统临时目录下的 `alavette_form/official_word_preview`。缓存只保存预览产物，不是用户方案和正式交付物；删除整个目录不会损坏任何业务数据，后续需要时会重新生成。

## 验证结果

已在 Windows + Microsoft Word 环境用当前 `official_gbt_standard` 母版完成真实链路：

1. 装配真实 DOCX 成功；
2. Word COM 导出 PDF 成功；
3. PDFium 生成分页 PNG 成功；
4. 预览页保留了母版中的红色发文机关、红线、标题、正文、落款和表格；
5. 相同输入可命中缓存；失败路径可自动回退到快速结构。

## 已知边界

- “真实 Word”表示由本机 Word 实际排版后转成图片，准确度显著高于 HTML 模拟，但它不是可编辑的嵌入式 Word 控件。
- 首次预览需要启动 Word 后台导出，速度会比快速结构慢；缓存命中后明显更快。
- 本机未安装 Word、Word 自动化被安全策略禁止或母版损坏时，会自动回退。
- 当前只在公文方案预览启用；正式生成链路未被改写。
