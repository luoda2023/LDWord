# 资料文本投影与结构化 Token 编辑统一重构记录

日期：2026-07-13

## 一、问题与结论

字段、文件、时间、图片、附件使用的是不同业务模型，但它们都存在同一类界面边界：真实值可能远长于当前列宽。若每个页面自行截断字符串，会同时引入复制错误、持久化污染、编辑丢字、规则漂移和重复代码。

本次统一为一条共享链路：

```text
业务模型中的 canonical value
        │
        ├─ 显示：按控件实际像素宽度生成 projection
        ├─ 复制：始终复制 canonical value
        └─ 编辑：载入完整 editable value，提交后重新组成 canonical value
```

省略号只是显示结果，任何时候都不能写回模型。

## 二、四种值必须分离

| 值 | 含义 | 约束 |
| --- | --- | --- |
| canonical value | 业务真实值 | 保存、校验和复制的唯一来源 |
| display projection | 当前宽度下的显示值 | 可省略，不可持久化 |
| editable value | 用户实际可修改的部分 | 编辑时必须完整，不显示省略号 |
| copied value | 写入剪贴板的值 | 必须等于 canonical value |

Token 还需要拆成三个结构段：

```text
locked prefix + editable core + locked suffix
```

- 普通 Token：`{{` + `字段1` + `}}`
- 文件内容 Token：`{{@content:` + `项目背景1` + `}}`

双击编辑时只把 core 放进输入框，前后结构由只读标签呈现，因此退格、全选或粘贴都无法误删大括号和 `@content:` 命名空间。

## 三、统一显示规则

| 语义 | 显示规则 | 示例 |
| --- | --- | --- |
| Token | 仅对 core 右侧省略，锁定前后缀 | `{{非常长的字段名…}}` |
| 名称 | 右侧省略 | `ISO9001质量管理体系…` |
| 单行字段值 | 右侧省略 | `中共某某市委员会综合…` |
| 路径 | 保留根路径提示、遗漏标记和文件扩展名 | `C:\…方案….docx` |
| 文件名 | 优先保留完整扩展名 | `项目总体技术….docx` |
| 时间结果 | 右侧省略 | `2026年7月13日至…` |
| 附件复合状态 | 中间省略，并保留完整可访问文本 | `单文件 · 1 项：… · 支持 PDF` |
| 多行正文值 | 保持换行；编辑时展开 | 不强制压成单行 |

所有规则均使用 `QFontMetrics` 按像素计算，不按字符数猜测。中文、英文、数字和不同字体宽度因此遵守同一边界。

## 四、交互契约

### Token 与名称

- 单击：复制完整 canonical value。
- 双击：进入编辑。
- Escape：恢复进入编辑前的完整值。
- 点击控件外：提交并退出编辑。
- F2：键盘进入编辑。
- Ctrl+C、Enter 或 Space：在只读投影状态复制完整值。
- 不使用悬浮提示弹窗作为主要交互说明；仅当可见投影确实省略时，悬浮卡片补充展示完整 canonical value。

### 直接填写的值

- 单击或键盘聚焦后进入完整值编辑。
- 输入期间继续发出与 `QLineEdit.textChanged` 一致的实时值信号。
- Escape 恢复快照时也发出恢复后的真实值，避免界面与模型状态分叉。

### 只读值、路径和时间结果

- 不进入编辑。
- 单击立即复制完整值。
- 只读控件没有双击编辑竞争，因此语义激活信号不做双击等待。

## 五、共享实现边界

核心实现集中在以下文件：

- `src/shared/ui/text_projection.py`：纯像素投影函数与 `ElidedTextLabel`。
- `src/shared/ui/projected_text_edit.py`：canonical / display / edit 生命周期和键鼠契约。
- `src/shared/ui/material_token_edit.py`：Token 结构拆分与重新组合。
- `src/shared/ui/material_name_edit.py`：材料名称适配器。
- `src/shared/ui/material_text_views.py`：普通值、只读值、路径、文件名适配器。
- `src/shared/ui/official_field_value_edit.py`：公文字段值兼容适配器。

领域 Presenter 只选择正确的语义控件，不再自行计算字符长度或临时拼接省略号。

## 六、已覆盖的业务链路

| 领域 | 已覆盖内容 |
| --- | --- |
| 字段资料 | 固定/自由字段 Token、手工字段 Token、字段名称、单行字段值 |
| 文件资料 | `{{@content:...}}` 结构冻结、文件路径 |
| 时间计划 | 时间 Token、只读日期结果 |
| 图片资料 | 单图 Token、单图名称、图片路径、图片说明；多图 Token、名称、文件夹路径 |
| 附件资料 | 角色标题与包含文件名/相对路径的复合状态 |

## 七、边界与非目标

- 不允许把 `…` 写入配置、资料包或运行时上下文。
- 不允许用固定字符数作为跨字体规则。
- Tooltip 不是完整值的唯一入口；完整值始终保留在 canonical value、可访问名称和编辑会话中。只有实际发生省略时才显示完整值悬浮卡片，宽度恢复后立即清空。
- 不为了省略显示改变 DOCX 插入、图片缩放、水印或附件处理链路。
- 多行正文保留换行和展开编辑语义；若将来需要“折叠为单行预览”，应扩展共享投影控件，不在页面内另写一套事件逻辑。

### 2026-07-13 长 Token 可见性补充

后续真实附件行核验发现，固定命名空间前缀和后缀会显著压缩 `QLineEdit` 的可编辑宽度；全选进入编辑时，原生横向滚动还会先卷走名称左端，造成内容似乎缺失的错觉。共享控件因此补充两层渐进披露：

- 展示态只在实际省略时，以全局主题悬浮卡片显示完整值；
- 编辑态在 editable core 超过当前可用像素宽度时，自动把同一个编辑器提升到屏幕边界内的锚定卡片，冻结结构移入实时完整值预览，不创建第二套模型或提交链路。

展开编辑仍沿用 Enter 提交、Esc 回滚、点击卡片外提交和单击复制/双击编辑消歧；短内容继续使用原行内编辑。

## 八、性能结论

投影只在值、尺寸、字体、样式或调色板变化时重新计算；没有轮询，也不会触发 Word/PDF 渲染。单次计算只处理当前控件的一段文本，因此不会引入此前担心的多轮 DOCX 校对开销。

复制提示仍使用一次短延迟区分“单击复制”和“双击编辑”；纯只读控件立即发送复制语义信号。

## 九、验证记录

已覆盖以下关键断言：

- Token 的大括号和内容命名空间不可编辑。
- 窄宽度仅改变 display projection。
- 复制内容始终等于 canonical value。
- 直接填写仍具有实时 `textChanged` 语义。
- Escape 恢复原值且不会残留编辑态。
- 路径和文件名保留扩展名。
- 图片、文件、时间、附件原有拖放、刷新、只读和行复用链路不变。
- Windows 实际字体引擎下完成字段页与图片页窄宽度截图核验。
