# 场景样式覆盖轻量预览投影执行记录

日期：2026-06-28

## 1. 本轮继续推进的问题

前两轮已经补齐了场景样式覆盖的两个关键点：

- `SectionStyleOverrideProjection`：让当前分区能显示“跟随模板 / 已覆盖 0 项 / 已覆盖 N 项”。
- `恢复模板`动作：让用户能直接撤销场景覆盖，重新跟随模板。

但用户仍然缺一个即时判断：当前有效样式到底大概长什么样。

如果场景页只有状态文字，用户仍需要跳到模板管理页或凭经验判断字体、字号、行距和对齐的效果。为了继续减少解释性文本，本轮补了一个轻量段落预览。

## 2. 设计边界

### 2.1 场景页不做完整模板纸张预览

模板管理页已经有完整的 `TemplateStylePreview`，负责展示页面比例、页边距、标题层级、正文、表格、页眉页脚等组合效果。

场景页如果再放一个完整纸张预览，会重新模糊职责边界：

- 模板页负责“文档整体长什么样”。
- 场景页负责“当前场景哪些分区覆盖模板”。

因此本轮只做轻量预览：当前编辑分区的一段样本文字，反映有效字体、字号、字形和对齐。

### 2.2 预览来源必须是有效样式

预览不应该直接读控件值，也不应该只读场景覆盖值。正确来源是：

```text
scene override -> template variant -> template body -> default
```

这样无论当前状态是跟随模板、已覆盖 0 项、已覆盖 N 项，预览都能展示真正会用于输出的有效样式。

## 3. 本轮实现

### 3.1 增强共享 `StylePreview`

文件：`src/shared/ui/style_preview.py`

`StylePreview.update_preview(...)` 保持原参数兼容，同时新增：

- `italic`
- `alignment`
- `sample_text`

这让小型样式预览可以表达更多段落状态，而不是只改字体、字号和粗体。

### 3.2 新增 `SectionStylePreviewProjection`

文件：`src/config/style_variant_semantics.py`

新增：

```python
SectionStylePreviewProjection
build_section_style_preview_projection(scene, template, variant_key)
```

投影内容包括：

- 当前分区 label
- 样本文案
- 来源状态：跟随模板 / 已覆盖 0 项 / 已覆盖 N 项
- 状态详情
- 字体、字号、粗体、斜体、对齐、行距类型和行距值

这让 UI 不直接猜“预览应该显示什么”，而是消费领域层给出的有效样式投影。

### 3.3 场景页接入轻量预览

文件：`src/ui/panels/scene_panel.py`

在“样式覆盖 > 编辑样式”里新增：

```text
StylePreview
```

它位于当前状态提示和 `ParagraphStyleEditor` 之间：

```text
编辑分区 + 恢复模板
状态提示
轻量样式预览
段落样式编辑器
```

预览 tooltip 显示状态来源：

```text
跟随模板：输出使用模板中的有效样式；开启覆盖后只影响当前场景。
已覆盖 0 项：已开启覆盖，但当前值与模板有效样式一致。
已覆盖 N 项：不同项：中文字体、字号、行距...
```

## 4. 对用户理解的改进

本轮后，“样式覆盖”形成更完整的交互链：

```text
状态摘要：参考文献 · 跟随模板 / 已覆盖 N 项
动作：恢复模板
预览：当前有效样式的一段样本文字
编辑器：具体修改字段
```

用户不必先理解字段名，也不必跳到模板页才能知道当前场景分区样式的大致效果。

这比继续增加说明文字更有效，因为界面直接显示结果。

## 6. 后续仍可继续推进

### 6.1 行距的视觉表达还很轻

当前 `StylePreview` 接收 `line_spacing`，但 QLabel 级预览并未真正渲染多行行距。后续若要更准确，可以把 `StylePreview` 升级为小型自绘段落预览，按行距和缩进绘制两行样本文字。

### 6.2 缩进和段距还未进入轻量预览

当前预览重点是字体、字号、字形和对齐。缩进、段前段后仍通过字段摘要和编辑器理解。后续可以把 `resolve_preview_indents_pt(...)` 接入轻量预览，使首行缩进和左右缩进也可视化。

### 6.3 模板页与场景页预览仍可共享更深投影

本轮是轻量首片。更完整的目标仍是：

```text
TemplateConfig + optional SceneSectionOverride
  -> ParagraphPreviewProjection
  -> TemplateStylePreview / Scene lightweight preview
```

这样模板页完整预览和场景页轻量预览可以共享更深的段落渲染投影。

## 7. 结论

本轮把场景样式覆盖从“状态可读、动作可执行”继续推进到“效果可见”。

现在用户在场景页里能看到：

- 当前分区是否跟随模板。
- 是否已覆盖以及覆盖了哪些项。
- 如何恢复模板。
- 当前有效样式的一段轻量预览。

这让场景样式覆盖更接近优秀设计需要的闭环：少解释，多状态，多动作，多反馈。
