# 试卷场景装配映射执行记录

日期：2026-07-01

## 1. 本轮结论

试卷场景不是普通“格式模板”的另一种说法，它需要额外记录“题目内容如何装进一张试卷”的长期规则。

本轮只做试卷场景的最小闭环，不扩展到题图、AI 出题、查重、资料包治理等更大的能力。

## 2. 新增配置边界

新增 `ExamPaperConfig`，挂在 `SceneWorkspace.exam_paper` 下。

它只保存场景长期策略：

- `blank_style_id`：空白试卷样式，例如默认试卷、紧凑试卷。
- `question_structure_mode`：题目装配方式，例如按 Markdown 标题识别、按题号识别。
- `answer_policy`：答案版本策略，例如学生卷 + 答案版、只生成学生卷。
- `runtime_fields`：工作台执行时要询问哪些字段，例如标题、科目、年级、考试时间、满分。

它不保存某一次考试的标题、科目、时间和满分。那些属于 Workbench 的本次任务输入。

## 3. 概览映射

试卷场景概览的四行现在都有稳定映射：

| 概览行 | 读取字段 | 入口 |
| --- | --- | --- |
| 空白试卷样式 | `scene.exam_paper.blank_style_id` | `scn_exam_paper` |
| 题目装配 | `scene.exam_paper.question_structure_mode` | `scn_exam_paper` |
| 答案处理 | `scene.exam_paper.answer_policy` + `delivery_presets` | `scn_exam_paper` |
| 本次信息 | `scene.exam_paper.runtime_fields` | `scn_exam_paper` |

其中“本次信息”只显示工作台会询问哪些字段，不在场景页填写本次值。

## 4. UI 落地

新增场景详情页 `试卷装配`，仅在试卷类场景显示。

该页提供：

- 空白试卷样式下拉框。
- 题目装配方式下拉框。
- 答案处理下拉框。
- 工作台填写字段勾选项。
- 当前装配结果实时摘要。
- 恢复默认动作。
- 去工作台填写动作，返回位置保持在试卷装配页。

普通场景不会显示这个入口，避免场景策略继续变得混杂。

### 4.1 交互补强

上一版只是把字段摆到页面上，仍然有两个问题：

- 顶部沿用了通用表单页的“主要控件 / 风险说明”，对试卷用户没有实际帮助。
- 工作台填写字段区域被布局撑高，看起来像不可交互的空白区域。

本轮已调整为：

- 隐藏通用说明卡，保留试卷专用说明。
- 字段勾选区限制为紧凑高度。
- 每次修改下拉框或字段勾选后，立即刷新“当前装配结果”。
- 支持一键恢复试卷默认配置。
- 支持从试卷装配页直接进入工作台填写本次信息。

## 5. 输出版本同步

当答案处理选择“只生成学生卷”时，会移除默认答案版输出。

当选择“学生卷 + 答案版”时，会确保存在答案版输出。

学生卷仍保留内容显隐规则：答案与解析不进入学生卷。

## 6. 参数归属

`exam_paper` 及四个子字段已登记到参数归属表：

- 归属层：场景。
- UI 入口：`ScenePanel exam paper`。
- 执行消费者：`workbench runner`。

这能防止后续把试卷装配规则误归到模板、资料包或输出通用配置里。
