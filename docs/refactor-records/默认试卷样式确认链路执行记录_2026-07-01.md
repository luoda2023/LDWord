# 默认试卷样式确认链路执行记录

日期：2026-07-01

## 本次落地内容

围绕 `试卷装配` 页补齐默认试卷样式确认链路：

- 默认试卷不再只是下拉框值，而是可显示状态、可预览、可生成样张的场景内卷面样式。
- 用户点击 `复制后修改` 会直接创建当前样式副本，并自动切换到副本。
- 副本保存在 `SceneWorkspace.exam_paper.custom_blank_styles`，属于场景配置，不进入通用模板库。
- 场景概览和左侧导航会读取同一套样式标签，能显示用户副本名。
- 样张生成输出真实 `.docx`，使用固定示例题，和正式工作台数据隔离。

## 用户确认路径

用户现在可以按这条链路确认默认试卷：

```text
试卷装配 -> 选择默认试卷 -> 打开母版 -> 生成样张 -> 去工作台填写本次考试信息
```

如果默认卷面不满意：

```text
试卷装配 -> 复制后修改 -> 自动切换到副本 -> 后续基于副本继续调整
```

这保证了内置默认试卷不会被破坏，同时普通用户第一次打开也能直接用。

## 母版卡片调整

追加调整：

- 删除 `试卷装配` 详情页里的 `工作台填写` 大块字段区、实时摘要和说明文字。
- 上方 `试卷装配` 卡片只保留长期装配规则：空白试卷样式、题目装配、答案处理。
- 下方新增 `试卷母版` 卡片，集中展示当前母版名称、内置/可修改状态、母版说明和动作按钮。
- `预览母版` 改为 `打开母版`，生成并打开真正的空白母版 Word。
- `生成样张` 保持为带示例题的校验文件，和空白母版分开。

调整后的用户理解：

```text
试卷装配：决定题稿怎么装配。
试卷母版：决定内置试卷外框长什么样。
工作台：每次填写标题、科目、时间、满分并生成正式试卷。
```

## 空白母版重定义

追加修正：

- `打开母版` 生成的 Word 不再使用 `【试卷标题】`、`【题目内容】` 等调试占位。
- 母版不再塞 1-4 道假题，只保留卷面骨架。
- 母版结构调整为：试卷标题、母版标识、考试信息栏、考生信息栏、注意事项、题目区起始位置、答题区和页脚。
- `生成样张` 继续负责带示例题、学生卷/答案版的真实效果校验。

新的分工：

```text

生成样张：看题目装入后的实际效果。
复制后修改：基于当前母版创建可修改副本。
```
