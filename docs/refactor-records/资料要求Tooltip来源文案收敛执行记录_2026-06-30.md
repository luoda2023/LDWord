# 资料要求 Tooltip 来源文案收敛执行记录

日期：2026-06-30

## 1. 本轮目标

上一轮已经把资料要求主控件文案改成：

```text
必填资料字段
必需图片/签章
```

但资料预览 tooltip 里仍会出现：

```text
profile override
```

这属于证据层文案，不在主控件上，但用户悬停查看时仍会遇到内部英文。当前目标不是隐藏真实字段 key，而是把“来源说明”改成人话。

## 2. 本轮实现

新增来源标签常量：

```text
SCENE_MATERIAL_REQUIREMENT_SOURCE_LABEL = "本场景补充要求"
```

并将资料字段和图片/签章预览中的 override 来源从：

```text
profile override
```

改为：

```text
本场景补充要求
```

## 3. 边界说明

本轮不隐藏 tooltip 里的真实 key：

```text
contract_no
legal_signature
seal
contract_parties_v1
signature_assets_v1
```

这些仍然用于：

- 诊断定位；
- 执行前问题排查；
- scene JSON 与资料规则核对；
- 高级用户确认字段来源。

本轮只把“来源是谁”改成人话：

| 层级 | 是否保留 raw key | 来源文案 |
| --- | --- | --- |
| 主界面 detail | 不保留 | 不显示来源 |
| tooltip | 保留 | 本场景补充要求 |
| 审计/执行报告 | 可保留 | 按执行层需要 |

## 4. 代码落点

| 文件 | 变化 |
| --- | --- |
| `src/ui/panels/scene_panel.py` | `_schema_field_preview(...)` 和 `_schema_role_preview(...)` 使用 `SCENE_MATERIAL_REQUIREMENT_SOURCE_LABEL` |
| `tests/test_scene_panel_architecture.py` | 守住 tooltip 显示“本场景补充要求”，不再显示 `profile override`；detail 继续不显示来源 |

## 6. 仍需继续

资料要求 block 现在已经把主控件、占位、预览概览、tooltip 来源都收敛到同一套语言。后续更适合推进两个方向：

### 6.1 明细格子降噪

有了“规则概览”后，“适用场景族”等证据型格子可以考虑折叠或弱化，减少用户第一屏的信息密度。

### 6.2 独立文件化

`_MaterialRequirementBlock` 已经有足够稳定的职责边界，可以考虑移出 `scene_panel.py`，让场景面板主文件变薄，也方便将来在执行前复核或资料面板复用。

## 7. 本轮结论

这轮把 tooltip 从“开发者知道什么意思”推进到“用户悬停也能理解”。主界面不再暴露内部来源词，证据层保留 raw key 但用中文说明来源，符合前面定下的分层原则。
