# 交付版本显示名目录下沉与输出入口归一执行记录

日期：2026-06-30

## 本轮结论

内容块 selector 已经下沉到配置层后，本轮继续把“交付版本显示名”也下沉为共享目录。现在场景族推荐、输出设置页、场景摘要、快速执行详情都可以使用同一套交付版本业务名。

这解决了上一轮记录中留下的问题：场景族推荐里的 `Student version`、`Answer key`、`Answer sheet` 等英文 label 不应继续进入主界面和新生成数据。现在应用考试/教学场景推荐后，生成的 `DeliveryPreset.label` 已是“学生版、答案版、答题卡”。

## 原问题

此前交付版本名称有三套来源：

- 场景族推荐 spec 写入 `DeliveryPreset.label`，其中不少仍是英文。
- 场景摘要内部有 `DELIVERY_PRESET_DISPLAY_LABELS`，能把部分 ID/英文翻译为中文。
- 输出设置页和快速执行详情下拉直接读 `preset.label`，因此仍可能显示 `Student version`、`Answer key`。

这导致同一个版本在不同入口看起来不一致：

- 摘要：学生版
- 输出设置：Student version
- 快速执行详情：Student version

用户会难以判断这些是不是同一个版本。

主要变更：

- 场景摘要改为从配置层导入交付版本显示名目录，不再独自持有一份字典。
- 场景族推荐 `_apply_delivery_spec()` 写入 `DeliveryPreset.label` 时先走 `delivery_preset_display_name()`。
- 输出设置页默认交付下拉改用共享显示名，并在 tooltip 中保留版本 ID 和原始标签。
- 输出设置页 `{preset_label}` 预览改用共享显示名，路径预览不再出现不必要的英文 label。
- 快速执行详情的内容块规则目标下拉也改用共享显示名。

## 边界调整

本轮明确了一个重要边界：标准推荐 label 和用户自定义 label 的处理不同。

- 标准推荐 label：应自动归一为中文业务名，例如 `Student version` -> “学生版”。
- 已知英文模板 label：显示时翻译为中文，例如 `Answer key` -> “答案版”。
- 用户自定义 label：优先保留，不按 ID 强行覆盖。例如用户把 `review` 改成 `Review package`，界面主值继续显示 `Review package`。

这个边界能避免两个坏结果：

1. 推荐配置继续污染主界面。
2. 用户手写名称被系统悄悄改掉。

## 链路复核

当前考试/教学场景推荐后：

```text
student_version -> 学生版
answer_key -> 答案版
answer_sheet -> 答题卡
```

输出设置页：

- “应用推荐” tooltip 点击前显示“学生版、教师版、答案版等 5 个”。
- 点击后默认交付下拉显示“学生版”“答案版”，不显示 `Student version`。
- 交付名称字段显示“学生版”。

快速执行详情：

- 内容块规则目标下拉显示“学生版（默认）”。
- tooltip 保留 `版本 ID：student_version` 和 `原始标签：Student version`，用于排查。

## 测试覆盖

新增/更新断言：

- 场景族应用推荐生成的 `student_version.label` 必须是“学生版”。
- `answer_sheet.label` 必须是“答题卡”。
- 输出设置页推荐 tooltip 不能出现 `Student version`。
- 输出设置页默认交付下拉必须显示“学生版”“答案版”。
- 快速执行详情的规则目标下拉必须显示“学生版（默认）”，tooltip 保留版本 ID 和原始标签。
- 自定义 label 仍然优先显示，例如 `Review package` 不会被 `review` ID 强行改回“审阅稿”。
