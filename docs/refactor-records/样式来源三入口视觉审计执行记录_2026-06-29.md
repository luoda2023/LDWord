## 4. 当前证据边界

本轮截图由 Qt offscreen 生成，能证明：

- 三个入口都真实渲染了同一个共享控件。
- `view_mode` 与按钮显隐符合预期。
- 行高、按钮列和动作边界可以被回归记录。
- 截图产物可以重复生成。

不能证明：

- 真实 Windows 字体下中文是否完全可读。
- 高 DPI、窗口阴影、系统字体渲染下是否仍然不拥挤。
- 用户实际桌面窗口里滚动位置和第一屏节奏是否已经足够优秀。

offscreen 截图中文仍可能显示为方块，因此文案正确性继续以源码、metrics 和测试断言为准。

## 6. 本轮发现的设计问题

视觉数据说明共享链路成立，但还没到优秀：

1. 场景概览在桌面宽度下已降到 50px，主要来自后续双按钮横排。

3. 模板页、场景页和 Workbench 在当前桌面审计中都为 50px，视觉节奏已更接近。
