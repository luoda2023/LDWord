# 模板正文排版场景覆盖控件移除执行记录

日期：2026-06-30

## 1. 结论

本轮按用户明确反馈执行：模板管理的“正文排版”页不再放置“场景覆盖”策略控件。

这次不是隐藏，而是从页面、投影、导航和测试守门中移除。原因很直接：

- “正文排版”是模板基线编辑页，用户在这里预期编辑模板默认样式。
- “场景覆盖”属于场景规划的分区样式配置，不应出现在模板正文排版主路径。
- 只读开关会制造误导：看起来能操作，实际不能操作。
- 截图中该区域还出现文字压缩和布局错位，说明视觉验收也不成立。

保留的正确边界是：

```text
模板正文排版：只编辑模板默认正文样式。
场景分区样式：决定哪些分区跟随模板、哪些分区独立调整。
Workbench：只读复核本次运行实际采用的模板和场景样式。
```

## 2. 删除内容

### 2.1 模板正文排版页

文件：`src/ui/panels/template_style_detail.py`

已删除：

- `StylePolicyControlDeck` 的导入。
- `StylePolicyToggleOption` 的导入。
- `STYLE_VARIANTS` 的导入。
- `scene_style_policy_key_from_field_id` 的导入。
- `_template_policy_deck` 创建。
- `rule_control=self._template_policy_deck` 接入。
- `scene_policy_requested` 信号。
- `_sync_template_policy_current_key()`。
- `_on_template_policy_selected()`。
- `focus_navigation_field(...)` 对 `scene.section_styles.*` 的模板页定位逻辑。

现在模板正文排版页的 `StyleManagementBlock(template_baseline_edit)` 只保留：

```text
source|scope|editor
```

不再有：

```text
source|scope|policy|editor
```

### 2.2 模板面板跳转

文件：`src/ui/panels/template_panel.py`

已删除：

- `_wire_parameter_detail_signals(...)` 中对 `scene_policy_requested` 的连接。
- `_on_template_scene_policy_requested(...)`。

原因：旧跳转入口只服务于被移除的只读“场景覆盖”控件。控件不存在后，模板正文页不再负责发起到场景分区样式页的跳转。

### 2.3 投影层

文件：`src/ui/panels/style_object_projection_builders.py`

已删除：

- `build_template_body_style_projection(...)` 中的 `policy=...`。
- `build_template_body_scene_policy_projection(...)`。
- `_template_scene_policy_toggle_tooltip(...)`。
- `__all__` 中的旧导出。

这样做是为了避免“界面删了，但投影仍暗示模板正文页有场景覆盖 policy”的半移除状态。

## 3. 测试守门

已把测试从“应该显示只读场景覆盖区”改为“正文排版页不得出现该控件”。

### 3.1 `tests/test_template_style_detail.py`

新增/更新守门：

- `style_management_content_plan == "source|scope|editor"`。
- `style_management_slot_plan == "source|scope|editor"`。
- `style_management_has_policy is False`。
- `style_management_has_policy_slot is False`。
- `style_management_policy_control_ready is False`。
- `StyleDetail` 不应拥有 `_template_policy_deck`。
- 即使当前 scene 有 `section_styles`，正文排版页也不显示 policy。
- `focus_navigation_field("scene.section_styles.references_body") is False`。
- 源码中不得出现：

```text
StylePolicyControlDeck(
_template_policy_deck
tpl_style_scene_policy
template_body_scene_policy
scene_style_policy_key_from_field_id
```

### 3.2 `tests/test_template_panel_architecture.py`

新增/更新守门：

- 当前场景存在分区覆盖时，模板正文排版仍只显示模板基线编辑。
- 详情页没有 `_template_policy_deck`。
- 不再测试从模板正文页点击 policy 行跳到场景页，因为该入口已经移除。

## 5. 后续边界

如果后续仍需要表达“哪些场景覆盖了模板正文样式”，不应放回正文排版页主区域。

可选位置：

- 场景规划的“分区样式”页。
- 场景概览的“核对依据”折叠区。
- 单独的模板引用/使用情况页。

不建议的位置：

- 模板正文排版主编辑区。
- 正文字段卡片下方。
- 只读开关列表形式的伪可操作区。
