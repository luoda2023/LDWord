# Alavette Form V1.0 快速开始

> 目标：用“通用版”处理一份 DOCX，在 10 分钟内得到一份新的可交付文档，并确认原稿没有被覆盖。

## 先准备好

- Windows 10 或 Windows 11。
- 已安装 Alavette Form，或已完整解压便携版发布目录。
- 一份可正常用 Word 打开的 `.docx` 文件。第一次练习建议使用发布包内的 `快速开始示例.docx`。
- 对输入文件和输出目录有读写权限。

> [!WARNING]
> 不要直接在 ZIP 压缩包内运行程序。请先完整解压；不要只复制 EXE，程序还需要同目录中的运行文件和默认配置。

## 1. 启动程序

从开始菜单启动 Alavette Form；便携版则双击发布目录中的 `Alavette-Form.exe`。首次打开时，Windows 可能需要几秒钟加载组件。

启动后应看到左侧导航和“工作台”页面。窗口顶部的工作模式应为“通用版”。

![工作台与通用版入口](screenshots/01-workbench-overview.png)

如果当前不是“通用版”，打开窗口顶部的工作模式选择器并切换到“通用版”。

## 2. 添加一份 DOCX

在左侧选择“工作台”，进入“文档执行”。把 DOCX 拖入文件区域，或选择“选择文件”。

选择成功后，界面会显示文件名和当前文档状态。

![已添加示例文档](screenshots/02-document-selected.png)

> [!TIP]
> 第一次使用先选单个 DOCX。批量文件和资料驱动生成适合在熟悉单文档流程后使用。

## 3. 确认方案和模板

在“处理方案与模板”中确认：

- 处理方案描述的是“要对文档做什么”；
- 模板描述的是“生成结果应当长什么样”。

第一次练习可以保留通用版默认值。若界面提示方案或模板不可用，请先恢复为内置默认项。

## 4. 选择输出位置

在“输出目录”中选择以下一种方式：

- 使用默认输出目录：适合快速练习；
- 自定义输出目录：适合正式交付或需要集中保存结果时。

建议选择一个容易找到、且不与原稿所在位置混淆的文件夹。

![输出设置与生成入口](screenshots/03-output-and-generate.png)

## 5. 查看预检结果

生成前，先查看界面中的预检或风险提示：

- “可执行”表示没有发现阻断项；
- “警告”表示可以继续，但生成后需要重点复核；
- “阻断”表示必须先修复问题，生成按钮可能不可用。

遇到缺少文件、模板、资料字段或输出权限时，按提示返回对应位置修复，再重新检查。

## 6. 生成文档

点击“生成文档”。如果出现风险确认，阅读影响范围后再决定是否继续。

执行过程中不要移动输入文件或关闭程序。完成后，结果区域会显示成功、部分成功或失败状态，并提供“打开文档”或“打开目录”等操作。

## 7. 验收结果

打开生成结果并完成四项检查：

1. 输出目录中出现了新的 `.docx`；
2. 原始文件仍然存在，名称和修改时间没有被生成操作覆盖；
3. 新文档可以正常用 Word 打开；
4. 标题、正文、分页、表格、图片和编号符合预期。

> [!IMPORTANT]
> “生成成功”表示程序已经完成处理，不代表业务内容、法规引用或专业结论一定正确。正式交付前仍需人工复核。

## 常见问题

| 现象 | 优先检查 | 处理方法 |
| --- | --- | --- |
| 双击后不能启动 | 是否完整解压、是否仍在 ZIP 内 | 重新完整解压后运行；保留 EXE 旁的所有目录 |
| 不能选择文件 | 文件类型、文件是否被占用 | 使用可正常打开的 DOCX；关闭可能锁定文件的程序后重试 |
| “生成文档”不可用 | 预检阻断、方案或模板缺失 | 查看阻断提示，补齐后重新预检 |
| 提示输出失败 | 输出目录权限、同名文件是否打开 | 换到可写目录；关闭已打开的同名结果 |
| 结果与预期不同 | 模式、方案、模板是否选错 | 回到工作台核对三项设置，再用副本重新生成 |
| 只完成了部分文件 | 查看执行结果中的失败项 | 修复失败项后只重试这些项目 |
