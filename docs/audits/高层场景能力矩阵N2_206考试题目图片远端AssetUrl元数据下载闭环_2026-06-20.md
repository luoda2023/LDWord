# 高层场景能力矩阵 N2.206 考试题目图片远端 AssetUrl 元数据下载闭环

## 1. 本轮定位

N2.206 继续执行 V43 的 P0 高级考试素材库路线，在 N2.205 的“`path` 是显式 URL 时可下载缓存”之后，补齐更接近素材库 handoff 的首片：

```text
当 question_figure 保留 asset_id/source 身份，
且 metadata 中已经携带真实下载 URL 时，
Workbench 执行前可解析该 URL、下载到本地缓存，并继续渲染 Word。
```

本轮仍不实现：

- 根据 `asset_id` 调用素材库 API 查 URL；
- 鉴权下载；
- 缓存刷新策略；
- 远端内容预览；
- 素材库版本、标签、批量治理。

## 2. 输入契约

本轮支持结构化元数据：

```json
{
  "role": "question_figure",
  "path": "",
  "metadata": {
    "question_index": "1",
    "asset_id": "remote-question-asset-1",
    "source": "lark_asset_library",
    "download_url": "https://example.com/question_1.png",
    "alt_text": "Downloaded asset URL figure"
  }
}
```

兼容别名：

```text
download_url / downloadUrl
remote_url / remoteUrl
asset_url / assetUrl
source_url / sourceUrl
original_url / originalUrl
url
```

CSV/XLSX 平铺导入新增列名后缀：

```text
questionFigure2DownloadUrl
questionFigure2RemoteUrl
questionFigure2AssetUrl
questionFigure2SourceUrl
questionFigure2OriginalUrl
questionFigure2Url
```

这些后缀统一进入 `metadata.download_url`。

## 3. 本轮实现

### 3.1 前台导入

`_ASSET_METADATA_IMPORT_SUFFIXES` 新增 URL 类后缀映射，使批量 CSV/XLSX 可导入：

- `asset_id`;
- `source`;
- `download_url`;
- `alt_text`;
- `question_index`。

导入后，AssetsPanel 仍显示远端题图行；因为下载发生在执行前，而不是导入时。

### 3.2 执行侧 URL 选择

`_material_context_with_remote_question_asset_cache()` 的下载 URL 选择顺序变为：

1. `AssetItem.path` 是 `http/https` URL；
2. 否则读取 `metadata.download_url` 及其别名。

下载成功后写入：

```json
{
  "cache_path": "<output_dir>/_remote_asset_cache/question_2_remote_<hash>.png",
  "download_url": "https://example.com/question_2_remote.png",
  "cache_status": "downloaded"
}
```

原始 `path` 可继续为空，`asset_id/source` 继续保留。

### 3.3 失败回链

如果 metadata 中有下载 URL 但下载失败，N2.204 的 `preflight_remote_question_figure_uncached` 仍会接管，`remote_asset_items` 会包含：

- `asset_id`;
- `source`;
- `download_url`;
- `question_index`。

这样用户能回到题图行修复 URL、替换本地图片，或等待后续鉴权/素材库 API 能力。

## 4. 闭环链路

```text
CSV/XLSX questionFigure2AssetId + questionFigure2DownloadUrl
-> asset_items.metadata.asset_id/source/download_url
-> Workbench run 前解析 metadata.download_url
-> 匿名下载到 _remote_asset_cache
-> metadata.cache_path / cache_status=downloaded
-> _asset_render_path 使用 cache_path
-> exam figure payload 保留 asset_id/source，path 使用本地缓存
-> Word 渲染图片
-> JSON/Markdown report 显示 assets=1/1
-> material manifest 保留 path="" + asset_id/source/download_url/cache_path
```

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote asset-url metadata download bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“只有 path URL 可下载”推进到“asset_id 旁带真实下载 URL 时也可自动缓存渲染”。N2.207 已继续追补 `asset_id/source` 通过本地解析清单获取下载 URL 的首片，N2.208 已继续追补受控 header 鉴权下载首片；它仍不是完整素材库 API，因为还不能向真实外部素材库登录、续期、签名、刷新缓存或预览远端内容。

## 6. 仍未闭合的边界

N2.208 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：

- 真实素材库 API：凭 `asset_id/source` 远程查询下载 URL，并在必要时完成登录、续期或签名 URL 生成；
- 权限失败细分：401/403/过期/无权限/签名失效的可读提示、重试和 UI 授权入口；
- 缓存刷新策略：过期判断、ETag、Last-Modified、强制刷新、失败重试；
- 远端内容预览：下载前预览、失败占位、类型/尺寸信息；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
