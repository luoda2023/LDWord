# 高层场景能力矩阵 N2.291 考试题目图片素材库远端写回权限失效重试治理闭环

## 1. 背景

N2.290 已经闭合远端写回冲突裁决三件套：应用远端、覆盖远端、字段合并。裁决能力具备以后，下一类高频断点是权限失效：用户已经有写回交接、幂等键和裁决记录，但远端素材库返回 401/403 时，前台不能只显示普通失败，而要告诉用户这是授权问题，并给出回到授权控件后重试的路径。

本轮只闭合“权限失效后的手动更新授权与重试首片”。它不实现 OAuth 登录、不自动续期 token、不续签 URL、不做组织/角色权限申请，也不把失败队列、后台重试或批量事务伪装为完成。

## 2. 已闭合能力

- 普通远端写回 HTTP POST 遇到 401/403 时，执行审计记录写入 `writeback_status=permission_required`。
- 权限失败记录同时写入 `permission_status=auth_failed`、`http_status`、`error` 和权限失效摘要。
- 远端当前快照 GET 遇到 401/403 时，写入 `writeback_status=remote_current_permission_required`。
- 覆盖远端裁决和字段合并裁决 POST 遇到 401/403 时，写入 `writeback_status=conflict_decision_permission_required` 与 `conflict_resolution_status=permission_required`。
- 远端写回表识别上述权限状态，并统一显示“权限失效”。
- “权限失效”行的动作区显示“更新授权”和“重试”。
- “更新授权”会把授权控件的 source 定位到当前题图库来源，并聚焦授权值输入框；header 为空或非法时自动回到 `Authorization`。
- “重试”会根据最近的权限失效记录分流：
  - 普通写回权限失效时重新执行 handoff 写回；
  - 远端当前快照权限失效时重新拉取 current snapshot；
  - 覆盖远端裁决权限失效时重新执行覆盖远端；
  - 字段合并裁决权限失效时读取已记录的 `field_merge_sources` 并重新执行字段合并。
- 重试继续复用同一条来源记录与 endpoint 的稳定幂等键，同时递增 `writeback_retry_attempt`。
- 权限失效与重试按钮继续使用共享按钮 variant 和表格动作容器，保持与模板管理控件样式一致。
- 新增测试锁定“先 401 权限失效、更新授权、再重试成功”的完整 UI/执行/审计链路。

## 4. 仍不宣称完成

- 素材库 OAuth/SSO 登录流程；
- token 自动续期、刷新 token 或静默重新登录；
- 签名 URL 自动续签；
- 组织、角色、题库权限申请或审批；
- 权限失败原因的细粒度业务分类，如禁用、越权、过期、租户切错；
- 失败队列、指数退避、后台重试；
- 批量事务、幂等窗口管理、重复提交防护中心；
- 远端回滚、跨资料包素材主数据版本系统。
