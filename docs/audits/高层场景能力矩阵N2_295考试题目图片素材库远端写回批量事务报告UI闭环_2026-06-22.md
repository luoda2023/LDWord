# 高层场景能力矩阵 N2.295 考试题目图片素材库远端写回批量事务报告 UI 闭环

## 1. 背景

N2.294 已经把批量执行里的 permission、conflict、failed、skipped 结果投影成前台失败队列，用户可以从失败项回到授权、重试、冲突处理或定位复核。但批量执行之后仍缺一份稳定的事务报告：哪些项成功、哪些项未解决、部分成功时哪些远端写回需要保留为回滚候选，都还只散落在执行摘要和单项历史里。

本轮闭合“批量事务报告 UI 首片”。它不执行远端回滚，也不做后台补偿任务；只把最近一次批量执行记录沉淀成可审计的报告记录，并在报告中标明补偿动作和回滚候选。

## 2. 已闭合能力

- 题图素材库区域新增 `question_figure_asset_library_remote_writeback_transaction_report_table`。
- 报告表按 `批次 / 结果 / 补偿 / 报告 / 处理` 展示最近一次批量执行。
- 报告表读取最近一次 `question_figure_library_remote_writeback_batch_execution`。
- 未生成报告时显示“生成报告”，已生成后显示“报告已生成”。
- 存在非成功项时显示“定位失败”，并回链到批量失败队列首项。
- 无非成功项时显示“定位批次”，并回链到批量事务表。
- “生成报告”追加 `question_figure_library_remote_writeback_batch_transaction_report` 历史记录。
- 报告记录保存 plan signature、execution changed_at、transaction status、attempted/success/failed/permission/conflict/skipped 计数。
- 报告记录保存 `transaction_report_items` JSON，每一项继承批量执行结果，并补充补偿动作。
- 完整成功项标记 `compensation_action=no_action`。
- 部分完成批次中的成功项标记 `compensation_action=rollback_candidate`，同时写入 `rollback_source`、`rollback_asset_id`、`rollback_alt_text`。
- 权限失败项标记 `refresh_auth_and_retry`。
- 远端冲突项标记 `resolve_conflict`。
- 普通失败项标记 `retry_writeback`。
- 跳过项标记 `manual_review`。
- 报告记录保存 `transaction_compensation_required_count`、`transaction_rollback_candidate_count`、`transaction_unresolved_count`。
- 新增测试锁定“一项成功、一项缺端点跳过 -> 生成事务报告 -> 成功项成为回滚候选 -> 跳过项进入人工复核 -> 报告动作变为定位失败”的链路。

## 3. 模型与成熟度变化

- `scene_product_readiness` 在 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback batch transaction report UI bridge` evidence。
- `pack:exam_education` 的 remaining gap 从 `advanced question asset library remote writeback batch rollback transaction report governance UI` 收窄为 `advanced question asset library remote writeback batch rollback execution governance UI`。
- `family:exam_teaching` 的 remaining gap 从 `advanced asset library remote writeback batch rollback transaction report governance UI` 收窄为 `advanced asset library remote writeback batch rollback execution governance UI`。
- `scene_product_maturity_upgrade_audit` 为新 gap 显式归入 `ui_control`、`runtime_execution`、`rule_governance`、`boundary_gate`，不再把该剩余 gap 计入 `report_artifact`。

## 4. 仍不宣称完成

- 远端批量回滚真实执行；
- 本地或远端补偿任务执行；
- 回滚前远端当前快照校验；
- 回滚幂等键和重复提交防护；
- 回滚失败队列和二次补偿队列；
- 事务 report drilldown 独立详情页；
- 事务 manifest 文件导出；
- 后台任务化、指数退避、并发控制、限流和调度取消；
- OAuth/SSO 登录、token 自动续期、签名 URL 自动续签；
- 组织、角色、题库权限申请或审批；
- 跨资料包素材主数据版本系统。
