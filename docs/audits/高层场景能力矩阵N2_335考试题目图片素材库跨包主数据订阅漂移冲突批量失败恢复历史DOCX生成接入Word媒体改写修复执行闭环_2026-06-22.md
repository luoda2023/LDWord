# 高层场景能力矩阵 N2.335 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复历史 DOCX 生成接入 Word 媒体改写修复执行闭环（2026-06-22）

## 1. 本轮定位

N2.334 已经把 durable worker 死信后的文件恢复中心推进到 Word XML/media 一致性扫描，但无 DOCX 时仍只能停在 `historical_word_docx_output_required`。本轮承接这个缺口，新增历史 DOCX 生成接入与 Word media rewrite repair execution 入口，让恢复批次能从“缺 DOCX 阻断”进入“生成/接入 DOCX、写入修复 manifest、复扫 XML/media、回写素材 metadata”的闭环。

本轮不声明任意旧 DOCX 的深层 XML 合并修复已经完成。当前承诺是：当前 `EntityArchive` 内的恢复批次可以从素材主数据生成一份历史 DOCX 接入件；若存在本地图片文件，会真实插入到 DOCX，并通过 `word/document.xml`、`word/_rels/document.xml.rels` 与 `word/media/*` 的一致性扫描；若只有远端 URL 或缺本地文件，会生成带审计说明的 text-only DOCX，并明确记录 `generated_without_local_images`，不伪装成本地图片已修复。

## 2. 新增能力

- 新增 `question_figure_asset_library_master_subscription_drift_batch_failure_recovery_historical_docx_repair_table`，位于文件恢复中心之后、远端写回之前。
- 新增 action：`question_figure_library_cross_package_master_subscription_drift_conflict_batch_failure_recovery_historical_docx_generation_intake_word_media_rewrite_repair_execution`。
- 新增 artifact 类型：`question_figure_master_subscription_drift_batch_failure_recovery_historical_docx_generation_intake_word_media_rewrite_repair_execution`。
- 新增 artifact 目录：`artifacts/subscription_drift_historical_docx_repairs`。
- 从 durable worker monitor / file recovery center 记录中提取 source + asset_id，回到当前归档素材项查找本地图片路径、cache path、preview path、thumbnail path、reference/download URL。
- 可用本地图片时生成带图片的 `.docx`，复制为 Word media repair 输出副本，并复用 N2.334 的 Word XML/media 扫描器验证关系一致性。
- 缺本地图片但有远端 URL 时生成 text-only DOCX，manifest 中保留 remote reference 和 missing 状态，避免把不可达远端图片伪装成已写入。
- metadata 回写历史 DOCX 修复状态、接入状态、媒体修复状态、生成 DOCX 数、修复 DOCX 数、本地图片数、缺本地图片数、manifest 路径、生成/修复 DOCX 路径、archive 信息和下一步。

## 3. UI 与控件一致性

历史 DOCX 修复表纳入 AssetsPanel 现有表格 QSS 选择器，继承素材库/模板管理同一套输入面、边框、字号、选中态、表头和按钮 variant。场景配置里的控件样式也应继续遵守这条约束：场景配置新增表格、选择器、开关、输入框时，应优先复用已有 `build_button_stylesheet`、`build_text_input_stylesheet`、selection control style 和模板表单布局，而不是为场景页单独创建一套视觉语言。

## 4. 状态边界

- `generation_required`：上游恢复中心无 DOCX，等待生成接入。
- `generated_from_current_archive_assets`：已从当前归档本地素材生成 DOCX，并插入至少一张本地图片。
- `generated_without_local_images`：已生成 DOCX，但只含审计文本，没有本地图片写入。
- `repair_docx_generated_and_verified`：修复副本已生成，Word XML/media 扫描一致且包含媒体文件。
- `repair_docx_generated_text_only`：修复副本已生成且 XML/media 一致，但没有媒体文件。
- `repair_execution_attention_required`：生成或复制后的 DOCX 仍存在 relationship/media 风险，需要下一层深修复。

## 5. 本轮仍未闭合

N2.335 后，剩余缺口不再是历史 DOCX 生成接入，而是更深的 Word XML relationship/media 深修复与回滚 connector：

- 对任意既有旧 DOCX 执行 `word/document.xml` 图片引用重写；
- 对 `word/_rels/document.xml.rels` 执行 relationship 新增、删除、改 target；
- 对 `word/media/*` 执行媒体补写、孤儿清理、替换审计；
- 将深修复与题图替换审计、回滚审计、二次补偿 connector 合流；
- 将同类能力推广到非题图素材族。
