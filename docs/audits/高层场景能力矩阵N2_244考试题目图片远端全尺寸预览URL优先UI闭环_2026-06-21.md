# 高层场景能力矩阵 N2.244 考试题目图片远端全尺寸预览 URL 优先 UI 闭环

日期：2026-06-21

## 本轮定位

N2.243 已经让 `thumbnail_url` / `preview_url` 能进入 `AssetsPanel` 下载前预览，但实现口径仍偏“缩略图”：当同一题图同时存在 `thumbnail_url` 和更适合审阅的 `preview_url` 时，前台不应继续优先拉缩略图。

本轮关闭的是远端预览优先级首片：`preview_url`、`fullPreviewUrl`、`fullImageUrl`、`originalPreviewUrl` 等全尺寸预览地址优先于 `thumbnail_url`，并以受控下载上限进入前台预览。它仍不是完整素材库预览服务。

## 已实现能力

- 新增远端全尺寸预览 URL 识别：
  - `preview_url` / `previewUrl`
  - `remote_preview_url` / `remotePreviewUrl`
  - `asset_preview_url` / `assetPreviewUrl`
  - `full_preview_url` / `fullPreviewUrl`
  - `full_size_preview_url` / `fullSizePreviewUrl`
  - `full_image_url` / `fullImageUrl`
  - `original_preview_url` / `originalPreviewUrl`
  - `original_image_url` / `originalImageUrl`
- CSV/XLSX 导入新增 `FullPreviewUrl`、`FullSizePreviewUrl`、`FullImageUrl`、`OriginalPreviewUrl`、`OriginalImageUrl`、`ImagePreviewUrl` 等列别名，统一写入 `preview_url`。
- 题图行同时存在 `thumbnail_url` 与 `preview_url` 时，表格名称、选中行预览和实际 HTTP 请求都优先使用全尺寸预览 URL。
- 远端全尺寸预览继续复用 N2.242 的 source-scoped Header 授权控件。
- 下载函数新增类型化上限：
  - 缩略图预览维持 2MB 上限；
  - 全尺寸预览使用 8MB 上限；
  - 两者仍只接受图片内容类型，并写入系统临时预览缓存。
- 前台状态文案区分“远端缩略图”和“远端原图预览”，避免把全尺寸预览伪装为缩略图。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote full-preview URL UI bridge` evidence。

## 未伪装完成的边界

本轮仍不承诺：

- 真实素材库 API 登录、续期、签名 URL 生成。
- 签名预览 URL 过期后的自动续期。
- 专门的大图查看器、缩放、平移、对比和下载操作。
- 后台预览队列、断点续传或并发下载调度。
- 内容级错图识别、复杂学科图质量判断或 AI 视觉判定。

后续边界应收窄为“真实素材库预览服务/签名预览 URL 续期、专门全尺寸查看器”，而不是继续把全尺寸 URL 优先级列为未完成。
