# 高层场景能力矩阵 N2.300 考试题目图片素材库远端写回批量二次补偿执行 Connector 闭环

## 1. 背景

N2.299 已经把审批后的二次补偿计划冻结为 execution plan，但仍只停留在“等待 connector”。这意味着系统知道要执行哪一版补偿计划，却还不能真正发起远端补偿请求，也不能把执行结果沉淀成审计记录。

本轮闭合“二次补偿执行 connector/UI 首段”。它执行已冻结、已审批的二次补偿执行计划，并追加独立执行审计；不实现执行失败队列、后台任务、manifest 或独立 drilldown。

## 2. 已闭合能力

- 二次补偿表在执行计划已冻结但未执行时显示“执行补偿”和“定位失败”。
- “执行补偿”读取 `second_compensation_execution_plan_items`，并补齐 endpoint、rollback metadata、source changed_at 等可执行字段。
- 二次补偿执行使用独立 connector 标识：`question_figure_library_remote_writeback_batch_second_compensation`。
- 二次补偿 payload 保存 report changed_at、rollback execution changed_at、plan changed_at、approval changed_at、execution plan changed_at、plan signature、metadata、compensation_from 和幂等键。
- 执行结果按 success、permission、conflict、failed、skipped 分类。
- 执行后追加 `question_figure_library_remote_writeback_batch_second_compensation_execution` 历史记录。
- 执行审计保存 report/rollback/plan/approval/execution-plan changed_at、connector、结果计数、状态汇总和 JSON 化结果项。
- 二次补偿成功项会纳入回滚 pending 判定，成功后回滚失败队列自动清空。
- 事务报告在原回滚 partial 但二次补偿清空待回滚项时显示“回滚补偿完成”。
- 二次补偿表在执行成功后显示“补偿执行完成 / 已执行”，保留定位入口。

## 3. 模型与成熟度变化

- `scene_product_readiness` 在 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback batch second compensation execution connector UI bridge` evidence。
- `pack:exam_education` 的 remaining gap 从 `advanced question asset library remote writeback batch second compensation execution connector governance UI` 收窄为 `advanced question asset library remote writeback batch second compensation execution failure queue governance UI`。
- `family:exam_teaching` 的 remaining gap 从 `advanced asset library remote writeback batch second compensation execution connector governance UI` 收窄为 `advanced asset library remote writeback batch second compensation execution failure queue governance UI`。
- `scene_product_maturity_upgrade_audit` 为 execution failure queue gap 显式归入 `ui_control`、`runtime_execution`、`rule_governance`、`boundary_gate`。

## 4. 仍不宣称完成

- 二次补偿执行失败队列；
- 二次补偿执行失败后的授权重试、冲突复核、失败重试；
- 回滚前远端当前快照校验；
- 回滚冲突字段级合并；
- 后台任务化、并发控制、限流、取消和指数退避；
- 回滚/补偿 manifest 文件导出和独立 drilldown；
- OAuth/SSO 登录、token 自动续期、签名 URL 自动续签；
- 组织、角色、题库权限申请或审批；
- 跨资料包素材主数据版本系统。
