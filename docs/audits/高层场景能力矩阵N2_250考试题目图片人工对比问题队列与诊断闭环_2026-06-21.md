# 高层场景能力矩阵 N2.250 考试题目图片人工对比问题队列与诊断闭环

## 1. 本轮定位

N2.249 已把用户在大图对比中人工确认的问题写回当前题图 `asset_items.metadata`。但如果该标注只停留在资料面板表格里，执行前问题队列、运行时诊断、批量报告和修复入口仍然断开。

N2.250 关闭的是“人工对比问题进入 Workbench 队列/诊断”的首片：不做自动错图识别，不做批量矩阵式图像差异报告，不做标注图层编辑，只把已由用户人工确认的对比问题变成可报告、可筛选、可点击回到题图行的结构化问题。

## 2. 已实现能力

- `material_asset_comparison_issue_items()` 从 `MaterialExecutionContext.asset_items` 读取 `comparison_issue_*` metadata。
- 运行前 Workbench issue queue 新增 `material_asset_comparison` 分类，显示为“题图对比”。
- 生成的 `WorkbenchIssueItem` 使用 `repair_target_type=question_figure_item`。
- 若当前资料上下文带 `profile_id` / `profile_name`，`workbench_issue_action_target()` 会路由为 `profile_question_figure_item`。
- QuickExecutionDetail 会把人工对比问题并入现有运行前问题队列，支持筛选、tooltip 和处理按钮。
- `WorkbenchProductionRunner` 的题图预检会把人工对比标注转成 `preflight_question_figure_manual_comparison_issue` material diagnostic。
- 批量运行会把该 diagnostic 透传到 `batch_issue_items[].comparison_issue_items`，并由 `batch_execution_issue_items()` 生成 Workbench 问题详情。
- 批量 JSON/Markdown 报告可看到人工对比问题，修复目标仍回到 `question_figure_item`。

## 3. 链路闭合

人工标注队列链路：

AssetsPanel 大图对比 -> 用户点击标记对比问题 -> `asset_items.metadata.comparison_issue_*` -> `MaterialExecutionContext.asset_items` -> Workbench 运行前 issue queue -> 点击处理 -> `question_figure_item` / `profile_question_figure_item` -> AssetsPanel 题图行。

运行时诊断链路：

`MaterialExecutionContext.asset_items` -> `_question_figure_file_diagnostics()` -> `preflight_question_figure_manual_comparison_issue` -> material manifest / batch report -> `batch_issue_items` -> Workbench issue queue。

## 4. 仍不宣称完成

- 自动内容级错图识别。
- 图像像素级差异检测。
- 批量矩阵式多图对比报告。
- 差异区域框选、标注图层、批注编辑。
- 将问题自动修复或一键替换为正确题图。
- 真实素材库预览服务、签名预览 URL 续期、登录续期、授权续期。

这些能力继续归入 `advanced question asset library UI` / `advanced asset library UI` 的后续产品化边界。
