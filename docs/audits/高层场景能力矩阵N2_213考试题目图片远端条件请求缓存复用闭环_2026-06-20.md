# 高层场景能力矩阵 N2.213 考试题目图片远端条件请求缓存复用闭环

## 1. 本轮定位

N2.213 继续执行 V43 的 P0 高级考试素材库路线，在 N2.212 “缓存过期自动刷新”之后，补齐深层缓存治理的条件请求首片：

```text
远端 question_figure 缓存过期并进入刷新链路时，如果 metadata 携带 ETag 或 Last-Modified，Workbench 会发送 If-None-Match / If-Modified-Since。远端返回 304 Not Modified 时，复用旧 cache_path，不重新下载，也不生成刷新失败诊断。
```

本轮不是完整缓存治理系统，仍不实现：
- 后台失败重试队列；
- 多 profile 共享缓存索引；
- 批量缓存失效和统一清理；
- 素材库版本锁定、人工审阅与复用治理；
- 下载前缩略图或内容级错图识别。

## 2. 输入契约

`question_figure.metadata` 可携带以下缓存校验字段：

```text
cache_etag / cacheEtag / etag / ETag / asset_etag / remote_etag
cache_last_modified / cacheLastModified / last_modified / lastModified / Last-Modified / asset_last_modified / remote_last_modified
```

示例：

```json
{
  "cache_path": "C:/cache/question_1.png",
  "download_url": "https://example.com/question_1.png",
  "cache_expires_at": "2000-01-01T00:00:00Z",
  "cache_etag": "\"exam-question-figure-v1\"",
  "cache_last_modified": "Wed, 01 Jan 2020 00:00:00 GMT"
}
```

进入刷新链路后，下载请求会自动带上：

```text
If-None-Match: "exam-question-figure-v1"
If-Modified-Since: Wed, 01 Jan 2020 00:00:00 GMT
```

## 3. 304 复用链路

```text
cache_path exists
-> cache_expires_at / TTL 触发刷新
-> metadata 提供 ETag 或 Last-Modified
-> 发送条件请求
-> 远端返回 304 Not Modified
-> 复用旧 cache_path
-> cache_refresh_status=not_modified
-> cache_revalidation_status=not_modified
-> download_status=not_modified
-> cache_status=reused
-> Word 使用旧缓存渲染
```

成功复用 metadata 示例：

```json
{
  "cache_path": "C:/cache/question_1.png",
  "download_url": "https://example.com/question_1.png",
  "cache_refresh_reason": "expired_at",
  "cache_refresh_status": "not_modified",
  "cache_revalidation_status": "not_modified",
  "cache_revalidation_http_status": "304",
  "cache_status": "reused",
  "download_status": "not_modified",
  "download_size_bytes": "763",
  "cache_etag": "\"exam-question-figure-v1\"",
  "cache_last_modified": "Wed, 01 Jan 2020 00:00:00 GMT"
}
```

## 4. 正常下载链路

如果远端返回 200，则继续沿 N2.210/N2.212 的刷新下载链路写入新 `_remote_asset_cache` 文件。响应头中的 `ETag` 与 `Last-Modified` 会写回：

```text
cache_etag
cache_last_modified
```

因此后续过期刷新可自然进入条件请求。

## 5. 失败边界

如果远端返回 304，但本地旧 `cache_path` 不存在或不是可复用文件，本轮不会伪造成功，而是返回下载失败 payload：

```text
download_failure_type = not_modified_without_cache
download_http_status = 304
```

当旧缓存存在时，304 不生成 `preflight_remote_question_figure_cache_refresh_failed`，因为这不是失败，而是远端确认本地缓存仍有效。

## 6. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote conditional revalidation bridge
```

覆盖对象：
- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“过期后总是尝试重新下载”，推进到“可用 HTTP 条件请求确认未修改并复用旧缓存”。

## 7. 仍未闭合的边界

N2.213 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：
- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 深层缓存治理：后台失败重试、共享缓存索引、批量失效、统一清理、缓存命中统计；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
