# 高层场景能力矩阵 N2.246 考试题目图片远端全尺寸预览缩放适应窗口 UI 闭环

## 1. 本轮定位

N2.245 已经让考试题图的远端全尺寸预览拥有独立“大图预览”窗口，但查看能力仍停在原始尺寸滚动查看。V43 剩余边界中仍保留“全尺寸缩放/对比增强”，说明查看器还缺少基础缩放控制。

N2.246 关闭的是“全尺寸缩放/适应窗口”首片：在不引入多图对比、标注、下载增强和真实素材库预览服务的前提下，让当前本地或远端预览缓存能够在查看器内放大、缩小、回到 100%，并按当前窗口适配显示。

## 2. 已实现能力

- `AssetsPanel` 大图预览弹窗新增 `asset_full_image_preview_toolbar`。
- 新增四个查看控制：
  - `asset_full_image_preview_zoom_out`：缩小到当前比例的 80%；
  - `asset_full_image_preview_zoom_in`：放大到当前比例的 125%；
  - `asset_full_image_preview_zoom_reset`：回到 100% 原始尺寸；
  - `asset_full_image_preview_fit`：按当前滚动区 viewport 适应窗口。
- 新增 `asset_full_image_preview_zoom_label`，实时显示当前缩放百分比。
- 查看器保存原始 `QPixmap`，缩放时从原始图重采样，避免连续缩放导致画质逐步退化。
- 远端全尺寸预览仍沿用 N2.244/N2.245 的 URL 优先、Header 授权、8MB 上限、图片内容类型校验和远端原始文件名展示。

## 3. 链路闭合

远端全尺寸预览链路更新为：

`fullPreviewUrl` / `preview_url` -> 授权下载远端原图到临时缓存 -> 小预览显示 -> 打开大图预览 -> 原始尺寸展示 -> 用户可缩小、放大、回到 100%、适应当前窗口 -> 缩放百分比同步显示。

审计链路：

`scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote full-preview zoom UI bridge` evidence，并由 `tests/test_scene_product_maturity_upgrade_audit.py` 锁定。

## 4. 仍不宣称完成

- 真实素材库预览服务、签名预览 URL 续期、登录续期、授权续期。
- 后台队列、断点续传、并发下载调度。
- 多图对比查看、差异标注、批注、下载增强。
- 内容级错图识别、复杂学科图质量判断、AI 质量边界。

这些能力继续归入 `advanced question asset library UI` / `advanced asset library UI` 的后续产品化边界。
