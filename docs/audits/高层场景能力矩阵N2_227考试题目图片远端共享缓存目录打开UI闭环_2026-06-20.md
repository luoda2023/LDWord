# 高层场景能力矩阵 N2.227 考试题目图片远端共享缓存目录打开 UI 闭环

## 1. 本轮定位

N2.227 继续承接 V43 的 P0 高级考试素材库路线。N2.225 已经能按目录浏览共享缓存摘要，N2.226 已经能下钻到 index 条目，但仍不能从前台直接打开对应的本地共享缓存目录。

本轮解决的断点是：

```text
共享缓存目录和 index 条目已经可见，
但用户要排查缓存文件时仍需要手工复制路径到文件管理器。
```

本轮只做“打开已存在的本地目录”。不做删除、不做清理、不做后台扫描、不做跨目录治理。

## 2. 新增前台动作

AssetsPanel 的 `question_figure_shared_cache_dirs_table` 从 4 列扩展为 5 列：

```text
共享缓存目录
题图
缓存状态
失效状态
处理
```

处理列新增“打开共享缓存目录”按钮：

- 目录存在时启用按钮；
- 目录不存在时禁用按钮；
- 调用现有 `_open_file_path()`，复用 `QDesktopServices.openUrl(QUrl.fromLocalFile(...))`；
- 打开成功后，图片材料状态行显示正在打开的共享缓存目录；
- 如果通过内部方法请求打开缺失目录，不调用系统打开，并提示“共享缓存目录不存在”。

## 3. 链路关系

```text
AssetItem.metadata.shared_cache_dir
-> question_figure_shared_cache_dirs_table
-> 处理列打开按钮
-> _open_question_figure_shared_cache_dir()
-> _open_file_path()
-> 系统文件管理器打开本地目录
```

这条链路与 N2.226 的 index 条目 drilldown 并列：一个负责看具体条目，一个负责打开本地目录继续人工排查。
