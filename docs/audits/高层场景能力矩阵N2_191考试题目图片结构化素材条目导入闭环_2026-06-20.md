# 高层场景能力矩阵 N2.191 考试题目图片结构化素材条目导入闭环

日期：2026-06-20

## 1. 目标

N2.190 已证明 Workbench 运行时可以消费多个 `question_figure`，并按 `question_index` / `question_id` 注入到具体题目。但当时这些多题图主要来自手写 `MaterialExecutionContext.asset_items`，前台资料档案和批量导入仍以 `asset_paths: role -> path` 为主，天然只能表达单角色单路径。

N2.191 闭合这一段：

```text
EntityProfile.asset_items
-> EntityArchive JSON
-> CSV/Excel repeated question figure columns
-> AssetsPanel material_context.asset_items
-> N2.190 per-question runtime mapping
```

它仍不是完整高级素材库 UI；它只让逐题题图的结构化资料源可归档、可导入、可进入运行时。

## 2. 落地内容

### 2.1 EntityProfile 结构化素材条目

`EntityProfile` 新增 `asset_items: list[dict[str, Any]]`。

它与既有字段分工如下：

| 字段 | 用途 |
| --- | --- |
| `asset_paths` | 普通单槽素材，例如 logo、seal、全局 question_figure |
| `asset_metadata` | 单槽角色级 metadata，例如全局题图 altText |
| `asset_items` | 可重复结构化素材条目，例如逐题题图、一角色多路径 |

`load_entity_archive()` / `save_entity_archive()` 会读写 `asset_items`，旧档案默认兼容。

### 2.2 AssetsPanel 汇总

`AssetsPanel.material_context()` 现在会把 profile 中的三类素材合并：

```text
scan_asset_collection(profile.assets_dir)
+ profile.asset_items
+ asset_items_from_role_paths(profile.asset_paths)
+ role-level asset_metadata
```

合并规则：

- `asset_items[].metadata` 比角色级 `asset_metadata` 更具体，优先级更高；
- 重复的 `(role, path, item_id)` 会去重；
- 现有单槽 UI 行为保持不变。

### 2.3 批量资料导入

JSON profile 可直接导入：

```json
{
  "asset_items": [
    {
      "item_id": "question_figure_1",
      "role": "question_figure",
      "path": "question_1.png",
      "metadata": {"question_index": "1", "alt_text": "第一题图"}
    }
  ]
}
```

CSV/Excel 可用重复列导入逐题题图：

```text
题目图片1,题目图片1说明,题目图片2,题目图片2说明
question_1.png,加法示意图,question_2.png,减法示意图
```

系统会生成两条 `AssetItem`，并自动补 `metadata.question_index=1/2`。

## 3. 成熟度影响

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset structured asset-items import bridge`；
- `family:exam_teaching` evidence 增加 `question asset structured asset-items import bridge`；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮闭合的是结构化资料源和批量导入，不是前台逐题素材编辑器、预览器或远端素材库。

N2.192 已继续补齐前台可见性摘要：导入多题图后，`question_figure` 槽位会显示已配置题图数量、图片说明覆盖率和前几项题号/文件名。后续高级素材库缺口因此不再包含“导入后前台完全看不见多题图”，而是逐题表格化编辑、缩略图预览/替换、缺项修复入口、远端 asset id/source、一题多图/图组排序、复杂学科图和素材/AI 质量边界。

## 4. 边界

仍不承诺：

- 前台逐题表格化编辑；
- 图片缩略图列表、预览、搜索；
- 缺项修复入口；
- 远端 asset id/source 解析；
- 一题多图/图组排序；
- 复杂学科图和素材/AI 质量判断。

这些继续属于 `advanced question asset library UI`、插件或 manual boundary。
