# 高层场景能力矩阵 N2.209 考试题目图片远端权限失败诊断闭环

## 1. 本轮定位

N2.209 继续执行 V43 的 P0 高级考试素材库路线，在 N2.208 “受控 header 鉴权下载”之后，补齐权限失败的首片可解释链路：

```text
当 question_figure 已拿到远端下载 URL，
但下载阶段返回 401/403/404 或其他可分类失败时，
Workbench 不再只报告“未缓存”，而是报告“下载失败 + HTTP 状态/失败类型”，
并继续回链到题图行修复。
```

本轮仍不实现完整授权体系：
- 不做登录、续期、签名 URL 生成；
- 不做 UI 授权弹窗或重新登录；
- 不自动重试或刷新 token；
- 不做缓存过期/刷新；
- 不做远端内容预览或内容级错图识别。

它的意义是把“远端题图为什么没落缓存”从模糊的未缓存状态，推进到用户可判断的下载失败状态：该修 URL、修权限、修素材库配置，还是替换本地图片。

## 2. 下载失败分类

`_download_remote_question_asset()` 从单纯返回 `None`，推进为返回：

```text
(cache_path, failure_payload)
```

失败 payload 的非敏感字段包括：

```json
{
  "download_status": "failed",
  "download_failure_type": "http_status",
  "download_http_status": "401",
  "download_failure_reason": "Remote asset download requires authentication or the token is invalid"
}
```

当前分类：

| failure_type | 场景 |
| --- | --- |
| `http_status` | 401/403/404 或其他 HTTP 错误 |
| `network_error` | URL 不可达、连接失败 |
| `unsupported_content_type` | 响应不是受支持图片 |
| `size_limit_exceeded` | 超过 25 MB 下载限制 |
| `empty_response` | 响应为空 |
| `unsupported_scheme` | 非 http/https |
| `download_error` | 其他下载异常 |

## 3. 诊断链路

下载失败后，运行时 cloned `AssetItem.metadata` 会保留非敏感失败状态：

```json
{
  "download_url": "https://example.com/question_5.png",
  "download_status": "failed",
  "download_failure_type": "http_status",
  "download_http_status": "401",
  "download_failure_reason": "Remote asset download requires authentication or the token is invalid"
}
```

`_remote_question_figure_uncached_diagnostic()` 会生成新的 change type：

```text
preflight_remote_question_figure_download_failed
```

并在 `remote_asset_items` 中透传：

```json
{
  "asset_id": "remote-question-asset-5",
  "source": "lark_asset_library",
  "download_url": "https://example.com/question_5.png",
  "download_status": "failed",
  "download_failure_type": "http_status",
  "download_http_status": "401",
  "download_failure_reason": "Remote asset download requires authentication or the token is invalid"
}
```

repair target 仍复用：

```text
repair_target_type = question_figure_item
```

因此用户仍会回到 AssetsPanel 的具体题图行，而不是落到泛化素材页。

## 4. Workbench Issue

批量或问题队列转换时，`batch_execution_issue_items()` 会把失败详情展示为：

```text
远端题图下载失败：题号 1 / remote-question-asset-5 / lark_asset_library / HTTP 401 / Remote asset download requires authentication or the token is invalid
```

如果没有失败分类，仍保持 N2.204 的旧文案：

```text
远端题图未缓存：题号 2 / remote-question-2 / lark_asset_library
```

这样“未解析/未缓存”和“已解析但下载失败”不再混在一起。

## 5. 闭环链路

```text
asset_id/source -> resolver 得到 download_url
-> 下载器请求远端
-> HTTP 401/403/404 等失败
-> metadata.download_status=failed + failure fields
-> preflight_remote_question_figure_download_failed
-> remote_asset_items 透传状态码/失败原因
-> JSON/Markdown report 记录 reason
-> Workbench issue detail 展示 HTTP 状态
-> repair target 回到 question_figure_item
```

## 6. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote permission failure diagnostics bridge
```

覆盖对象：
- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“可带鉴权下载”，推进到“鉴权失败也可解释、可报告、可回链”。N2.210 已继续追补显式缓存刷新首片；它仍不是完整授权或缓存治理产品，因为没有 UI 授权入口、自动续期、权限审计、素材库登录流程、自动过期判断或条件请求。

## 7. 仍未闭合的边界

N2.210 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：

- 真实素材库 API：凭 `asset_id/source` 远程查询下载 URL，并在必要时完成登录、续期或签名 URL 生成；
- UI 授权入口：401/403/过期/无权限/签名失效时的重新授权、token 刷新、权限申请或账号切换；
- 自动缓存治理：过期判断、ETag、Last-Modified、条件请求、失败重试、共享缓存索引；
- 远端内容预览：下载前预览、失败占位、类型/尺寸信息；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
