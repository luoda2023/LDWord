# 高层场景能力矩阵 N2.231 考试题目图片远端缓存清理预览闭环

## 1. 本轮定位

N2.231 承接 N2.230 的跨目录缓存索引清理。N2.230 已能显式清理多个缓存目录中的 stale index entry，并把结果写入 manifest/report；但后续要做前台确认 UI 或后台调度前，系统必须先能回答“如果现在清理，会影响哪些目录、候选数是多少”，并且这个预览不能改动真实索引或删除文件。

本轮解决的断点是：

```text
清理动作已有执行能力，
但缺少不会修改磁盘状态的预览证据，
前台确认 UI 和后台任务无法复用一份安全的清理候选报告。
```

本轮只做运行时 dry-run 首片：统计 stale index entry 与孤儿文件候选数，写入 manifest/report，不修改被扫描目录的 `index.json`，不删除任何缓存图片。

## 2. 新增配置语义

在开启清理的基础上增加：

```text
remote_asset_cache_cleanup=true
remote_asset_cache_cleanup_dry_run=true
```

支持别名：

```text
remote_asset_cache_cleanup_preview
remote_asset_cache_prune_dry_run
question_figure_cache_cleanup_dry_run
question_asset_cache_cleanup_dry_run
cache_cleanup_dry_run
cache_cleanup_preview
```

同时支持 camelCase 变体。

清理目录范围仍沿用 N2.230：

- 当前运行目录 `_remote_asset_cache`；
- 本次题图涉及的共享缓存目录；
- `remote_asset_cache_cleanup_dirs` 额外指定的目录。

## 3. Dry-run 行为

dry-run 只计算候选，不执行写回：

- stale index entry 会计入 `stale_index_entry_candidate_count`；
- 若开启 `remote_asset_cache_cleanup_orphans=true`，孤儿图片文件计入 `orphan_file_candidate_count`；
- `stale_index_entry_removed_count` 与 `orphan_file_removed_count` 保持为 0；
- 每个目录的 `dry_run=true`；
- 有候选清理项的目录状态为 `previewed`；
- 没有候选清理项的目录状态为 `scanned`；
- 被扫描目录原始 `index.json` 不变。

## 4. Manifest 与报告

`remote_asset_cache` 摘要新增或强化：

```text
cache_cleanup_dry_run
cache_cleanup_stale_index_entry_candidate_count
cache_cleanup_orphan_file_candidate_count
```

资料包报告 `## Remote Asset Cache` 的 `Cache cleanup` 行现在同时展示：

```text
status
dry_run
dirs
stale_index_entry_candidates
stale_index_entries_removed
orphan_file_candidates
orphan_files_removed
```

这样后续前台确认 UI 可以先显示候选数；用户确认后再走 N2.230 的真实清理路径。

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cache cleanup dry-run bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

本轮把高级考试素材库从“能清理”推进到“能先预览清理影响范围并留痕”。

## 6. 仍未闭合的边界

N2.231 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API 登录、续期、签名 URL 与 UI 授权入口；
- 跨 profile 的后台定时清理、前台确认 UI 和清理任务历史；
- 断点续传、后台队列、并发下载调度；
- 跨运行缓存命中率趋势面板；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图或 AI 质量判断；
- 素材库版本、历史审阅、版权真实性和批量审阅 UI。
