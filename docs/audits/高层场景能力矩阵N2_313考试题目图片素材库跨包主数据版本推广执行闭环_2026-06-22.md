# 高层场景能力矩阵 N2.313 考试题目图片素材库跨包主数据版本推广执行闭环

日期：2026-06-22

## 本轮定位

N2.312 已经让同一个远端题图素材在多个资料包/profile 中的版本漂移可见，并能记录跨包主数据版本治理计划。N2.313 继续关闭“推广执行”首片：只有在治理计划已记录后，前台才允许执行推广；执行时选择版本声明最完整、更新时间/版本号更靠后的 occurrence 作为本轮主版本，把版本、ETag、更新时间、题图说明和引用字段推广到其他受影响资料包。

这一轮仍不声明远端主数据 registry、素材库版本 API 双向同步、后台扫描或主数据审批锁已经完成。当前只承诺本地 archive 内的跨包主版本推广可执行、可审计、可退场。

## 已闭合内容

- 跨包主数据版本治理表在计划已记录后新增“执行推广”动作；
- 推广执行前要求已有 `question_figure_library_cross_package_master_version_governance_plan`，避免绕过治理计划直接写 metadata；
- 主版本选择采用保守的确定性策略：优先选择版本/ETag/更新时间/说明/引用声明更完整的 occurrence，其次按更新时间、自然版本号、ETag 和资料包/profile 标识排序；
- 推广字段包括 `asset_version`、`asset_etag`、`asset_updated_at`、`alt_text`、`download_url`、`asset_url`、`thumbnail_url`、`preview_url`、`cache_path`；
- 推广后会更新所有受影响 profile 的题图 `asset_items` metadata，同时保留各 profile 自身的 package id / package name；
- 新增 `question_figure_library_cross_package_master_version_promotion_execution` 审计记录，保存 master key、主版本来源、推广字段、变更条目、资料包列表和 profile 列表；
- 同一 master key 已推广后不会重复执行；
- 推广后如果版本漂移已消除，跨包主数据版本治理表自动退场；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library cross-package master version promotion execution UI evidence；
- 成熟度 gap 从 `advanced question asset library cross-package asset master data version promotion execution UI` 收敛为 `advanced question asset library cross-package asset master data remote registry sync UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data remote registry sync UI`。

## 边界说明

本轮不声明以下能力完成：

- 连接真实远端素材主数据 registry；
- 调用远端素材库版本 API 做双向同步；
- 远端主数据锁、审批、订阅、冲突广播和后台扫描；
- 在多个 archive 文件之间做持久化主数据中心；
- 对已生成 Word 输出进行追溯修复；
- 对非题图素材族的跨包主数据执行。

当前“跨包主数据版本推广执行”只承诺：在本地 archive 内，对已经形成治理计划的同一题图素材执行确定性主版本推广，并沉淀可审计执行记录。后续剩余缺口聚焦远端 registry/API 同步。
