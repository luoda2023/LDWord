# 高层场景能力矩阵 N2.229 考试题目图片远端缓存筛选批量治理闭环

## 1. 本轮定位

N2.229 承接 N2.224 的运行级批量缓存失效和 N2.228 的远端下载失败重试。此前 `remote_asset_cache_invalidate_all` 只能对本轮题图缓存做全量批量失效，适合彻底刷新，但不适合老师或运营只想治理某一类题图的场景。

本轮解决的断点是：

```text
批量缓存治理只有全量口径，
无法按题型、学科、来源等元数据缩小影响范围，
也无法在报告中说明哪些题图命中治理、哪些题图被跳过。
```

本轮只做运行级筛选批量治理首片：筛选命中的题图执行 batch invalidation，未命中的题图保持缓存命中/复用。不做跨目录统一清理，不做后台队列，不做素材库版本治理 UI。

## 2. 新增配置语义

全量入口保持兼容：

```text
remote_asset_cache_invalidate_all
question_figure_cache_invalidate_all
question_asset_cache_invalidate_all
cache_invalidate_all
invalidate_all_remote_asset_cache
purge_all_remote_asset_cache
clear_all_remote_asset_cache
```

在开启批量治理后，可额外通过 `MaterialExecutionContext.entity_data` 限定筛选条件：

```text
remote_asset_cache_invalidate_source
remote_asset_cache_invalidate_question_type
remote_asset_cache_invalidate_subject
remote_asset_cache_invalidate_question_index
```

同时支持 `question_figure_*`、`question_asset_*`、`cache_*` 和 camelCase/plural 变体。多个值可用逗号、分号或竖线分隔。

筛选条件采用 AND 语义：配置了多个维度时，题图必须全部命中才进入 batch invalidation。未配置任何筛选条件时，继续沿用 N2.224 的全量批量失效行为。

## 3. 匹配视角

运行时从题图 metadata 中读取以下别名：

| 筛选维度 | metadata 别名 |
| --- | --- |
| source | `source`、`asset_source`、`source_id`、`library`、`asset_library`、`provider` |
| question_type | `question_type`、`item_type`、`section_type`、`type` |
| subject | `subject`、`subject_name`、`discipline`、`course`、`course_name` |
| question_index | `question_index`、`question_id`、`question_no`、`number`、`no` |

`question_index` 额外复用题号解析逻辑，允许 `1`、`q1`、`question_1` 等形式互通。

## 4. 运行时证据

命中筛选并执行批量失效的题图写入：

```text
cache_invalidation_reason=batch_manual
cache_invalidation_scope=batch
cache_invalidation_filter_status=matched
cache_invalidation_filter_fields
cache_invalidation_filter_values
```

批量治理开启但未命中筛选条件的题图写入：

```text
cache_invalidation_filter_status=skipped
cache_invalidation_filter_fields
cache_invalidation_filter_values
```

未命中项不会删除缓存；若已有缓存文件存在，继续进入 `cache_status=reused` 与 `download_status=cache_hit`。

## 5. 索引与报告

远端缓存 `index.json` entry 新增：

```text
cache_invalidation_filter_status
cache_invalidation_filter_fields
cache_invalidation_filter_values
```

`remote_asset_cache` 摘要新增：

```text
cache_invalidation_filter_status_counts
```

资料包报告 `## Remote Asset Cache` 新增：

```text
Invalidation filter statuses
```

这样批量治理不再只说明“删了几个”，还能说明“哪些是筛选命中，哪些是筛选跳过”。

## 6. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote filtered batch cache invalidation bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

本轮把高级考试素材库从“只能运行级全量批量失效”推进到“可按题图元数据进行运行级筛选治理”。

## 7. 仍未闭合的边界

N2.229 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API 登录、续期、签名 URL 与 UI 授权入口；
- 跨运行、跨目录、跨 profile 的后台统一清理；
- 断点续传、后台队列、并发下载调度；
- 跨运行缓存命中率趋势面板；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图或 AI 质量判断；
- 素材库版本、历史审阅、版权真实性和批量审阅 UI。
