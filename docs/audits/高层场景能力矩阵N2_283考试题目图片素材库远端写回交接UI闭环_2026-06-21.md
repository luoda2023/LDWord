# 高层场景能力矩阵 N2.283 考试题目图片素材库远端写回交接 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.283 承接 N2.282 的题图素材库版本回滚 UI。上一轮已经能从本地版本历史安全恢复 `source / asset_id / alt_text`，但本地治理结果仍没有清晰的远端写回交接入口：用户无法看到哪些题图 metadata 已经在本地变更、是否适合交给远端素材库同步、是否已生成交接记录。

本轮只补“远端写回交接 UI”闭环：基于本地版本历史和当前题图 metadata 生成待交接清单，允许显式生成本地 `question_figure_library_remote_writeback_handoff` 审计记录。它不调用真实远端素材库 API，不宣称完成登录、续期、签名、权限续签或远端冲突合并。

## 2. 已闭合能力

- AssetsPanel 新增 `question_figure_asset_library_remote_writeback_table`。
- 写回交接表展示 `题目 / 库来源 / 素材ID / 字段 / 状态 / 处理`。
- 交接候选来自最新的本地 metadata update/rollback 记录。
- 只展示当前 metadata 具备远端库来源和素材 ID 的题图。
- 同一题图只展示最新一条需要交接的版本记录，避免旧版本重复干扰。
- 当前 metadata 与历史记录 after 值一致时，状态为 `待生成交接`。
- 已经为该历史记录生成过交接记录时，状态为 `已生成交接`。
- 当前 metadata 已发生后续变更时，状态进入 `需复核`，只允许定位，不允许直接交接。
- 点击“生成交接”会追加 `question_figure_library_remote_writeback_handoff` 审计记录。
- 交接记录保存题目标签、题号、素材条目 ID、字段清单、当前库来源、素材 ID、图片说明、来源历史记录时间和 `handoff_ready` 状态。
- 交接记录独立存放在 `asset_item_history`，不进入运行时 `AssetItem.metadata`。
- 生成交接后会刷新 archive、material context、题图明细表、素材库索引表、版本历史表、远端写回交接表和摘要状态。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback handoff UI bridge` evidence。
- 成熟度剩余 gap 从 `advanced question asset library remote writeback UI` 细化为 `advanced question asset library remote writeback execution connector`。

## 3. 链路视角

```text
metadata update or rollback record
  -> current question_figure metadata
  -> remote source + asset_id candidate filter
  -> compare current metadata with history after-values
  -> show pending / handed-off / review-needed state
  -> explicit handoff action
  -> append remote_writeback_handoff audit record
  -> refresh archive, material context, tables and status
```

这条链路补的是“远端写回前的本地交接视图”。N2.282 解决本地版本可恢复；N2.283 解决本地治理结果如何被识别为远端写回候选、如何避免版本错交、如何留下交接审计。

## 4. 场景矩阵影响

`exam_education` 与 `exam_teaching` 的高级题图素材库路线继续收窄：

- 按题索引可见性由 N2.277 闭合；
- 单题 metadata 编辑由 N2.278 闭合；
- 高频 metadata 治理问题清单由 N2.279 闭合；
- 批量治理计划 UI 由 N2.280 闭合；
- 本地版本历史 UI 由 N2.281 闭合；
- 本地版本回滚 UI 由 N2.282 闭合；
- 远端写回交接 UI 由 N2.283 闭合；
- 后续 remaining gap 明确转为 `advanced question asset library remote writeback execution connector`。

这意味着后续不能再把“没有远端写回清单、没有交接入口、没有交接审计记录、没有版本复核状态”重复计算为 L5 blocker。真正剩余的是素材库 connector/API 的真实执行、权限、续期、签名、远端冲突合并和失败重试。

## 5. 仍不宣称完成的边界

- 不做真实远端素材库写入。
- 不做素材库 API 登录、续期、签名 URL 或权限续签。
- 不做远端素材库版本冲突合并。
- 不做远端写回失败重试、幂等键、批量事务或回滚。
- 不做跨资料包素材主数据版本系统。
- 不做学校、学科、题型题库规则治理。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：本地题图素材 metadata 治理结果可以形成远端写回交接清单、显式生成交接审计、避免版本错交，并保持运行时 metadata 干净。
