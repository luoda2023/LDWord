# 高层场景能力矩阵 N2.318 考试题目图片素材库跨包主数据订阅漂移冲突分诊指派审批闭环
日期：2026-06-22

## 本轮定位

N2.317 已经让订阅变更 callback 发现的远端/本地 diff 进入可审计队列。N2.318 继续关闭下一段缺口：已入队的跨包主数据漂移不应停留在 `queued`，而要进入可见、可确认、可追踪的分诊、指派与审批状态。

这一轮仍不声明字段级裁决、接受远端、保留本地、字段合并、自动应用远端版本、批量执行或后台任务完成。当前只承诺：已登记队列的 drift/conflict 可以在前台被分诊到素材治理责任域，确认优先级和人工审批策略，并沉淀为后续 decision plan 可消费的审计记录。

## 已闭合内容

- 新增 `question_figure_asset_library_master_subscription_drift_triage_table`；
- 分诊表从 `question_figure_library_cross_package_master_subscription_drift_conflict_queue_governance` 审计记录反推，不依赖临时 UI 状态；
- 仅展示 `subscription_drift_queue_status=queued` 且尚未分诊审批的跨包主数据；
- 分诊表展示 master key、queue id、分派对象/优先级、审批策略、状态和处理动作；
- “分诊审批”写入 `question_figure_library_cross_package_master_subscription_drift_conflict_triage_assignment_approval` 审计记录；
- 分诊审批记录保留 queue id、queue changed_at、event id/type/changed_at、remote/local metadata、diff fields、Registry 与订阅锁信息；
- 题图 metadata 回写 triage status、assignee、priority、approval status、approval policy、approved_at、next step 和 queue id；
- 优先级按 diff fields 派生：`asset_version` 或 `reference` 变化优先进入高优先级；
- 分派默认进入素材治理团队，并按 source 保留责任域；
- 分诊审批仍不覆盖本地 `asset_version` 等主版本字段；
- 分诊审批后该候选行退场，避免重复审批；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library cross-package master subscription drift conflict triage assignment approval UI evidence；
- 成熟度 gap 从 `advanced question asset library cross-package asset master data subscription drift conflict triage assignment approval UI` 收敛为 `advanced question asset library cross-package asset master data subscription drift conflict decision plan UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data subscription drift conflict decision plan UI`。

## 边界说明

本轮不声明以下能力完成：

- 字段级裁决计划；
- 接受远端、保留本地、字段合并；
- 批量筛选、批量审批、批量应用；
- 队列 SLA、优先级人工调整、后台提醒、重放和跨 archive 持久化；
- 历史 Word 输出追溯修复；
- 非题图素材族的订阅漂移/冲突分诊审批。

当前剩余缺口应聚焦：审批通过后的 decision plan，也就是如何把“接受远端/保留本地/字段合并”等裁决选项结构化，而不是继续把 triage、assignment、approval 入口列为未打通。
