## 3. 版本语义

当前首片按 DeliveryPreset / ContentVisibilityRule 解释版本：

| 版本 | 行为 |
| --- | --- |
| `student_version` | 保留题干和选项，隐藏答案、解析、解法、知识点 |
| `teacher_version` | 保留题干、答案、解析和知识点 |
| `answer_key` | 隐藏题干和解析，只输出题号与答案 |
| `analysis_version` | 隐藏题干，保留答案和解析 |
| `answer_sheet` | 隐藏题干、答案和解析，输出固定行高答题区表格 |

这证明学生版、教师版、答案版和解析版来自同一份结构化源，而不是分别由 AI 或人工生成四份彼此可能漂移的文档。

## 5. 边界

本轮明确不承诺：

- 自动生成复杂几何图、电路图、化学结构图；
- 判断 AI 题目质量、答案正确性或学科难度；
- 复杂自定义答题卡版位设计器；
- 图片/素材替换 UI；
- 引入 `docxtpl` 或替换当前 pipeline。

答题卡固定行高首片已由 N2.185 归入 fixed-layout profile；复杂自定义版位仍属于后续 profile 深化，图片/素材替换归 AssetsPanel/结构化资产链路，复杂图形与 AI 内容质量继续由 plugin/manual gate 承载。
