# 高层场景能力矩阵 N2.259 考试题目图片对比修复候选单项回滚闭环

## 1. 本轮定位

N2.258 已经让单候选前台确认替换在成功后留下 `question_figure_repair_audit.json` 审计记录，能追溯 `original_path`、`applied_path`、候选队列、来源 issue 和确认状态。但这条记录仍只能“看”，不能用于撤回一次误替换。

N2.259 关闭的是“单项审计回滚首片”：给 `AssetsPanel` 增加显式确认的 `revert_question_figure_repair_audit_record(..., confirmed=True)`，只允许基于一条成功应用的审计记录，把当前题图从 `applied_path` 恢复到 `original_path`，并追加一条 rollback 审计记录。

## 2. 已实现能力

- `AssetsPanel.revert_question_figure_repair_audit_record()` 新增显式确认回滚入口。
- 回滚前置条件：
  - 必须 `confirmed=True`；
  - 审计记录 `action=frontstage_question_figure_repair_apply`；
  - 审计记录 `status=applied`；
  - `original_path` 必须存在于本地；
  - 当前题图行必须能通过 `repair_target_key`、`item_id`、`question_index` 或 `applied_path` 定位；
  - 如果记录提供 `applied_path`，当前题图路径必须仍等于该路径，避免旧审计误回滚新状态。
- 回滚成功后复用 `_replace_question_figure_item_path()`，同步 archive、material context、题图表和预览。
- 回滚成功后追加审计记录：
  - `action=frontstage_question_figure_repair_rollback`；
  - `status=rolled_back`；
  - `linked_apply_audit_id` 指向原应用审计；
  - 保留 queue/source issue/profile/题号/目标 key；
  - 记录 `rollback_from_path` 与 `rollback_to_path`；
  - 写回同一个 `question_figure_repair_audit.json`。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset comparison repair queue rollback bridge` evidence。

## 3. 链路闭合

当前链路推进为：

`question_figure_repair_audit.records[action=frontstage_question_figure_repair_apply]` -> `AssetsPanel.revert_question_figure_repair_audit_record(..., confirmed=True)` -> 校验当前题图仍处于 `applied_path` -> `_replace_question_figure_item_path(original_path)` -> archive/context/table/preview 同步 -> 追加 `frontstage_question_figure_repair_rollback` 审计。

这让 N2.258 的“替换后可追溯”进一步变成“单项误替换可按审计记录撤回”。

## 4. 明确不宣称完成

- 不做批量回滚；
- 不做事务回滚；
- 不做替换前文件快照复制；
- 不做候选冲突裁决；
- 不做批量确认执行；
- 不写回 Word 或远端素材库；
- 不处理原文件已删除、当前题图已被其他操作改写后的强制恢复；
- 不做内容级错图识别、视觉 diff 或 AI 判图。

当前能力只承诺：单条已应用审计记录，在原图仍存在且当前题图仍处于该应用状态时，可以经显式确认恢复到原路径，并追加回滚审计。批量/事务回滚仍是后续缺口。

## 5. 验收锚点

- `test_assets_panel_rolls_back_question_figure_repair_audit_record`

  - 断言 `question_figure_repair_audit.json` 追加第二条记录，并通过 `linked_apply_audit_id` 指向原应用审计。
