# 高层场景能力矩阵 N2.230 考试题目图片远端缓存跨目录清理闭环

## 1. 本轮定位

N2.230 承接 N2.229 的筛选批量缓存治理。此前远端题图缓存已经能下载、复用、刷新、失效、重试、索引、报告和按 metadata 筛选治理，但清理动作仍集中在当前题图或当前目录。共享缓存跨多次运行、多目录使用后，旧 `index.json` 可能残留指向已不存在缓存文件的 stale entry。

本轮解决的断点是：

```text
缓存治理能处理本次题图，
但无法显式把多个 run cache / shared cache 目录纳入同一次清理审计，
也无法把跨目录清理结果写进资料包报告。
```

本轮只做显式触发的跨目录缓存索引清理首片：清理缺失文件对应的 stale index entry，并可选清理 index 未引用的孤儿图片文件。不做常驻后台任务、不做跨 profile 全盘扫描、不做前台删除确认 UI。

## 2. 新增配置语义

在 `MaterialExecutionContext.entity_data` 中开启：

```text
remote_asset_cache_cleanup=true
```

支持别名：

```text
remote_asset_cache_cleanup_all
remote_asset_cache_prune
question_figure_cache_cleanup
question_asset_cache_cleanup
cache_cleanup
cleanup_remote_asset_cache
prune_remote_asset_cache
```

同时支持 camelCase 变体。

默认清理范围包括：

- 当前运行目录 `_remote_asset_cache`；
- 本次题图 metadata 指向的所有 `shared_cache_dir` / `remote_asset_cache_dir`。

可额外指定旧运行目录或其他缓存目录：

```text
remote_asset_cache_cleanup_dirs
```

支持 `question_figure_cache_cleanup_dirs`、`question_asset_cache_cleanup_dirs`、`cache_cleanup_dirs` 和 camelCase 变体。多个路径可用逗号、分号或竖线分隔，也可传 JSON list 字符串。

## 3. 清理边界

默认动作只清理 stale index entry：

- 读取每个目录下的 `index.json`；
- 检查 entry 的 `cache_path`；
- 若 `cache_path` 缺失、文件不存在或文件为空，则从 index 中移除该 entry；
- 保留仍可用的 entry；
- 更新 `entry_count` 和 `updated_at`。

可选开启孤儿文件清理：

```text
remote_asset_cache_cleanup_orphans=true
```

启用后，仅删除同一缓存目录中没有被该目录 `index.json` 引用、且后缀属于受支持图片类型的文件。没有 `index.json` 的目录不会被当作“全是孤儿文件”自动删除。

## 4. 运行时证据

清理汇总写入运行目录 `_remote_asset_cache/index.json` 顶层：

```text
cleanup.status
cleanup.dir_count
cleanup.stale_index_entry_removed_count
cleanup.orphan_file_removed_count
cleanup.orphan_file_skipped_count
cleanup.orphan_cleanup_enabled
cleanup.status_counts
cleanup.dirs[]
```

每个目录明细包含：

```text
cache_dir
index_path
status
entry_count_before
entry_count_after
stale_index_entry_removed_count
orphan_file_removed_count
orphan_file_skipped_count
orphan_cleanup_enabled
```

目录状态语义：

- `cleaned`：删除了 stale index entry 或孤儿文件；
- `scanned`：已扫描但无需清理；
- `missing`：目录不存在；
- `no_index`：目录存在但无 `index.json`；
- `write_failed`：尝试写回 index 失败。

## 5. Manifest 与报告

`remote_asset_cache` 摘要新增：

```text
cache_cleanup
cache_cleanup_status
cache_cleanup_dir_count
cache_cleanup_stale_index_entry_removed_count
cache_cleanup_orphan_file_removed_count
cache_cleanup_orphan_file_skipped_count
cache_cleanup_status_counts
```

资料包报告 `## Remote Asset Cache` 新增：

```text
Cache cleanup
Cleanup statuses
```

这样用户能在资料包中看到跨目录清理覆盖了几个目录、删了多少 stale index entry、是否触发孤儿文件清理。

## 6. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cross-directory cache cleanup bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

本轮把高级考试素材库从“仅能对当前题图或单目录做缓存治理”推进到“可显式跨多个缓存目录执行清理并写入审计报告”。

## 7. 仍未闭合的边界

N2.230 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API 登录、续期、签名 URL 与 UI 授权入口；
- 跨 profile 的后台定时清理、清理预览和前台确认 UI；
- 断点续传、后台队列、并发下载调度；
- 跨运行缓存命中率趋势面板；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图或 AI 质量判断；
- 素材库版本、历史审阅、版权真实性和批量审阅 UI。
