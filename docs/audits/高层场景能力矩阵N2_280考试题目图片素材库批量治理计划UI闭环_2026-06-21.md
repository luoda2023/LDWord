# 高层场景能力矩阵 N2.280 考试题目图片素材库批量治理计划 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.280 承接 N2.279 的题图素材库治理问题清单。上一轮已经能逐条发现缺图片说明、缺库来源、缺素材 ID、重复素材 ID 等高频问题，但用户仍缺少批量视角：同类问题有多少、影响哪些题、下一步应该按什么治理动作处理，都需要从明细表里人工汇总。

本轮只补“批量治理计划 UI”首片：把治理问题按类型聚合成计划表，显示数量、影响范围和建议下一步，并允许定位到该治理项的第一条问题。它不宣称自动批量修复、版本历史、远端写回或完整素材主数据治理。

## 2. 已闭合能力

- AssetsPanel 新增 `question_figure_asset_library_bulk_governance_table`。
- 批量计划表展示 `治理项 / 数量 / 范围 / 下一步 / 处理`。
- 治理问题会按类型聚合：缺图片说明、缺库来源、缺素材 ID、重复素材 ID。
- 每个治理项显示影响题目范围，超过 3 项时按摘要呈现。
- 每个治理项给出下一步建议，例如批量补说明、批量补库来源、批量补素材 ID、裁决重复引用。
- 选择计划行或点击“定位首项”会跳到对应治理问题明细。
- 治理问题明细继续定位到原题图行、按题素材库索引行和 metadata 编辑器。
- 修正 `asset_id` 或 `alt_text` 后，批量治理计划表会随 `asset_items` 刷新。
- 新表复用 AssetsPanel 既有表格、按钮和选择样式，继续保持场景配置控件与模板管理控件样式一致。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library bulk governance plan UI bridge` evidence。
- 成熟度剩余 gap 从 `advanced question asset library bulk version governance UI` 细化为 `advanced question asset library version governance UI`。

## 3. 链路视角

```text
CSV/XLSX/JSON question figure asset items
  -> EntityProfile.asset_items
  -> governance issue scan
  -> governance issue table
  -> bulk governance plan aggregation
  -> select governance plan row
  -> locate first issue row
  -> locate original question figure and asset library row
  -> metadata editor
  -> save canonical metadata
  -> refresh issue table and bulk plan table
```

这条链路补的是“批量治理计划可见”。N2.279 让单条治理问题可见；N2.280 让同类问题可以被聚合、计数、定位和形成下一步处理意图。

## 4. 场景矩阵影响

`exam_education` 与 `exam_teaching` 的高级题图素材库边界继续被拆细：

- 按题索引可见性由 N2.277 闭合；
- 单题 metadata 编辑由 N2.278 闭合；
- 高频 metadata 治理问题清单由 N2.279 闭合；
- 批量治理计划 UI 由 N2.280 闭合；
- 后续 remaining gap 明确转为 `advanced question asset library version governance UI`。

这意味着后续不能再把“没有批量治理入口”重复计算为 L5 blocker。真正剩余的是版本历史、变更审计、版本回滚、远端写回和跨资料包素材主数据治理。

## 5. 仍不宣称完成的边界

- 不做批量 metadata 自动修复。
- 不做素材 ID 合并、拆分、去重的完整裁决执行。
- 不做版本历史。
- 不做变更审计。
- 不做版本回滚。
- 不做远端素材库写回。
- 不做素材库 API 登录、续期或签名 URL 管理。
- 不做学校、学科、题型规则治理。
- 不做跨资料包素材主数据管理。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：高频治理问题可以按类型形成批量计划、显示数量和范围、定位首项，并被测试锁定。
