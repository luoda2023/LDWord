# 高层场景能力矩阵 N2.288 考试题目图片素材库远端写回放弃本地裁决执行闭环

日期：2026-06-21

## 1. 本轮定位

N2.288 承接 N2.287 的“远端写回冲突当前快照 UI”。上一轮已经能拉取远端当前 metadata 并形成远端/本地字段差异，但裁决仍没有真正执行。N2.288 先闭合风险最低、最可控的一类裁决：放弃本地待写回值，应用远端当前快照。

本轮不覆盖远端、不做字段合并、不发起二次远端写回。它只把已拉取的远端当前值应用回本地题图 metadata，并记录裁决执行审计。

## 2. 已闭合能力

- 远端快照成功后，远端写回表从“远端已取值”显示“应用远端”动作。
- “应用远端”只在存在 `remote_current_snapshot_ready` 快照时开放。
- 执行前校验当前 metadata 仍等于来源历史 after 值，避免对后续修改误应用旧快照。
- 执行后将本地题图 metadata 的 source、asset_id、alt_text 改为远端当前快照值。
- 执行时保留 writeback_url、current_url、question_index 等非冲突字段。
- 执行后追加 `question_figure_library_remote_writeback_conflict_decision` 审计记录。
- 裁决记录声明 `conflict_decision=abandon_local`。
- 裁决记录声明 `conflict_resolution_action=abandon_local_apply_remote_snapshot`。
- 裁决记录声明 `conflict_resolution_status=applied`。
- 裁决记录保存 source/asset_id/alt_text 的 before/after。
- 裁决记录保留来源变更时间、远端快照时间、冲突处理计划时间、冲突执行记录时间、writeback endpoint、current endpoint、幂等键和 retry attempt。
- 执行后远端写回表显示“已应用远端”，处理动作退回“定位”。
- 同一来源变更已执行裁决后不再重复追加裁决记录。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback abandon-local decision execution UI bridge` evidence。
- 成熟度 gap 从 `advanced question asset library remote writeback conflict decision execution UI` 收窄为 `advanced question asset library remote writeback overwrite merge decision execution UI`。

## 3. 链路视角

```text
remote_conflict execution
  -> conflict_resolution_planned audit
  -> remote_current_snapshot_ready audit
  -> table "远端已取值"
  -> frontstage "应用远端"
  -> local metadata source/asset_id/alt_text = remote snapshot
  -> conflict_decision audit
  -> table "已应用远端"
```

这条链路补的是“人工裁决中的放弃本地执行”。N2.287 负责事实快照；N2.288 负责将一种明确裁决落到本地状态和审计。

## 4. 场景矩阵影响

P0 高级考试素材库远端写回链路现在为：

- N2.283：本地 metadata 治理结果生成远端写回交接。
- N2.284：具备 endpoint 的单项 handoff 可执行 HTTP JSON POST。
- N2.285：写回请求具备幂等键、retry attempt 审计和远端冲突分类。
- N2.286：远端冲突可生成前台人工处理计划并进入审计。
- N2.287：人工处理计划可拉取远端当前值，并记录字段级差异快照。
- N2.288：可执行“放弃本地、应用远端当前值”的本地裁决。

剩余 gap 不再是泛化的“冲突裁决执行”，而是更明确的 `advanced question asset library remote writeback overwrite merge decision execution UI`。

## 5. 仍不宣称完成的边界

- 素材库登录态续期。

- 失败队列、指数退避和后台重试。

- 跨资料包素材主数据版本系统。
