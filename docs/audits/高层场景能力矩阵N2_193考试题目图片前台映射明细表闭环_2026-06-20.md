# 高层场景能力矩阵 N2.193 考试题目图片前台映射明细表闭环

日期：2026-06-20

## 1. 目标

N2.192 已让多条 `question_figure` 在 `AssetsPanel` 前台显示摘要，但用户仍只能看到：

```text
已配置 2 张题目图片 · 题图 2 张，图片说明 2/2 · 题1：question_1.png；题2：question_2.png
```

这对“是否识别到多题图”够用，但对高频核对动作还不够：用户导入 `题目图片1/2` 后，需要确认每一张图的目标题目、文件名、说明和文件状态。N2.193 闭合这一段可见性：

```text
CSV/Excel repeated question figure import
-> EntityProfile.asset_items
-> AssetsPanel current editor state
-> question_figure slot summary
-> question_figure frontstage detail table
```

它仍不是完整逐题素材编辑器；本轮只做明细可见和核对。

## 2. 落地内容

### 2.1 前台明细表

`AssetsPanel` 的图片材料卡新增 `question_figure_asset_items_table`。当当前 profile 中存在多条 `role=question_figure` 素材时，显示四列：

| 列 | 含义 |
| --- | --- |
| 题目 | 从 `metadata.question_index` / `question_id` / `question_no` / `number` 等字段推导 |
| 图片 | 本地文件名 |
| 说明 | `alt_text` / `alt` / `description` / `caption`，缺失时显示“缺说明” |
| 状态 | 本地文件存在时显示“可用”，否则显示“缺文件” |

单张普通 `question_figure` 仍保持原有单槽状态，不额外展开表格，避免扰动 logo、seal、signature 等单素材场景。

### 2.2 样式一致性

明细表复用生成预览表的表格 QSS：

- 同一输入背景；
- 同一边框、圆角、选中态；
- 同一表头样式；
- 同一行内 padding。

这满足 V41/V42 的控件一致性原则：场景侧不是单独发明一个新控件样式，而是在现有素材/模板管理语言内扩展。

### 2.3 成熟度证据

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset frontstage detail table`；
- `family:exam_teaching` evidence 增加 `question asset frontstage detail table`；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮只提供逐题映射明细核对，不提供逐题编辑、缩略图预览、拖拽替换、缺项修复入口、远端素材库或一题多图排序。

## 3. 与 V42 的关系

N2.193 是 V42 `QuestionAssetLibrary` 槽位的一片产品化证据。它验证了一个高频用户动作：

```text
我批量导入了多张题目图片，前台能不能明确告诉我每张图会进哪一道题？
```

现在答案是：可以核对，但还不能在同一个表格里完成编辑/替换/修复。

## 4. 仍保留的边界

仍不承诺：

- 前台逐题编辑；
- 单题缩略图预览和替换；
- 缺项修复入口；
- 远端 `asset_id` / `source` 解析；
- 一题多图或图组排序；
- 复杂学科图自动生成；
- AI 出题质量或素材质量判断。

这些继续属于 `advanced question asset library UI`、插件能力或 manual boundary。
