# 高层场景能力矩阵 N2.187 考试题目素材替换 UI 桥接闭环

日期：2026-06-20

## 1. 目标

N2.186 已经证明 `question.figure.path` 可以进入 Word 运行时和报告，但用户侧仍需要从资料包/素材面板选择题目图片，并让这份选择真正进入考试题源执行链。N2.187 闭合的是这条 UI -> material context -> exam runtime 的桥接首片。

本轮闭合链路：

```text
AssetsPanel question_figure slot
-> MaterialExecutionContext.asset_items
-> WorkbenchProductionRunner exam asset bridge
-> entity_data.exam_items figure.path
-> exam_delivery_runtime rendered Word image
-> report assets=<rendered>/<total>
```

## 2. 落地内容

### 2.1 AssetsPanel

考试场景使用 `exam_items_v1` MaterialSchema 时，AssetsPanel 会从 schema 的 `question_figure` asset role 自动生成图片槽位：

- 用户能在“选图片”区域选择题目图片；
- `material_context.asset_items` 会带出 `role=question_figure`；
- `to_resolve_kwargs().images` 仍保留普通占位图路径，便于模板占位符场景复用；
- 该槽位不是必填，因此不会阻断普通结构化题源执行。

### 2.2 Workbench 执行桥

`src/ui/panels/workbench/execution_runtime.py` 新增 exam 专用窄桥：

- 仅当当前场景引用 `exam_items_v1` 时生效；
- 读取 `MaterialExecutionContext.asset_items` 中的 `question_figure`；
- 在 `resolve_config()` 前，把该本地图片路径注入到 `entity_data.exam_items` 的第一个缺图题目；
- 不覆盖已有 `question.figure`；
- 普通表单、合同、资质、产品素材等场景不受影响。

### 2.3 报告证据

桥接后的运行时仍走 N2.186 的统一报告字段：

- `question_asset_count`；
- `rendered_question_asset_count`；
- `missing_question_asset_count`；
- Markdown `assets=<rendered>/<total>`。

## 3. 成熟度影响

`scene_product_readiness` 已同步：

- `pack:exam_education` evidence 增加 `question asset replacement UI bridge`；
- `family:exam_teaching` evidence 增加 `question asset replacement UI bridge`；
- total gaps 仍为 49；
- exam 的 remaining gap 从粗粒度“question asset replacement UI”收窄为 `advanced question asset library UI` / `advanced asset library UI`。

当前裁决：题目素材替换已经具备首片 UI 桥接，不再是“前台选图和运行时断链”。仍不升 Green/L5，因为素材库/远端 asset id、逐题多图映射、altText/可访问性、复杂学科图生成和素材质量判断还没有完整产品化。

## 4. 边界

仍不承诺：

- 多题多图的精细映射 UI；
- 远端素材库或 asset id 解析服务；
- Word 图片 altText 写入；
- 几何图、电路图、化学结构式生成；
- 自动判断图片是否对应题意。

这些应作为高级素材库、专业插件或人工确认边界继续推进。
