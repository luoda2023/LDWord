# 高层场景能力矩阵 N2.338 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复非题图素材族跨归档恢复执行回滚 Connector 闭环

## 1. 本轮定位

N2.337 已把非题图素材族跨归档恢复治理做成可见、可审计入口：能按 `role/source/asset_id` 聚合 Logo、签章、签名、资质、二维码、封面等素材族，并生成治理 manifest。本轮 N2.338 承接它的下一缺口，把治理事实推进为第一段执行/回滚连接器：对缺失本地文件且存在可用候选的素材项执行真实复制，写入 execution manifest 和 rollback plan，并回写 profile metadata。

本轮不伪装完成历史 Word 输出改写。非题图素材族可能落在正文、页眉、页脚、封面、附件或输出版本差异中，后续仍需要专门的 Word XML relationship/media rewrite verification 链路来处理历史 DOCX 内部引用。

## 2. 新增能力

- 新增执行记录 action：`asset_library_cross_package_master_subscription_drift_conflict_batch_failure_recovery_non_question_asset_family_cross_archive_recovery_execution_rollback_connector`。
- 从治理记录的 `governance_rows` 派生执行项，不重新扫描一套事实源。
- 对 `recovery_route=copy_from_recovery_candidate` 且目标 path 缺失的项执行 `shutil.copy2(candidate, target)`。
- 对已存在目标文件的项不覆盖，记录 `verified_target_already_available`。
- 对无目标 path、无候选文件、人工补源项写入 blocked/attention 状态。
- 新增 execution JSON/Markdown manifest，记录 copied/blocked 计数、target、candidate、rollback action 和 execution status。
- 回写素材 metadata：execution status、execution id、copied count、blocked count、rollback plan status、manifest paths 和 next step。
- UI 行动作从 `Record` 切换为 `Execute + Manifest`，执行后切换为 `Manifest`，状态列显示 `executed` 或 `attention`。

## 3. 回滚边界

本轮 rollback connector 是文件级首片：

- 对本轮复制出的目标文件记录 `rollback_action=remove_copied_file`；
- 对执行前已存在的目标文件记录 `none_target_preexisting`，不作为本轮回滚对象；
- 不覆盖已有本地文件；
- 不删除候选文件；
- 不改写历史 DOCX；
- 不做二次补偿和远端写回。

这保证执行动作可审计、可回滚，但不会把更复杂的 Word XML 引用改写混入当前切片。

## 4. Word XML 视角

本轮复制文件只让 profile 素材 path 从缺失变为可用。它还没有证明历史 DOCX 已经引用新文件。下一缺口必须覆盖：

- `word/document.xml` 中正文图片引用；
- `word/header*.xml` 与 `word/footer*.xml` 中 Logo、水印、签章等引用；
- 对应 `.rels` 文件的 relationship target 新增/修改；
- `word/media/*` 媒体补写、孤儿清理、重复媒体处理；
- 学生版/教师版/正式版/内部版等多输出版本的素材一致性扫描；
- 执行前 DOCX 副本、执行后 DOCX 副本、rollback source 和 post-scan verification。

因此 readiness/maturity 的剩余缺口推进为：

- pack：`advanced question asset library cross-package asset master data subscription drift conflict batch failure recovery non-question asset family historical Word XML relationship media rewrite verification UI`
- family：`advanced asset library cross-package asset master data subscription drift conflict batch failure recovery non-question asset family historical Word XML relationship media rewrite verification UI`
