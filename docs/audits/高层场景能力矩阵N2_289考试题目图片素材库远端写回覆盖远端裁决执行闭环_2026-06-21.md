# 高层场景能力矩阵 N2.289 考试题目图片素材库远端写回覆盖远端裁决执行闭环

## 1. 背景

N2.288 已把远端冲突快照推进到“放弃本地，应用远端当前值”的本地裁决执行。但同一冲突处理计划仍缺少另一条高频路径：用户确认保留本地修改，并把本地待写回值二次覆盖写回远端。

本轮只闭合“覆盖远端”裁决，不把字段级合并、权限续期、批量事务或远端回滚伪装为完成。

## 2. 已闭合能力

- 远端快照成功后，远端写回表不再只有“应用远端”，而是在同一动作区提供“应用远端”和“覆盖远端”两个裁决按钮。
- “覆盖失败”和“覆盖仍冲突”状态仍保留同一双动作区，允许继续覆盖重试或改走应用远端。
- 动作按钮继续使用 `apply_button_variant` 与 `build_button_stylesheet`，避免场景配置页形成一套独立样式。
- 新增 `_execute_question_figure_library_remote_writeback_overwrite_remote_decision_row`，执行前校验：
  - 已确认用户动作；
  - 来源历史记录仍存在；
  - 远端写回交接记录存在；
  - 远端当前快照为 `remote_current_snapshot_ready`；
  - 当前题图 metadata 仍等于来源历史 after 值；
  - 写回 endpoint 存在；
  - 尚无成功执行的终局裁决。
- 新增覆盖远端专用 POST payload：
  - `connector=question_figure_library_remote_writeback_conflict_decision`；
  - `conflict_decision=overwrite_remote`；
  - `metadata` 写入本地待写回的 source、asset_id、alt_text；
  - `remote_current` 写入远端快照值；
  - 保留来源变更时间、快照时间、冲突处理计划时间、冲突执行时间、幂等键与重试次数。
- 覆盖远端请求使用独立 `Idempotency-Key`，前缀为 `qfig-overwrite-`，避免与第一次普通写回幂等键混淆。
- 新增覆盖裁决重试计数，按来源历史、endpoint、`overwrite_remote` 决策维度累计。
- 覆盖成功后追加 `question_figure_library_remote_writeback_conflict_decision` 审计记录：
  - `writeback_status=conflict_decision_applied`；
  - `conflict_resolution_status=applied`；
  - `conflict_resolution_action=overwrite_remote_writeback`；
  - `conflict_decision=overwrite_remote`；
  - `conflict_decision_applied_scope=remote_metadata`。
- 覆盖成功不修改本地题图 metadata，因为本地值就是本次要保留并写回远端的事实源。
- 覆盖成功后表格状态显示“已覆盖远端”，动作退回“定位”。
- 覆盖再次遇到 HTTP 409/412 时记录 `conflict_decision_remote_conflict`，状态显示“覆盖仍冲突”。
- 覆盖请求失败时记录 `conflict_decision_failed`，状态显示“覆盖失败”。
- 成功裁决后，重复执行覆盖或应用远端都会被拦截为“远端冲突裁决已执行”。

## 3. 模型与成熟度变化

- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback overwrite decision execution UI bridge` evidence。
- `pack:exam_education` 的 remaining gap 从 `advanced question asset library remote writeback overwrite merge decision execution UI` 收窄为 `advanced question asset library remote writeback field merge decision execution UI`。
- `family:exam_teaching` 的 remaining gap 从 `advanced asset library remote writeback overwrite merge decision execution UI` 收窄为 `advanced asset library remote writeback field merge decision execution UI`。
- `scene_product_maturity_upgrade_audit` 的显式 gap-domain mapping 已同步新 gap 名，仍归属 `ui_control`、`runtime_execution`、`rule_governance`、`boundary_gate`。
