# 高层场景能力矩阵 N2.281 考试题目图片素材库版本历史 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.281 承接 N2.280 的题图素材库批量治理计划 UI。上一轮已经让高频 metadata 问题可以聚合成治理计划，但版本治理仍缺少事实基础：用户修正 `source / asset_id / alt_text` 后，无法在资料包中看到本地变更历史。

本轮只补“版本历史 UI”首片：当用户通过按题素材库 metadata 编辑器修改题图 metadata 时，记录一条本地 `asset_item_history` 审计记录，并在素材库区域展示版本历史表。它不宣称完成版本回滚、远端素材库写回或完整主数据版本系统。

## 2. 已闭合能力

- `EntityProfile` 新增 `asset_item_history` 字段，用于保存素材条目治理/版本审计。
- `load_entity_archive` / `save_entity_archive` 会读写 `asset_item_history`。
- `AssetsPanel.current_archive()`、`set_archive()`、profile 复制与导入返回路径会保留历史记录。
- AssetsPanel 新增 `question_figure_asset_library_version_history_table`。
- 历史表展示 `时间 / 题目 / 字段 / 变更 / 处理`。
- 通过 metadata 编辑器保存 `source / asset_id / alt_text` 的真实变更时，会追加一条 `question_figure_library_metadata_update` 记录。
- 无实际变化的保存不会制造历史噪声。
- 历史记录保存变更前后值、字段清单、题目标签、题号、素材条目 ID 和变更摘要。
- 历史表行选择或点击“定位”会回到对应题图素材行和 metadata 编辑器。
- 历史记录独立存放在 `asset_item_history`，不会写入 `AssetItem.metadata`，因此不污染 Word 渲染、运行时报告或素材 metadata 消费链路。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library version history UI bridge` evidence。
- 成熟度剩余 gap 从 `advanced question asset library version governance UI` 细化为 `advanced question asset library version rollback UI`。

## 3. 链路视角

```text
select per-question asset library row
  -> metadata editor
  -> save source / asset_id / alt_text
  -> compare canonical before/after metadata
  -> append EntityProfile.asset_item_history record
  -> persist current archive profile
  -> refresh version history table
  -> select history row
  -> locate original question figure row and metadata editor
```

这条链路补的是“版本历史可见和可追溯”。N2.280 有治理计划，但没有变更审计；N2.281 让本地 metadata 修正具备历史记录和前台定位入口。

## 4. 场景矩阵影响

`exam_education` 与 `exam_teaching` 的高级题图素材库边界继续被拆细：

- 按题索引可见性由 N2.277 闭合；
- 单题 metadata 编辑由 N2.278 闭合；
- 高频 metadata 治理问题清单由 N2.279 闭合；
- 批量治理计划 UI 由 N2.280 闭合；
- 本地版本历史 UI 由 N2.281 闭合；
- 后续 remaining gap 明确转为 `advanced question asset library version rollback UI`。

这意味着后续不能再把“没有版本历史/变更审计可见入口”重复计算为 L5 blocker。真正剩余的是从历史记录执行回滚、冲突校验、回滚审计和远端素材库写回。

## 5. 仍不宣称完成的边界

- 不做版本回滚执行。
- 不做回滚前冲突校验。
- 不做回滚审计链。
- 不做远端素材库写回。
- 不做素材库 API 登录、续期或签名 URL 管理。
- 不做跨资料包素材主数据版本系统。
- 不做批量 metadata 自动修复。
- 不做素材 ID 合并、拆分、去重的完整裁决执行。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：本地题图素材 metadata 变更可以被记录、持久化、展示、定位，并保持运行时 metadata 干净。
