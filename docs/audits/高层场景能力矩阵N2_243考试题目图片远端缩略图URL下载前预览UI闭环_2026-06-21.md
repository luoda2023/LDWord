# 高层场景能力矩阵 N2.243 考试题目图片远端缩略图 URL 下载前预览 UI 闭环

日期：2026-06-21

## 本轮定位

N2.235 已经把“远端缩略图/下载前预览”的第一片收窄为受控本地 `thumbnail_path` 前台预览。N2.242 又补齐了 `AssetsPanel` 远端素材 Header 授权入口，让前台可以把受控 Header 写入执行层已有的 `question_asset_download_auth` 字段。

本轮继续收窄这个边界：当题图素材元数据里存在 `thumbnail_url` 或 `preview_url` 时，`AssetsPanel` 可以在用户选中题图行后下载远端缩略图并预览。它是“下载前预览 UI 首片”，不是完整真实素材库服务。

## 已实现能力

- CSV/XLSX 导入识别 `ThumbnailUrl`、`ThumbnailRemoteUrl`、`RemoteThumbnailUrl`、`ThumbUrl`、`PreviewUrl`、`RemotePreviewUrl`、`AssetPreviewUrl` 等列，并规范写入 `thumbnail_url` 或 `preview_url`。
- 题图素材表在缺少本地文件但存在远端缩略图 URL 时显示素材名和“远端预览”状态。
- 题图详情名称优先使用本地文件名，其次使用远端缩略图 URL 文件名，再回退到 `asset_id` 或标签。
- 用户选中题图行时，如果预览引用是 `http`/`https` URL，则进入远端缩略图下载前预览流程。
- 远端缩略图预览复用 N2.242 的 Header 授权控件：
  - 来源为空时按全局 Header 使用；
  - 来源填写 `lark_asset_library` 等值时，仅在素材来源匹配时注入 Header；
  - 继续过滤不应由资料配置注入的 forbidden header。
- 预览下载只接受图片内容类型，并限制 2MB 上限，缓存写入系统临时目录 `lark_formatter_remote_asset_preview`。
- 失败时前台显示“远端缩略图预览失败”，状态栏保留可读失败原因，不把失败伪装成本地缺图。
- 成功时沿用现有图片预览控件渲染缩略图，并显示“正在查看题图远端缩略图：文件名”。
- `current_archive()` 与 `material_context()` 保留 `thumbnail_url` / `preview_url` 元数据，使资料包、执行上下文与前台预览入口保持同一来源。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote thumbnail-url preview UI bridge` evidence。

## 未伪装完成的边界

本轮不等同于完整素材库产品化能力，仍不承诺：

- 真实素材库 API 登录、续期、签名。
- 签名缩略图 URL 过期后的自动续期或刷新。
- 素材库账号、组织、角色权限模型。
- 全尺寸远端图片预览、缩放和对比。
- 后台下载队列、断点续传、并发调度。
- 跨资料包长期预览缓存治理。
- 内容级错图识别、复杂学科图质量判断或 AI 视觉判定。

后续边界应从“真实远端缩略图服务/下载前联网预览”收窄为“真实素材库预览服务/签名缩略图续期、全尺寸远端预览”，并继续与内容级错图识别、复杂图质量判断分开治理。
