# 试卷场景装配器功能与交互规划

日期：2026-07-01

## 1. 修正后的核心判断

试卷场景不应该要求普通用户先去“模板管理”理解和维护空白卷面模板。

更合理的交互是：

```text
试卷场景自带一套默认卷面样式。
用户在试卷场景里确认或复制修改卷面样式。
工作台只负责导入 Markdown 题稿并生成。
```

因此，试卷场景的第一阶段核心模型应是：

```text
Markdown 题稿 + 试卷场景自带卷面样式 + 装配规则 = 完整试卷
```

这里的“卷面样式”底层可以仍然是模板文件，但用户认知上它属于试卷场景，不应让用户跨到模板管理里才能完成基础配置。

## 2. 第一阶段边界

### 应该做

- 试卷场景内置一个默认卷面样式，开箱即可生成。
- 用户可以在试卷场景里选择、复制、恢复或编辑卷面样式。
- 导入 Markdown 题稿。
- 解析试卷信息、题型、题目、选项、答案、解析、分值。
- 将题稿装配进卷面样式中的题目区域。
- 生成学生卷、答案卷、解析版。
- 按版本隐藏或保留答案、解析。
- 给出题稿解析预览和必要问题提示。

### 第一阶段不做

- 不接题图素材。
- 不接资料包。
- 不做 AI 出题。
- 不判断题目正确性。
- 不判断是否超纲。
- 不做查重。
- 不做自动评分。
- 不做答题卡复杂排版。

题图后续可以作为第二阶段能力，但第一阶段先把纯文本试卷装配跑通。

## 3. 用户看到的三个对象

### 3.1 Markdown 题稿

这是用户或 AI 给出的题目内容。

推荐结构：

```markdown
---
exam_title: 七年级数学期末测试
subject: 数学
grade: 七年级
duration: 90分钟
total_score: 100
---

# 一、选择题

## 1. 下列计算正确的是（  ）
A. ...
B. ...
C. ...
D. ...

答案：B
解析：...
分值：3

# 二、填空题

## 11. 已知 ...

答案：...
分值：4
```

### 3.2 试卷样式

这是试卷场景自带的卷面外观。

它负责：

- 标题区域。
- 学校、姓名、班级、考号等信息栏。
- 注意事项。
- 题目正文区域。
- 页边距、字体、行距、分栏。
- 页眉页脚、页码。

用户不需要从零创建它。默认试卷场景必须自带一套可用样式。

### 3.3 装配规则

这是试卷场景负责的规则。

它负责：

- Markdown 题型识别。
- Markdown 题目识别。
- 题号策略。
- 分值显示策略。
- 答案/解析显隐策略。
- 输出版本。

## 4. 板块职责

### 4.1 场景配置

场景配置是试卷场景的主入口。

用户在这里做：

- 选择或新建“试卷装配”场景。
- 确认试卷样式。
- 复制默认样式并修改。
- 恢复默认样式。
- 设置题稿识别规则。
- 设置题号策略。
- 设置答案/解析输出规则。
- 设置生成版本。

场景概览建议显示：

```text
当前场景：试卷装配

试卷样式：默认试卷样式
内容入口：Markdown 题稿
题目识别：一级标题识别题型，二级标题识别题目
生成版本：学生卷、答案卷、解析版
```

按钮建议：

```text
[预览样式] [修改样式] [恢复默认] [打开题稿示例]
```

这里的“修改样式”应该是防呆的：

- 修改前自动复制默认样式。
- 不直接改内置默认样式。
- 用户改坏后可以恢复默认。
- 保存时自动检查题目插入位置。

最终效果：

```text
用户得到一套可复用、可直接生成的试卷场景。
```

### 4.2 工作台

工作台负责一次实际生成。

用户在这里做：

- 选择“试卷装配”场景。
- 导入 Markdown 题稿。
- 查看题稿解析预览。
- 选择要生成的版本。
- 点击生成。

工作台不要求用户选择空白模板，因为试卷样式已经在场景里确认。

最终效果：

```text
生成完整 Word 试卷。
```

### 4.3 模板管理

模板管理不是普通用户的必经路径。

它只作为高级入口：

- 管理底层样式文件。
- 导入复杂学校卷面。
- 维护多个可复用试卷样式。

普通用户从零开始不应该必须进入模板管理。

### 4.4 资料包

第一阶段不参与试卷装配。

原因：

- 当前目标是纯文本 Markdown 题稿装配。
- 题图、材料图、二维码等素材会显著增加复杂度。
- 资料包介入后容易让用户误以为整份试卷内容也应放进资料包。

第二阶段如果做题图，再让资料包承担题图素材库职责。

## 5. 从零开始的完整用户路径

### 5.1 普通用户首次使用

用户进入：`场景配置`

操作：

1. 选择内置场景：试卷装配。
2. 看到默认试卷样式已启用。
3. 可点击“预览样式”查看卷面。
4. 如果默认样式够用，不做任何修改。
5. 如果需要修改，点击“修改样式”，系统自动复制一份默认样式供用户编辑。
6. 确认生成版本：学生卷、答案卷、解析版。
7. 保存场景。

结果：

```text
用户不需要理解模板系统，也能得到可用的试卷生成场景。
```

### 5.2 每次生成一份试卷

用户进入：`工作台`

操作：

1. 选择场景：试卷装配。
2. 导入 AI 生成的 Markdown 题稿。
3. 查看解析预览：
   - 试卷标题。
   - 题型数量。
   - 题目数量。
   - 答案识别情况。
   - 解析识别情况。
4. 勾选输出版本：
   - 学生卷。
   - 答案卷。
   - 解析版。
5. 点击生成。

结果：

```text
生成：
- 学生卷.docx
- 答案卷.docx
- 解析版.docx
```

### 5.3 需要学校固定卷面时

用户仍然从：`场景配置` 进入。

操作：

1. 点击“修改样式”。
2. 选择“导入 Word 卷面”。
3. 系统检查是否有题目插入位置。
4. 如果没有，提示用户自动插入题目区域。
5. 用户保存为当前场景样式。

结果：

```text
这套试卷场景使用学校固定卷面生成，但用户仍不需要先去模板管理。
```

## 6. 防呆设计

### 6.1 默认可用

试卷场景必须自带默认样式。

用户第一次进入时，不应看到：

```text
请先创建模板
```

而应该看到：

```text
默认试卷样式已启用，可以直接生成。
```

### 6.2 修改不破坏默认

用户点击“修改样式”时：

- 系统复制默认样式。
- 用户编辑副本。
- 内置默认样式不可被覆盖。

### 6.3 自动检查题目区域

底层样式必须存在题目插入位置。

如果导入的 Word 卷面没有题目插入位置，系统应提示：

```text
没有找到题目区域，是否自动插入？
```

用户确认后，系统在合适位置插入题目区域。

### 6.4 一键恢复

用户改坏样式后，可以点击：

```text
[恢复默认样式]
```

恢复后不影响已经保存的历史输出。

## 7. 工作台解析预览

执行前只展示题稿是否被正确识别。

推荐预览：

```text
已识别：3 个题型，24 道题

选择题：10 道
填空题：8 道
解答题：6 道

答案：24 条
解析：18 条
```

如果存在问题，只展示需要处理的问题：

```text
需要确认：
- 第 15 题没有识别到答案。
- “三、解答题”下存在未编号题目。
- 未识别到试卷标题，将使用文件名作为标题。
```

## 8. 输出版本设计

### 8.1 学生卷

- 保留题干、选项、材料文本。
- 隐藏答案。
- 隐藏解析。
- 可显示分值。

### 8.2 答案卷

- 保留题干。
- 显示答案。
- 隐藏解析。

### 8.3 解析版

- 保留题干。
- 显示答案。
- 显示解析。

### 8.4 答题卡

第一阶段不做。

原因：

- 答题卡需要独立作答区布局。
- 它不是简单隐藏答案。
- 需要题型和作答区域映射。

## 9. 场景概览最终形态

试卷场景概览建议只有一块关键加法：`试卷装配`。

示意：

```text
当前场景
[ 试卷装配                         v ]

[ + 新建场景 ] [ 创建副本 ] [ 重命名场景 ] [ 打开场景文件夹 ] [ 删除场景 ]

试卷装配
试卷样式：默认试卷样式
内容入口：Markdown 题稿
识别规则：标题识别题型和题目
生成版本：学生卷、答案卷、解析版

[预览样式] [修改样式] [恢复默认] [打开题稿示例]
```

这里不显示题图、不显示资料包、不显示风险检查。

## 10. 第一阶段落地顺序

### 第一步：试卷场景自带默认样式

- 新增内置试卷样式。
- 场景概览显示当前样式。
- 支持预览样式。
- 支持复制修改和恢复默认。

### 第二步：Markdown 题稿解析

- 工作台导入 Markdown。
- 解析试卷元信息、题型、题目、答案、解析、分值。
- 展示解析预览。

### 第三步：生成学生卷

- 先只生成学生卷。
- 将题干和选项装配进默认样式。
- 隐藏答案和解析。

### 第四步：生成答案卷和解析版

- 复用同一题稿。
- 按版本规则保留或隐藏答案、解析。

### 第五步：高级样式导入

- 允许在试卷场景中导入 Word 卷面。
- 自动检测题目区域。
- 自动修复缺失的题目插入位置。

## 11. 最终用户效果

普通用户最合理的体验是：

```text
1. 打开场景配置，选择试卷装配。
2. 默认试卷样式已经可用。
3. 每次把 AI 生成的 Markdown 丢进工作台。
4. 点击生成。
5. 得到学生卷、答案卷、解析版。
```

高级用户才需要：

```text
复制默认样式 -> 修改卷面 -> 保存为本场景样式。
```

这比要求用户先维护空白模板更合理，也更防呆。
