# 高层场景能力矩阵 N2.249 考试题目图片远端全尺寸预览人工差异标注 UI 闭环

## 1. 本轮定位

N2.248 已让大图查看器支持选择同一资料包内其他题图进行对比。剩余边界里的“差异标注增强”不能直接跳成 AI 错图识别，但高频人工核查场景已经可以先闭合：用户看到当前题图与对比图不一致时，需要能在当前资料包里留下可追踪标记。

N2.249 关闭的是“人工差异标注”首片：在不宣称自动内容识别、不进入批量矩阵对比、不做标注图层编辑的前提下，把对比问题写回当前题图 `asset_items.metadata`。

## 2. 已实现能力

- 大图查看器工具栏新增 `asset_full_image_preview_mark_issue`。
- 标注按钮只在当前大图存在可对比对象时启用。
- 点击标注后，当前题图条目的 metadata 写入：
  - `comparison_issue_status=flagged`
  - `comparison_issue_type=manual_compare`
  - `comparison_issue_reference`
  - `comparison_issue_display_name`
  - `comparison_issue_kind`
  - `comparison_issue_marked_at`
  - `comparison_issue_summary`
- 标注结果通过 `current_archive()` 和 `material_context()` 均可读取。
- 题图明细表状态列显示 `对比问题`，让用户回到表格后仍能看到人工标注结果。
- 状态栏展示 `已标记对比问题：<文件名>`。

## 3. 链路闭合

人工差异标注链路：

打开远端全尺寸预览 -> 选择同题缩略图或其他题图作为对比对象 -> 用户人工判断存在差异 -> 点击标记问题 -> 当前题图 `metadata` 写入人工标注字段 -> 资料包与运行上下文可见 -> 题图明细表状态变为 `对比问题`。

审计链路：

`scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote full-preview manual annotation UI bridge` evidence，并由 `tests/test_scene_product_maturity_upgrade_audit.py` 锁定。

## 4. 仍不宣称完成

- 自动内容级错图识别。
- 复杂学科图质量判断、AI 质量边界。
- 批量矩阵式多图对比。
- 标注图层、批注编辑、差异区域绘制。
- 将人工标注自动汇入报告 issue queue 与一键修复流。
- 真实素材库预览服务、签名预览 URL 续期、登录续期、授权续期。

这些能力继续归入 `advanced question asset library UI` / `advanced asset library UI` 的后续产品化边界。
