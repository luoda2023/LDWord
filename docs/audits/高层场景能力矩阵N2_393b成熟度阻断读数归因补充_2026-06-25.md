# 高层场景能力矩阵 N2.393b 成熟度阻断读数归因补充

## 目标

N2.393 已经把 `maturity_l5_blocked=6/27` 纳入残留比例账本，N2.392 也已经把 6 个 Blue/Boundary 成熟度保留项封装为 release envelope。本补充把这两个事实在发布摘要中直接并排显示，避免 `maturity_l5_blocked=6/27` 被误读为未治理缺口。

## 发布口径

- `maturity_l5_blocked=6/27` 必须保留，表示 6 个 subject 仍不能声明 Green/L5；
- `maturity_l5_enveloped=6/6` 必须同时出现，表示 6 个 blocker 全部由 `scene_boundary_maturity_release_envelope_audit` 承接；
- `maturity_l5_alignment=6/6` 必须同时出现在 release gate 摘要中，表示 `maturity_l5_blocked` 行的 6 个 release envelope ID 与 retained gap exit criteria ID 集合精确一致；
- `boundary_envelopes=6/6` 仍作为 envelope 审计总读数；
- `residual_ratios=3/3` 继续说明残留比例账本已经发布。

## 闭环要求

- `scene_boundary_maturity_release_envelope_audit` 暴露 `l5_blocker_enveloped_count`；
- `scene_matrix_dashboard` counts、`boundary_release_envelopes` 卡片、`release_residual_ratios` 卡片、`release_acceptance_certificate` 卡片、`maturity_upgrade` 卡片都展示 L5 blocker envelope 或 alignment 口径；
- `scene_summary_projection` 在 boundary/evidence/readiness 摘要中展示 `6/6 L5 blockers enveloped` 和 `6/6 L5 blockers aligned`；
- `verify_scene_matrix_release_gate.py` 最终摘要展示 `maturity_l5_enveloped=6/6`；
- `scene_release_residual_ratio_ledger_audit` 检查 release gate 中的 `maturity_l5_enveloped=` marker。
- `maturity_l5_blocked` 行的 6 个 `release_envelope_ids` 必须与 `scene_boundary_maturity_release_envelope_audit` 的 envelope id 集合完全一致，并且也必须与 `scene_retained_gap_exit_criteria_audit` 的 criteria id 集合完全一致，避免 6/6 只是数量相等。

这条补充不升级成熟度，不减少 blocked 数；它只证明 blocked 读数不是未闭合缺口，而是已经由发布封套治理的边界保留项。
