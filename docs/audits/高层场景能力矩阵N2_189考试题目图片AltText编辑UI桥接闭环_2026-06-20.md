# 高层场景能力矩阵 N2.189 考试题目图片 AltText 编辑 UI 桥接闭环

日期：2026-06-20

## 1. 目标

N2.188 已经证明：如果结构化题源里存在题目图片 altText，运行时会把它写入 Word `wp:docPr/@descr`，并在 JSON/Markdown 报告里统计覆盖率。

N2.189 继续闭合前台链路的窄切片：

```text
AssetsPanel question_figure 图片说明
-> EntityProfile.asset_metadata
-> EntityArchive JSON
-> MaterialExecutionContext.asset_items[].metadata
-> Workbench exam payload injection
-> Word wp:docPr/@descr
-> report / material manifest / tests
```

它仍不是完整高级题目素材库，也不把 `exam_education` 或 `exam_teaching` 升为 Green/L5。

## 2. 落地内容

### 2.1 模型与归档

- `AssetItem` 新增 `metadata`，用于承载素材角色级别的可执行元数据；
- `EntityProfile` 新增 `asset_metadata`，按素材角色保存元数据；
- `load_entity_archive()` / `save_entity_archive()` 会读写 `asset_metadata`，旧档案默认兼容；
- `MaterialExecutionContext.from_payload()` 会清洗外部 payload 中的 `asset_items[].metadata`。
- 批量资料 JSON 可导入 `asset_metadata`，CSV/Excel 可用 `题目图片说明`、`question_figure_alt_text` 等列导入题图说明。

### 2.2 AssetsPanel 前台桥接

`exam_items_v1` 下的 `question_figure` 素材槽新增“图片说明”输入：

- 用户填写的说明会进入 `AssetItem.metadata["alt_text"]`；
- 当前档案会保存 `asset_metadata.question_figure.alt_text`；
- 已填写时素材状态展示“图片说明已填写”；
- 场景切换导致素材槽重建时，会先持久化当前 profile，并把已有说明重新灌回输入框。

### 2.3 Workbench 执行链

Workbench 在将 `question_figure` 注入结构化题源时，会读取素材 metadata：

- 支持 `alt` / `alt_text` / `altText` / `description` / `caption`；
- 将说明写入注入后的 `question.figure.alt`；
- 后续复用 N2.188 的 Word XML 与报告链路；
- material manifest 会保留 `asset_items[].metadata`，便于交付包追溯。

## 3. 成熟度影响

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset altText editing UI bridge`；
- `family:exam_teaching` evidence 增加 `question asset altText editing UI bridge`；
- `question asset altText runtime/report` 仍作为运行时和报告证据保留；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮只打通“一个全局题图槽位的图片说明编辑”。完整高级题目素材库还需要逐题/多图映射、素材库浏览与预览、远端 asset id/source、缺项修复入口、学科复杂图边界和 AI/素材质量人工确认。

## 4. 高层矩阵裁决

这次闭环把 V41 中“altText 编辑 UI”从高级素材库缺口里拆出首片，但不改变高层矩阵的三层判断：

```text
高频覆盖层：exam 教学场景已被覆盖；
业务语义层：题源、题图、答案显隐、多版本与答题卡语义已可解释；
产品成熟层：高级素材库仍未完整产品化。
```

因此后续不能再把 `question_figure.alt_text` 当作缺口重复计算；但也不能宣称考试素材库已经完善。

N2.190 已继续补齐多个 `question_figure` 按 `question_index` / `question_id` 映射到具体题目的运行时消费者。后续高级素材库缺口因此进一步收窄为前台逐题素材编辑/预览、素材缺项修复入口、远端 asset id/source、一题多图/图组排序、复杂学科图和素材/AI 质量边界。

## 5. 后续边界

仍不承诺：

- 前台每道题单独选择图片；
- 一题多图或图组排序；
- 远端素材库 / asset id 服务；
- 自动生成或校验 altText；
- 判断题图是否对应题意；
- 复杂几何、电路、化学结构等学科图自动生成；
- AI 题目质量或素材质量判断。

这些必须继续由 `advanced question asset library UI`、插件或 manual boundary 承载。
