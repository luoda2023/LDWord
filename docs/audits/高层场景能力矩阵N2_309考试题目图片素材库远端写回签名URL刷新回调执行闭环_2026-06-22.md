# 高层场景能力矩阵 N2.309 考试题目图片素材库远端写回签名 URL 刷新回调执行闭环

日期：2026-06-22

## 本轮定位

N2.308 已经让“签名 URL 已过期”从不可解释的阻断，推进为可生成“续签申请”的交接记录；但申请生成后仍没有执行入口，用户即使拿到了新的签名 URL，也只能重新导入资料或手工改 metadata。N2.309 关闭这段断链：预检表在续签申请生成后提供“执行续签”，系统可应用续签回调字段或调用刷新 connector，把新的 URL / 过期时间写回题图 metadata，并让预检阻断自然退场。

## 已闭合内容

- 企业鉴权预检表中，签名 URL 过期且已生成续签申请后新增“执行续签”动作；
- 支持资料导入中的续签回调字段：`renewed_writeback_url`、`refreshed_writeback_url`、`renewed_current_url`、`refreshed_current_url`、`renewed_signed_url_expires_at`、`refreshed_signed_url_expires_at` 等；
- 支持 connector endpoint 字段：`signed_url_refresh_url`、`signed_url_renewal_url`、`writeback_refresh_url`、`current_refresh_url`、`url_refresh_endpoint`；
- connector 使用既有远端素材授权 header，GET JSON 后从 `metadata`、`data.metadata`、`data` 或顶层字段提取刷新结果；
- 刷新结果统一写入结构化题图 item 的 metadata，而不是只写历史记录；
- 新增 `question_figure_library_remote_writeback_signed_url_refresh_execution` 审计记录，保存来源、endpoint、HTTP 状态、前后 URL、过期时间、变更字段和剩余问题；
- 成功写回后，签名 URL 预检行消失，单项远端写回交接可继续生成；
- `scene_product_readiness` 为 `exam_education` 与 `exam_teaching` 新增 per-question asset library remote writeback signed URL refresh callback execution UI evidence；
- 成熟度 gap 从 `advanced question asset library remote writeback enterprise auth connector signed URL refresh callback execution UI` 收窄为 `advanced question asset library remote writeback enterprise auth connector external permission callback execution UI`。

## 边界说明

本轮不声明以下能力完成：

- 企业 OAuth/SSO 登录跳转；
- token 自动续期；
- 企业身份平台真实 connector；
- 外部组织/角色/题库权限审批回调；
- 权限主数据同步；
- 跨资料包素材主数据版本系统；
- 后台任务化的自动定时续签。

当前“执行续签”只承诺：当刷新结果已经以 metadata 回调字段存在，或 refresh endpoint 可返回新 URL 时，前台可以受控执行、写回 metadata、沉淀审计并解除签名 URL 过期阻断。
