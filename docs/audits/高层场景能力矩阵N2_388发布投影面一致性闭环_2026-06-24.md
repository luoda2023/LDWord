# 高层场景能力矩阵 N2.388 发布投影面一致性闭环

## 背景

N2.380-N2.387 已经把边界守护、残留 warning、非满分 readiness、发布例外、行级 trace、主体证据包、非主体归因和 trace 分区逐层闭合。当前更高一层的风险不是某个审计缺数字，而是某个审计只存在于后端，却没有同步进入用户可见的 dashboard、drilldown、summary projection、release gate、导出脚本、CI 和闭环文档。

本轮补 `release_projection_surface_parity`：它把发布相关的 7 个能力面统一登记，并检查每个能力面是否同时打通所有投影表面。

## 守门口径

每个 projection 必须同时满足：

- 有审计 source id。
- 有 release gate check。
- 已进入 dashboard source list。
- 有 dashboard card。
- 有 drilldown item。
- summary projection 中有可见摘要 marker。
- 有 JSON/Markdown 导出脚本。
- CI workflow 纳入对应测试。
- 有对应 N2 闭环文档。

## 打通范围

- 审计模块：`src/config/scene_release_projection_surface_parity_audit.py`
- 导出脚本：`scripts/export_scene_release_projection_surface_parity_audit.py`
- Release gate：新增 `scene_release_projection_surface_parity_audit` check，并输出 `scene_release_projection_surface_parity_*` 计数。
- Dashboard：新增 `release_projection_surfaces` 卡片，并把本审计纳入 release/boundary/evidence/readiness 视角。
- Drilldown：新增 `release_projection_surface_parity` 明细源，7 行展示每个 projection 的横向投影状态。
- Summary projection：Boundary、Evidence、Readiness 和 Matrix drilldown 摘要展示 `7/7 release projections` 与 `0 release projection gaps`。
- CI：纳入 `tests/test_scene_release_projection_surface_parity_audit.py`。

## 后续断链定位

- 如果 dashboard source 或 card 缺失，说明后端审计存在但用户总览看不到。
- 如果 drilldown item 缺失，说明用户无法从总览定位到具体 projection。
- 如果 summary projection 缺失，说明概览区无法解释 release gate 中保留的边界状态。
- 如果 release gate check 缺失，说明审计无法阻断发布。
- 如果 export script、workflow test 或 closure doc 缺失，说明证据包不可复现或不可持续维护。
