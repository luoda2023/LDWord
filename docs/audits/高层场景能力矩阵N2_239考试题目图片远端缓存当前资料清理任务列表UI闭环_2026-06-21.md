# 高层场景能力矩阵 N2.239 考试题目图片远端缓存当前资料清理任务列表 UI 闭环

日期：2026-06-21

## 本轮定位

N2.238 已经把前台 `cleanup_confirmation.json` 消费到 Workbench 清理执行链路，但前台仍只有“选中共享缓存目录”的 cleanup history 表。用户如果切换到无 history 的目录，会失去当前资料里其他目录待确认/已确认任务的总览。

本轮闭合一个明确的首片：在 AssetsPanel 当前资料上下文内聚合所有共享缓存目录的清理任务记录，形成当前资料范围的清理任务列表 UI。

## 已实现能力

- `AssetsPanel` 新增 `question_figure_shared_cache_tasks_table`。
- 表格位于共享缓存目录表之后、目录内 index 条目表之前。
- 聚合当前 `asset_items` 出现过的全部 `shared_cache_dir`。
- 逐目录读取 `<shared_cache_dir>/cleanup_history.json`，最多取每目录最近 20 条记录，整体按时间倒序截取 50 条。
- 表格展示目录名、记录时间、模式、状态、候选/删除总数、确认状态和任务 id。
- 确认状态读取 `<shared_cache_dir>/cleanup_confirmation.json`，将 dry-run 待处理任务区分为“待确认”和“已确认”，将已执行清理展示为“已执行”。
- 点击清理确认后，除目录级确认行刷新外，同步刷新聚合任务列表。
- 切换到无 cleanup history 的共享缓存目录时，目录级 cleanup history/确认行仍隐藏，但聚合任务列表保持可见。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote cache cleanup task list UI bridge` evidence。

## 未伪装完成的边界

本轮不是完整后台任务中心，不承担以下能力：

- 跨 profile 的清理任务聚合。
- 后台调度、定时清理、取消/重试/并发控制。
- 清理任务的全局通知中心。
- 长任务断点续传和后台队列持久化。
- 真实素材库 API 登录、续期、签名和 UI 授权入口。

因此，后续边界应命名为“后台/跨 profile 全局任务中心”，不再与本轮的“当前资料聚合任务列表 UI”混淆。
