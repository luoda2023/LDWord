# 高层场景能力矩阵 N2.287 考试题目图片素材库远端写回冲突当前快照 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.287 承接 N2.286 的“远端写回冲突处理计划 UI”。上一轮已经能把 `remote_conflict` 推进为可审计的人工处理计划，但仍缺少远端当前值事实，因此后续覆盖远端、放弃本地、字段合并都缺少可靠比较基线。

本轮补“远端当前快照 UI”首片：导入支持 `questionFigureNCurrentUrl` 等字段，冲突处理计划存在且有 current endpoint 时，远端写回表显示“待拉取远端”，点击“拉取远端”执行 HTTP GET，记录远端当前 metadata 与本地待写回值的字段差异。

## 2. 已闭合能力

- CSV/XLSX 导入新增 `questionFigureNCurrentUrl`、`RemoteCurrentUrl`、`CurrentSnapshotUrl`、`ConflictUrl` 等当前值查询字段。
- 当前值查询字段进入题图 metadata 的 `current_url`。
- 远端写回表在冲突处理计划已记录且存在 `current_url` 时显示“待拉取远端”。
- “待拉取远端”与“取值失败”状态显示“拉取远端”动作。
- 拉取请求使用 HTTP GET，`Accept=application/json`。
- 拉取请求复用现有远端素材授权控件的 source-scoped Header。
- 成功后追加 `question_figure_library_remote_writeback_conflict_snapshot` 审计记录。
- 快照记录保存来源变更时间、冲突处理计划时间、冲突执行记录时间、writeback endpoint、current endpoint、幂等键、retry attempt、HTTP 状态与响应摘要。
- 快照记录解析远端 `metadata.source`、`metadata.asset_id`、`metadata.alt_text`，也兼容顶层同名字段。
- 快照记录保存远端值与本地待写回值。
- 快照记录写入 `remote_current_diff_fields` 与 `remote_current_diff_summary`。
- 拉取成功后表格状态显示“远端已取值”。
- 拉取失败后表格状态显示“取值失败”，保留再次拉取入口。
- 当前 metadata 已偏离来源历史 after 值时，不允许拉取旧冲突的远端快照。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback conflict current snapshot UI bridge` evidence。
- 成熟度 gap 从 `advanced question asset library remote writeback conflict merge execution UI` 收窄为 `advanced question asset library remote writeback conflict decision execution UI`。

## 3. 链路视角

```text
remote_conflict execution
  -> conflict_resolution_planned audit
  -> metadata current_url exists
  -> table "待拉取远端"
  -> HTTP GET current endpoint with auth header
  -> conflict_snapshot audit
  -> remote/local field diff summary
  -> table "远端已取值"
  -> later overwrite / abandon / merge-field decision execution
```

这条链路补的是“人工裁决前的远端事实层”。N2.286 负责把冲突进入人工计划；N2.287 负责拉取远端当前值并形成本地/远端差异证据。

## 4. 场景矩阵影响

P0 高级考试素材库远端写回链路现在为：

- N2.283：本地 metadata 治理结果生成远端写回交接。
- N2.284：具备 endpoint 的单项 handoff 可执行 HTTP JSON POST。
- N2.285：写回请求具备幂等键、retry attempt 审计和远端冲突分类。
- N2.286：远端冲突可生成前台人工处理计划并进入审计。
- N2.287：人工处理计划可拉取远端当前值，并记录字段级差异快照。

剩余 gap 不再是“远端当前值拉取”或笼统“合并 UI”，而是更明确的 `advanced question asset library remote writeback conflict decision execution UI`。
