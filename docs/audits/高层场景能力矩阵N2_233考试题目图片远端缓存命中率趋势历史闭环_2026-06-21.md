# 高层场景能力矩阵 N2.233 考试题目图片远端缓存命中率趋势历史闭环

## 1. 背景

N2.232 已经把远端缓存清理从单次摘要推进到任务历史 artifact。剩余边界里仍有“跨运行命中率趋势面板”，但前台趋势图不能先于数据底座出现，否则会变成没有可追溯来源的展示壳。

本轮把该边界收窄为第一片：写出远端缓存 metrics history，并把当前运行与共享缓存目录的历史记录进入 manifest、资料包和 archive report。它为后续前台趋势面板提供可读数据源，但不声称已经完成趋势面板 UI。

## 2. 闭合范围

本轮闭合：

- 当前运行 `_remote_asset_cache/metrics_history.json`；
- 共享缓存目录 `metrics_history.json`；
- material manifest 暴露当前运行 history 与 shared history 摘要；
- 资料包复制当前运行 history 与 shared history；
- archive report 输出 history source/package 与共享历史条目数；
- 成熟度矩阵补入 hit-rate trend history evidence。

本轮不做：

- 前台趋势折线图、筛选器、时间窗口；
- 后台定时采样任务；
- 跨 profile 全局聚合；
- 远端素材库服务端真实统计 API；
- AI 级异常趋势解释。

## 3. 数据链路

当前运行 history：

```text
_remote_asset_cache/metrics_history.json
```

每条 record 写入：

```text
run_id
history_scope
index_path
entry_count
cache_reusable_entry_count
cache_downloaded_entry_count
cache_failed_entry_count
cache_reuse_rate
cache_key_type_counts
cache_status_counts
download_status_counts
cache_scope_counts
shared_cache_dir_counts
updated_at
recorded_at
```

共享缓存目录 history：

```text
<shared_cache_dir>/metrics_history.json
```

当一次运行使用共享缓存目录时，系统会基于共享目录自己的 `index.json` 写入一条 `history_scope=shared` 的 metrics record。连续多次运行同一共享目录后，该文件会累计形成跨输出目录的命中率趋势底座。

## 4. Manifest / Package / Report

material manifest 的 `remote_asset_cache` 新增：

```text
cache_metrics_history_path
cache_metrics_history_entry_count
cache_metrics_history_latest_run_id
cache_metrics_history_source_count
cache_metrics_shared_history_paths
cache_metrics_shared_history_entry_count
cache_metrics_shared_history_latest_run_ids
```

资料包复制：

```text
remote_asset_cache/metrics_history.json
remote_asset_cache/shared_metrics_history/shared_1_metrics_history.json
```

archive report 的 `## Remote Asset Cache` 新增：

```text
Cache metrics history entries
Cache metrics history source
Cache metrics history package
Shared cache metrics history entries
Shared cache metrics history packages
```

这使“单次命中率摘要”升级为“可随共享缓存目录跨运行累积的命中率历史证据”。
