# 高层场景能力矩阵 N2.297 考试题目图片素材库远端写回批量回滚失败队列 UI 闭环

## 1. 背景

N2.296 已经可以从事务报告里的 rollback candidates 发起真实远端回滚，并生成 `question_figure_library_remote_writeback_batch_rollback_execution` 审计记录。但如果回滚执行遇到权限失效、远端冲突、普通失败或跳过，问题仍只停留在审计 JSON 里，用户不能从前台队列继续处理。

本轮闭合“批量回滚失败队列 UI 首片”。它不做二次补偿审批，也不做后台任务；只负责把最近一次回滚执行中的非成功项投影成前台队列，并把权限更新、回滚重试、报告定位打通。

## 2. 已闭合能力

- 题图素材库区域新增 `question_figure_asset_library_remote_writeback_rollback_failure_queue_table`。
- 队列表按 `问题 / 题目 / 状态 / 下一步 / 处理` 展示。
- 队列来源为最近一次 `question_figure_library_remote_writeback_batch_rollback_execution` 的 `rollback_result_items`。
- 只展示 permission、conflict、failed、skipped 等非 success 结果。
- 已经在后续回滚执行中成功的候选不会继续出现在失败队列。
- 权限失败项显示“回滚权限失效”，下一步为“更新授权后重试回滚”。
- 权限失败项提供“更新授权”“重试回滚”“定位报告”。
- “更新授权”会把该回滚项使用的素材库 source 填回远端素材授权控件。
- “重试回滚”会重新执行对应事务报告的 pending rollback candidates。
- 回滚冲突项显示“回滚冲突”，提供“重试回滚”和“定位报告”。
- 普通失败项显示“回滚失败”，提供“重试回滚”和“定位报告”。
- 跳过项显示“回滚已跳过”，只提供“定位报告”。
- 事务报告表在回滚失败时新增“定位回滚失败”动作，并回链到回滚失败队列首项。
- 新增测试锁定“回滚权限失效 -> 回滚失败队列显示 -> 更新授权 -> 重试回滚 -> 队列清空 -> 报告显示回滚已执行”的链路。

- 回滚冲突字段级合并；
- 回滚任务后台化、并发控制、限流、取消和指数退避；
- 回滚 manifest 文件导出和独立 drilldown；

- 组织、角色、题库权限申请或审批；
- 跨资料包素材主数据版本系统。
