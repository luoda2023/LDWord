# 高层场景能力矩阵 N2.200 考试题目图片平铺导入一题多图闭环

## 1. 本轮定位

N2.200 继续执行 V43 的 P0 高级考试素材库路线，闭合 N2.199 后保留的一个明确入口缺口：CSV/XLSX 平铺列名无法直接表达“同一道题多张图”。

这不是模板管理参数，也不是 Word 样式参数。它归属高层场景能力矩阵中的两个功能组：

- 输入事实源与结构化模型：CSV/XLSX 表格列名必须能稳定转成机器可信的 `asset_items`。
- 资料、素材与附件：题目图片是场景资产，必须绑定题号、图序、说明、远端来源等元数据。

外部试卷生成技术记录中已经明确：AI 不应直接生成 Word，正式渲染事实源应是结构化 JSON，Markdown 用于人工预览，Word 是最终输出。N2.200 因此把表格导入也收束到同一个事实源模型：表格只负责声明素材事实，后续仍由 `asset_items`、运行时注入、Word 渲染和报告链路消费。

## 2. 导入语法

旧语法继续兼容：

```text
questionFigure1
questionFigure1AltText
questionFigure2
questionFigure2AltText
```

新语法支持在题号后声明图序：

```text
questionFigure1Image1
questionFigure1Image1AltText
questionFigure1Image2
questionFigure1Image2AltText
questionFigure1Figure1
questionFigure1Figure2
```

对应语义：

| 列名片段 | 含义 | 输出 metadata |
| --- | --- | --- |
| `questionFigure1` | 第 1 题单图 | `question_index=1` |
| `questionFigure1Image2` | 第 1 题第 2 张图 | `question_index=1`, `figure_order=2` |
| `questionFigure1Figure2AltText` | 第 1 题第 2 张图说明 | `alt_text`, `question_index=1`, `figure_order=2` |
| `questionFigure1Image2AssetId` | 第 1 题第 2 张远端图资产 ID | `asset_id`, `question_index=1`, `figure_order=2` |
| `questionFigure1Image2Source` | 第 1 题第 2 张远端图来源 | `source`, `question_index=1`, `figure_order=2` |

生成的 `item_id` 使用稳定结构：

```text
question_figure_1
question_figure_1_1
question_figure_1_2
```

旧格式没有图序时保持 `question_figure_1`，新格式带图序时使用 `question_figure_{question_index}_{figure_order}`。

## 3. 链路闭合

本轮打通的链路是：

```text
CSV/XLSX row
-> _row_asset_item_payloads()
-> EntityProfile.asset_items
-> AssetsPanel.material_context()
-> question_figure 明细表/状态摘要
-> Workbench question asset runtime injection
-> exam JSON figure list
-> Word 图片渲染
-> JSON/Markdown report and material manifest
```

关键行为：

- CSV 与 XLSX 共用同一套行解析，不分叉实现；
- 表格列顺序不决定图组顺序，导入后按题号和 `figure_order` 排序；
- `questionFigure1Image2` 即使出现在 `questionFigure1Figure1` 前面，也会输出为图1在前、图2在后；
- `AltText`、`Description`、`Caption` 等说明字段继续转入素材 metadata；
- 无本地 path 但有 `asset_id` 的远端条目继续保留，不被导入层过滤；
- N2.199 的运行时图组追加逻辑继续消费同一组 `asset_items`。

## 4. 成熟度证据

`scene_product_readiness` 已新增 evidence：

```text
question asset flat figure group import bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“底层支持同题多图”推进到“表格批量资料也能声明同题多图”。但它仍然不是 Green/L5，因为剩余边界并非导入语法本身，而是素材库产品能力和质量边界。

## 5. 仍未闭合的边界

N2.200 后，`advanced question asset library UI` 的剩余边界收窄为：

- 文件名题号错配预检已由 N2.201 追补，剩余为内容级错图识别与人工审阅；
- 远端素材真实下载、鉴权、缓存、预览和失效处理；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。

CountEngine 技术记录强调 profile-driven multi-metric，而不是单一“字数”函数。这个原则也适用于 N2.200：表格导入不应该隐式猜测素材质量或内容正确性，只能把当前 profile 中声明的素材事实稳定、可追溯地传给后续消费者。
