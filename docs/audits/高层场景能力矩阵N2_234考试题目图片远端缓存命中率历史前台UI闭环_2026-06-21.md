# 高层场景能力矩阵 N2.234 考试题目图片远端缓存命中率历史前台 UI 闭环

## 1. 背景

N2.233 已经把远端题图缓存命中率从单次摘要推进为 metrics history artifact，并进入 manifest、资料包和报告。但“跨运行命中率趋势面板”仍缺前台可发现入口。

本轮先做前台 UI 首片：在 AssetsPanel 的共享缓存目录 drilldown 区域读取 `metrics_history.json`，展示最近的命中率历史记录。它让用户能在素材面板内看到共享缓存目录的下载/复用趋势底座，但不把完整趋势图、时间窗口筛选或跨 profile 聚合伪装为已完成。

## 2. 闭合范围

本轮闭合：

- AssetsPanel 新增 `question_figure_shared_cache_metrics_table`；
- 选择共享缓存目录时，联动读取该目录的 `metrics_history.json`；
- history 表展示最近 20 条记录；
- 表格展示记录时间、条目数、复用数、下载数、失败数和复用率；
- tooltip 展示 index path、缓存状态分布和下载状态分布；
- 无 history 文件或目录无记录时隐藏该表；
- 成熟度矩阵补入 hit-rate trend history UI evidence。

本轮不做：

- 折线图、柱状图、时间窗口筛选；
- 跨 profile / 全局历史聚合；
- 后台定时采样；
- 趋势异常解释；
- 与远端素材库服务端统计 API 对齐。

## 3. UI 链路

前台入口：

```text
素材管理 -> 图片材料 -> 共享缓存目录表 -> 选中目录 -> 命中率历史表
```

读取文件：

```text
<shared_cache_dir>/metrics_history.json
```

表格列：

```text
记录时间
条目
复用
下载
失败
复用率
```

联动规则：

- 共享缓存目录表切换行后，index 条目表和 metrics history 表同步刷新；
- 有 `metrics_history.json` 时展示最近记录；
- 没有 history 或解析失败时隐藏表，不阻断图片材料面板；
- 仍沿用现有表格样式、选择行为和只读状态。

## 5. 仍未闭合的边界

N2.234 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API 登录、续期、签名 URL 与 UI 授权入口；
- 跨 profile 后台定时清理、前台确认 UI 和任务历史列表 UI；
- 断点续传、后台队列、并发下载调度；
- 完整跨运行缓存命中率趋势面板 UI，包括图表、筛选和跨 profile 聚合；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图或 AI 质量判断；
