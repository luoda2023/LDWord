# 高层场景能力矩阵 N2.198 考试题目图片远端资产 ID 来源桥接闭环

日期：2026-06-20

## 1. 定位

N2.197 已经把缺文件题图从运行时诊断、问题队列、Workbench 路由和 AssetsPanel 明细行定位打通，但仍保留一个明确边界：

```text
远端 asset_id / source 解析尚未进入导入、前台和运行时闭环。
```

本轮 N2.198 闭合这一片：

```text
CSV/XLSX/JSON 资料
-> question_figure asset_id/source
-> AssetsPanel 结构化条目
-> 前台逐题明细表“远端”状态
-> exam JSON 运行时注入
-> report / material manifest
-> scene_product_readiness evidence
```

这不是远端素材下载服务，也不是图库权限/版权/质量判断。本轮只保证远端资产引用作为一等素材引用不再被丢弃，并且在报告中可追。

## 2. 已闭合链路

### 2.1 导入层

`AssetsPanel` 的批量资料导入现在支持重复题图的远端字段：

```text
questionFigure2AssetId
questionFigure2Source
题目图片2说明
```

导入后生成结构化条目：

```json
{
  "item_id": "question_figure_2",
  "label": "remote-question-2",
  "role": "question_figure",
  "path": "",
  "metadata": {
    "asset_id": "remote-question-2",
    "source": "lark_asset_library",
    "alt_text": "远端减法图",
    "question_index": "2"
  }
}
```

关键修复点：

- `_row_asset_item_payloads()` 允许无 path 但有 `asset_id` 的 `question_figure` 条目进入 payload；
- `_normalized_asset_item_payloads()` 不再把无 path 的远端 asset item 二次过滤掉；
- `asset_id` / `assetId` 和 `source` 已纳入重复题图 metadata suffix。

### 2.2 前台 AssetsPanel

前台逐题题图明细表现在能显示远端条目：

| 列 | 远端条目显示 |
| --- | --- |
| 题目 | `题2` |
| 图片 | `remote-question-2` |
| 说明 | `远端减法图` |
| 状态 | `远端` |

行级 repair target 匹配也支持 `asset_id`：

- 优先按 `item_id`；
- 其次按题号 metadata；
- 再按 path；
- 最后按 `asset_id` / `assetId`。

### 2.3 运行时注入

`WorkbenchProductionRunner` 在 exam schema 场景下会把远端题图引用注入结构化题源：

```json
{
  "source": "lark_asset_library",
  "path": "",
  "asset_id": "remote-question-1",
  "alt": "远端加法示意图"
}
```

`exam_question_schema` 当前仍只渲染本地可访问文件；远端 `asset_id` 不会被误当成本地成功渲染。报告会体现：

```text
assets=0/1, missing_assets=1, source_altText=1/1
```

这表示：

- 结构化题图资产存在；
- 本地 Word 渲染没有插入图片；
- 源端已经携带图片说明；
- 不触发 N2.197 的“缺本地文件”修复诊断，因为无 path 的远端资产不是本地缺文件。

### 2.4 报告与 manifest

本轮补充了 Markdown 报告的源端 altText 口径：

```text
source_altText={question_asset_alt_text_count}/{question_asset_count}
```

这样远端题图即使未本地渲染，也能在报告中看见“源端说明已覆盖”的证据。

Material manifest 保留：

- `question_index`;
- `asset_id`;
- `source`;
- `alt_text`。

保留 gap 的原因：

## 5. 后续边界

N2.198 后，`advanced question asset library UI` 的剩余边界收窄为：

- 一题多图 / 图组排序；
- 批量自动匹配错图的检测与修复；
- 远端素材真实下载、鉴权、缓存和预览；
- 复杂学科图生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅与历史版本管理。

后续 N2.199 已承接并闭合结构化 `asset_items` 路径的一题多图 / 图组排序第一片；CSV/XLSX 平铺列名的一题多图导入语法、错图匹配和远端素材真实下载/鉴权/缓存/预览仍不属于 N2.198 范围。
