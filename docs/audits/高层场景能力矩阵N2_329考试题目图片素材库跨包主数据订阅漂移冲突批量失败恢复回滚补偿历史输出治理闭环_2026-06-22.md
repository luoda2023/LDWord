# 高层场景能力矩阵 N2.329 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复回滚补偿历史输出治理闭环

日期：2026-06-22

## 1. 本轮目标

N2.328 已经让订阅漂移批量失败恢复批次进入 SLA 与当前归档恢复中心，但恢复闭合后仍缺少后续治理承接：哪些已恢复项需要回滚影响评估，哪些未闭合项需要补偿，哪些已经生成过的历史输出需要追溯复核。本轮承接 `batch failure recovery rollback compensation historical output governance UI`，新增恢复后续治理首片，让恢复报告、Drilldown、SLA 记录之后继续形成可审计的回滚、补偿、历史输出治理入口。

本轮不声明已经实现自动批量回滚、二次补偿 connector、历史 Word 输出 trace repair 或跨文件归档扫描。当前只承诺：当前 EntityArchive 内的题图素材订阅漂移批量失败恢复事实，可以被投影为“回滚评估 / 补偿判断 / 历史输出追溯”的治理记录，并写回历史记录和题图素材 metadata。

## 3. 链路边界

当前链路是：

1. 批量失败恢复队列形成恢复报告。
2. 恢复报告生成 Drilldown artifact。
3. SLA center 聚合恢复批次并记录 SLA 治理。
4. 后续治理表根据恢复状态判断回滚、补偿、历史输出追溯。
5. 用户记录后续治理审计。
6. 审计记录写入相关 profile 的 `asset_item_history`。
7. 可匹配题图素材同步写入后续治理 metadata。
8. 表格仍可定位回失败项、恢复报告或 Drilldown 明细。

`historical_output_scope=current_archive_generated_outputs` 当前表示当前归档内已经由本应用生成或可追溯的输出集合，不表示已经扫描并修改历史 Word 文件。

- 自动提醒、责任人通知和升级发送；

- 历史 Word 输出 trace repair；
