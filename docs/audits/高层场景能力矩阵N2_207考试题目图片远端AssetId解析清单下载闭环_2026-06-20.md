# 高层场景能力矩阵 N2.207 考试题目图片远端 AssetId 解析清单下载闭环

## 1. 本轮定位

N2.207 继续执行 V43 的 P0 高级考试素材库路线，在 N2.206 “asset_id 旁显式携带 download_url 可下载缓存”之后，补齐更接近素材库 API 的第一段解析链路：

```text
当 question_figure 只有 asset_id/source 身份，
但场景运行上下文 entity_data 内携带本地素材解析清单时，
Workbench 可在执行前解析真实下载 URL、下载到本地缓存，并继续渲染 Word。
```

本轮不是完整远端素材库服务，仍不实现：
- 外部素材库 API 请求；
- token、cookie、签名 URL 等鉴权下载；
- ETag、Last-Modified、过期判断、强制刷新等缓存刷新策略；
- 下载前远端预览；
- 内容级错图识别、复杂学科图/AI 制图质量判断；
- 素材库批量审阅、版本治理、标签治理。

它的意义是把“只有 asset_id/source 的远端题图”从只能进入修复提示，推进到“若场景资料包能提供解析清单，则可自动落缓存并渲染”的闭环。

## 2. 输入契约

题图素材仍以 `asset_items` 表达：

```json
{
  "role": "question_figure",
  "path": "",
  "metadata": {
    "question_index": "1",
    "asset_id": "remote-question-asset-3",
    "source": "lark_asset_library",
    "alt_text": "Resolved asset id figure"
  }
}
```

解析清单放在 `MaterialExecutionContext.entity_data`，优先支持以下 key：

```text
question_asset_library
question_figure_asset_library
question_asset_resolver
asset_library
asset_resolver
asset_url_resolver
```

每个值可以是 JSON 字符串，支持三类高频形态。

### 2.1 按 source 分组

```json
{
  "lark_asset_library": {
    "remote-question-asset-3": {
      "download_url": "https://example.com/question_3.png"
    }
  }
}
```

### 2.2 直接按 asset_id 映射

```json
{
  "remote-question-asset-3": "https://example.com/question_3.png"
}
```

或：

```json
{
  "remote-question-asset-3": {
    "source": "lark_asset_library",
    "download_url": "https://example.com/question_3.png"
  }
}
```

### 2.3 记录列表

```json
[
  {
    "asset_id": "remote-question-asset-3",
    "source": "lark_asset_library",
    "download_url": "https://example.com/question_3.png"
  }
]
```

URL 字段沿用 N2.206 的别名：

```text
download_url / downloadUrl
remote_url / remoteUrl
asset_url / assetUrl
source_url / sourceUrl
original_url / originalUrl
url
```

## 3. URL 选择顺序

`_material_context_with_remote_question_asset_cache()` 的下载 URL 选择顺序变为：

1. `AssetItem.path` 是 `http/https` 图片 URL；
2. `metadata.download_url` 及其别名；
3. `entity_data` 内的素材解析清单按 `asset_id/source` 命中。

解析清单命中后，本次运行的 cloned `AssetItem.metadata` 会写入：

```json
{
  "download_url": "https://example.com/question_3.png",
  "asset_url_resolved_from": "entity_data.question_asset_library"
}
```

下载成功后继续写入：

```json
{
  "cache_path": "<output_dir>/_remote_asset_cache/question_3_remote_<hash>.png",
  "cache_status": "downloaded"
}
```

原始 `path` 可继续为空，`asset_id/source` 继续保留为素材身份。

## 4. 闭环链路

```text
asset_items.metadata.asset_id/source
-> entity_data.question_asset_library
-> Workbench 执行前解析 download_url
-> 匿名下载到 _remote_asset_cache
-> metadata.download_url / asset_url_resolved_from / cache_path / cache_status
-> _asset_render_path 使用 cache_path
-> exam figure payload 保留 asset_id/source，path 使用本地缓存
-> Word 渲染图片
-> JSON/Markdown report 显示 assets=1/1
-> material manifest 保留 path="" + asset_id/source/download_url/resolved_from/cache_path
```

若解析清单命中但下载失败，N2.204 的 `preflight_remote_question_figure_uncached` 仍会接管。因为 metadata 已写入 `download_url`，报告与 issue queue 可展示可修复 URL，并回到题图行替换本地文件或修正清单。

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote asset-id resolver bridge
```

覆盖对象：
- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“asset_id 旁带显式 URL 才能下载”，推进到“asset_id/source 可通过本地解析清单获得 URL 并渲染”。N2.208 已继续追补受控 header 鉴权下载首片；但它仍不是完整素材库 API，因为解析清单和鉴权配置仍由场景资料包携带，不负责向外部素材库登录、续期、签名或查询。

## 6. 仍未闭合的边界

N2.208 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：

- 真实素材库 API：凭 `asset_id/source` 远程查询下载 URL，并在必要时完成登录、续期或签名 URL 生成；
- 权限失败细分：401/403/过期/无权限/签名失效的可读提示、重试和 UI 授权入口；
- 缓存刷新策略：过期判断、ETag、Last-Modified、强制刷新、失败重试；
- 远端内容预览：下载前预览、失败占位、类型/尺寸信息；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
