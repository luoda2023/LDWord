# 文档执行统一入口落地记录

日期：2026-07-30

## 最终产品裁决

工作台固定保留两个入口：

1. **文档执行**
2. **成套交付**

本轮主交付是「文档执行」。原「批量生成」不再作为独立导航功能，而是并入「文档执行」内部的「按资料」形态。「成套交付」保留独立入口；当前工作树中的成套预检与界面改动属于另一组待单独验收的变更，不计入本文档执行闭环。

## 文档执行的三个任务形态

| 模式 | 输入关系 | 执行关系 | 输出关系 |
|---|---|---|---|
| 单份 | 1 个文档 | 当前方案、模板与资料 | 1 组结果 |
| 多文件 | N 个文档或 1 个文件夹 | 共享方案、模板与当前资料；逐文件独立执行 | N 组隔离结果 |
| 按资料 | 0 或 1 个共用源文档 + N 条资料（N 可为 1） | 每条资料独立生成；官方文档表可不依赖源文档 | N 组隔离结果 |

不支持隐式的「N 个文件 × N 条资料」自动配对。该关系没有明确映射规则时必须阻止，不能按顺序猜测。

## 已落地内容

- 工作台固定导航由「快速执行 / 批量生成 / 成套生成」收敛为「文档执行 / 成套交付」。
- 「文档执行」根据实际文档数和显式资料选择自动识别「单份 / 多文件 / 按资料」，不增加手动模式开关。
- 旧「快速执行」完整保留为「单份」模式。
- 旧「批量生成」完整保留为「按资料」模式。
- 新增「多文件」模式：
  - 支持多选文件；
  - 支持选择或拖入文件夹；
  - 文件夹递归收集当前方案允许的文档格式；
  - 自动去重；
  - 每个文件建立独立不可变执行会话；
  - 每个文件独立输出、独立失败，不因单项失败中断其余文件；
  - 支持取消与批次结果汇总。
- 资料页直接发送「文档执行 + 按资料」意图，不保留旧 `batch_generate` 导航或兼容分支。

## 安全边界

- 多文件模式不会把第一个文档的章节/处理范围决定复用于其他文档。
- 可自动接受处理范围的文档直接进入批次。
- 需要用户逐份确认处理范围的文档会被明确阻止，并提示切换到「单份」处理。
- 对象预检存在警告时，第一次点击只展示确认，第二次点击才执行。
- 存在阻断对象时不允许批量绕过。
- 单批最多 500 个文档。

## 未扩展内容

- 不实现多文件与多资料的自动配对。
- 不把多文件理解为多文档合并。
- 不新增资料编辑器；多文件模式只消费当前共享资料上下文。
- 文档执行不依赖成套交付扩展；当前成套交付差异必须独立审阅、独立验收，不得由本文档执行记录代为声明完成。
