# 高层场景能力矩阵 N2.210 考试题目图片远端缓存刷新闭环

## 1. 本轮定位

N2.210 继续执行 V43 的 P0 高级考试素材库路线，在 N2.209 “权限失败可解释诊断”之后，补齐缓存刷新策略的首片：

```text
当 question_figure 已有可用 cache_path，
且资料明确要求 force_refresh / cache_refresh / refresh_cache，
Workbench 会尝试重新下载远端图片、更新本次运行缓存路径，并继续渲染 Word。
```

本轮不是完整缓存治理系统，仍不实现：
- ETag / Last-Modified 条件请求；
- 自动过期判断；
- 后台重试队列；
- 多 profile 共享缓存索引；
- 远端预览；
- 真实素材库版本治理。

它的意义是把“有旧缓存但用户明确要求刷新”的高频场景从无入口，推进到可执行、可报告、可回退。

## 2. 输入契约

题图素材可以同时携带旧缓存与下载 URL：

```json
{
  "role": "question_figure",
  "path": "",
  "metadata": {
    "question_index": "1",
    "asset_id": "remote-question-refresh-1",
    "source": "lark_asset_library",
    "cache_path": "C:/cache/old.png",
    "download_url": "https://example.com/question_1.png",
    "force_refresh": "true"
  }
}
```

刷新标志兼容以下字段：

```text
force_refresh / forceRefresh
cache_refresh / cacheRefresh
refresh_cache / refreshCache
cache_force_refresh / cacheForceRefresh
```

真值兼容：

```text
1 / true / yes / y / on / force / forced / refresh / always
```

## 3. 成功链路

当旧 `cache_path` 存在，且刷新标志为真时：

1. `_material_context_with_remote_question_asset_cache()` 不再因为 `cache_path` 存在而提前跳过；
2. URL 仍按 N2.207 的顺序解析：`path URL -> metadata URL -> entity_data resolver`；
3. `_download_remote_question_asset(..., refresh=True)` 会绕过“目标缓存文件已存在直接返回”的短路；
4. 下载成功后写入新的运行时缓存路径；
5. Word 渲染使用新缓存。

成功 metadata：

```json
{
  "cache_path": "<output_dir>/_remote_asset_cache/question_1_refreshed_<hash>.png",
  "download_url": "https://example.com/question_1_refreshed.png",
  "cache_status": "downloaded",
  "download_status": "downloaded",
  "cache_refresh_status": "refreshed",
  "force_refresh": "true"
}
```

`path` 可继续为空，`asset_id/source` 继续保留。

## 4. 失败降级链路

如果刷新失败，但旧 `cache_path` 仍存在：

- 不删除旧缓存；
- 不把题图判定为缺失；
- Word 继续使用旧缓存渲染；
- material manifest 记录刷新失败状态；
- material diagnostics 生成：

```text
preflight_remote_question_figure_cache_refresh_failed
```

失败 metadata：

```json
{
  "cache_path": "C:/cache/old.png",
  "cache_refresh_status": "failed",
  "cache_refresh_failure_type": "http_status",
  "cache_refresh_http_status": "401",
  "cache_refresh_failure_reason": "Remote asset download requires authentication or the token is invalid"
}
```

Workbench issue detail 展示：

```text
远端题图缓存刷新失败：题号 1 / remote-question-refresh-failed-1 / lark_asset_library / HTTP 401 / Remote asset download requires authentication or the token is invalid
```

repair target 继续复用：

```text
repair_target_type = question_figure_item
```

因此用户仍会回到具体题图行修复 URL、权限或替换本地图片。

## 5. 闭环链路

```text
cache_path exists + force_refresh=true
-> 解析 download_url
-> refresh=True 下载远端图片
-> 成功：cache_refresh_status=refreshed + 新 cache_path
-> 失败：保留旧 cache_path + cache_refresh_status=failed
-> Word 仍可渲染可用缓存
-> report/manifest/issue 记录刷新状态
-> repair target 回到 question_figure_item
```

## 6. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cache refresh bridge
```

覆盖对象：
- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“缓存一旦存在就固定使用”，推进到“用户可显式要求刷新，且刷新失败不破坏旧缓存交付”。

## 7. 仍未闭合的边界

N2.210 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：

- 真实素材库 API：凭 `asset_id/source` 远程查询下载 URL，并在必要时完成登录、续期或签名 URL 生成；
- UI 授权入口：401/403/过期/无权限/签名失效时的重新授权、token 刷新、权限申请或账号切换；
- 自动缓存治理：过期判断、ETag、Last-Modified、条件请求、失败重试、共享缓存索引；
- 远端内容预览：下载前预览、失败占位、类型/尺寸信息；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
