# 高层场景能力矩阵 N2.216 考试题目图片远端缓存索引摘要闭环

## 1. 本轮定位

N2.216 继续执行 V43 的 P0 高级考试素材库路线，在 N2.214/N2.215 已经写入 `_remote_asset_cache/index.json` 后，补齐上层可消费入口：

```text
material manifest 需要知道本次远端题图缓存索引的总体状态，而不是让后续 UI、统计或审计逻辑再自行扫描 `_remote_asset_cache/index.json`。
```

本轮不是完整缓存管理 UI，也不是跨 profile 全局缓存中心。它只把当前任务输出目录中的本地缓存索引摘要写入主 material manifest，形成后续前台统计、artifact 浏览和素材库治理的稳定入口。

## 2. 主清单摘要字段

当 `<output_dir>/_remote_asset_cache/index.json` 存在时，material manifest 新增：

```json
{
  "remote_asset_cache": {
    "schema_version": 1,
    "present": true,
    "index_path": "C:/output/_remote_asset_cache/index.json",
    "entry_count": 1,
    "updated_at": "2026-06-20T00:00:00Z",
    "cache_key_type_counts": {
      "download_url": 1
    },
    "cache_status_counts": {
      "downloaded": 1
    },
    "download_status_counts": {
      "downloaded": 1
    },
    "cache_refresh_status_counts": {},
    "cache_revalidation_status_counts": {},
    "content_type_counts": {
      "image/png": 1
    }
  }
}
```

摘要只放统计和索引路径，不复制完整条目。完整的 `download_url`、`cache_path`、`asset_id`、`question_index`、ETag/Last-Modified 等细节仍保留在 `_remote_asset_cache/index.json`。

## 3. 覆盖链路

本轮摘要覆盖两条已闭合路径：

- 普通远端下载：`cache_key_type_counts.download_url=1`、`cache_status_counts.downloaded=1`、`download_status_counts.downloaded=1`；
- 已有缓存命中：`cache_key_type_counts.cache_path=1`、`cache_status_counts.reused=1`、`download_status_counts.cache_hit=1`。

同时，摘要字段也兼容 N2.213/N2.214 已闭合的 304 复用路径，可通过：

- `cache_revalidation_status_counts.not_modified`
- `cache_refresh_status_counts.not_modified`

承接后续统计。

## 4. 产品意义

N2.216 把缓存索引从“旁路 artifact”推进到“主清单可发现能力”：

- 场景页可以展示本次任务是否产生远端缓存索引；
- artifact 浏览器可以从 material manifest 找到 `_remote_asset_cache/index.json`；
- issue/repair 可以判断是下载、复用、304 复用还是直接命中；
- 后续缓存命中统计面板不必重新扫描输出目录；
- 素材库批量审阅可以先看摘要，再按需打开明细索引。

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cache index summary bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“有本地缓存索引文件”推进到“主 material manifest 暴露缓存索引摘要”。

## 6. 仍未闭合的边界

N2.216 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 深层缓存治理：跨 profile 共享缓存索引、后台失败重试、批量失效、统一清理、全局命中率统计；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
