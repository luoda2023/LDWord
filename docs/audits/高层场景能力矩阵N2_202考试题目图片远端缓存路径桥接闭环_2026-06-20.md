# 高层场景能力矩阵 N2.202 考试题目图片远端缓存路径桥接闭环

## 1. 本轮定位

N2.202 继续执行 V43 的 P0 高级考试素材库路线，推进 N2.201 后保留的远端素材边界第一片：当远端 `asset_id/source` 已经具备本地缓存文件时，前台预览、运行时 Word 渲染、报告统计和 material manifest 必须消费同一条缓存路径。

这不是远端下载器，也不处理鉴权。它闭合的是“远端资产引用已经落地到本地缓存后，产品链路仍断开”的问题。

## 2. 输入契约

远端题图继续保留：

```text
asset_id
source
```

新增可消费的缓存路径 metadata：

```text
cache_path
cached_path
local_path
local_cache_path
resolved_path
download_path
asset_path
```

CSV/XLSX 平铺导入也支持：

```text
questionFigure2CachePath
questionFigure2LocalPath
questionFigure2CachedPath
questionFigure2ResolvedPath
questionFigure2DownloadPath
questionFigure2AssetPath
```

这些后缀统一归一到 `metadata.cache_path`。

## 3. 链路闭合

本轮打通的链路：

```text
CSV/XLSX 或 JSON asset_items
-> metadata.cache_path
-> AssetsPanel 题图明细表显示缓存文件名与“缓存”状态
-> 选中行可预览缓存图
-> Workbench 注入 exam figure payload 时使用 cache_path 作为 path
-> Word 渲染缓存图
-> JSON/Markdown report 显示 assets=1/1
-> material manifest 保留 path="" + asset_id/source/cache_path
```

设计原则：

- 普通本地 `path` 优先，不改变既有本地素材行为；
- 当 `path` 为空或是远端 URL 时，才使用 `cache_path` 作为本地渲染路径；
- `asset_id/source` 不被缓存路径覆盖，继续保留远端资产身份；
- 若没有缓存路径，仍保持 N2.198 的远端引用行为：Word 不渲染，报告显示缺本地资产；
- 若缓存路径配置但文件缺失，仍进入现有缺文件/修复通道。

## 5. 仍未闭合的边界

N2.203 后，`advanced question asset library UI` 的剩余边界收窄为：

- 远端素材真实下载、鉴权、缓存刷新策略和无缓存预览；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
