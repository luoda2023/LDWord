# 高层场景能力矩阵 N2.192 考试题目图片前台映射摘要闭环

日期：2026-06-20

## 1. 目标

N2.191 已把多个逐题题图接入 `EntityProfile.asset_items`、批量导入和 `AssetsPanel.material_context()`，但前台仍有一个可见性断点：用户导入了 `题目图片1/2` 后，素材槽状态只显示单槽 `question_figure` 的默认文案，无法确认多题图是否已经被当前 profile 识别。

N2.192 闭合这一段：

```text
CSV/Excel repeated question figure import
-> EntityProfile.asset_items
-> AssetsPanel current editor state
-> question_figure slot status
-> image material summary label
```

它不是完整逐题素材编辑器；它只保证逐题题图导入后能在素材面板被用户看见和核对。

## 2. 落地内容

### 2.1 编辑器状态

`AssetsPanel` 新增当前编辑器级 `asset_items` 缓存：

- `set_archive()` / profile 切换会把 `EntityProfile.asset_items` 灌入编辑器；
- 批量导入后会刷新摘要；
- `_current_asset_items()` 会合并当前编辑器的结构化素材条目；
- `_persist_current_profile_editor()` 会把编辑器中的结构化素材条目写回 profile。

这修复了 N2.191 后的一个断点：导入 profile 虽然已经有 `asset_items`，但当前前台状态读取不到它。

### 2.2 题图槽位状态

当 `question_figure` 有多条素材时，槽位状态会显示：

```text
已配置 2 张题目图片 · 题图 2 张，图片说明 2/2 · 题1：question_1.png；题2：question_2.png
```

单张题图仍保持原来的“已选择：文件名”样式，避免扰动 logo、seal 等普通单槽素材。

### 2.3 图片材料总状态

图片材料总状态会追加逐题题图摘要：

```text
图片目录未选择，已识别 2 个材料；题图 2 张，图片说明 2/2。
```

这让用户无需进入隐藏 payload，就能确认导入素材已被识别。

## 3. 成熟度影响

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset frontstage mapping summary`；
- `family:exam_teaching` evidence 增加 `question asset frontstage mapping summary`；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮只是前台可见性摘要，不是逐题编辑器、缩略图预览器、缺项修复入口或远端素材库。

## 4. 边界

仍不承诺：

- 前台逐题表格化编辑；
- 单题缩略图预览、拖拽替换；
- 缺项修复入口；
- 远端 asset id/source 解析；
- 一题多图/图组排序；
- 复杂学科图和素材/AI 质量判断。

这些继续属于 `advanced question asset library UI`、插件或 manual boundary。
