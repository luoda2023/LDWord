# 高层场景能力矩阵 N2.221 考试题目图片远端共享缓存索引闭环

## 1. 本轮定位

N2.221 继续执行 V43 的 P0 高级考试素材库路线，在 N2.220 已经补齐单次运行缓存命中率摘要后，推进一个更接近批量/profile 场景的缓存治理断点：

```text
多个 profile 或多个输出目录可以声明同一个远端题图共享缓存目录，
但每次运行仍必须保留自己的输出索引、manifest 和报告证据。
```

本轮不是完整跨运行缓存管理面板，也不是后台失败重试或批量失效。它只完成“共享缓存目录可声明、缓存文件可复用、共享索引与本次运行索引可同时留痕”的首片。

## 2. 新增共享缓存声明

题图素材 metadata 或 `entity_data` 可声明以下任一字段：

```text
shared_cache_dir
sharedCacheDir
remote_cache_dir
remoteCacheDir
remote_asset_cache_dir
remoteAssetCacheDir
asset_cache_dir
assetCacheDir
cache_dir
cacheDir
```

解析规则：

- 绝对路径直接使用；
- 相对路径按当前输出目录解析；
- 未声明时仍使用 `<output_dir>/_remote_asset_cache`，保持旧行为。

## 3. 运行时链路

当声明共享缓存目录时：

- 下载文件写入共享目录；
- 共享目录写入自己的 `index.json`；
- 当前输出目录仍写入 `<output_dir>/_remote_asset_cache/index.json`；
- 当前输出目录的 material manifest 仍从本次运行索引生成 `remote_asset_cache` 摘要；
- index entry 写入 `cache_scope=shared` 与 `shared_cache_dir`；
- 资料包复制仍使用 metadata 中的 `cache_path`，可把共享缓存文件带入资料包。

此外，远端 URL 后缀可识别且共享缓存文件已存在时，运行时会在发起网络请求前直接命中缓存：

```text
shared cache file exists
-> cache_status=reused
-> download_status=cache_hit
-> Word 渲染继续使用共享缓存文件
-> 本次输出目录仍写入 index/manifest/report 证据
```

## 4. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote shared cache index bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“单次输出目录缓存摘要可读”推进到“多个 profile/输出目录可共享缓存文件，同时保留各自运行证据”。

## 5. 仍未闭合的边界

N2.221 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 深层缓存治理：共享缓存目录浏览、后台失败重试、批量失效、统一清理、跨运行缓存命中率面板；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
