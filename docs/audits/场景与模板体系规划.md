# 场景与模板体系规划

> 规划日期：2026-04-02
> 目标：梳理清楚"场景""模板""保存预设"的定义边界以及 UI 交互方案

---

## 一、当前问题

### 1.1 三套定义互不连通

| 文件 | 角色 | 状态 |
|------|------|------|
| `config/scene.py` → `SceneWorkspace` | 真实数据模型（28个模块开关+处理范围+细项配置） | ✅ 完整，但 UI 没用它 |
| `config/template.py` → `TemplateConfig` | 真实排版参数（字体/编号/页面/表格/页眉...） | ✅ 完整，但 UI 没用它 |
| `scene_presets.py` → `ScenePreset` | UI 展示层（纯展示，独立发明的数据类） | ❌ 与上面两个完全脱节 |

**结果**：用户在快速执行面板选了"论文排版"场景，实际上不会影响执行——因为 UI 层的 `ScenePreset` 和 Pipeline 用的 `SceneWorkspace` 不是一回事。

### 1.2 三个概念的定义混乱

用户看到的 UI 上写着"场景与模板"，但：
- **场景**到底管什么？开关？范围？还是都管？
- **模板**到底管什么？字体？编号？还是把一切都包了？
- **保存下来的东西**叫什么？预设？配置？会话？

## 二、概念重新定义

### 2.1 三个东西各管各的

```
场景（Scene）= 做什么事
├── 28个功能模块各自 ON/OFF
├── 处理哪些文档分区（正文/摘要/参考文献/...）
├── 结构策略（重建编号 or 保留原编号）
└── 细项配置（空白清洗的具体选项等）

模板（Template）= 文档长什么样
├── 页面设置（纸张/页边距）
├── 标题编号方案（第一章 vs 1. vs 一、）
├── 字体/字号/行距/缩进
├── 表格样式（三线表/全框线）
├── 页眉页脚样式
├── 题注格式
└── 目录参数

会话预设（Session Preset）= 一整套"当前工作状态快照"
├── 选的哪个场景
├── 选的哪个模板
├── 当时微调过的开关/分区覆盖
├── 输出目录
└── 输入文档路径（可选）
```

### 2.2 有了这三个概念，用户的操作流程

```
第一次使用：
  1. 拖入文档
  2. 选场景 → 自动匹配默认模板 + 预设一堆开关
  3. 选模板 → 自动应用对应排版参数
  4. （可选）展开高级调整，微调几个开关
  5. 执行
  6. 下次还要用同样的配置？→「保存为会话预设」

日常使用：
  1. 拖入文档
  2. 选一个之前保存的「会话预设」→ 一键恢复所有配置
  3. 执行
```

## 三、"保存预设"放在哪？

### 方案对比

| 方案 | 放在哪 | 优点 | 缺点 |
|------|--------|------|------|
| A. 场景与模板卡片内放"保存" | 场景选择器下方加个小按钮 | 所见即所得，保存入口近 | 卡片区域变拥挤 |
| B. 配置管理里放"保存" | 左侧导航"配置管理"面板 | 不干扰主流程，集中管理 | 多一步跳转 |
| **C. 混合（推荐）** | 场景卡片放"快速保存"，配置管理放"管理所有预设" | 操作快、管理也方便 | 需要两处维护 |


## 五、会话预设（Session Preset）

### 5.1 保存什么

```yaml
# 会话预设 JSON 示例
{
  "preset_name": "毕业论文-日常",
  "created_at": "2026-04-02T19:00:00",

  # 引用
  "scene_id": "thesis",
  "template_id": "thesis_gbt",

  # 微调覆盖（只记录与场景默认不同的部分）
  "overrides": {
    "module_switches": {
      "citation_link": false    # 这次不处理参考文献
    },
    "format_scope_sections": {
      "errata": true            # 这次加上勘误页
    },
    "strategy": "preserve"      # 这次保留原编号
  },

  # 执行上下文
  "output_dir": "D:/output/thesis/",
  "last_document": "D:/论文/毕业论文v3.docx"   # 可选
}
```

### 5.2 保存不保存的边界

| 保存 ✅ | 不保存 ❌ |
|---------|----------|
| 选的场景 ID | 实际执行进度和历史 |
| 选的模板 ID | 执行结果/报告 |
| 微调过的开关覆盖 | 临时的拖入文档 |
| 输出目录 | |
| 处理范围的微调 | |

## 八、模板编辑面板边界补充（2026-04-11）

本节只针对“模板编辑面板”本身，不讨论场景面板、执行面板或运行期专项能力。

模板编辑面板的正式范围限定为：

1. 页面设置
2. 正文排版
3. 标题编号
4. 表格
5. 页眉页脚与目录
6. 参考文献
7. 题注

以下能力不纳入模板编辑面板定义：

- 公式专项
- 引文链接专项
- 空白规范 / 清理策略
- 水印
- 输出产物开关

这些能力即使底层配置层暂时存在字段，也应优先视为场景层、专项面板或执行层职责，而不是模板编辑面板职责。

当前审阅结论（只针对模板编辑面板）：

- 已定义并已接入：页面设置、正文排版、标题编号
- 应有但当前缺失：表格、页眉页脚与目录、参考文献、题注
- 其他项不再视为模板编辑面板缺失项
