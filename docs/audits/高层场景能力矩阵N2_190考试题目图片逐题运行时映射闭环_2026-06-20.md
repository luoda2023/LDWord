# 高层场景能力矩阵 N2.190 考试题目图片逐题运行时映射闭环

日期：2026-06-20

## 1. 目标

N2.189 已把 `question_figure` 的全局图片说明编辑 UI 接到 Word altText 与报告链路，但高级考试素材库仍保留一个运行时断点：

```text
多个 question_figure AssetItem
-> 按 question_index / question_id 映射到具体题目
-> 注入 question.figure
-> Word 多图渲染
-> JSON/Markdown 资产与 altText 覆盖统计
-> material manifest 追溯
```

本轮只闭合“逐题运行时映射”。它不是完整逐题素材库 UI，也不承诺一题多图、素材库浏览、远端 asset id 服务或复杂学科图生成。

## 2. 落地内容

### 2.1 Workbench 注入逻辑

`WorkbenchProductionRunner` 现在会收集所有 `role=question_figure` 的 `AssetItem`，不再只取第一个。

每个素材可通过 metadata 指定目标题目：

- `question_index` / `questionIndex` / `index` / `order` / `position`：按 1-based 题序映射；
- `question_id` / `questionId` / `question_key` / `question_no` / `number` / `no` / `id`：按题目身份字段映射。

没有指定目标的素材仍按原兼容行为顺序填充缺图题目；已有 `question.figure` 的题目不会被覆盖。

### 2.2 题图 payload

注入后的 `question.figure` 会保留：

- `source`
- `path`
- `asset_id`
- `alt`
- `title`
- `caption`

其中 `alt` 继续复用 N2.188/N2.189 的 altText 链路，`asset_id` 优先来自 metadata，其次来自 `AssetItem.item_id`，最后回落到 `question_figure`。

### 2.3 报告与 manifest

多个逐题图片注入后仍走既有 exam runtime/report：

- `question_asset_count`
- `rendered_question_asset_count`
- `missing_question_asset_count`
- `rendered_question_asset_alt_text_count`
- `missing_question_asset_alt_text_count`
- Markdown `assets=<rendered>/<total>` / `altText=<with_alt>/<rendered>`

material manifest 会保留每个 `asset_items[].metadata`，因此可追溯每张题图映射到了哪个题目。

## 3. 成熟度影响

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset per-question runtime mapping`；
- `family:exam_teaching` evidence 增加 `question asset per-question runtime mapping`；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮证明运行时消费者已支持逐题映射，但用户可见的逐题素材编辑、素材库浏览与预览、缺项修复入口、远端 asset id/source 和一题多图仍没有产品化。

N2.191 已继续把多个 `question_figure` 的来源前推到 `EntityProfile.asset_items`、实体档案 JSON 和 CSV/Excel 重复列导入。后续高级素材库缺口因此不再包含“多题图只能手写 runtime payload”，而是前台逐题素材编辑/预览、素材缺项修复入口、远端 asset id/source、一题多图/图组排序、复杂学科图和素材/AI 质量边界。

## 4. 边界

仍不承诺：

- 前台逐题拖拽或表格化编辑；
- 一题多图、图组排序和图注版式；
- 素材库浏览、预览、搜索、远端 id 解析；
- 自动判断题图和题意是否一致；
- 自动生成复杂学科图；
- AI 题目或素材质量判断。

这些继续属于 `advanced question asset library UI`、插件或 manual boundary。
