# 高层场景能力矩阵 N2.186 考试题目素材运行时渲染闭环

日期：2026-06-20

## 1. 目标

N2.185 之后，`exam_education` / `exam_teaching` 的固定版式答题卡已经进入运行时、报告和 fixed-layout profile 审计，但考试教学仍保留一个 L5 blocker：题目素材替换 UI。

本轮不直接完成前台素材替换 UI，而是先补齐它下方最关键的运行时断点：结构化题源中的本地题目图片必须能进入 Word 交付版本，并在报告中留下可审计的渲染统计。否则即使后续做了 UI，也没有执行消费者和报告证据。

本轮闭合链路：

```text
question.figure.path
-> schema figure validation
-> Word version image insertion
-> ExamRenderedVersion asset counts
-> JSON/Markdown report
-> product maturity domain narrowing
```

## 2. Word 与结构化源视角

题目素材不属于普通段落样式，也不属于固定行高。它的承载层是 `exam_items_v1` 的结构化题源和 `question_figure` asset role。

| 输入字段 | 含义 | 本轮处理 |
| --- | --- | --- |
| `question.figure.path` | 本地题目图片路径 | 题干可见版本中插入 Word 图片 |
| `question.figure.asset_path` | 等价本地素材路径 | 作为 fallback 路径读取 |
| `question.figure.asset_id` | 素材 id 或可解析路径 | 仅当能解析为本地文件时插入 |
| `question.figure.alt` | 图片说明 | 保留为结构化元数据，暂不承诺 Word altText UI |

本轮只处理本地可解析图片文件。复杂几何图、电路图、化学结构式、AI 生成图和素材质量判断仍属于 plugin/manual boundary，不进入核心自动承诺。

## 3. 落地内容

`src/shared/engine/exam_question_schema.py`：

- `ExamRenderedVersion` 新增：
  - `question_asset_count`；
  - `rendered_question_asset_count`；
  - `missing_question_asset_count`。
- `_render_exam_version_docx()` 在题干可见时调用 `_render_question_figures()`；
- 学生版、教师版等题干可见版本会插入本地图片；
- `answer_key`、`analysis_version` 隐藏题干时不插入题目图片；
- `answer_sheet` 作为固定版式答题区，不插入题目图片。

`src/report_writer.py`：

- JSON 报告保留每个 rendered version 的素材统计；
- Markdown 报告在版本行追加 `assets=<rendered>/<total>`；
- 如果素材路径缺失或图片不可读，会记录 `missing_assets=<n>`。

## 5. 边界

仍不承诺：

- 自动生成复杂学科图；
- 判断图片内容是否正确；
- 把 `asset_id` 接到完整素材库或远端存储；
- 在 Word 中写入完整 altText/可访问性属性；
- 给答题卡插入题目图片。

后续高级 UI 应接到同一条 runtime/report 字段，不能另起一套只在前台存在的素材状态。
