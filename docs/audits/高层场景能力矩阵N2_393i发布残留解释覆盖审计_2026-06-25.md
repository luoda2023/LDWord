# 高层场景能力矩阵 N2.393i 发布残留解释覆盖审计

## 背景

N2.393c 到 N2.393h 已经把 static-closed、dashboard warning、retained gaps、warning 来源级、gap domain 等残留读数补成成对发布表达。为了防止未来新增 warning/gap/blocker 后只出现裸计数，本轮新增 `scene_release_residual_explanation_audit`，并以 `SCENE_RELEASE_RESIDUAL_EXPLANATION_SPECS` 把所有允许保留的非零 residual 读数集中成一张覆盖总表。

本轮发布读数：`residual_explanations=14/14 covered`。

## 审计规则

`scene_release_residual_explanation_audit` 对每个 residual row 做两类检查：

- `residual_count == governed_count`；
- `scripts/verify_scene_matrix_release_gate.py` 中存在对应 `summary_marker`。

如果未来新增非零残留读数但没有添加成对治理表达，或者 release gate 摘要没有展示 marker，本审计应失败。

## 链路

```text
source audits
  -> scene_release_residual_explanation_audit
  -> verify_scene_matrix_release_gate.py: residual_explanations=14/14 covered
  -> scene_matrix_dashboard / scene_summary_projection: 14/14 residual explanations
  -> tests/test_scene_release_residual_explanation_audit.py
```

## 非目标

本轮不消除 residual，也不把 Blue/Boundary 主体升级为 Green/L5。它只建立发布残留解释覆盖审计，保证 residual 不再以裸读数方式漂移。
