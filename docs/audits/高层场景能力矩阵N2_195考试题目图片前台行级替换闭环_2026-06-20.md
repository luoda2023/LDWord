# 高层场景能力矩阵 N2.195 考试题目图片前台行级替换闭环

日期：2026-06-20

## 1. 目标

N2.194 已经让用户选中逐题题图明细行后预览该题图片，但仍有一个高频操作断点：

```text
发现第 2 题图片不对
-> 只能回 CSV/Excel 或重新导入资料包
-> 不能在当前明细行直接替换这一题图片。
```

N2.195 闭合这段前台替换链路：

```text
question_figure detail row
-> 替换按钮
-> QFileDialog 选择新图片
-> 更新 EntityProfile.asset_items[n].path
-> refresh summary/table/preview
-> MaterialExecutionContext 使用新路径
```

它不是完整素材库编辑器；本轮只保证一行一题的本地图片替换可落入结构化素材条目。

## 2. 落地内容

### 2.1 明细表新增处理列

`question_figure_asset_items_table` 从四列扩展为五列：

```text
题目 / 图片 / 说明 / 状态 / 处理
```

每行的“处理”列提供“替换”按钮。按钮只作用于当前行，不影响其他题图。

### 2.2 替换结构化素材条目

新增 `_replace_question_figure_item_path(row_index, path)`：

- 根据当前行定位对应 `question_figure`；
- 优先按 `item_id` 匹配 `EntityProfile.asset_items`；
- 其次按题号 metadata 匹配；
- 最后按旧 path 匹配；
- 只更新该条 payload 的 `path`；
- 保留 `metadata.question_index` 和 `metadata.alt_text`；
- 写回当前 profile 并刷新 summary/table/preview。

这保证替换后的新图会继续进入 N2.190 的逐题运行时映射，不需要新建运行时分支。

### 2.3 成熟度证据

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset frontstage row replacement`；
- `family:exam_teaching` evidence 增加 `question asset frontstage row replacement`；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮只支持单题本地图片替换，不包含缺项修复入口、远端素材、图组排序或复杂学科图插件。

## 3. 与 V42 的关系

N2.195 是 V42 `QuestionAssetLibrary` 槽位的继续补强。它把前台链路推进为：

```text
题图导入
-> 映射明细
-> 选中单题
-> 预览该题图片
-> 替换该题图片
-> 运行时继续按题号消费新路径
```

这让用户能在 AssetsPanel 内完成最基础的“发现错图并替换”闭环。

## 4. 仍保留的边界

仍不承诺：

- 缺项修复入口；
- 远端 `asset_id` / `source` 解析；
- 一题多图或图组排序；
- 批量自动匹配错图；
- 复杂学科图自动生成；
- AI 出题质量或素材质量判断。

这些继续属于 `advanced question asset library UI`、插件能力或 manual boundary。
