# 高层场景能力矩阵 N2.303 考试题目图片素材库远端写回批量回滚冲突字段合并闭环

## 1. 背景

N2.302 已经把批量回滚/二次补偿前的远端当前快照校验接入执行闸口。新的剩余风险是：当远端当前值已经被第三方修改时，系统只能把回滚标记为冲突并要求人工复核，尚不能在不覆盖第三方全部改动的前提下完成部分字段回滚。

本轮闭合“批量回滚冲突字段合并”。它不做后台任务、manifest 或独立 drilldown；只承诺 current snapshot 冲突进入回滚失败队列后，可以按字段选择“回滚值”或“远端当前值”，生成合并后的回滚写回请求，并以 batch rollback execution 审计记录沉淀。

## 2. 已闭合能力

- 回滚失败队列识别 `current_snapshot_status=changed` 的冲突项。
- current snapshot 冲突项的下一步从普通“人工复核后重试回滚”细化为“合并字段后回滚”。
- current snapshot 冲突项动作变为“合并字段 / 重试回滚 / 定位报告”。
- 新增回滚字段合并对话框，控件样式复用模板管理同源输入框、按钮 variant 和尺寸规范。
- 字段来源使用 `rollback` / `remote`，并兼容旧调用中的 `local=rollback`。
- 字段合并要求至少同时选择一个回滚值和一个远端当前值，避免把“全量回滚”或“放弃回滚”伪装成字段合并。
- 合并后的 metadata 默认以回滚值为基础，冲突字段按用户选择覆盖为远端当前值。
- 新增 `question_figure_library_remote_writeback_batch_rollback_field_merge` connector payload。
- payload 保存 transaction report、transaction execution、plan signature、原始 rollback target、remote current、rollback_from、field_sources 和稳定幂等键。
- 幂等键使用 `qfig-rollback-merge-*`，包含 report、endpoint、rollback item 和字段来源。
- 字段合并执行结果仍写入 `question_figure_library_remote_writeback_batch_rollback_execution`，保持与批量回滚成功项、失败队列和事务报告联动。
- result item 保留原始 `rollback_*` 作为 pending/success 归并 key，同时新增 `merged_rollback_*`、`rollback_field_merge_sources`、`rollback_conflict_resolution_action` 和 `execution_connector`。
- 合并成功后原 current snapshot 冲突项从回滚失败队列退场，事务报告显示回滚已执行。

## 3. 测试锁定

- 新增 `_RollbackCurrentConflictSimpleHTTPRequestHandler`，模拟 `/current/1` 返回第三方已修改的远端当前值。
- 新增 `test_assets_panel_merges_remote_writeback_batch_rollback_current_conflict`：
  - 批量写回成功 1 项、异常 1 项；
  - 回滚前 current snapshot GET 发现远端值已变更，不发送普通回滚 POST；
  - 回滚失败队列出现“合并字段”动作；
  - 字段选择 `asset_id=rollback, alt_text=remote` 后执行合并回滚；
  - POST payload 的 metadata 为回滚值与远端当前值的混合结果；
  - 成功后失败队列退场，报告表回到“回滚已执行”。

## 4. 模型与成熟度变化

- `scene_product_readiness` 在 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback batch rollback conflict field merge UI bridge` evidence。

- `family:exam_teaching` 的 remaining gap 从 `advanced asset library remote writeback batch rollback conflict field merge governance UI` 收窄为 `advanced asset library remote writeback batch rollback manifest drilldown governance UI`。
