# 高层场景能力矩阵 N2.348 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复非题图素材族修复历史 Word 输出远端冲突裁决复核后重试重放闭环

## 1. 定位

N2.347 已经把 `rollback_execution_review_required` 推进为人工远端状态复核，并把无异常副作用的项释放为 `retry_or_replay_handoff_ready_after_review`。本轮 N2.348 补齐复核后的幂等 retry/replay 执行：前台不再停在 reviewed 状态，而是可以真实重放原远端冲突裁决，并把重放结果归档为独立 manifest。

## 2. 本轮闭环

- `remote_state_review_completed` 状态下表格提供 `Replay`、`Manifest`。
- `Replay` 复用原 non-question asset family remote conflict decision connector，重放原 `overwrite_remote` / `keep_remote_upload_new_version` / `abandon_local` 决策。
- 重放沿用原 decision id 与 idempotency key 生成规则，记录 retry attempt、HTTP 状态、decision status 和 underlying decision manifest。
- replay manifest 独立写入 `artifacts/subscription_drift_non_question_asset_family_word_output_remote_conflict_decision_retry_replays`。
- replay metadata 回写到相关 profile 的 asset item，成功后表格状态推进为 `replayed`。
- `Manifest` 优先级调整为 replay > review > execution > queue > decision > connector。

## 3. 链路变化

复核后重放链路现在变为：

```text
... -> Queue -> Execute -> Review -> Replay -> Manifest
```

其中 `Replay` 是真实远端裁决重放节点；如果重放成功，记录 `retry_replay_after_review_completed`。如果重放仍失败、权限不足或再次冲突，则进入后续失败补偿队列。
