# 高层场景能力矩阵 N2.235 考试题目图片远端缩略图前台预览闭环

## 1. 背景

N2.234 已经让共享缓存命中率历史在 AssetsPanel 中可见。剩余高级素材库边界里仍有“远端缩略图/下载前预览”。完整能力需要真实素材库 API、缩略图服务、授权续期和 UI 下载策略，不能一次性伪装完成。

本轮先闭合受控本地缩略图路径首片：当远端题图素材的 metadata 已提供本地缩略图路径时，AssetsPanel 能在题图表中展示缩略图文件名、状态和预览，不触发隐式联网下载。

## 2. 闭合范围

本轮闭合：

- `AssetItem.metadata` 支持本地缩略图路径作为预览 fallback；
- 支持 `thumbnail_path`、`thumbnail_cache_path`、`thumbnail_local_path`、`remote_thumbnail_path`、`remote_thumbnail_cache_path`、`preview_path` 等字段及 camelCase 变体；
- CSV/XLSX 导入支持 `questionFigureNThumbnailPath`、`questionFigureNPreviewPath` 等列进入 `thumbnail_path`；
- AssetsPanel 题图表在主图和缓存都不可用但缩略图可用时显示缩略图文件名；
- 题图状态显示“缩略图”；
- 选中该题图行后，右侧预览区显示缩略图；
- 成熟度矩阵补入 remote thumbnail preview UI evidence。

本轮不做：

- UI 刷新时直接访问远端 URL；
- 下载前实时拉取远端缩略图；
- 缩略图 URL 授权、续期和签名；
- 远端素材库服务端 thumbnail API；
- 缩略图与主图内容一致性判断。

## 3. 字段链路

受控路径字段：

```text
thumbnail_path
thumbnailPath
thumbnail_cache_path
thumbnailCachePath
thumbnail_local_path
thumbnailLocalPath
remote_thumbnail_path
remoteThumbnailPath
remote_thumbnail_cache_path
remoteThumbnailCachePath
preview_path
previewPath
preview_cache_path
previewCachePath
```

导入列示例：

```text
questionFigure2ThumbnailPath
questionFigure2PreviewPath
```

导入后统一写入：

```text
metadata.thumbnail_path
```

预览优先级：

```text
本地主图存在 -> 本地缓存存在 -> 本地缩略图存在 -> 原始 path/cache_path 文本
```

因此缩略图不会被误当作已下载主图，只作为前台检查远端素材的受控预览。

## 5. 仍未闭合的边界

N2.235 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API 登录、续期、签名 URL 与 UI 授权入口；
- 跨 profile 后台定时清理、前台确认 UI 和任务历史列表 UI；
- 断点续传、后台队列、并发下载调度；
- 完整跨运行缓存命中率趋势面板 UI，包括图表、筛选和跨 profile 聚合；
- 真实远端缩略图服务、缩略图 URL 授权续期和下载前联网预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图或 AI 质量判断；
- 素材库版本、历史审阅、版权真实性和批量审阅 UI。
