# 高层场景能力矩阵 N2.306 考试题目图片素材库远端写回批量回滚补偿并发限流取消重试治理闭环

本轮闭合 N2.305 后的 `concurrency/limit/cancel/retry governance` 缺口首片：在题目图片素材库远端写回的批量回滚、回滚冲突字段合并、二次补偿执行链路中加入统一任务治理策略。它不声明真正后台 worker、分布式队列、异步恢复或自动 OAuth/SSO 续期已经完成；它承诺前台策略控件能进入执行判断、远端 payload、执行审计、任务表和 manifest。

## 已闭合内容

- 题图素材库远端授权区下新增“远端任务治理”控件组：固定并发 `1`、每轮批量上限、重试上限、退避秒数、暂停回滚/补偿。
- 控件样式复用模板/场景同源契约：`QSpinBox` 走 `build_text_input_stylesheet(..., selector="QSpinBox")`，暂停开关走 `build_checkbox_stylesheet`，并统一 size class。
- 批量回滚执行前读取策略：暂停时不发起远端请求、不写入伪执行记录；批量上限会裁剪候选；重试上限在 GET current snapshot / POST rollback 前拦截。
- 回滚冲突字段合并同样受暂停与重试上限治理，避免主回滚受控而合并链路绕过策略。
- 二次补偿执行复用同一策略：暂停、批量上限、重试上限均在执行前生效。
- 执行记录新增 `task_governance_status`、`task_concurrency_limit`、`task_batch_limit`、`task_retry_limit`、`task_backoff_seconds`、`task_cancel_requested`、候选数前后变化、限流数量和 `task_policy_summary`。
- result item 保留同一策略字段，并记录 `task_policy_item_status` 与 `task_retry_limit_exceeded`。
- rollback、field merge、second compensation payload 均新增 `task_policy`，让远端 connector 能看到本次前台治理策略。
- manifest payload 在 rollback/second compensation execution 摘要层投影 `task_policy`，不需要展开每个 result item 才能审计策略。
- 后台任务治理表的 rollback/second compensation 行在治理列追加策略摘要。
- `scene_product_readiness` 在 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback batch rollback concurrency limit cancel retry governance UI bridge` evidence。

- `family:exam_teaching` 的 remaining gap 从 `advanced asset library remote writeback batch rollback concurrency limit cancel retry governance UI` 收窄为 `advanced asset library remote writeback enterprise auth signed URL organization permission governance UI`。

## 仍不宣称完成

- 真正后台 worker / 队列调度、任务锁、断点续跑、自动失败重放。
- 指数退避的真实定时调度；当前 `backoff_seconds` 是策略留痕，不会 sleep 阻塞前台。
- OAuth/SSO 登录、token 自动续期、签名 URL 自动续签。
- 组织/角色/题库权限审批与企业权限主数据。
- 跨资料包素材主数据版本系统。
