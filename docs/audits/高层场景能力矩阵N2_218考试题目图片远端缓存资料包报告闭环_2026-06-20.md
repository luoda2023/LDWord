# 高层场景能力矩阵 N2.218 考试题目图片远端缓存资料包报告闭环

## 1. 本轮定位

N2.218 继续执行 V43 的 P0 高级考试素材库路线，在 N2.217 已经把远端题图缓存图片和 `_remote_asset_cache/index.json` 放入 material package 后，补齐人类可读 artifact 断点：

```text
archive_report.md 需要直接说明远端缓存索引的状态，而不是只列出包内存在 remote_asset_cache/index.json。
```

本轮不是全局缓存统计面板，也不是素材库 UI。它只让资料包报告能够被人工审阅、归档系统或 artifact drilldown 直接读懂。

## 2. 报告新增段落

当 `package_manifest.json` 包含 `remote_asset_cache.present=true` 时，`archive_report.md` 新增：

```text
## Remote Asset Cache

- Entries: 1
- Source index: C:/output/_remote_asset_cache/index.json
- Package index: remote_asset_cache/index.json
- Cache key types: download_url=1
- Cache statuses: downloaded=1
- Download statuses: downloaded=1
- Content types: image/png=1
```

该段落使用稳定 ASCII 文本，便于测试、搜索和后续 artifact browser 解析。

## 3. 产品意义

N2.218 把远端缓存资料包从“文件齐全”推进到“报告可读”：

- 用户打开 `archive_report.md` 即可知道远端缓存条目数；
- 用户能看到包内缓存索引路径；
- 用户能看到下载、复用、304 复用等状态计数；
- artifact drilldown 后续可以直接定位 `Remote Asset Cache` 段；
- 资料包归档不必先打开 JSON 才知道远端题图缓存状态。

## 4. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cache package report bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“资料包携带缓存图片和索引”推进到“资料包报告可解释远端缓存状态”。

## 5. 仍未闭合的边界

N2.218 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 深层缓存治理：跨 profile 共享缓存索引、后台失败重试、批量失效、统一清理、全局命中率统计；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
