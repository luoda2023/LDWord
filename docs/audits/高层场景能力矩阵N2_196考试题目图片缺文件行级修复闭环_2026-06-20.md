# 高层场景能力矩阵 N2.196 考试题目图片缺文件行级修复闭环

日期：2026-06-20

## 1. 目标

N2.195 已经支持在逐题题图明细行替换本地图片，但仍需要补一个更高频、更接近修复语义的路径：

```text
CSV/Excel 导入了题目图片2
-> 路径不存在
-> 前台明细表显示“缺文件”
-> 用户在同一行替换为可用图片
-> profile 和 material context 使用新路径。
```

N2.196 闭合这段缺文件行级修复链路。它不是完整 issue queue repair target；本轮只证明已进入前台明细表的缺文件题图，可以在同一行被修复。

## 2. 落地内容

### 2.1 缺文件行保持可见

当前 `_question_figure_asset_items()` 会保留非空 path，即使文件不存在。`_question_figure_detail_rows()` 会按本地文件存在性显示：

```text
可用 / 缺文件
```

因此导入了失效路径的 `question_figure` 不会从明细表消失，用户能看到哪一道题缺图。

### 2.2 同行替换修复

缺文件行继续复用 N2.195 的“替换”按钮：

- 选择可用图片；
- 更新对应 `EntityProfile.asset_items[n].path`；
- 保留 `metadata.question_index` 和 `metadata.alt_text`；
- 刷新明细表状态，从“缺文件”变为“可用”；
- 预览区显示修复后的图片；
- `MaterialExecutionContext.asset_items` 读取新路径。

### 2.3 成熟度证据

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset missing-file row repair`；
- `family:exam_teaching` evidence 增加 `question asset missing-file row repair`；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮只是明细表内的行级修复，不包含从报告 issue queue 自动跳转到缺图行、远端素材解析、一题多图或复杂图插件。

## 3. 与 V42 的关系

N2.196 是 V42 `QuestionAssetLibrary` 和 `RepairConfirmation` 的交叉首片。它把前台链路推进为：

```text
题图导入
-> 映射明细
-> 缺文件状态
-> 同行替换修复
-> material context 使用修复后路径
```

这让“缺文件”不再只是状态文本，而是可在当前表格中修复的用户动作。

## 4. 仍保留的边界

仍不承诺：

- 报告 issue queue 自动跳转缺图行；
- 远端 `asset_id` / `source` 解析；
- 一题多图或图组排序；
- 批量自动匹配错图；
- 复杂学科图自动生成；
- AI 出题质量或素材质量判断。

这些继续属于 `advanced question asset library UI`、插件能力或 manual boundary。
