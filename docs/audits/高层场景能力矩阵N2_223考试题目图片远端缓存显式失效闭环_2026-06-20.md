# 高层场景能力矩阵 N2.223 考试题目图片远端缓存显式失效闭环

## 1. 本轮定位

N2.223 继续执行 V43 的 P0 高级考试素材库路线，承接 N2.221/N2.222 已经打通的共享缓存目录、共享索引和目录摘要。

本轮只实现单项题图的显式缓存失效与重拉，不把它扩大成完整缓存管理器。它解决的是：

```text
用户明确声明某道题图的远端缓存不再可信时，
运行链路不能继续命中旧缓存，
而要先清理旧缓存文件和索引痕迹，再按远端 URL 重新下载。
```

这与 `force_refresh` 的语义不同：
- `force_refresh` / `cache_refresh` 是刷新旧缓存，刷新失败时可保留旧缓存作为回退；
- `cache_invalidate` / `invalidate_cache` 是声明旧缓存失效，本轮不再继续复用旧 `cache_path`；
- 目录级浏览、后台重试、批量失效、统一清理、缓存版本治理仍属于后续素材库治理 UI。

## 2. 新增参数语义

题图 `metadata` 新增显式失效开关识别：

```text
cache_invalidate / cacheInvalidate
invalidate_cache / invalidateCache
cache_purge / cachePurge
purge_cache / purgeCache
cache_clear / cacheClear
clear_cache / clearCache
```

真值包括：

```text
1 / true / yes / y / on / force / forced / invalidate / invalidated / purge / clear / delete / always
```

命中后运行时写入：

```text
cache_invalidation_reason=manual
cache_invalidation_status=removed|not_found|skipped
cache_invalidation_removed_count
cache_invalidation_missing_count
cache_invalidation_skipped_count
cache_invalidation_index_removed_count
```

若显式失效发生，本轮会从 metadata 中移除旧 `cache_path`，即使后续下载失败，也不把旧缓存当作有效回退。

## 3. 运行链路

`_material_context_with_remote_question_asset_cache()` 的新链路为：

```text
question_figure item
-> 解析 cache_dir / shared_cache_dir
-> 解析 cache_invalidate
-> 根据 download_url、cache_path、cache index 反查候选缓存文件
-> 只删除目标缓存目录内的图片缓存文件
-> 从 index.json 摘除旧条目
-> 清空本轮旧 cache_path
-> _download_remote_question_asset(..., refresh=True)
-> 写回 cache_path / cache_status / download_status
-> 双写共享 index 与当前输出 index
```

安全边界：
- 不删除 `cache_dir` 外部的任意文件；
- 不删除 `index.json` 自身；
- 只删除支持的图片后缀缓存文件；
- 若只提供了远端 URL 且 URL 后缀可识别，会按缓存命名规则定位旧文件；
- 若 URL 后缀不可识别，则可通过旧 index 的 `cache_path` 反查缓存文件。

## 4. Manifest / Report 输出

远端缓存 index entry 新增：

```text
cache_invalidation_status
cache_invalidation_reason
cache_invalidation_removed_count
cache_invalidation_index_removed_count
```

`remote_asset_cache` 摘要新增：

```text
cache_invalidation_status_counts
```

资料包报告 `## Remote Asset Cache` 段新增：

```text
Invalidation statuses: removed=1
```

这使用户可以从 material manifest、缓存 index、资料包报告三处确认本次运行是否发生了显式失效重拉。

## 6. 仍未闭合的边界

N2.223 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 共享缓存目录浏览 UI；
- 批量失效、统一清理、按题型/学科/来源批量治理；
- 后台失败重试、断点续传、并发下载队列；
- 跨运行缓存命中率趋势面板；
- token 续期、签名 URL 更新、401/403 后重新授权；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图生成；
- 素材库版本、历史审阅、版权/真实性/AI 质量边界。
