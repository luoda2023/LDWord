# 高层场景能力矩阵 N2.285 考试题目图片素材库远端写回幂等重试冲突分类闭环

日期：2026-06-21

## 1. 本轮定位

N2.285 承接 N2.284 的题图素材库远端写回执行 connector。上一轮已经能在具备 `writeback_url`、版本未变且授权 Header 可用时执行一次 HTTP JSON POST，但失败后的治理仍过粗：没有稳定幂等键、没有重试尝试审计，也不能区分普通失败和远端版本冲突。

本轮补“幂等、重试审计、远端冲突分类”首片：执行请求带稳定 `Idempotency-Key`，审计记录写入 `writeback_retry_attempt`，HTTP 409/412 会归类为 `remote_conflict`，前台状态显示为“远端冲突”并停止直接重试。

## 2. 已闭合能力

- 写回执行请求新增稳定 `Idempotency-Key` Header。
- 幂等键由 endpoint、题图条目、题号、asset_id、来源历史时间和交接时间派生。
- 写回 payload 新增 `writeback_idempotency_key`。
- 写回 payload 新增 `writeback_retry_attempt`。
- 执行审计记录新增 `writeback_idempotency_key`。
- 执行审计记录新增 `writeback_retry_attempt`。
- 同一来源历史记录和 endpoint 的重复执行会递增 retry attempt。
- HTTP 409 / 412 会写为 `writeback_status=remote_conflict`。
- 远端冲突审计保留 HTTP 状态、错误摘要和冲突摘要。
- 远端写回交接表识别 `remote_conflict` 并显示“远端冲突”。
- “远端冲突”行只保留定位动作，不继续给直接执行按钮。
- 普通失败仍保留“执行写回”入口，为后续失败队列/重试策略留出路径。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback retry idempotency conflict classification bridge` evidence。
- 成熟度剩余 gap 从 `advanced question asset library remote writeback retry conflict governance` 细化为 `advanced question asset library remote writeback conflict resolution UI`。

## 3. 链路视角

```text
handoff_ready record
  -> current metadata still matches history after-values
  -> writeback_url exists
  -> derive stable idempotency key
  -> count previous execution attempts
  -> HTTP JSON POST with Idempotency-Key
  -> success / failed / remote_conflict audit
  -> refresh table status
```

这条链路补的是“写回失败治理的基础事实”。N2.284 解决可执行；N2.285 让重复执行可追踪、请求具备幂等键、远端版本冲突不再混入普通失败。

## 4. 场景矩阵影响

`exam_education` 与 `exam_teaching` 的高级题图素材库路线继续收窄：

- 按题索引可见性由 N2.277 闭合；
- 单题 metadata 编辑由 N2.278 闭合；
- 高频 metadata 治理问题清单由 N2.279 闭合；
- 批量治理计划 UI 由 N2.280 闭合；
- 本地版本历史 UI 由 N2.281 闭合；
- 本地版本回滚 UI 由 N2.282 闭合；
- 远端写回交接 UI 由 N2.283 闭合；
- 远端写回执行 connector 首片由 N2.284 闭合；
- 幂等键、重试尝试审计和远端冲突分类由 N2.285 闭合；
- 后续 remaining gap 明确转为 `advanced question asset library remote writeback conflict resolution UI`。

这意味着后续不能再把“没有幂等键、没有 retry attempt、没有远端冲突分类”重复计算为 L5 blocker。真正剩余的是冲突解决 UI、权限续期、签名续签、失败队列、批量事务和远端回滚。

## 5. 仍不宣称完成的边界

- 不做远端冲突合并 UI。
- 不做远端版本 diff 或远端当前值拉取。
- 不做冲突时覆盖远端/放弃本地/合并字段的人工裁决。
- 不做素材库登录态续期。
- 不做签名 URL 自动续签。
- 不做失败队列、指数退避或后台重试。
- 不做批量事务、幂等窗口管理或重复提交防护中心。
- 不做远端回滚。
- 不做跨资料包素材主数据版本系统。

本轮只承诺：单项远端写回具备稳定幂等键、重试尝试审计和远端冲突分类，并保持运行时 metadata 干净。
