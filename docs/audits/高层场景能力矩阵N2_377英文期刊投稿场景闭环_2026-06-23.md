# 高层场景能力矩阵 N2.377：英文期刊投稿场景闭环

## 1. 当前执行位置

本轮 N2.377 继续处理剩余非边界型高频组：

- `pack:english_journal`
- `family:journal_en`

原剩余缺口：

- `english_journal`：reviewed journal profile updates、full submission package depth
- `journal_en`：reviewed journal source updates、submission artifact depth

## 2. 本轮实现内容

### 2.1 MaterialSchema

`journal_submission_materials_v1` 新增可选字段：

- `target_journal_profile_id`
- `reviewed_rule_source_id`
- `submission_package_manifest`
- `citation_source_manifest`
- `publisher_boundary_note`

这些字段用于把目标期刊 profile、reviewed rule source、投稿包 manifest、BibTeX/CSL 来源和 publisher 边界写进资料包证据链。它们不改变原有必填字段，也不让系统自动信任未审的出版社规则。

### 2.2 Sample Fixture

英文期刊 fixture 增强：

- `english_journal_revision_comments` 增加 `reviewed_journal_profile_update`、`submission_artifact_manifest`
- `english_journal_bibtex_csl_degraded` 增加 `reviewed_journal_profile_update`、`submission_artifact_manifest`
- `english_journal_publisher_rule_manual_boundary` 增加 `reviewed_journal_profile_update`、`submission_artifact_manifest`

原有 `citation_source_report`、`journal_submission_package`、`journal_rule_source_governance`、`plugin_manual_gate` 继续保留。

### 2.3 场景概览投影

新增 `build_journal_submission_evidence_summary_items(scene)`，并接入 `build_scene_overview_summary_items(scene)`。

它会在 `english_journal` / `journal_en` 场景中显示：

- schema：`journal_submission_materials_v1`、`journal_materials_v1`
- reports：`journal_rule_source_governance`、`reviewed_journal_profile_update`、`citation_source_report`、`journal_submission_package`、`submission_artifact_manifest`、`plugin_manual_gate`
- rules：`journal_submission_reviewed_generic_rules`
- fixtures：`english_journal_revision_comments`、`english_journal_bibtex_csl_degraded`、`english_journal_publisher_rule_manual_boundary`

### 2.4 产品成熟度

以下 subject 已升级为 Green/L5：

- `pack:english_journal`
- `family:journal_en`

升级后的边界：

- reviewed generic profile 可以作为产品默认能力。
- 目标出版社/期刊专属规则必须经过 reviewed source update 才能严格执行。
- publisher-final layout 不属于核心承诺。
- response letter 或出版社规则不确定时仍进入 manual/plugin gate。
