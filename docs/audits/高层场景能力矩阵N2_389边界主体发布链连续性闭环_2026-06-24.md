# 高层场景能力矩阵 N2.389 边界主体发布链连续性闭环

## 背景

N2.380-N2.388 已经把发布残余逐层治理到 trace、subject dossier、non-subject attribution、partition guard 与 projection parity。继续审阅后，仍有一个更细的软断链风险：同一个 Blue/Boundary subject 可能在 maturity、guarded completion、readiness reconciliation、terminal release trace 或 subject dossier 中某一层缺席，但总体计数仍看起来正确。

本轮补 `boundary_subject_release_continuity`：证明 6 个边界主体在发布链五层中是同一批主体，而不是各层各算各的。

## 守门口径

每个 subject 必须同时出现在：

- `scene_product_maturity_upgrade_audit` 的 Blue/Boundary maturity row。
- `scene_boundary_guarded_completion_audit` 的 guarded completion row。
- `scene_boundary_readiness_reconciliation_audit` 的 linked boundary subject。
- `scene_terminal_release_exception_audit` 的 row-level trace linked boundary subject。
- `scene_boundary_subject_release_dossier_audit` 的 subject dossier row。

## 打通范围

- 审计模块：`src/config/scene_boundary_subject_release_continuity_audit.py`
- 导出脚本：`scripts/export_scene_boundary_subject_release_continuity_audit.py`
- Release gate：新增 `scene_boundary_subject_release_continuity_audit` check，并输出 `scene_boundary_subject_release_continuity_*` 计数。
- Dashboard：新增 `boundary_subject_continuity` 卡片，并把本审计纳入 boundary、evidence chain、product readiness 视角。
- Drilldown：新增 `boundary_subject_release_continuity` 明细源，6 行逐 subject 展示五层是否齐全。
- Summary projection：Boundary、Evidence、Readiness 与 Matrix drilldown 摘要展示 `6/6 subject continuity` 与 `0 subject continuity gaps`。
- CI：纳入 `tests/test_scene_boundary_subject_release_continuity_audit.py`。

## 后续断链定位

- 如果 `maturity_subject_count` 不等于 6，说明产品成熟度边界主体集合漂移。
- 如果 `guarded_completion_subject_count` 不等于 6，说明某个边界主体没有完整 guarded completion。
- 如果 `readiness_reconciliation_subject_count` 不等于 6，说明非满分 readiness 没有完整归到同一批主体。
- 如果 `terminal_release_subject_count` 不等于 6，说明 release exception trace 没有覆盖同一批主体。
- 如果 `subject_dossier_count` 不等于 6，说明用户验收证据包和上游边界主体不一致。
