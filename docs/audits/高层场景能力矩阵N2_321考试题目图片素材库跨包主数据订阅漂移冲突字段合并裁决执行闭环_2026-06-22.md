# 高层场景能力矩阵 N2.321 考试题目图片素材库跨包主数据订阅漂移冲突字段合并裁决执行闭环
日期：2026-06-22

## 本轮定位

N2.320 已经把跨包主数据订阅漂移冲突推进到基础裁决执行：版本、ETag、更新时间接受远端，说明与引用可以先保留本地并形成审计。N2.321 补上上一轮明确留下的字段合并缺口，让 `alt_text` 与 `reference` 这类人工复核字段可以逐字段选择本地或远端来源，并把选择结果应用回所有受影响 profile。

本轮仍不声明批量裁决、批量应用、后台执行队列、失败重试、回滚、二次补偿、SLA、提醒、重放、跨 archive 持久化或历史 Word 输出追溯修复完成。当前只承诺：已生成的订阅漂移 decision plan 中，支持 `field_merge` 的字段可以通过前台表格进入字段合并执行，生成独立审计记录并回写题图 metadata。

## 已闭合内容

- 新增 `question_figure_asset_library_master_subscription_drift_field_merge_execution_table`，承接已生成的订阅漂移裁决计划。
- 字段合并表只展示尚未执行字段合并、且 plan item 中存在 `field_merge` 能力的字段。
- 表格展示主数据键、计划、可合并字段、来源选择提示、状态和处理动作。
- “合并字段”支持为 `alt_text` 与 `reference` 逐字段选择本地或远端来源。
- 执行后生成 `question_figure_library_cross_package_master_subscription_drift_conflict_field_merge_decision_execution` 审计记录。
- 审计记录包含 field merge execution id、connector、plan id、合并字段、变更字段、字段来源、执行项 JSON 与 next step。
- 执行项逐字段记录本地值、远端值、采用来源、实际应用值、是否改变和执行状态。
- `reference` 继续使用规范字段语义，并通过执行层投射回 `download_url`、`asset_url`、`preview_url`、`thumbnail_url` 或 `cache_path` 等实际元数据承载字段。
- metadata 写入独立的 `master_subscription_drift_field_merge_*` 状态、执行 id、执行时间、plan id、字段、变更字段、来源和 next step。
- 字段合并执行后，该 master key 从字段合并表退场，避免重复执行。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 per-question asset library cross-package master subscription drift conflict field merge decision execution UI evidence。
- 成熟度 gap 从 `advanced question asset library cross-package asset master data subscription drift conflict field merge decision execution UI` 收敛为 `advanced question asset library cross-package asset master data subscription drift conflict batch decision execution UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data subscription drift conflict batch decision execution UI`。

## 边界说明

本轮后仍不声明以下能力完成：

- 多条漂移队列的批量裁决、批量执行和批量失败队列；
- 后台执行 worker、取消、暂停、限流、重试和失败重放；
- 字段合并后的回滚与二次补偿；
- 队列 SLA、优先级人工调整、提醒、重放和跨 archive 持久化；
- 历史 Word 输出追溯修复；
- 非题图素材族的订阅漂移冲突字段合并。

下一轮高优先缺口应聚焦批量决策/批量执行治理，而不是继续把 `field_merge` 单项执行列为未打通。
