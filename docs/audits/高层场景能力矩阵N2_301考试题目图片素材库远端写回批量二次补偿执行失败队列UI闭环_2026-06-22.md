# 高层场景能力矩阵 N2.301 考试题目图片素材库远端写回批量二次补偿执行失败队列 UI 闭环

## 1. 背景

N2.300 已经让二次补偿执行计划可以通过独立 connector 发起远端请求，并沉淀执行审计。但当二次补偿执行出现权限、冲突或普通失败时，用户仍缺少前台队列来定位失败项、更新授权并只重试未成功的补偿项。

本轮闭合“二次补偿执行失败队列 UI”。它不实现后台任务、manifest、独立 drilldown 或远端当前快照校验；只承诺二次补偿执行失败项可以前台可见、可定位、可授权重试，并在后续成功后自动退场。

## 2. 已闭合能力

- 新增 `question_figure_asset_library_remote_writeback_second_compensation_failure_queue_table`。
- 队列表按 `问题 / 题目 / 状态 / 下一步 / 处理` 展示二次补偿执行非成功项。
- 队列来源为最新 `question_figure_library_remote_writeback_batch_second_compensation_execution` 审计记录。
- success 项不进入队列；已在后续二次补偿执行中成功的项不再显示。
- 权限失败项显示“更新授权 / 重试补偿 / 定位补偿”。
- “更新授权”会把失败项 source 回填到远端素材授权控件。
- “重试补偿”复用已冻结的二次补偿执行计划，但只执行仍未成功的 pending 项。
- 冲突和普通失败项支持重试补偿和定位补偿。
- 跳过项只保留定位补偿入口。
- 二次补偿失败队列与二次补偿表、回滚失败队列、事务报告状态联动；重试成功后队列自动隐藏。

## 4. 仍不宣称完成

- 回滚/补偿前远端当前快照校验；
- 回滚冲突字段级合并；
- 后台任务化、并发控制、限流、取消和指数退避；
- 回滚/补偿 manifest 文件导出和独立 drilldown；
- OAuth/SSO 登录、token 自动续期、签名 URL 自动续签；
- 组织、角色、题库权限申请或审批；
- 跨资料包素材主数据版本系统。
