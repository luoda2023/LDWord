# 高层场景能力矩阵 N2.278 考试题目图片素材库按题 Metadata 编辑 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.278 承接 N2.277 的 `question_figure_asset_library_table`。上一轮已经让题图素材按题可见、可定位，但仍保留 `advanced question asset library editing UI` 缺口：用户能看到每道题的库来源和素材 ID，却不能在这个素材库视角直接修正元数据。

本轮只补“按题素材库 metadata 编辑 UI”首片：在按题素材库索引下方提供 `source / asset_id / alt_text` 编辑区，选择素材库行后可修改并写回当前 `EntityProfile.asset_items`、material context 和表格视图。它不宣称完成远端素材库写回、批量 metadata 治理或学校/学科题库规则治理。

## 2. 已闭合能力

- AssetsPanel 在按题素材库索引表下方新增 metadata 编辑区。
- 编辑区包含 `source`、`asset_id`、`alt_text` 三个字段和保存动作。
- 选择按题素材库行时，编辑区会读取对应题图条目的当前 metadata。
- 保存后会写回当前 profile 的 `asset_items` payload。
- 保存后会刷新 material context、题图明细表、按题素材库索引表和摘要状态。
- 写回时统一使用 canonical metadata key：`source`、`asset_id`、`alt_text`。
- 写回前会清理常见别名：`assetSource`、`librarySource`、`assetId`、`altText`、`description`、`caption` 等，避免同义字段并存造成后续链路歧义。
- 索引表与编辑区继续复用 AssetsPanel 既有表格、输入框和按钮样式，保持与模板管理中“同类控件同类表达”的要求一致。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library metadata editing UI bridge` evidence。
- 成熟度剩余 gap 从 `advanced question asset library editing UI` 继续收窄为 `advanced question asset library governance UI`。

## 3. 链路视角

```text
CSV/XLSX/JSON question figure asset items
  -> EntityProfile.asset_items
  -> AssetsPanel question_figure_asset_library_table
  -> select per-question library row
  -> metadata editor: source / asset_id / alt_text
  -> save canonical metadata
  -> refresh archive profile / material context / question figure table / library table
  -> runtime and report continue consuming canonical asset metadata
```

这条链路补的是“单题素材 metadata 可编辑并能回到资料包”。N2.277 解决了素材库视角可见性；N2.278 让用户可以在同一视角完成最常见的三类元数据修正：库来源、素材 ID 和图片说明。

## 4. 场景矩阵影响

`exam_education` 与 `exam_teaching` 的高级题图素材库边界继续被拆细：

- 索引可见性已经由 N2.277 闭合；
- 单题 metadata 编辑已经由 N2.278 闭合；
- 后续 remaining gap 明确转为 `advanced question asset library governance UI`。

这意味着后续不能再把“看不到按题素材库”或“不能编辑单题 source/asset_id/alt_text”重复计算为 L5 blocker。真正剩余的是治理层：批量规则、合并拆分、版本、远端写回、权限和质量判断。

## 5. 仍不宣称完成的边界

- 不做远端素材库写回。
- 不做素材库 API 登录、续期或签名 URL 管理。
- 不做素材 metadata 批量治理。
- 不做素材 ID 合并、拆分、去重治理。
- 不做完整素材库版本历史。
- 不做学校、学科、题型规则治理。
- 不做跨资料包素材主数据管理。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：按题素材库中单条题图的 `source / asset_id / alt_text` 可编辑、可写回、可刷新、可被测试锁定。
