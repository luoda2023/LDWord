# 高层场景能力矩阵 N2.211 考试题目图片远端内容元数据闭环

## 1. 本轮定位

N2.211 继续执行 V43 的 P0 高级考试素材库路线，在 N2.210 “显式缓存刷新”之后，补齐远端题图内容预览的第一片底座：

```text
远端 question_figure 下载成功后，Workbench 会把 HTTP Content-Type 与实际下载字节数写回素材 metadata，并随 material manifest 留痕。
```

本轮不是完整远端预览 UI，仍不实现：
- 下载前缩略图预览；
- 远端素材库 preview API；
- 图片尺寸、哈希、OCR 或内容级错图识别；
- UI 中的预览占位、失败缩略图、批量审阅；
- ETag / Last-Modified 条件请求或自动过期治理。

它的意义是让“下载成功但前台无法判断内容形态”的链路前进一步：至少有可追踪、可测试、可进入后续 UI 的内容类型与体积证据。

## 2. 运行时契约

成功下载远端题图后，`_download_remote_question_asset()` 返回成功 payload：

```json
{
  "download_content_type": "image/png",
  "download_size_bytes": "763"
}
```

`_material_context_with_remote_question_asset_cache()` 将该 payload 合并进当前运行时 `AssetItem.metadata`，因此 manifest 中可同时看到：

```json
{
  "cache_path": "<output_dir>/_remote_asset_cache/question_1_<hash>.png",
  "download_url": "https://example.com/question_1.png",
  "download_content_type": "image/png",
  "download_size_bytes": "763",
  "cache_status": "downloaded",
  "download_status": "downloaded"
}
```

如果命中既有 `_remote_asset_cache` 文件且未强制刷新，下载函数也会以缓存文件大小回填 `download_size_bytes`。如果下载失败，仍沿用 N2.209 的 failure payload，不把失败伪装成内容元数据。

## 3. 链路闭环

```text
远端题图 URL / metadata URL / asset_id resolver
-> _download_remote_question_asset()
-> 校验支持的图片后缀或 image/* content-type
-> 写入 _remote_asset_cache
-> 返回 download_content_type + download_size_bytes
-> material context metadata
-> material manifest
-> 后续预览 UI / 批量审阅 / 缓存治理可消费
```

本轮只承诺下载后的内容元数据，不承诺下载前预览。原因是当前没有真实素材库 preview endpoint，也没有前台缩略图控件与批量审阅状态机。

## 4. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote content metadata bridge
```

覆盖对象：
- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“可下载、可鉴权、可诊断、可刷新”，推进到“下载成功后的内容类型与体积也能进入 manifest 留痕”。剩余的 `advanced question asset library UI` / `advanced asset library UI` 不应再泛称“完全没有远端内容信息”，而应收窄为真实预览 UI、下载前 preview、缩略图、内容级错图识别和批量审阅治理。

## 5. 仍未闭合的边界

N2.211 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：
- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 自动缓存治理：过期判断、ETag、Last-Modified、条件请求、失败重试、共享缓存索引；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
