# 高层场景能力矩阵 N2.204 考试题目图片远端无缓存修复闭环

## 1. 本轮定位

N2.204 继续执行 V43 的 P0 高级考试素材库路线，补齐 N2.203 后保留的另一个窄断点：

```text
远端 question_figure 只有 asset_id/source 或远端 URL，
没有本地 path，也没有 metadata.cache_path 时，
运行时虽然会统计 missing_assets，
但预检和问题队列此前没有明确的 repair target。
```

本轮不实现远端素材真实下载、鉴权、刷新器或远端内容预览；它只把“远端引用尚未落本地”的状态前台化、报告化，并接入题图行级修复入口。N2.205 已继续追补显式 HTTP/HTTPS 图片 URL 的匿名下载缓存首片。

## 2. 断点分析

N2.198 已经把远端 `asset_id/source` 作为题图引用保留下来，N2.202/N2.203 又补齐了缓存路径存在、缓存路径失效两种情况。但仍有一类高频输入：

```json
{
  "role": "question_figure",
  "path": "",
  "metadata": {
    "question_index": "2",
    "asset_id": "remote-question-2",
    "source": "lark_asset_library"
  }
}
```

或：

```json
{
  "role": "question_figure",
  "path": "https://example.com/question_2.png",
  "metadata": {
    "question_index": "2"
  }
}
```

这类资产不能被 Word 直接渲染，也没有可预览的本地缓存。过去运行时会在 exam delivery report 中显示 `missing_assets=1`，但 `material_diagnostics` 会跳过空 path 或远端 URL，导致问题队列无法把用户带回具体题图行。

## 3. 本轮实现

### 3.1 新增远端无缓存诊断

`_question_figure_file_diagnostics()` 现在在遇到空 path 或远端 URL 时，会尝试生成：

```text
preflight_remote_question_figure_uncached
```

触发条件：

- `question_figure` 拥有远端 `asset_id`；或
- `question_figure.path` 是远端 URL；
- 且没有可用 `cache_path` / `cached_path` / `local_path` / `resolved_path` / `download_path` / `asset_path`。

该诊断保持 warning，不阻断执行。

### 3.2 repair target 复用题图行

诊断继续使用：

```text
repair_target_type=question_figure_item
```

`repair_target_key` 复用 N2.203 增强后的题图目标结构，至少携带：

- `role=question_figure`;
- `item_id`，如果存在；
- `question_index`;
- `path`，远端 URL 场景会保留远端 URL；
- `asset_id`，如果存在；
- `metadata`。

因此 AssetsPanel 可以按 item_id、题号、path 或 asset_id 定位回题图明细表。

### 3.3 Workbench 问题队列明细

批量执行时，`batch_issue_items` 新增 `remote_asset_items`，并由 Workbench issue adapter 展示：

```text
远端题图未缓存：题号 2 / remote-question-2 / lark_asset_library
```

这让用户能分辨：

- 本地 path 配置了但文件不存在：`preflight_missing_question_figure_file`;
- 本地 cache_path 配置了但缓存缺失：仍属于缺文件修复；
- 远端引用还没有本地缓存：`preflight_remote_question_figure_uncached`。

## 4. 闭环链路

```text
CSV/XLSX 或 JSON asset_items
-> metadata.asset_id/source 或远端 URL path
-> AssetsPanel 题图明细表显示“远端”
-> Workbench 预检生成 preflight_remote_question_figure_uncached
-> material_diagnostics.remote_asset_items
-> batch_issue_items.remote_asset_items
-> Workbench issue queue 展示“远端题图未缓存”
-> repair_target_type=question_figure_item
-> AssetsPanel.focus_material_repair_target()
-> 定位到远端题图行
-> 用户替换为本地文件或后续远端下载器写入 cache_path
```

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote no-cache repair bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“远端 ID 可追踪”推进到“远端无本地缓存也可被明确报告并回链修复”。N2.205 已继续追补显式 URL 的匿名下载缓存；它仍不等于完整远端素材库，因为素材库 `asset_id` 解析、鉴权、缓存刷新策略和远端内容预览仍未实现。

## 6. 仍未闭合的边界

N2.205 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：

- 素材库 `asset_id` 解析下载、鉴权、缓存刷新策略和远端内容预览；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
