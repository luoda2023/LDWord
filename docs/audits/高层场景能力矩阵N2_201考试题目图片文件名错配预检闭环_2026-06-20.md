# 高层场景能力矩阵 N2.201 考试题目图片文件名错配预检闭环

## 1. 本轮定位

N2.201 继续执行 V43 的 P0 高级考试素材库路线，闭合 N2.200 后保留的“批量错图匹配”第一片可执行能力：当题图文件名明确暴露题号，但素材 metadata 指向另一个题号时，运行前给出非阻断 warning，并把问题回链到 AssetsPanel 的题图行级修复入口。

这不是图片内容识别，也不是 AI 视觉判断。它只覆盖保守、可解释、可自动证明的一类高频错误：

```text
metadata.question_index = 2
path = question_3.png
```

系统应提示“文件名看起来像第 3 题，但素材声明给第 2 题”，让用户人工确认或替换。

## 2. 检测规则

当前仅解析明确题号模式：

```text
question_3.png
question-3.png
q3.png
题3.png
第3题.png
```

不会解析纯数字、日期、版本号或 `figure_2` 这类容易误报的名称。

比对逻辑：

```text
question_figure metadata -> question_index / questionId / question_no / number
filename question hint -> question / q / 题 / 第N题
if both numeric and different -> warning
```

## 3. 链路闭合

本轮新增诊断：

```text
preflight_suspicious_question_figure_mismatch
```

诊断进入：

- `material_diagnostics`
- `batch_issue_items`
- batch JSON report
- batch Markdown report
- Workbench issue adapter details
- `question_figure_item` repair target

repair target 复用既有题图行级修复通道：

```json
{
  "role": "question_figure",
  "item_id": "question_figure_2",
  "question_index": "2",
  "path": ".../question_3.png",
  "metadata": {
    "question_index": "2"
  }
}
```

因此用户可以从批量问题中心回到 AssetsPanel，对应题图行仍可预览、替换和持久化。

## 4. 成熟度证据

`scene_product_readiness` 已新增 evidence：

```text
question asset filename mismatch preflight bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“缺图可修复”推进到“疑似错图可提示、可回链修复”。但它仍不是完整错图匹配，因为没有进行图片内容识别、OCR、图像相似度或题干语义比对。

## 5. 仍未闭合的边界

N2.201 后，`advanced question asset library UI` 的剩余边界收窄为：

- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 远端缓存路径桥接已由 N2.202 追补，剩余为真实下载、鉴权、缓存刷新、无缓存预览和失效处理；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
