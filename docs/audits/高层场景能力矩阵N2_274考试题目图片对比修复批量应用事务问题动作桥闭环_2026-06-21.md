# 高层场景能力矩阵 N2.274 考试题目图片对比修复批量应用事务问题动作桥闭环

日期：2026-06-21

## 1. 本轮定位

N2.274 承接 N2.273 的 `task_summary`。上一轮已经能把题图批量应用事务归纳为 `active`、`completed`、`blocked`、`orphaned` 或 `empty`，但这些状态主要停留在 artifact 和 Markdown 报告里。对前台用户而言，`active`、`blocked`、`orphaned` 仍然不是明确的 Workbench 待处理项，QuickExecution 的问题队列也无法把它们作为“需要处理的事务任务”暴露出来。

本轮只做事务任务摘要到 Workbench issue/action 的桥接，不做回滚执行、不做任务调度、不做后台任务中心、不做自动补偿。

## 2. 已闭合能力

- 新增 `question_figure_transaction_task_issue_items()`，从 `batch_apply_transaction_manifest.task_summary` 生成 Workbench issue item。
- 仅 `active`、`blocked`、`orphaned` 进入问题队列；`completed` 和 `empty` 继续作为产物与历史信息保留，不制造待处理噪声。
- 新增 issue category：`question_figure_batch_apply_transaction_task`。
- 新增 action target：`question_figure_batch_apply_transaction_task_summary`。
- action payload 保留 `status`、`next_action`、`report_path`、`artifact_path`、`fragment`、事务计数、可回滚计数和最近审计 id。
- `blocked` 状态映射为 `severity=error` 且 `blocking=True`；`active`、`orphaned` 映射为 warning。
- QuickExecutionDetail 点击“处理”时会发出事务任务 action target。
- WorkbenchPanel 对该 target 明确切回 `quick_execute`，避免落入旧的 `content_fill` 兜底。
- 问题筛选分类新增中文标签“题图事务任务”。
- RecentRun 与 artifact browser 补齐事务台账、事务报告、事务任务的中文 kind label。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset comparison repair queue batch apply transaction task issue-action bridge` evidence。

## 3. 链路视角

```text
question_figure_batch_apply_audit.json
  -> batch_apply_transaction_manifest
  -> task_summary
  -> Workbench artifact: transaction_tasks
  -> Workbench issue: question_figure_batch_apply_transaction_task
  -> QuickExecution action: question_figure_batch_apply_transaction_task_summary
  -> report_path#question-figure-batch-apply-transaction-task-summary
```

这条链路把“台账里存在一个需要复查的事务状态”提升成“执行中心可见、可筛选、可点击的待处理事项”。用户不必先知道 Markdown 报告在哪里，问题队列会直接指出当前是 active、blocked 还是 orphaned，并携带报告 anchor 与台账路径。

## 4. 仍不宣称完成的边界

- 不执行回滚。
- 不自动打开外部编辑器或文件浏览器。
- 不实现后台任务中心。
- 不做任务调度、取消、重试或并发执行。
- 不做跨 docx 队列。
- 不做原子事务。
- 不做自动回滚或失败补偿执行。
- 不做文件快照系统。
- 不做远程素材库写回。
- 不做重复图片智能 disambiguation。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：事务任务摘要已经从报告/产物视角进入 Workbench 问题队列与 action 路由视角。
