# 高层场景能力矩阵 N2.258 考试题目图片对比修复候选替换审计闭环

## 1. 本轮定位

N2.257 已经让 ready 的本地文件候选可以从 Workbench 问题按钮进入 AssetsPanel，并完成单候选人工确认替换。但替换成功后缺少独立审计记录：只能从当前题图路径变化推断“换过”，不能追溯原路径、替换来源、候选队列 id、来源 issue 和确认状态。

N2.258 关闭的是“单候选替换审计首片”：`AssetsPanel.apply_question_figure_repair_candidate(..., confirmed=True)` 在替换成功后生成结构化审计记录，并在能推导出本地目录时写入 `question_figure_repair_audit.json`。失败、未确认、blocked 或不可应用候选不会写入已应用审计。

## 2. 已实现能力

- `AssetsPanel` 新增内存态 `current_question_figure_repair_audit_records()`，用于读取本轮前台替换审计记录。
- `apply_question_figure_repair_candidate()` 在替换前抓取原始题图条目，替换成功后调用审计记录函数。
- 审计记录包含：
  - `audit_id`、`action=frontstage_question_figure_repair_apply`、`status=applied`、`applied_at`；
  - archive/profile 信息；
  - `queue_id`、`source_issue_id`、`source_kind`、`issue_summary`；
  - `question_index`、`item_id`、`target_label`、`repair_target_key`；
  - `original_path`、`replacement_source_path`、`replacement_source_kind`、`applied_path`；
  - `confirmation_action`、`confirmation_status`、`confirmation_apply_supported`、`confirmed=true`。
- 若当前 profile 的 `assets_dir`、原题图目录或替换文件目录可用，则追加写入 `question_figure_repair_audit.json`：
  - `schema_version=1`；
  - `entry_count`；
  - `records[]`；
  - `updated_at`。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset comparison repair queue replacement audit bridge` evidence。

## 3. 链路闭合

当前链路推进为：

`profile_question_figure_repair_candidate` -> AssetsPanel 消费候选 -> `apply_question_figure_repair_candidate(..., confirmed=True)` -> 捕获原题图条目 -> `_replace_question_figure_item_path()` 成功替换 -> `_record_question_figure_repair_application()` -> 内存审计记录 -> best-effort `question_figure_repair_audit.json` artifact。

这让 N2.257 的“能替换”进一步变成“替换后可追溯”：至少能回答谁的 profile、哪个候选、从哪个原图替到哪个本地来源、来源 issue 是什么、确认状态是什么。

## 4. 明确不宣称完成

- 不做撤销或回滚；
- 不做替换前文件快照复制；
- 不做批量确认执行；
- 不做候选冲突裁决；
- 不写回 Word 或远端素材库；
- 不承诺审计 artifact 一定能落盘，目录不可写或没有可推导目录时只保留内存记录；
- 不做内容级错图识别、视觉 diff 或 AI 判图。

当前能力只承诺：单候选前台人工确认替换成功后，会形成结构化审计记录；具备可写本地目录时，会同步落成 JSON artifact。回滚仍是后续缺口。

## 5. 验收锚点

- `test_assets_panel_applies_confirmed_question_figure_repair_candidate`
  - 断言未确认不替换；
  - 断言确认后替换 archive、material context 与题图表；

  - 断言 `question_figure_repair_audit.json` 写入本地目录并保留同一条 `audit_id`。

  - 断言 exam pack/family 包含 `question asset comparison repair queue replacement audit bridge` evidence。

## 6. 与 V43 主矩阵的关系

V43 的 P0 高级考试素材库路线从 N2.257 的“候选队列前台确认应用”推进到 N2.258 的“候选替换审计首片”。已闭合能力新增：单候选替换不再只是改写当前 AssetsPanel 题图行，而是会留下可追溯的替换审计记录。

仍保留的高级素材库边界是：真实素材库 API 登录/续期/签名与授权续期、跨资料包/后台定时清理、后台全局任务中心、断点续传/后台队列/并发下载调度、跨资料包长期命中率趋势中心、真实素材库预览服务/签名预览 URL 续期、自由框选/多区域标注/标注图层编辑、批量确认执行、候选冲突裁决、替换回滚、内容级错图识别、复杂学科图或 AI 质量判断。
