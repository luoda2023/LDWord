# 高层场景能力矩阵 N2.298 考试题目图片素材库远端写回批量二次补偿计划审批 UI 闭环

## 1. 背景

N2.297 已经把远端回滚失败项投影成前台队列，并支持更新授权、重试回滚和定位报告。但当回滚失败仍未解决时，系统还缺少“二次补偿”治理入口：哪些失败项需要升级为人工补偿、补偿计划是否冻结、是否已经审批，都没有结构化审计记录。

本轮闭合“二次补偿计划/审批 UI 首片”。它不执行二次补偿，也不生成后台任务；只负责从当前回滚失败队列冻结二次补偿计划，并追加人工审批记录，为后续执行计划提供审计前提。

## 2. 已闭合能力

- 题图素材库区域新增 `question_figure_asset_library_remote_writeback_second_compensation_table`。
- 二次补偿表按 `范围 / 问题 / 方案 / 状态 / 处理` 展示。
- 表格来源为最近一次回滚失败队列中的未解决项。
- 未生成计划时显示“生成计划”和“定位失败”。
- “生成计划”追加 `question_figure_library_remote_writeback_batch_second_compensation_plan` 历史记录。
- 二次补偿计划记录保存 transaction report changed_at、rollback execution changed_at、plan signature、item count、category summary 和 JSON 化计划项。
- 计划生成后表格状态变为“待审批”，动作变为“审批计划”和“定位失败”。
- “审批计划”追加 `question_figure_library_remote_writeback_batch_second_compensation_approval` 历史记录。
- 审批记录指向计划 changed_at，并保存 approval status、item count 和 next step。
- 审批后表格显示“等待二次补偿执行计划 / 已审批”，仅保留“定位失败”。
- 新增测试锁定“回滚权限失败 -> 二次补偿表出现 -> 生成计划 -> 审批计划 -> 仍可授权重试回滚并清空失败队列”的链路。
