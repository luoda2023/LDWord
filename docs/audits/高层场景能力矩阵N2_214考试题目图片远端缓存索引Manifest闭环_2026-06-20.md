# 高层场景能力矩阵 N2.214 考试题目图片远端缓存索引 Manifest 闭环

## 1. 本轮定位

N2.214 继续执行 V43 的 P0 高级考试素材库路线，在 N2.213 “条件请求与 304 复用”之后，补齐共享缓存索引的前置能力：

```text
远端 question_figure 每次下载、刷新或 304 复用成功后，Workbench 会在 `_remote_asset_cache/index.json` 写入本地缓存索引 manifest。
```

本轮不是完整共享缓存系统，仍不实现：
- 跨 output_dir / profile 的全局共享缓存；
- 批量缓存失效和统一清理；
- 后台失败重试队列；
- 素材库版本锁定、人工审阅与复用治理；
- 前台缓存索引浏览器或命中统计面板。

它的意义是先把“本次运行产生了哪些远端缓存、它们对应哪个素材身份、状态是什么”变成可读、可测试、可追踪的索引文件，给后续共享缓存、批量失效和缓存命中统计打底。

## 2. 索引位置

索引固定写入当前输出目录的远端缓存目录：

```text
<output_dir>/_remote_asset_cache/index.json
```

即使 304 复用的旧 `cache_path` 在外部目录，本轮仍会把索引写入当前运行的 `_remote_asset_cache/index.json`，便于本次任务的报告和后续治理读取。

## 3. 索引结构

```json
{
  "schema_version": 1,
  "entry_count": 1,
  "updated_at": "2026-06-20T00:00:00Z",
  "entries": {
    "<download_url_sha256>": {
      "url_hash": "<download_url_sha256>",
      "download_url": "https://example.com/question_1.png",
      "cache_path": "<output_dir>/_remote_asset_cache/question_1_<hash>.png",
      "cache_name": "question_1_<hash>.png",
      "item_id": "remote_url_fig_q1",
      "label": "Remote URL question figure",
      "asset_id": "remote-question-1",
      "source": "lark_asset_library",
      "question_index": "1",
      "cache_status": "downloaded",
      "download_status": "downloaded",
      "cache_refresh_status": "",
      "cache_refresh_reason": "",
      "cache_revalidation_status": "",
      "download_content_type": "image/png",
      "download_size_bytes": "763",
      "cache_etag": "\"exam-question-figure-v1\"",
      "cache_last_modified": "Wed, 01 Jan 2020 00:00:00 GMT",
      "indexed_at": "2026-06-20T00:00:00Z"
    }
  }
}
```

`download_url` 会去掉 query 与 fragment，避免未来签名 URL 或带 token URL 被索引 manifest 直接裸写。真实查找键使用完整下载 URL 的 SHA-256。

## 4. 覆盖链路

索引写入覆盖以下成功路径：

- 首次远端 URL 下载；
- asset_id + metadata download_url 下载；
- asset_id/source 本地解析清单下载；
- 鉴权下载成功；
- 显式刷新成功；
- 过期/TTL 自动刷新成功；
- ETag / Last-Modified 条件请求返回 304 并复用旧缓存。

失败路径仍由 N2.209/N2.210/N2.212 的 diagnostics 与 repair target 负责，本轮不把失败写成可用缓存条目。

`scene_product_readiness` 新增 evidence：

```text

```

覆盖对象：

这使高级考试素材库从“缓存只散落为文件路径”，推进到“远端缓存有本地索引 manifest，可为后续共享缓存索引、批量失效、命中统计和前台浏览提供输入”。

## 6. 仍未闭合的边界

N2.214 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：
- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 深层缓存治理：跨 profile 共享缓存索引、后台失败重试、批量失效、统一清理、缓存命中统计；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
