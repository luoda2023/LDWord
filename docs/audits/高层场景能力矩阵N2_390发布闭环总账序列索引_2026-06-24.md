# 高层场景能力矩阵 N2.390 发布闭环总账序列索引

## 背景

N2.380-N2.394 已经把发布残余拆成一组可审计闭环：边界守护、残留 warning、readiness 调和、发布例外、行级 trace、主体证据包、非主体 trace、trace 分区、投影面一致性、主体连续性、边界成熟度封套、残留比例读数账本，以及最终发布验收证书。

`release_closure_ledger` 是这条发布链的有序总账。它不替代单项审计事实源，只验证每个发布阶段是否同时具备顺序、上游依赖、release gate、dashboard、drilldown、summary、导出脚本、CI 和闭环文档。

## 守门口径

每个发布阶段必须同时具备：

- 阶段顺序与上游依赖；
- release gate check；
- dashboard source 与 dashboard card；
- drilldown item；
- summary projection marker；
- JSON/Markdown 导出脚本；
- workflow 测试；
- 对应 N2 闭环文档。

## 后续断链定位

- 如果 `stage_order_count` 不等于 13，说明发布阶段顺序或 N2 映射漂移。
- 如果 `upstream_dependency_ready_count` 不等于 18，说明某个阶段绕开了必要上游证据。
- 如果 release gate / dashboard / drilldown / summary 任一计数不等于 13，说明某个发布阶段只存在于局部实现中。
- 如果 export script / workflow test / closure doc 任一计数不等于 13，说明证据包不可复现或不可持续维护。
- 如果 `release_acceptance_certificate` 不在本索引中，说明总账索引已经落后于最终验收面。
