# 高层场景能力矩阵 N2.253 考试题目图片对比修复候选队列闭环

## 1. 本轮定位

N2.252 已经把人工确认的题图对比问题推进到“当前视图差异区域证据”，但报告侧仍只能告诉用户哪里有问题，不能把这些问题整理成后续可处理的修复候选项。

N2.253 关闭的是“题图对比修复候选队列”的首片：把 `comparison_issue_items`、题号、profile、差异区域、修复目标和来源 issue 汇总为 `question_figure_repair_queue`。它不做自动替换，不做一键写回，也不承诺视觉 diff 或 AI 判图，只提供可审阅、可追踪、必须人工确认的候选修复清单。

## 2. 已实现能力

- batch JSON report 新增 `question_figure_repair_queue`。
- Workbench batch payload 同步暴露 `payload["question_figure_repair_queue"]`，避免报告有字段但执行结果不可消费。
- 队列项按人工题图对比 issue 生成，保留：
  - `queue_id`
  - `kind=question_figure_repair_candidate`
  - `action=review_question_figure_replacement`
  - `status=candidate`
  - `profile_id` / `profile_name`
  - `question_index`
  - `item_id` / `label` / `asset_id`
  - `current_path` / `cache_path`
  - `comparison_reference` / `comparison_display_name`
  - `issue_kind` / `issue_type` / `issue_summary`
  - `region_type` / `region_summary` / `region_json`
  - `repair_target_type=question_figure_item`
  - `repair_target_key`
  - `source_issue_id` / `source_kind`
  - `review_surface=assets_panel.question_figure_item`
  - `requires_user_confirmation=true`
  - `auto_apply_supported=false`
- Markdown batch report 新增 `## Question Figure Repair Queue`，展示候选数量、确认要求、自动应用禁用状态、profile、题号、修复目标、对比参考与区域摘要。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset comparison repair queue candidate bridge` evidence。

## 3. 链路闭合

当前链路为：

AssetsPanel 人工标记对比问题 -> `comparison_issue_*` / `comparison_issue_region_*` metadata -> MaterialExecutionContext -> Workbench material diagnostics -> `batch_issue_items[].comparison_issue_items[]` -> `question_figure_comparison_matrix` -> `question_figure_repair_queue` -> batch JSON / Markdown report。

这条链路把“人工发现问题”推进为“可排队审阅的修复候选项”。后续 UI 可以直接使用队列里的 `repair_target_type` 和 `repair_target_key` 回到 AssetsPanel 的题图行级替换入口。

## 4. 明确不宣称完成

- 自动把错误题图替换为参考图；
- 一键批量应用所有候选项；
- 应用前后 diff 预览；
- 修复事务、回滚、审计记录；
- 冲突合并和多候选裁决；
- 从远端素材库重新搜索正确图；
- 内容级错图识别；
- 复杂学科图或 AI 质量判断。

当前队列是“候选 + 人工确认”层，不是“自动修复执行”层。后续如果继续推进，应把剩余边界命名为“一键确认执行/自动替换增强”，而不是再笼统写“修复队列增强”。

## 6. 与 V43 主矩阵的关系

V43 的 P0 高级考试素材库路线从 N2.252 的“差异区域证据”推进到 N2.253 的“修复候选队列”。已闭合能力新增：基于人工确认题图对比问题的候选修复队列、区域证据透传、报告可审阅和成熟度证据。

仍保留的高级素材库边界是：真实素材库 API 登录/续期/签名与授权续期、跨资料包/后台定时清理、后台全局任务中心、断点续传/后台队列/并发下载调度、跨资料包长期命中率趋势中心、真实素材库预览服务/签名预览 URL 续期、自由框选/多区域标注/标注图层编辑、一键确认执行/自动替换、内容级错图识别、复杂学科图或 AI 质量判断。
