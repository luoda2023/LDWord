# 高层场景能力矩阵 N2.248 考试题目图片远端全尺寸预览多题图对比 UI 闭环

## 1. 本轮定位

N2.247 已经让同一题图的远端原图预览与缩略图可以在大图查看器内并排核查。V43 剩余边界中仍保留“全尺寸多图对比/标注增强”，其中下一段可在当前前台闭合的是：打开某一题图大图后，能够选择另一题图作为对比对象，核查题图是否串题、错位或导入错行。

N2.248 关闭的是“多题图对比查看”首片：在不引入批注、差异标注、AI 错图判断和真实素材库预览服务的前提下，让大图查看器的对比面板支持同一资料包内其他题图。

## 2. 已实现能力

- 大图查看器新增 `asset_full_image_preview_compare_combo`，使用共享输入控件样式。
- 当前题图打开大图预览后，对比选项会自动生成：
  - 首项保留 N2.247 的“同题缩略图”；
  - 后续追加同一资料包内其他题图的当前可预览引用；
  - 本地图直接使用本地路径；
  - 远端图继续使用其可预览 URL 与 source 信息。
- `asset_full_image_preview_compare` 按钮改为读取当前下拉选项：
  - 同题缩略图保持 `缩略图对比` 状态文案；
  - 其他题图显示为 `题图对比`；
  - 本地对比图不会触发远端 HTTP 请求；
  - 远端对比图继续复用 source-scoped Header 授权。
- 对比面板继续复用：
  - `asset_full_image_preview_compare_panel`
  - `asset_full_image_preview_compare_scroll`
  - `asset_full_image_preview_compare_image`
  - `asset_full_image_preview_compare_title`

## 3. 链路闭合

多题图对比链路：

题图明细表当前行 -> 生成同题缩略图对比选项 -> 枚举其他 `question_figure` 条目 -> 读取每条题图的本地路径、缓存路径或远端预览 URL -> 大图查看器下拉选择对比对象 -> 点击对比 -> 右侧对比面板显示目标题图原始尺寸。

审计链路：

`scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote full-preview multi-compare UI bridge` evidence，并由 `tests/test_scene_product_maturity_upgrade_audit.py` 锁定。
