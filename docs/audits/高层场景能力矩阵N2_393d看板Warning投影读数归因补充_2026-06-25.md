# 高层场景能力矩阵 N2.393d 看板 Warning 投影读数归因补充

## 背景

N2.381 已将残留 warning 纳入 `scene_residual_warning_governance_audit`，N2.383/N2.384 已把 `dashboard_warning_projection` 作为发布例外账本的一类 governed exception。当前 release gate 仍会出现 `scene_matrix_dashboard_warning_count=3`，如果只看裸计数，容易误读为 dashboard 自己产生了 3 个未治理缺口。

本轮补充的发布读数是：`dashboard_warning_projection=3/3 governed`。

## 闭环定义

这 3 个 dashboard warning 分别来自：

| pack | warning 来源 | 归因 |
| --- | --- | --- |
| `exam_education` | InputSource 插件/人工边界 | dashboard 只镜像输入源边界 |
| `professional_disclosure` | 专业披露输入质量边界 | dashboard 只镜像专业人工边界 |
| `import_ai_boundary` | Import/OCR/PDF/LaTeX 边界输入轴 | dashboard 只镜像导入边界 |

`dashboard_warning_projection=3/3 governed` 表示：

- 分母 3 来自 `scene_matrix_dashboard.warning_count` 与 `scene_residual_warning_governance_dashboard_projection_warning_count`；
- 分子 3 来自 `scene_terminal_release_exception_audit.warning_projection_count`；
- 每条 warning 都必须能追到 `scene_residual_warning_governance_audit` 中 `governance_mode="dashboard_projection"` 的行级记录；
- 若 dashboard 新增 warning 但没有进入 residual warning governance 和 terminal exception trace，发布摘要会出现不一致读数。

## 链路

```text
scene_matrix_dashboard.warning_count
  -> scene_residual_warning_governance_audit.dashboard_projection_warning_count
  -> scene_terminal_release_exception_audit.warning_projection_count
  -> verify_scene_matrix_release_gate.py: dashboard_warning_projection=3/3 governed
  -> scene_matrix_dashboard / scene_summary_projection
```

## 发布要求

- release gate 最终摘要必须展示 `dashboard_warning_projection=3/3 governed`；
- dashboard 的 Managed warnings 与 Release exceptions 卡片必须展示 `3/3 dashboard` 的治理关系；
- summary projection 的 Boundary、Evidence、Readiness 视角必须展示 `3/3 dashboard warnings governed`；
- terminal release exception 源证据必须包含本文件，并以 `dashboard_warning_projection` 作为 marker。

## 非目标

本轮不消除这 3 个 warning，也不把输入源插件/人工边界改写为核心能力。它只关闭“dashboard warning 是否已被治理归因”的读数缺口。
