# 高层场景能力矩阵 N2.311 考试题目图片素材库远端写回外部权限审批回调执行闭环

日期：2026-06-22

## 本轮定位

N2.310 已经把企业授权续期 connector 接入前台执行链路，但外部组织、角色、scope 或题库权限审批仍停留在“生成审批申请 / 手动确认审批”。N2.311 关闭外部权限审批回调的首片执行链路：审批申请生成后，前台可以同步外部审批结果或应用已经导入的审批回调状态；当结果为 `approved` 时，系统会写回题图元数据，并让组织权限预检自然退场。

这一轮只承诺外部审批结果已经存在或 callback endpoint 可用时的受控执行，不声明权限主数据中心、跨组织角色体系或后台自动同步任务已经完成。

## 已闭合内容

- 组织/角色/scope 权限预检行在审批申请已生成后新增“同步审批”动作；
- 支持题图 CSV/XLSX 元数据中的权限审批 callback endpoint：`permission_callback_url`、`external_permission_callback_url`、`organization_permission_callback_url`、`org_permission_callback_url`、`role_permission_callback_url`、`scope_permission_callback_url`、`permission_approval_url`、`permission_status_url`、`approval_status_url`；
- 支持直接导入审批状态字段：`external_permission_status`、`permission_callback_status`、`permission_approval_status`、`organization_permission_callback_status`、`org_permission_callback_status`、`role_permission_callback_status`、`scope_permission_callback_status`、`external_approval_status`；
- callback 返回的 JSON 可以从顶层、`metadata`、`data.metadata` 或 `data` 中解析审批状态、审批人和审批说明；
- `approved` 会写回结构化题图 item metadata：`permission_status=approved`、`permission_granted=true`、`external_permission_callback_status=approved`、`external_permission_synced_at`，并保留可用的 `permission_approved_by` 与 `permission_callback_message`；
- `pending`、`rejected`、`permission_required`、`failed` 会生成审计记录，但不会伪装成已授权，也不会解除预检阻断；
- 新增 `question_figure_library_remote_writeback_external_permission_callback_execution` 审计记录，保存 callback 来源、endpoint、HTTP 状态、审批状态、审批人、说明和回调前后状态；
- 审批同步成功后，组织权限预检行退场，单项远端写回交接可以继续生成；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library remote writeback external permission callback execution UI evidence；
- 成熟度 gap 从 `advanced question asset library remote writeback external permission callback execution UI` 收敛为 `advanced question asset library cross-package asset master data version governance UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data version governance UI`。

## 边界说明

本轮不声明以下能力完成：

- 企业 OAuth/SSO 交互式登录跳转；
- token 后台自动定时续期；
- 真实企业身份平台账号体系；
- 权限主数据中心或跨组织角色主数据同步；
- 跨资料包素材主数据版本系统；
- 后台定时扫描外部审批状态；
- 多审批流、会签、撤回、重新发起、审批链路 SLA。

当前“外部权限审批回调执行”只承诺：当审批结果已经以元数据或 callback endpoint 形式可读取时，前台可以受控同步、审计、写回题图元数据，并让本地组织权限预检阻断退场。它仍把跨包资产主数据版本治理保留为明确的后续 L5 缺口。
