# 高层场景能力矩阵 N2.268 考试题目图片对比修复批量应用执行结果审计闭环

日期：2026-06-21

## 1. 本轮目标

N2.268 承接 N2.267 的 Word media 写入首片。N2.267 已经能在计划 ID、计划指纹、显式确认和 docx media 唯一匹配均成立时，输出修复后的 docx 副本；但执行结果仍主要存在于运行时 payload 和报告摘要中，缺少独立可留存的审计 artifact。

本轮关闭的是批量应用执行结果审计首片：

- 成功写出修复 docx 后追加 `question_figure_batch_apply_audit.json`；
- 审计记录保留计划、输入输出、输出哈希、确认人、应用数量和 entry results；
- 运行时结果暴露 `audit_written`、`audit_path`、`audit_record_id` 和 `audit_record`；
- Markdown 报告和 Workbench artifact detail 均显示 audit 状态；
- 审计写入是 best-effort，不把已成功写出的 docx 因审计文件写入失败再回滚。

## 2. 已实现结构

运行时新增/扩展：

- `_question_figure_batch_apply_audit_record()`
- `_append_question_figure_batch_apply_audit_record()`
- `_read_question_figure_batch_apply_audit_payload()`
- `_apply_question_figure_repair_batch_execution_to_docx()`

成功执行后，`batch_apply_execution_result` 新增：

- `audit_supported`
- `audit_written`
- `audit_path`
- `audit_record_id`
- `audit_record`

审计文件结构：

```json
{
  "schema_version": 1,
  "kind": "question_figure_repair_batch_apply_audit",
  "entry_count": 1,
  "records": [
    {
      "kind": "question_figure_repair_batch_apply_audit_record",
      "action": "question_figure_repair_batch_apply_word_media_write",
      "status": "applied"
    }
  ]
}
```

## 3. 审计内容

每条 audit record 保留：

- `audit_id`
- `plan_id`
- `execution_plan_fingerprint`
- `freeze_id`
- `dry_run_status`
- `input_path`
- `output_path`
- `output_sha1`
- `confirmed`
- `confirmed_by`
- `confirmed_at`
- `confirmation_note`
- `planned_candidate_count`
- `planned_target_count`
- `applied_count`
- `applied_target_count`
- `entry_results[]`

`entry_results[]` 包含每个应用条目的 queue id、media path、原题图路径、替换图路径、原图 SHA-1、替换图 SHA-1、题号和 item id。

## 4. 前台与报告

Markdown batch report 的执行结果摘要新增 audit 状态：

```text
Batch apply execution result: status=<status>; applied=<n>; output=<path>; word_write=<true|false>; audit=<written|not_written>
```

Workbench artifact detail 新增：

```text
exec_result=<status>; applied=<n>; audit=<written|not_written>
```

## 5. 不宣称完成

本轮仍不宣称：

- 完整批量事务中心；
- 批量事务回滚；
- 审计记录驱动的自动回滚；
- 跨多 docx 后台任务调度；
- 重复图片智能 disambiguation；
- 图像内容质量判断；
- 自动候选优先级排序；
- 完整候选对比选择器。

N2.268 只保证成功执行后的结果可留存、可追溯；事务回滚和后台任务中心仍是后续独立闭环。
