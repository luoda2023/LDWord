# 高层场景能力矩阵 N2.236 考试题目图片远端缓存清理任务历史前台 UI 闭环

## 1. 背景

N2.232 已经生成运行级 `cleanup_history.json`，N2.234/N2.235 又把共享缓存目录的命中率历史和缩略图预览推进到 AssetsPanel 前台。剩余边界中仍有“前台确认 UI/任务历史列表”，但完整跨 profile 后台任务列表还需要调度器和全局任务存储，不能直接伪装完成。

本轮闭合共享缓存目录级清理历史首片：cleanup / dry-run 后，运行时会为被扫描的共享缓存目录写出目录自己的 `cleanup_history.json`；AssetsPanel 在选中共享缓存目录时读取并展示最近清理任务。

## 2. 闭合范围

本轮闭合：

- cleanup / dry-run 后，除运行目录 history 外，被扫描的共享缓存目录也写入 `cleanup_history.json`；
- material manifest 暴露 `cache_cleanup_dir_history_paths`、`cache_cleanup_dir_history_count`、`cache_cleanup_dir_history_latest_task_ids`；
- AssetsPanel 新增 `question_figure_shared_cache_cleanup_table`；
- 选中共享缓存目录时，联动读取该目录的 `cleanup_history.json`；
- 表格展示最近 20 条记录；
- 表格展示记录时间、模式、状态、是否 dry-run、stale entry 候选/删除数、孤儿文件候选/删除数和任务 id；
- 无 history 文件或解析失败时隐藏该表，不阻断素材面板；
- 成熟度矩阵补入 cache cleanup history UI evidence。

本轮不做：

- 跨 profile 后台定时清理；
- 前台清理确认按钮和危险操作确认流；
- 全局任务列表、任务取消、任务重试；
- 后台队列和并发调度；
- 清理策略编辑 UI。

## 3. 数据链路

运行级 history：

```text
<output_dir>/_remote_asset_cache/cleanup_history.json
```

目录级 history：

```text
<shared_cache_dir>/cleanup_history.json
```

目录级 record 只保留该目录自己的任务明细：

```text
task_id
mode
status
dry_run
dir_count
stale_index_entry_candidate_count
stale_index_entry_removed_count
orphan_file_candidate_count
orphan_file_removed_count
dirs[0].cache_dir
dirs[0].entry_count_before
dirs[0].entry_count_after
updated_at
```

前台入口：

```text
素材管理 -> 图片材料 -> 共享缓存目录表 -> 选中目录 -> 清理历史表
```
