# 高层场景能力矩阵 N2.393h Warning 子类治理读数归因补充

## 背景

N2.393f 已把 warning 来源级读数补成 `input_warnings=5/5 managed` 与 `count_profile_warnings=2/2 managed`。继续扫描 release gate 后，还能看到三个 warning governance 子类读数：

- `scene_residual_warning_governance_plugin_manual_warning_count=5`
- `scene_residual_warning_governance_reference_profile_warning_count=2`
- `scene_residual_warning_governance_visio_fixture_closed_count=1`

本轮补充发布表达：

- `plugin_manual_warnings=5/5 managed`
- `reference_profile_warnings=2/2 managed`
- `visio_fixture=1/1 closed`

## 闭环定义

`plugin_manual_warnings=5/5 managed` 表示输入源 warning 中的插件/人工/边界输入类 warning 全部被治理。它们不是核心能力失败，而是必须保留的插件或人工确认边界。

`reference_profile_warnings=2/2 managed` 表示 `basic` 与 `word_xml_full` 两个 CountProfile warning 都被解释为 reference/fallback profile，不是 family-level ready promise。

`visio_fixture=1/1 closed` 表示 Visio/复杂绘图风险的独立 fixture closure 已经完成，不应再被当作 ObjectPreflight 未闭合 warning。

## 链路

```text
SCENE_RESIDUAL_WARNING_GOVERNANCE_SPECS
  -> plugin_manual_managed_warning_count / reference_profile_managed_warning_count
  -> verify_scene_matrix_release_gate.py:
       plugin_manual_warnings=5/5 managed
       reference_profile_warnings=2/2 managed
       visio_fixture=1/1 closed
  -> scene_matrix_dashboard / scene_summary_projection
```

## 发布要求

- release gate 最终摘要必须展示 `plugin_manual_warnings=5/5 managed`；
- release gate 最终摘要必须展示 `reference_profile_warnings=2/2 managed`；
- release gate 最终摘要必须展示 `visio_fixture=1/1 closed`；
- dashboard 的 Managed warnings 卡片必须展示 plugin/manual、reference profile、Visio fixture 三类子读数；
- summary projection 的 Boundary、Evidence、Readiness 视角必须展示同样的子类治理读数；
- `scene_residual_warning_governance_audit` source evidence 必须检查 release gate 中的 `plugin_manual_warnings=`、`reference_profile_warnings=`、`visio_fixture=` marker。

## 非目标

本轮不消除插件/人工边界 warning，不移除 reference profile，也不把 Visio 风险改成无风险对象。它只关闭 warning 子类读数的发布归因缺口。
