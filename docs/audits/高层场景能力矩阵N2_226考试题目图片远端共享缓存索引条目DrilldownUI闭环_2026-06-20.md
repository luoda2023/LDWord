# 高层场景能力矩阵 N2.226 考试题目图片远端共享缓存索引条目 Drilldown UI 闭环

## 1. 本轮定位

N2.226 继续承接 V43 的 P0 高级考试素材库路线。N2.225 已经把共享缓存目录做成 AssetsPanel 前台摘要，但用户仍只能看到“这个目录有几张题图、缓存状态是什么”，不能继续下钻到具体 index 条目。

本轮解决的断点是：

```text
共享缓存目录已能浏览，
但 index.json / AssetItem.metadata 中的逐条缓存事实仍不可前台排查，
用户无法知道某个目录下具体是哪一题、哪个 asset、哪个缓存文件、哪个索引来源。
```

本轮只做当前 profile / 当前 material context 的轻量 drilldown。不做打开目录、不做删除、不做后台重试、不做跨目录清理。

## 2. 新增前台控件

AssetsPanel 图片材料区在 `question_figure_shared_cache_dirs_table` 下新增：

```text
question_figure_shared_cache_entries_table
```

表格列为：

```text
题目
资产
缓存文件
缓存状态
索引/来源
失效
```

显示规则：

- 选择某个共享缓存目录后，条目表刷新为该目录下的缓存 index 明细；
- 优先读取共享目录下的 `index.json`，展示真实 index entry；
- 如果目录没有 `index.json`，或当前上下文里有未写入 index 的远端题图，则回退到 `AssetItem.metadata`；
- `index.json` 和 metadata 指向同一个 cache path 时按同一条去重；
- 选中条目后，如果有缓存文件路径，则复用现有图片预览链路显示缓存图；
- 列文本复用执行链路字段：`question_index`、`asset_id`、`cache_path/cache_name`、`cache_status`、`download_url/cache_key`、`cache_invalidation_status/scope`。

## 3. 链路关系

```text
shared_cache_dir
-> AssetsPanel 目录摘要表
-> 目录选择
-> shared_cache_dir/index.json entries
-> question_figure_shared_cache_entries_table
-> cache_path 预览
```

回退链路：

```text
shared_cache_dir
-> 当前 MaterialExecutionContext.asset_items
-> AssetItem.metadata
-> question_figure_shared_cache_entries_table
```

这让 N2.221-N2.225 的缓存索引、目录摘要、显式失效和批量失效结果有了同一个前台排查面。

## 5. 仍未闭合的边界

N2.226 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余缓存治理边界继续收窄为：

- 打开共享缓存目录；
- 按题型、学科、来源、素材库版本筛选的批量治理；
- 跨运行、跨目录、跨 profile 的后台统一清理；
- 后台失败重试、断点续传、并发下载队列；
- 跨运行缓存命中率趋势面板；
- token 续期、签名 URL 更新、401/403 后重新授权；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图生成；
- 素材库版本、历史审阅、版权真实性和 AI 质量边界。
