# 高层场景能力矩阵 N2.339 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复非题图素材族历史 Word XML 媒体验证闭环

## 1. 本轮定位

N2.338 已把非题图素材族从治理事实推进到文件级恢复执行：缺失素材能从候选复制到目标 path，并写入 rollback manifest。但这还不能证明历史 DOCX 已经真实引用该素材。本轮 N2.339 补上第一段 historical Word XML/media verification：读取非题图素材 metadata 中关联的历史 DOCX 路径，扫描 `word/document.xml`、`word/_rels/document.xml.rels` 和 `word/media/*`，并用素材文件内容 hash 验证历史 DOCX 的 `word/media/*` 中是否存在该素材。

本轮闭合的是验证与证据链，不伪装完成 header/footer relationship rewrite。Logo、签章、水印型图片等非题图素材常位于页眉、页脚、封面或多输出版本中，下一步仍需要更深的 rewrite execution。

## 2. 新增能力

- 新增 verification action：`asset_library_cross_package_master_subscription_drift_conflict_batch_failure_recovery_non_question_asset_family_historical_word_xml_relationship_media_rewrite_verification`。
- 从 execution record 派生 verification，不重新定义素材族事实源。
- 从匹配素材 metadata 中读取 `historical_docx_path(s)`、`historical_output_docx_path(s)`、`word_output_path(s)`、`docx_path(s)`、`docx_targets` 等历史 DOCX 目标。
- 复用现有 DOCX XML/media scanner，输出 relationship/media 一致性状态。
- 额外读取 `word/media/*`，用 SHA1 对比恢复后的素材文件内容，判断 `asset_media_present` / `asset_media_missing`。
- 写入 JSON/Markdown manifest，记录 docx target count、checked count、asset media verified count、missing relationship/media/orphan 计数。
- 回写 profile metadata：verification status、verification id、docx target count、asset media verified count、manifest paths 和 next step。
- UI 在执行后显示 `Verify + Manifest`，验证后显示 `Manifest`，状态列显示 `verified` 或 `attention`。

## 3. 当前边界

本轮只验证历史 DOCX，不修改历史 DOCX：

- 不新增或修改正文 relationship；
- 不改写 header/footer relationship；
- 不复制媒体进入历史 DOCX；
- 不生成 `.verified.docx` 或 `.rewrite.docx` 副本；
- 不做多输出版本差异合并；
- 不清理孤儿媒体；
- 不执行二次补偿。

若 DOCX 自身 XML/media 一致但没有素材内容命中，状态进入 `verification_attention_required`，下一步为 `non_question_asset_family_historical_word_xml_media_rewrite_required`。

## 4. Word XML 视角

现有 scanner 已覆盖 `word/document.xml` 与 `word/_rels/document.xml.rels` 的图片引用和 `word/media/*` 文件一致性。本轮在此基础上补了“业务素材是否出现在 media 内”的验证，避免只证明 DOCX 自身关系完整，却没有证明签章/Logo/二维码等实际素材已进入输出。

仍未闭合的 Word 视角是 header/footer 与多 part rewrite：

- `word/header*.xml` 与 `word/_rels/header*.xml.rels`；
- `word/footer*.xml` 与 `word/_rels/footer*.xml.rels`；
- 封面、文本框、浮动对象所在 part；
- relationship target 改写与媒体补写；
- rewrite 后 post-scan 与 rollback source。
