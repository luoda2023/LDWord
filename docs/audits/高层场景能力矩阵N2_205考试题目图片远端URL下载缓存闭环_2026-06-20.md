# 高层场景能力矩阵 N2.205 考试题目图片远端 URL 下载缓存闭环

## 1. 本轮定位

N2.205 继续执行 V43 的 P0 高级考试素材库路线，在 N2.204 的“远端无缓存可报告、可回链”之后，补齐第一片真实下载能力：

```text
当 question_figure.path 是明确的 http/https 图片 URL，
且没有 metadata.cache_path 时，
Workbench 执行前会尝试匿名下载到本次输出目录的本地缓存，
再复用 N2.202 的缓存渲染链路插入 Word。
```

本轮不处理：

- 素材库 `asset_id` 到真实 URL 的服务解析；
- 需要 token、cookie、签名 URL 或其他鉴权的下载；
- 缓存过期、ETag、Last-Modified、强制刷新等策略；
- 远端内容直接预览；
- 非图片或超大远端文件。

## 2. 输入契约

本轮支持的输入是显式 URL：

```json
{
  "role": "question_figure",
  "path": "https://example.com/question_1.png",
  "metadata": {
    "question_index": "1",
    "source": "remote_url",
    "alt_text": "Downloaded remote URL figure"
  }
}
```

不支持把普通 `asset_id` 猜成 URL。仅有：

```json
{
  "asset_id": "remote-question-1",
  "source": "lark_asset_library"
}
```

时，仍保持 N2.204 的 `preflight_remote_question_figure_uncached` warning 和 repair target。

## 3. 本轮实现

### 3.1 下载时机

`WorkbenchProductionRunner.run()` 在资料预检之前调用：

```text
_material_context_with_remote_question_asset_cache()
```

它克隆当前 `MaterialExecutionContext`，只修改本次运行用的 runtime context，不反写用户原始档案。

### 3.2 缓存目录

下载成功后写入：

```text
<output_dir>/_remote_asset_cache/
```

文件名由 URL 路径 stem 和 URL hash 生成，避免不同 URL 同名覆盖。

### 3.3 元数据写回

下载成功后，当前运行时 `AssetItem.metadata` 会补齐：

```json
{
  "cache_path": "<output_dir>/_remote_asset_cache/question_1_remote_<hash>.png",
  "download_url": "https://example.com/question_1.png",
  "cache_status": "downloaded"
}
```

原始 `AssetItem.path` 仍保留远端 URL，因此 material manifest 可以同时说明“来源 URL”和“本次缓存路径”。

### 3.4 安全边界

下载器只接受：

- `http`;
- `https`;
- 图片扩展名或 `image/*` content type；
- 单文件最大 25 MB。

下载失败不阻断执行，也不抛给用户。失败后保持原始远端引用，由 N2.204 的远端未缓存 warning 接管。

## 4. 闭环链路

```text
question_figure.path=http/https 图片 URL
-> Workbench run 前匿名下载到 _remote_asset_cache
-> metadata.cache_path / download_url / cache_status=downloaded
-> _question_figure_file_diagnostics 不再生成远端未缓存 warning
-> _asset_render_path 使用 cache_path
-> exam figure payload 使用本地缓存 path
-> Word 渲染图片
-> JSON/Markdown report 显示 assets=1/1
-> material manifest 保留 path=<remote URL> + metadata.cache_path
```

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote url download cache bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“远端无缓存只能提示修复”推进到“显式 URL 可自动落本地缓存并渲染”。N2.206 已继续追补 `asset_id` 旁显式 `download_url` 元数据的下载缓存，N2.207 已继续追补 `asset_id/source` 本地解析清单，N2.208 已继续追补受控 header 鉴权下载；它仍不是完整远端素材库，因为真实素材库 API 登录/续期/签名、权限失败 UI、缓存刷新策略和远端内容预览还没有实现。

## 6. 仍未闭合的边界

N2.208 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：

- 真实素材库 API：凭 `asset_id/source` 远程查询下载 URL，并在必要时完成登录、续期或签名 URL 生成；
- 权限失败细分：401/403/过期/无权限/签名失效的可读提示、重试和 UI 授权入口；
- 缓存刷新策略：过期判断、ETag、Last-Modified、强制刷新、失败重试；
- 远端内容预览：下载前预览、失败占位、类型/尺寸信息；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
