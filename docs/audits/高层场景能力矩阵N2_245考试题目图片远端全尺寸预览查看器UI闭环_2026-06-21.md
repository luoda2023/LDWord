# 高层场景能力矩阵 N2.245 考试题目图片远端全尺寸预览查看器 UI 闭环

## 1. 本轮定位

N2.244 已经把考试题图的远端预览从“缩略图优先”推进到“全尺寸预览 URL 优先”：`preview_url`、`fullPreviewUrl`、`fullImageUrl`、`originalPreviewUrl` 等字段会优先于 `thumbnail_url` 进入前台预览链路。

N2.245 关闭的是下一段用户体验断点：全尺寸预览下载后不应只塞进 260 x 180 的小预览框，而要有一个明确的“大图预览”入口，让用户能在 AssetsPanel 内打开当前本地或远端缓存图，并按原始像素尺寸查看。

## 2. 已实现能力

- `AssetsPanel` 图片预览区新增 `asset_full_image_preview_button`，当前预览没有可用本地文件时保持禁用。
- 成功选择本地图或成功下载远端缩略图/全尺寸预览后，记录当前可打开预览路径，并启用“大图预览”按钮。
- 大图预览使用独立 `QDialog`：
  - `asset_full_image_preview_dialog`
  - `asset_full_image_preview_scroll`
  - `asset_full_image_preview_image`
- 弹窗通过 `QScrollArea + QLabel` 承载原始 `QPixmap`，不改变原图像素尺寸；小预览仍保持原有 260 x 180 预览职责。
- 远端预览下载到本地缓存后，弹窗标题、尺寸说明和状态栏展示远端 URL 的原始文件名，而不是缓存哈希名。
- 远端全尺寸预览继续复用 N2.242 的 source-scoped Header 授权与 N2.244 的 8MB 下载上限、图片内容类型校验。

## 3. 链路闭合

导入链路：

`questionFigure2FullPreviewUrl` / `fullPreviewUrl` -> `preview_url` -> 题图表显示全尺寸预览文件名 -> 选中行触发远端原图预览 -> 带授权 Header 下载到临时缓存 -> 小预览显示 -> 大图按钮启用 -> 独立弹窗按原始像素尺寸查看。

本地链路：

本地题图路径 -> 小预览显示 -> 大图按钮启用 -> 独立弹窗按原始像素尺寸查看。

审计链路：

`scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote full-preview viewer UI bridge` evidence，并由 `tests/test_scene_product_maturity_upgrade_audit.py` 锁定。

## 4. 仍不宣称完成

- 全尺寸查看器的缩放比例、适应窗口、对比查看、标注或下载增强。
- 内容级错图识别、复杂学科图质量判断、AI 质量边界。
