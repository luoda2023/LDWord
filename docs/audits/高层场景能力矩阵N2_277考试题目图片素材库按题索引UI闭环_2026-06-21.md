# 高层场景能力矩阵 N2.277 考试题目图片素材库按题索引 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.277 承接 N2.276 后 `exam_education` / `exam_teaching` 仍保留的 `advanced question asset library UI` 缺口。当前 AssetsPanel 已经具备题图批量导入、逐题替换、altText、远端预览、缓存、对比、修复队列、批量应用事务与报告审计能力，但缺少一个按题维度可见的素材库索引视角。

本轮只补“按题素材库索引 UI”：让用户能在资料包图片区域看到每道题的库来源、素材 ID、缓存/预览引用和状态，并能从索引表定位回题图行。它不宣称完成素材库编辑、规则治理或远端库写回。

## 2. 已闭合能力

- AssetsPanel 新增 `question_figure_asset_library_table`。
- 索引表列出 `题目 / 库来源 / 素材ID / 缓存/预览 / 状态 / 处理`。
- 当题图集合中存在远端素材 ID、素材来源、缓存路径、缩略图、远端预览、共享缓存目录或下载 URL 时，显示按题索引。
- 索引表覆盖同一题图集合中的本地项与远端项，避免只看到远端条目而丢失题目上下文。
- 点击或选择索引行会定位回原题图明细行，并复用现有题图预览链路。
- 新表复用现有 asset table 样式，保持与题图明细、共享缓存、任务表一致。
- `scene_product_readiness` 新增 `question asset per-question asset library index UI bridge` evidence。
- `remaining_product_gaps` 从泛化的 `advanced question asset library UI` 细化为 `advanced question asset library editing UI`。

## 3. 链路视角

```text
CSV/XLSX/JSON question figure asset items
  -> AssetItem metadata: question_index / source / asset_id / cache / preview
  -> AssetsPanel question figure table
  -> question_figure_asset_library_table
  -> select library row
  -> select original question figure row
  -> existing image preview / remote preview / compare options
```

这条链路补的是“按题库视角可见性”。此前远端素材能力散落在导入字段、题图明细、共享缓存和预览链路里；现在同一题图集合可以被汇总成素材库索引，方便用户确认每道题的来源、ID 和缓存状态。

## 4. 仍不宣称完成的边界

- 不做远端素材库写回。
- 不做素材库 API 登录/续期。
- 不做学校/学科题库规则治理。
- 不做素材库 metadata 批量编辑。
- 不做素材 ID 合并、拆分、去重治理。
- 不做完整素材库版本历史。
- 不做重复图片智能 disambiguation。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：按题素材库索引 UI 已经可见、可定位、可被测试锁定；高级素材库编辑 UI 仍作为下一阶段明确缺口保留。
