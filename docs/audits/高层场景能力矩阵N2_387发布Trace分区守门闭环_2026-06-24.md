# 高层场景能力矩阵 N2.387 发布 Trace 分区守门闭环

## 背景

N2.384 已经把 terminal release exception 展开为 36 条 row-level trace。N2.385 将其中 26 条归入 6 个 Boundary subject release dossier，N2.386 将剩余 10 条非主体 trace 归因到 dashboard projection、registry-only profile、plugin/manual pack boundary 与 generic not-applicable surface。

本轮补 `release_trace_partition_guard`：它不新增业务承诺，而是证明这两类下游视角对 36 条 terminal trace 的覆盖是完整且互斥的。

## 守门口径

- Terminal baseline：`scene_terminal_release_exception_audit` 输出 36 条 terminal release trace。
- Subject partition：`scene_boundary_subject_release_dossier_audit` 输出 26 条 subject-owned trace。
- Non-subject partition：`scene_non_subject_release_trace_attribution_audit` 输出 10 条 non-subject trace。
- Complete partition：subject 与 non-subject 合并后必须是 36/36。
- Exclusive partition：subject 与 non-subject 不允许出现 overlap。
- No extra trace：subject 与 non-subject 不允许包含 terminal ledger 之外的 trace。

## 当前结论

- `terminal_trace_count = 36`
- `subject_trace_count = 26`
- `non_subject_trace_count = 10`
- `partitioned_trace_count = 36`
- `missing_trace_count = 0`
- `overlap_trace_count = 0`
- `extra_trace_count = 0`
- `issue_count = 0`

这说明发布残余的最终链路已经从“顶层 exception ledger”落到了两种互补归属：主体证据包与非主体归因；没有浮空 trace，也没有同一 trace 被两边重复认领。

## 打通范围

- 审计模块：`src/config/scene_release_trace_partition_guard_audit.py`
- 导出脚本：`scripts/export_scene_release_trace_partition_guard_audit.py`
- Release gate：输出 `scene_release_trace_partition_guard_*` 计数并在 summary 中显示 `trace_partition=36/36`。
- Dashboard：新增 `release_trace_partition` 卡片，并把分区守门纳入 boundary、evidence chain 与 readiness 视角。
- Drilldown：新增 `release_trace_partition_guard` 明细源，展示 terminal total、subject partition、non-subject partition 三行。
- Summary projection：在 Boundary signals、Evidence chain、Readiness 与 Matrix drilldown 摘要中展示 trace partition 结果。

## 后续断链定位

- 如果 `missing_trace_count > 0`，说明 terminal ledger 新增了 trace，但没有进入主体证据包或非主体归因。
- 如果 `overlap_trace_count > 0`，说明同一 trace 被 Boundary subject dossier 与 Non-subject attribution 同时认领，需要重新划定归属边界。
- 如果 `extra_trace_count > 0`，说明下游分区保留了 terminal ledger 中已经不存在的 trace，需要清理残留引用。
- 如果 source evidence 缺失，说明 UI、release gate、文档或审计模块之间的投影链路没有同步。

## 验收标准

- 独立审计返回 passed。
- JSON/Markdown 导出均可用。
- release gate 中 `scene_release_trace_partition_guard_partitioned_trace_count == 36`。
- dashboard、drilldown、summary projection 均可看到同一组分区数字。
- CI 中纳入 `tests/test_scene_release_trace_partition_guard_audit.py`。
