# 高层场景能力矩阵 N2.314 考试题目图片素材库跨包主数据远端 Registry 同步闭环

日期：2026-06-22

## 本轮定位

N2.313 已经把同一个远端题图素材在多个资料包/profile 中的主版本推广执行闭合到本地 archive。N2.314 继续关闭“推广后只能停在本地”的缺口：当资料中显式提供 Registry 同步端点时，跨包主数据版本治理表会在推广完成后保留该 master key，并把动作切换为“同步Registry”，将 canonical 主数据版本通过 HTTP JSON POST 登记到远端 Registry/API。

这一轮仍不声明真实主数据中心、后台订阅、锁定审批、跨 archive 持久化中心或远端版本 API 双向订阅完成。当前只承诺：已有本地治理计划、已执行本地推广、且 metadata 中存在 Registry 同步端点时，前台可以受控同步、审计和退场。

## 已闭合内容

- 跨包主数据版本表新增第三阶段状态：`记录计划 -> 执行推广 -> 同步Registry`；
- 无 Registry 端点的数据保持 N2.313 行为：推广后漂移消失，表格退场；
- 有 `registry_sync_url` / `master_registry_sync_url` / `asset_registry_sync_url` 等端点的数据，在推广后显示“待同步Registry”；
- 新增导入别名：`RegistrySyncUrl`、`MasterRegistrySyncUrl`、`AssetRegistrySyncUrl`、`MasterDataRegistryUrl`、`LibraryRegistryUrl`、`AssetRegistryUrl`、`RegistryUrl`；
- Registry 同步复用现有远端素材授权 Header 控件，避免另建认证孤岛；
- 同步 payload 包含 `master_data_key`、source、asset id、canonical version/ETag/updated_at/alt_text/reference、package/profile 列表和 affected_items；
- 同步请求带 `qfig-master-registry-*` 幂等键；
- 成功后写入 `question_figure_library_cross_package_master_registry_sync_execution` 审计记录，并回写题图 metadata：`master_registry_sync_status`、`master_registry_synced_at`、`master_registry_sync_endpoint`、`master_registry_id`、`master_registry_version`；
- 失败、权限失效或冲突只沉淀执行记录，不把链路判定为完成；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library cross-package master registry sync UI evidence；
- 成熟度 gap 从 `advanced question asset library cross-package asset master data remote registry sync UI` 收敛为 `advanced question asset library cross-package asset master data subscription lock governance UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data subscription lock governance UI`。

## 边界说明

本轮不声明以下能力完成：

- 真实远端主数据中心的数据模型治理；
- 远端素材库版本 API 的双向订阅和定时拉取；
- 主数据锁、审批锁、租户锁、编辑锁或跨组织权限锁；
- 后台扫描、批量订阅推送、变更广播和冲突队列；
- 跨 archive 的持久化主数据中心；
- 对历史 Word 输出的追溯修复；
- 非题图素材族的跨包主数据远端同步。

当前剩余缺口应聚焦：Registry 同步完成后，如何治理后续远端主数据变更、订阅回调、锁定审批、冲突扩散和后台任务边界，而不是继续把“远端 Registry 同步入口”列为未打通。
