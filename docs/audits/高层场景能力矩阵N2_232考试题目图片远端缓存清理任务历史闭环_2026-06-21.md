# 高层场景能力矩阵 N2.232 考试题目图片远端缓存清理任务历史闭环

## 1. 本轮定位

N2.232 承接 N2.231 的缓存清理 dry-run 预览。此前系统已经能执行清理、预览清理候选，并把本次结果写入 manifest/report；但“任务历史”仍只是边界声明。后续若要做前台确认 UI、后台定时清理或任务列表，必须先有一份可打包、可报告、可追踪的历史 artifact。

本轮解决的断点是：

```text
cleanup / dry-run 只有本次摘要，
没有稳定的任务历史文件，
资料包和报告不能回看清理任务记录。
```

本轮只做运行级任务历史首片：每次 cleanup 或 dry-run 后写出 `cleanup_history.json`，并进入 manifest、资料包和 archive report。不做后台调度器、不做跨 profile 历史聚合 UI。

## 2. 新增历史文件

运行缓存目录 `_remote_asset_cache` 新增：

```text
cleanup_history.json
```

结构：

```text
schema_version
entry_count
records[]
updated_at
```

每条记录包含：

```text
task_id
mode
status
dry_run
dir_count
stale_index_entry_candidate_count
stale_index_entry_removed_count
orphan_file_candidate_count
orphan_file_removed_count
orphan_cleanup_enabled
status_counts
dirs[]
created_at
updated_at
```

`records` 最多保留最近 100 条，避免单个运行缓存目录无限增长。

## 3. Manifest 与报告

`remote_asset_cache.cache_cleanup` 新增：

```text
history_path
history_entry_count
history_latest_task_id
```

`remote_asset_cache` 摘要新增：

```text
cache_cleanup_history_path
cache_cleanup_history_entry_count
cache_cleanup_history_latest_task_id
```

资料包复制：

```text
remote_asset_cache/cleanup_history.json
```

资料包报告 `## Remote Asset Cache` 新增：

```text
Cleanup history entries
Cleanup history source
Cleanup history package
```

这样 dry-run 预览、真实清理和后续前台确认 UI 可以共用同一份任务历史证据。

## 4. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cache cleanup history bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

本轮把高级考试素材库从“单次清理摘要”推进到“清理任务可追踪、可打包、可报告”。

## 5. 仍未闭合的边界

N2.232 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API 登录、续期、签名 URL 与 UI 授权入口；
- 跨 profile 后台定时清理、前台确认 UI 和任务历史列表 UI；
- 断点续传、后台队列、并发下载调度；
- 跨运行缓存命中率趋势面板；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图或 AI 质量判断；
- 素材库版本、历史审阅、版权真实性和批量审阅 UI。
