# 高层场景能力矩阵 N2.241 考试题目图片远端缓存当前资料包命中率趋势面板 UI 闭环

日期：2026-06-21

## 本轮定位

N2.233 已经建立 `metrics_history.json`，N2.234 已经在选中的共享缓存目录下显示 metrics history 列表。但用户仍需要逐目录查看，无法在当前资料包范围内快速判断哪些共享缓存目录复用率在上升、下降或刚开始记录。

本轮闭合当前资料包内的命中率趋势面板首片。

## 已实现能力

- `AssetsPanel` 新增 `question_figure_shared_cache_trends_table`。
- 表格位于清理任务中心之后、目录内 index 条目表之前。
- 聚合当前 `EntityArchive.profiles` 中所有 profile 引用过的共享缓存目录。
- 同一共享缓存目录被多个 profile 引用时，按目录去重读取一次 `metrics_history.json`。
- 表格展示资料、目录、最新记录时间、记录数、条目数、复用/下载/失败、复用率和趋势。
- 趋势通过最新记录与上一条记录的 `cache_reuse_rate` 差值计算。
- 单条记录显示“首次”，差异小于 0.05 个百分点显示“持平”，其余显示 `+N.Npp` 或 `-N.Npp`。
- tooltip 写入资料归属、共享目录、记录数、最新 index path、缓存状态分布和下载状态分布。
- 不改变运行时 metrics history 写入格式，也不新增新的统计口径。

## 未伪装完成的边界

本轮仍不是完整长期趋势中心，不承担以下能力：

- 跨资料包或全应用趋势聚合。
- 图形化折线/柱状趋势图。
- 后台定时刷新与后台指标队列。
- 长周期趋势筛选、导出和告警。
- 真实素材库 API 授权入口。

后续边界应继续表述为“跨资料包长期命中率趋势中心”。
