# 高层场景能力矩阵 N2.251 考试题目图片批量对比矩阵报告闭环

## 1. 本轮定位

N2.250 已经把人工确认的题图对比问题接入 Workbench issue queue、运行时诊断、批量 `batch_issue_items` 和题图行修复入口。剩余断点是：批量执行报告仍只能逐条展示 issue，缺少一个按 profile 与题号横向审阅的矩阵视角。

N2.251 关闭的是“人工题图对比问题进入批量矩阵式报告”的首片：不做自动错图识别，不做像素级 diff，不做差异区域框选，也不做一键替换；只把已经确认或诊断出的 `comparison_issue_items` 聚合为结构化 `question_figure_comparison_matrix`，让批量审阅有稳定的 JSON/Markdown 承载。

## 2. 已实现能力

- 批量报告 JSON 新增 `question_figure_comparison_matrix`。
- 矩阵按 `profile_id/profile_name` 聚合每份试卷的题图对比问题。
- 矩阵按 `question_index` 聚合跨 profile 的同题问题。
- 每个矩阵 item 保留 `item_id`、`path`、`reference`、`display_name`、`issue_kind`、`marked_at`、`repair_target_type` 与 `repair_target_key`。
- Markdown 批量报告新增 `Question Figure Comparison Matrix` 小节，展示总问题数、涉及 profile 数、涉及题号数，以及 profile / question 的可读行。
- Workbench batch payload 同步携带 `question_figure_comparison_matrix`，后续 UI drilldown 或一键修复可以复用同一结构。

## 3. 链路闭合

矩阵报告链路：

`asset_items.metadata.comparison_issue_*` -> 运行时 `preflight_question_figure_manual_comparison_issue` -> `batch_issue_items[].comparison_issue_items` -> `question_figure_comparison_matrix` -> batch JSON / Markdown report -> 后续 report drilldown / repair queue。

与 N2.250 的关系：

- N2.250 解决“单条人工对比问题能进入队列和诊断”；
- N2.251 解决“多 profile / 多题号批量执行时能形成横向审阅矩阵”。

## 4. 仍不宣称完成

- 自动识别题图内容是否放错；
- 像素级、感知哈希级或 OCR/图像语义级差异检测；
- 差异区域框选、标注图层和批注编辑；
- 依据矩阵结果自动替换题图或一键修复；
- AI 判断复杂几何、电路、化学、坐标图等学科图质量。

这些能力仍属于 `advanced question asset library UI` / `advanced asset library UI` 的后续产品化边界。
