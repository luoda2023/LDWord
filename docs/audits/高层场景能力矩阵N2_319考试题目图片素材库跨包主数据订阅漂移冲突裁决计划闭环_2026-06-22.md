# 高层场景能力矩阵 N2.319 考试题目图片素材库跨包主数据订阅漂移冲突裁决计划闭环
日期：2026-06-22

## 本轮定位

N2.318 已经让已入队的订阅漂移/冲突进入分诊、指派与审批状态。N2.319 继续关闭下一段缺口：审批通过后，系统需要把“接受远端、保留本地、字段合并”等裁决选项结构化为可审计计划，而不是直接停留在人工说明或直接执行。

这一轮仍不声明裁决执行、字段合并写回、自动应用远端版本、批量应用、远端同步或历史 Word 输出追溯修复完成。当前只承诺：审批通过的 drift/conflict 可以生成字段级 decision plan，计划记录每个 diff 字段的本地值、远端值、可选动作和推荐裁决方向，供后续执行层消费。

## 已闭合内容

- 新增 `question_figure_asset_library_master_subscription_drift_decision_plan_table`；
- 裁决计划表从 `question_figure_library_cross_package_master_subscription_drift_conflict_triage_assignment_approval` 审计记录反推，不依赖临时 UI 状态；
- 仅展示已分诊审批且尚未生成裁决计划的跨包主数据；
- 裁决计划表展示 master key、diff 字段、推荐策略、影响摘要、状态和处理动作；
- “生成计划”写入 `question_figure_library_cross_package_master_subscription_drift_conflict_decision_plan` 审计记录；
- 计划记录包含 plan id、plan status、strategy、item count、decision plan items、queue id、approval changed_at、event、remote/local metadata、diff fields、Registry 与订阅锁信息；
- `decision_plan_items` 按 diff field 记录本地值、远端值、可选动作和推荐方向；
- `asset_version`、`asset_etag`、`asset_updated_at` 默认推荐 `accept_remote_after_review`；
- `alt_text`、`reference` 支持 `field_merge` 选项，并默认推荐人工字段合并复核；
- 题图 metadata 回写 decision plan status、plan id、planned_at、strategy、item count、next step 和 plan fields；
- 裁决计划仍不覆盖本地 `asset_version` 等主版本字段；
- 计划生成后该候选行退场，避免重复生成；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library cross-package master subscription drift conflict decision plan UI evidence；
- 成熟度 gap 从 `advanced question asset library cross-package asset master data subscription drift conflict decision plan UI` 收敛为 `advanced question asset library cross-package asset master data subscription drift conflict decision execution UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data subscription drift conflict decision execution UI`。

## 边界说明

本轮不声明以下能力完成：

- 接受远端、保留本地、字段合并的真实执行；
- 批量裁决、批量应用、后台执行队列；
- 冲突执行失败重试、回滚、二次补偿；
- 队列 SLA、优先级人工调整、后台提醒、重放和跨 archive 持久化；
- 历史 Word 输出追溯修复；
- 非题图素材族的订阅漂移/冲突裁决计划。

当前剩余缺口应聚焦：decision execution，也就是如何把已生成的计划按字段写入本地或远端，并形成可回滚、可重试、可审计的执行链路。
