# 高层场景能力矩阵 N2.347 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复非题图素材族修复历史 Word 输出远端冲突裁决回滚远端状态复核闭环

## 1. 定位

N2.346 已经把 failed remote conflict decision queue 推进到 rollback execution。对于 `rollback_execution_confirmed_no_remote_change` 的项，系统可以直接交给 retry/replay handoff；但对于 `rollback_execution_manual_remote_review_required` 的项，仍需要一个明确的人工远端状态复核入口，避免把“远端副作用未知”的失败裁决直接重放。

本轮 N2.347 补齐这个入口：当 rollback execution 的状态为 `rollback_execution_review_required` 时，前台提供 `Review`，记录人工远端状态复核、异常副作用裁决和复核后的 retry/replay handoff。

## 2. 本轮闭环

- `rollback_execution_review_required` 状态下表格提供 `Review`、`Manifest`。
- `Review` 消费 rollback execution items 中的 `rollback_execution_manual_remote_review_required` 项。
- review record 记录：
  - `manual_remote_snapshot_review_recorded`；
  - `remote_side_effect_absence_confirmed_by_manual_review`；
  - `no_abnormal_remote_side_effect_detected`；
  - `release_retry_or_replay_handoff`；
  - `retry_or_replay_handoff_ready_after_review`。
- review manifest 独立写入 `artifacts/subscription_drift_non_question_asset_family_word_output_remote_conflict_decision_remote_state_reviews`。
- review metadata 回写到相关 profile 的 asset item，表格状态推进为 `reviewed`。
- `Manifest` 优先级调整为 review > execution > queue > decision > connector。

## 3. 链路变化

需要人工远端状态复核的失败裁决链路现在变为：

```text
... -> Decide -> Queue -> Execute -> Review -> Manifest
```

其中 `Review` 是人工确认“没有异常远端副作用”的审计节点；它不再执行写回，而是把队列项释放到复核后的 retry/replay handoff。

## 4. 矩阵口径

新增 evidence：

- `question asset per-question asset library cross-package master subscription drift conflict batch failure recovery non-question asset family repaired historical Word output remote conflict decision rollback remote state review UI bridge`

剩余 gap 收窄为：

- pack：`advanced question asset library cross-package asset master data subscription drift conflict batch failure recovery non-question asset family repaired historical Word output remote conflict decision retry replay after remote state review UI`
- family：`advanced asset library cross-package asset master data subscription drift conflict batch failure recovery non-question asset family repaired historical Word output remote conflict decision retry replay after remote state review UI`

这表示人工远端状态复核已经产品化；后续要补的是复核完成后的 retry/replay 执行、幂等重放结果、二次 manifest 和失败补偿队列。
