# 高层场景能力矩阵 N2.273 考试题目图片对比修复批量应用事务任务摘要闭环

日期：2026-06-21

## 1. 本轮定位

N2.273 承接 N2.270-N2.272 的事务台账路线。此前系统已经能把 apply/rollback 审计归并为事务台账、写出 JSON artifact，并生成可读 Markdown 报告；但如果后续要进入完整批量事务中心或后台任务中心，前台还需要一个更轻的任务摘要事实源，回答：

- 当前是否还有 active 事务；
- 有多少事务仍可回滚；
- 最近一条事务是什么状态；
- 应该进入报告复查、历史复查，还是先处理 manifest blocker。

本轮只做事务任务摘要首片，不做任务调度、任务取消、任务重试、并发执行、跨多 docx 队列、原子事务、自动回滚或失败补偿。

## 2. 已闭合能力

- 事务台账新增 `task_summary`。
- `task_summary.kind` 固定为 `question_figure_repair_batch_apply_transaction_task_summary`。
- `task_summary.status` 支持 `active`、`completed`、`blocked`、`orphaned`、`empty`。
- `task_summary.next_action` 支持 `review_active_transaction`、`review_transaction_history`、`resolve_manifest_blocker`、`review_orphan_rollback`、`review_history`。
- `task_summary` 记录 transaction、active、rolled_back、rollback_available、orphan rollback 计数。
- `task_summary` 记录 active / rolled_back / rollback_available transaction ids。
- `task_summary` 记录 latest transaction、latest apply audit 和 latest rollback audit。
- 事务 Markdown 报告新增 `## Task Summary` 段落。
- 批量执行 Markdown 摘要新增 `task=<status>` 和 `rollback_available=<n>`。
- Workbench `question_figure_repair_queue` detail 新增 `tx_task=<status>` 和 `rollback_available=<n>`。
- Workbench artifact list 新增 `question_figure_batch_apply_transaction_task_summary`，锚到事务报告的 task summary 段。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset comparison repair queue batch apply transaction task summary bridge` evidence。

## 3. 链路视角

```text
question_figure_batch_apply_audit.json
  -> batch_apply_transaction_manifest.transactions[]
  -> batch_apply_transaction_manifest.task_summary
  -> question_figure_batch_apply_transaction_manifest.json
  -> question_figure_batch_apply_transaction_manifest.md#Task Summary
  -> Workbench artifact: transaction_tasks
```

这条链路让 Workbench 不只知道“有一份事务台账”，还知道这份台账当前更像一个 active task、completed history、blocked manifest，还是 orphan rollback 复查对象。

## 4. 仍不宣称完成的边界

- 不做完整批量事务中心。
- 不做后台任务中心。
- 不做任务调度、取消、重试或并发执行。
- 不做跨多 docx 队列。
- 不做原子事务。
- 不做自动回滚或失败补偿执行。
- 不做文件快照系统。
- 不做远程素材库写回。
- 不做重复图片智能 disambiguation。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：已有事务台账能派生出可被 UI、报告和后续任务中心消费的轻量任务摘要。
