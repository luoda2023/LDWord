# 高层场景能力矩阵 N2.393k 残留比例退出准入链接补充

## 目标

N2.393 已经把 `count_profiles=14/15`、`delivery_families=14/15`、`maturity_l5_blocked=6/27` 做成 `release_residual_ratio_ledger`。N2.393j 又补上了 `retained_gap_exit_criteria=6/6 release-allowed`。本轮把这两层打通：凡是残留比例来自 retained boundary gap，必须能追到 release envelope 和 retained gap exit criteria。

## 本轮链接

`release_residual_ratio_ledger` 现在新增 `retained_gap_exit_criteria_trace` 和 `boundary_scope_guard_trace`：

| Ratio | 读数 | 新增 release envelope | 新增 exit criteria | 说明 |
| --- | ---: | ---: | ---: | --- |
| `count_profiles` | `14/15` | 2 | 2 | `ip_patent_documents` 是专业审查边界；`import_ai_boundary` 是导入/AI 转换边界 |
| `delivery_families` | `14/15` | 2 | 2 | 专利交付和导入转换不能被宣称为核心最终 DOCX 承诺 |
| `maturity_l5_blocked` | `6/27` | 6 | 6 | 六个 Blue/Boundary 主体继续由发布封套和退出准入共同治理 |

因此总读数为：

- `residual_ratio_exit_criteria=10/10`
- `count_delivery_alignment=4/4`
- `boundary_scope_alignment=6/6`
- `release_envelope_link_count=10`
- `retained_gap_exit_criteria_link_count=10`

## 闭环口径

这不是把 `14/15` 改成满格，也不是把边界能力升级为 Green/L5。它只补强一个发布解释：当 release gate 暴露非满格比例时，用户能够从该比例一路追到来源行、终端例外、发布封套、禁止核心宣称和退出信号。

验收要求：

- `scene_release_residual_ratio_ledger_audit` 必须校验 retained gap exit criteria 链接存在且 `release_allowed_with_exit_criteria`；
- release gate 人类摘要必须展示 `residual_ratio_exit_criteria=10/10`、`count_delivery_alignment=4/4` 和 `boundary_scope_alignment=6/6`；
- dashboard 和 summary projection 必须展示 residual ratio exit criteria 链接数与 boundary scope guarded 读数；
- drilldown 的 `release_residual_ratio_ledger` 行必须直接展示对应 boundary capability 与 excluded core claims，避免用户只能看到 envelope id 却看不到本地可做范围和禁止宣称范围；
- N2.394 baseline 证书继续通过 `release_residual_ratio_ledger`、`release_residual_ratio_exit_criteria=10/10`、`count_delivery_boundary_alignment=4/4`、`maturity_l5_blocker_alignment=6/6`、`release_residual_boundary_scope_alignment=6/6`、`release_export_scripts=15/15 ready` 和 `release_acceptance_certificate=12/12` 接收该治理层；N2.400 后当前证书增加 receipt rows，并提升为 `acceptance_certificate=14/14`。
