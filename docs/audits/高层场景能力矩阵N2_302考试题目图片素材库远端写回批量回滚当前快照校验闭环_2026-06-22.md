# 高层场景能力矩阵 N2.302 考试题目图片素材库远端写回批量回滚当前快照校验闭环

## 1. 背景

N2.301 已经把二次补偿执行失败项推进到前台队列，但批量回滚和二次补偿仍缺少一个关键保护闸：在真正向远端 POST 回滚/补偿前，系统必须确认远端当前值仍然是本系统上一轮写入后的值。

本轮闭合“批量回滚当前快照校验”。它不做后台任务、manifest、独立 drilldown 或 OAuth 续期；只承诺在回滚/补偿前读取远端 current endpoint，匹配后才执行 POST，权限失败或远端被改动时进入可审计失败状态，避免覆盖他人后续更新。

## 2. 已闭合能力

- 批量写回执行结果继承 `questionFigureNCurrentUrl` / `current_endpoint`，事务报告和回滚候选可继续拿到远端当前快照入口。
- 回滚结果项新增 `current_endpoint`、`current_snapshot_status`、`current_snapshot_diff_fields`、`remote_current_*`、`expected_current_*` 等审计字段。
- 新增统一校验函数 `_question_figure_remote_writeback_batch_current_snapshot_guard`。
- 回滚执行前先 GET `current_endpoint`，以 `source_after`、`asset_id_after`、`alt_text_after` 作为“期望远端当前值”。
- 二次补偿执行前同样先 GET `current_endpoint`，复用同一套校验逻辑。
- 未配置 current endpoint 或缺少期望值时标记 `not_configured`，兼容旧导入数据并继续执行。
- GET 401/403 时返回 `permission_required`，记录 `current_snapshot_status=permission_required` 和 HTTP 状态，并阻止后续 POST。
- GET 失败或响应不是对象时返回 `fetch_failed`，阻止后续 POST。
- 远端 current metadata 与期望值不一致时返回 `remote_conflict`，记录差异字段并阻止后续 POST。
- 远端 current metadata 完全匹配时返回 `matched`，允许继续执行回滚或二次补偿 POST。
- 回滚失败队列和二次补偿失败队列继续复用现有权限重试入口；授权更新后重新执行时会再次校验 current snapshot，匹配后才 POST。

## 3. 测试锁定

- `_WritebackSimpleHTTPRequestHandler` 新增 `/current/1` GET 模拟和 GET 授权头/路径记录。
- `test_assets_panel_creates_remote_writeback_batch_transaction_report` 锁定成功路径：rollback 前 GET `/current/1`，授权头正确，`current_snapshot_status=matched`，随后才发送 rollback POST。
- `test_assets_panel_surfaces_remote_writeback_batch_rollback_failure_queue_permissions` 锁定失败路径：rollback 与 second compensation 在 stale token 下只 GET current snapshot，不继续 POST；失败结果进入权限分类；更新授权并重试后重新 GET 成功，再执行补偿 POST。
- 成熟度审计测试新增 `question asset per-question asset library remote writeback batch rollback current snapshot UI bridge` evidence，并把 remaining gap 推进到回滚冲突字段级合并治理。
