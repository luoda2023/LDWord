# 高层场景能力矩阵 N2.310 考试题目图片素材库远端写回企业授权续期 Connector 执行闭环

日期：2026-06-22

## 本轮定位

N2.309 已经让签名 URL 刷新结果能进入系统并解除预检阻断，但企业授权仍停留在“生成续期申请 / 手动更新授权”。N2.310 关闭企业授权续期的首片执行链路：续期申请生成后，前台可以执行企业授权续期 connector 或应用授权回调，把返回的 Header / Token 写入既有远程素材授权控件，并让企业授权预检自然退场。

## 已闭合内容

- 企业鉴权预检表中，企业授权待补齐且已生成续期申请后新增“执行续期”动作；
- 支持资料导入中的企业授权续期 endpoint：`enterprise_auth_renewal_url`、`enterprise_auth_refresh_url`、`auth_renewal_url`、`auth_refresh_url`、`token_refresh_url`、`oauth_refresh_url`、`sso_refresh_url`；
- 支持授权回调字段：`renewed_auth_payload`、`refreshed_auth_payload`、`renewed_authorization`、`renewed_access_token`、`renewed_api_key`、`renewed_cookie` 等；
- connector 复用既有远端素材授权 header，并从 JSON `metadata`、`data.metadata`、`data` 或顶层字段提取 `source`、`headers`、`access_token`、`api_key`、`cookie`；
- 通用授权 payload 解析器支持返回 `source`，避免企业素材库 token 被错误写成全局授权；
- 成功续期后调用既有远程素材授权控件写入 `source/header/value`，并通过 profile fields 持久化；
- 新增 `question_figure_library_remote_writeback_enterprise_auth_renewal_execution` 审计记录，保存来源、endpoint、HTTP 状态、授权来源、Header 与脱敏 value；
- 成功写入后，企业授权预检行消失，单项远端写回交接可继续生成；
- `scene_product_readiness` 为 `exam_education` 与 `exam_teaching` 新增 per-question asset library remote writeback enterprise auth renewal connector execution UI evidence；
- 成熟度 gap 从 `advanced question asset library remote writeback enterprise auth connector external permission callback execution UI` 收窄为 `advanced question asset library remote writeback external permission callback execution UI`。

## 边界说明

本轮不声明以下能力完成：

- 交互式 OAuth/SSO 浏览器登录跳转；
- token 自动定时续期与后台刷新任务；
- 真实企业身份平台的完整账号体系；
- 外部组织/角色/题库权限审批回调；
- 权限主数据同步；
- 跨资料包素材主数据版本系统。

当前“执行续期”只承诺：当企业授权刷新结果已经以 metadata 回调字段存在，或 renewal endpoint 可返回授权 header/token 时，前台可以受控执行、写入授权控件、沉淀审计并解除企业授权预检阻断。
