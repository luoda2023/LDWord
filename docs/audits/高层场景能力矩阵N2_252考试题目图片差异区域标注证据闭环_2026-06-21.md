# 高层场景能力矩阵 N2.252 考试题目图片差异区域标注证据闭环

## 1. 本轮定位

N2.251 已经把人工确认的题图对比问题聚合为批量 `question_figure_comparison_matrix`。但矩阵里仍只能看到“哪份试卷、哪道题、和哪个对象对比有问题”，缺少“用户当时看到的是图片的哪个区域”的结构化证据。

N2.252 关闭的是“差异区域标注证据”的首片：不做自由框选画布，不做标注图层编辑，也不做自动视觉差异检测；只在用户点击“标记对比问题”时，把当前大图查看器的可见区域、缩放比例、主图尺寸与对比图尺寸写入 `comparison_issue_region_*` metadata，并让该区域证据进入运行前问题、运行时诊断、批量 issue 和矩阵报告。

## 2. 已实现能力

- AssetsPanel 大图查看器标记对比问题时写入：
  - `comparison_issue_region_type=current_view`
  - `comparison_issue_region_summary`
  - `comparison_issue_region_json`
- 区域 JSON 使用 `schema_version=1`、`unit=px`，记录主图 `image`、可见区域 `view`、对比对象 `compare`。
- `preflight_question_figure_manual_comparison_issue` 会透传 `comparison_issue_region_*`。
- Workbench 运行前问题详情会展示“差异区域：current_view(...)”。
- `batch_issue_items[].comparison_issue_items[]` 保留区域字段。
- `question_figure_comparison_matrix` 的 item 新增 `region_type`、`region_summary`、`region_json`。
- Markdown batch report 的 `Question Figure Comparison Matrix` 行会追加区域摘要。
- `scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset comparison region annotation bridge` evidence。

## 3. 链路闭合

区域证据链路：

AssetsPanel 大图查看器 -> 当前可见区域 `current_view` -> `asset_items.metadata.comparison_issue_region_*` -> MaterialExecutionContext -> Workbench issue queue -> material diagnostics -> `batch_issue_items` -> `question_figure_comparison_matrix` -> batch JSON / Markdown report。

这使后续真正的框选、图层编辑或一键修复可以复用同一份区域 schema，而不是重新设计报告字段。

## 4. 仍不宣称完成

- 鼠标拖拽自由框选；
- 多区域标注；
- 标注图层显示、编辑、删除；
- 自动像素差异或语义差异检测；
- 按区域自动替换或一键修复；
- AI 判断复杂几何、电路、化学、坐标图等学科图质量。

当前区域是“标注时当前视图区域”，不是完整的视觉 diff 区域编辑器。
