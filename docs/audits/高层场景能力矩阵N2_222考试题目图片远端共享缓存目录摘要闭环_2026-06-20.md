# 高层场景能力矩阵 N2.222 考试题目图片远端共享缓存目录摘要闭环

## 1. 本轮定位

N2.222 继续执行 V43 的 P0 高级考试素材库路线，在 N2.221 已经支持共享缓存目录和索引双写后，补齐前台浏览和报告消费所需的摘要入口：

```text
共享缓存目录不能只藏在 index entry 里，
material manifest 和资料包报告也要直接告诉用户本次运行用了哪些共享缓存目录。
```

本轮不是完整共享缓存目录管理器，也不是批量失效或统一清理。它只把共享缓存作用域和目录汇总为主清单/资料包报告可读字段，给后续缓存治理面板提供稳定输入。

## 2. 新增摘要字段

`remote_asset_cache` 摘要新增：

```text
cache_scope_counts
shared_cache_dir_counts
```

其中：

- `cache_scope_counts` 汇总 `cache_scope`，例如 `shared=1`；
- `shared_cache_dir_counts` 汇总 `shared_cache_dir`，例如 `C:/cache/exam=1`；
- 未使用共享缓存时，这两个字段保持空计数，不影响旧输出。

## 3. 报告可读输出

资料包报告的 `## Remote Asset Cache` 段新增：

```text
- Cache scopes: shared=1
- Shared cache dirs: C:/cache/exam=1
```

这样用户打开资料包报告即可知道本次运行是否使用共享缓存，以及具体命中了哪个共享缓存目录。

## 4. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote shared cache directory summary bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“可声明并复用共享缓存”推进到“共享缓存目录可由 manifest/report 直接发现”。

## 5. 仍未闭合的边界

N2.222 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 深层缓存治理：共享缓存目录浏览 UI、后台失败重试、批量失效、统一清理、跨运行缓存命中率面板；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
