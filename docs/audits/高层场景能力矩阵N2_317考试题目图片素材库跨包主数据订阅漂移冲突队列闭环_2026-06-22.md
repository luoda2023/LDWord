# 高层场景能力矩阵 N2.317 考试题目图片素材库跨包主数据订阅漂移冲突队列闭环
日期：2026-06-22

## 本轮定位

N2.316 已经让订阅变更 callback 能把远端变化带入本地审计，并记录远端/本地 diff。N2.317 继续关闭下一段缺口：当 callback 结果为 `remote_change_detected` 且存在 diff fields 时，前台出现“订阅漂移/冲突队列”入口，用户可以把该主数据漂移登记为可治理队列项。

这一轮仍不声明队列分派、审批、字段级裁决、自动应用远端版本、批量扩散或后台任务完成。当前只承诺：callback 已发现远端变化后，前台能把 drift/conflict 形成可审计、可恢复、可进入下一流程的队列记录。

## 已闭合内容

- 新增 `question_figure_asset_library_master_subscription_drift_queue_table`；
- 队列表从 `question_figure_library_cross_package_master_subscription_change_callback_execution` 审计记录反推，不依赖临时 UI 状态；
- 仅展示 callback 成功、`subscription_change_status=remote_change_detected` 且尚未登记队列的跨包主数据；
- 队列表展示 master key、资料包范围、变更事件、diff fields、队列状态和处理动作；
- “登记队列”写入 `question_figure_library_cross_package_master_subscription_drift_conflict_queue_governance` 审计记录；
- 队列记录包含 queue id、scope、category、next step、callback changed_at、event id/type/changed_at、remote/local metadata、diff fields、Registry 与订阅锁信息；
- 题图 metadata 回写 `master_subscription_drift_queue_status`、queue id、queued_at、scope、next step、diff fields、event id；
- 队列登记仍不覆盖本地 `asset_version` 等主版本字段；
- 队列登记后该候选行退场，避免重复入队；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library cross-package master subscription drift conflict queue UI evidence；
- 成熟度 gap 从 `advanced question asset library cross-package asset master data subscription drift conflict queue UI` 收敛为 `advanced question asset library cross-package asset master data subscription drift conflict triage assignment approval UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data subscription drift conflict triage assignment approval UI`。

## 边界说明

本轮不声明以下能力完成：

- 队列分派、责任人/角色/租户审批；
- 字段级裁决、接受远端、保留本地、字段合并；
- 批量队列筛选、批量审批、批量应用；
- 队列 SLA、优先级、后台提醒、重放和跨 archive 持久化；
- 历史 Word 输出追溯修复；
- 非题图素材族的订阅漂移/冲突队列。

当前剩余缺口应聚焦：入队后的 triage、assignment、approval 与裁决边界，而不是继续把“订阅漂移/冲突队列登记入口”列为未打通。
