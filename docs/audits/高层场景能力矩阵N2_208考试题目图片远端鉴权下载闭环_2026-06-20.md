# 高层场景能力矩阵 N2.208 考试题目图片远端鉴权下载闭环

## 1. 本轮定位

N2.208 继续执行 V43 的 P0 高级考试素材库路线，在 N2.207 “asset_id/source 可通过本地解析清单获得 download_url”之后，补齐远端图片下载的鉴权首片：

```text
当 question_figure 的 URL 已来自 path、metadata.download_url 或 entity_data resolver，
且场景运行上下文提供下载鉴权 header 时，
Workbench 可在执行前携带 header 下载图片、落本地缓存，并继续渲染 Word。
```

本轮不是完整权限系统，仍不实现：
- 外部素材库 API 的登录、刷新 token 或签名 URL 生成；
- 权限失败原因细分、重试、重新登录或 UI 授权流程；
- ETag、Last-Modified、过期判断、强制刷新等缓存刷新策略；
- 下载前远端内容预览；
- 内容级错图识别、复杂学科图/AI 制图质量判断；
- 素材库批量审阅、版本治理、标签治理。

它的意义是把“需要 Authorization/Cookie/API key 的远端题图”从只能失败并回到修复入口，推进到“资料包可携带受控下载鉴权配置，执行时使用但不泄漏”的闭环。

## 2. 输入契约

题图素材仍沿用 N2.205-N2.207 的三类 URL 来源：

```text
AssetItem.path URL
metadata.download_url / remote_url / asset_url / source_url / original_url / url
entity_data.question_asset_library 等 resolver
```

鉴权配置放在 `MaterialExecutionContext.entity_data`，支持以下 key：

```text
question_asset_download_auth
question_figure_download_auth
remote_question_asset_download_auth
asset_download_auth
remote_asset_download_auth
asset_auth
```

这些 key 在执行下载后会从本次运行的 `runtime_material.entity_data` 中移除，不进入模板填充、material manifest 字段、JSON report 或 Markdown report。

### 2.1 全局 headers

```json
{
  "headers": {
    "Authorization": "Bearer <token>"
  }
}
```

### 2.2 按 source 分组

```json
{
  "lark_asset_library": {
    "headers": {
      "Authorization": "Bearer <token>"
    }
  }
}
```

### 2.3 按 asset_id 或记录列表

```json
{
  "lark_asset_library:remote-question-asset-4": {
    "headers": {
      "Authorization": "Bearer <token>"
    }
  }
}
```

或：

```json
[
  {
    "asset_id": "remote-question-asset-4",
    "source": "lark_asset_library",
    "headers": {
      "Authorization": "Bearer <token>"
    }
  }
]
```

### 2.4 简写字段

除 `headers` 外，单条配置也支持：

```text
authorization / auth_header
bearer_token / access_token / token
cookie / cookies
api_key / x_api_key
```

其中 `token` 类字段会自动写成 `Authorization: Bearer <token>`；`api_key` 类字段写成 `X-API-Key`。

## 3. 安全约束

下载请求会过滤不应由资料配置注入的 header：

```text
Connection
Content-Length
Host
Proxy-Authorization
Transfer-Encoding
```

执行成功后，题图 metadata 只记录非敏感来源：

```json
{
  "download_auth_source": "entity_data.question_asset_download_auth"
}
```

不会把 token、cookie、API key 写入：
- `asset_items.metadata`;
- material manifest `fields`;
- material manifest `asset_items`;
- JSON report;
- Markdown report。

## 4. 闭环链路

```text
asset_items.metadata.asset_id/source
-> entity_data.question_asset_library 解析 download_url
-> entity_data.question_asset_download_auth 匹配 source/asset_id/header
-> urllib Request 携带 Authorization/Cookie/API key
-> 下载到 _remote_asset_cache
-> metadata.download_auth_source + cache_path/cache_status
-> _asset_render_path 使用 cache_path
-> Word 渲染图片
-> JSON/Markdown report 显示 assets=1/1
-> material manifest 保留鉴权来源，不保留鉴权密钥
```

若鉴权缺失或鉴权失败，下载器保持失败不阻断，N2.204 的 `preflight_remote_question_figure_uncached` 继续接管，回链到题图行替换本地文件、修正 URL 或修正鉴权配置。权限失败原因的细粒度展示仍属于后续边界。

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote authenticated download bridge
```

覆盖对象：
- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“匿名 URL 或本地解析 URL 可下载”，推进到“需要 header 鉴权的远端题图也可在执行时安全下载”。N2.209 已继续追补 401/403 等权限失败的可解释诊断首片；但它仍不是完整素材库权限体系，因为鉴权配置仍由场景资料包携带，未包含登录、续期、权限审计和 UI 授权流程。

## 6. 仍未闭合的边界

N2.209 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界收窄为：

- 真实素材库 API：凭 `asset_id/source` 远程查询下载 URL，并在必要时完成登录、续期或签名 URL 生成；
- UI 授权入口：401/403/过期/无权限/签名失效时的重新授权、token 刷新、权限申请或账号切换；
- 缓存刷新策略：过期判断、ETag、Last-Modified、强制刷新、失败重试；
- 远端内容预览：下载前预览、失败占位、类型/尺寸信息；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
