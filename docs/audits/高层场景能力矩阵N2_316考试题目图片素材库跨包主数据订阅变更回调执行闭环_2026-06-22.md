# 高层场景能力矩阵 N2.316 考试题目图片素材库跨包主数据订阅变更回调执行闭环
日期：2026-06-22

## 本轮定位

N2.315 已经把跨包题图主数据推进到 Registry 同步后的订阅锁治理。N2.316 继续关闭下一段缺口：当资料显式提供订阅变更 callback endpoint 时，跨包主数据版本治理表会在订阅锁治理成功后保留该 master key，并把动作切换为“执行变更回调”，通过 HTTP JSON GET 拉取远端变更快照。

这一轮仍不声明真实后台订阅服务、签名校验、后台扫描、定时拉取、变更广播、自动应用远端版本或冲突队列完成。当前只承诺：已有治理计划、已本地推广、已 Registry 同步、已订阅锁治理、且 metadata 中存在 callback endpoint 时，前台可以受控执行 callback，记录远端/本地差异，回写 drift metadata，并让该阶段退场。

## 已闭合内容

- 跨包主数据版本表新增第五阶段状态：`记录计划 -> 执行推广 -> 同步Registry -> 治理订阅锁 -> 执行变更回调`；
- 无 callback endpoint 的数据保持 N2.315 行为：订阅锁治理后退场；
- 有 `subscription_change_callback_url` / `master_subscription_change_callback_url` / `change_callback_url` / `subscription_callback_url` 等端点的数据，在订阅锁治理成功后显示“待执行变更回调”；
- 新增导入别名，覆盖 `SubscriptionChangeCallbackUrl`、`MasterSubscriptionChangeCallbackUrl`、`AssetSubscriptionChangeCallbackUrl`、`RegistryChangeCallbackUrl`、`MasterDataChangeCallbackUrl`、`AssetChangeCallbackUrl`、`ChangeCallbackUrl`、`SubscriptionCallbackUrl`；
- 变更回调复用现有远端素材授权 Header 控件，并通过 HTTP JSON GET 读取 callback payload；
- callback payload 可从顶层、`metadata`、`change.metadata`、`data.metadata`、`change` 或 `data` 中解析 event id、change type、changed_at、远端 source、asset id、asset_version、asset_etag、asset_updated_at、alt_text、reference/download_url；
- 成功后写入 `question_figure_library_cross_package_master_subscription_change_callback_execution` 审计记录；
- 审计记录保留 Registry id/version、subscription id、lock token、lock version、callback endpoint、远端字段、本地字段和 diff fields；
- 题图 metadata 回写 `master_subscription_change_callback_status`、callback 时间、endpoint、change status、diff fields、event id/type/changed_at，以及远端 source、asset id、version、etag、updated_at、alt text、reference；
- callback 只记录远端漂移，不覆盖本地 `asset_version`、`asset_etag`、`asset_updated_at`、`alt_text` 和 reference；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library cross-package master subscription change callback execution UI evidence；
- 成熟度 gap 从 `advanced question asset library cross-package asset master data subscription change callback execution UI` 收敛为 `advanced question asset library cross-package asset master data subscription drift conflict queue UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data subscription drift conflict queue UI`。

## 边界说明

本轮不声明以下能力完成：

- 真实远端订阅服务、Webhook 签名校验和重放防护；
- 后台扫描、定时拉取、变更广播和跨 archive 持久化主数据中心；
- 漂移/冲突队列、批量扩散、审批流、字段级裁决和自动应用远端版本；
- 主数据锁的租约续期、释放、多人编辑锁、跨租户审批锁；
- 历史 Word 输出追溯修复；
- 非题图素材族的跨包主数据订阅变更 callback。

当前剩余缺口应聚焦：callback 已经能把远端变化带入本地审计后，如何把 drift/conflict 变成可筛选、可分派、可审批、可批量处理的队列，而不是继续把“订阅变更 callback 执行入口”列为未打通。
