# 高层场景能力矩阵 N2.294 考试题目图片素材库远端写回批量失败队列 UI 闭环

## 1. 背景

N2.293 已经让冻结计划中的 ready 项可以进入批量执行队列，并产生批量执行摘要。但批量执行出现权限失败、远端冲突、普通失败或跳过时，用户仍需要自己回到单项表里找对应题图，链路还没有形成“失败项可见、可定位、可动作”的队列。

本轮闭合“批量失败队列首片”。它不做后台重试、不做指数退避、不做事务报告 artifact，也不做回滚或补偿；只负责把最近一次批量执行摘要中的非成功项投影成前台队列，并把每类问题路由回已有单项动作。

## 2. 已闭合能力

- 题图素材库区域新增 `question_figure_asset_library_remote_writeback_failure_queue_table`。
- 失败队列表按 `问题 / 题目 / 状态 / 下一步 / 处理` 展示。
- 队列来源为最近一次 `question_figure_library_remote_writeback_batch_execution` 的 `transaction_result_items`。
- 只展示非 success 结果，包括 permission、conflict、failed、skipped。
- 展示前重新复核当前单项远端写回状态；如果某失败项后来已经进入终局状态，如“已执行”“已应用远端”“已覆盖远端”“已合并字段”，则自动从失败队列移除。
- 权限失败项显示“权限失效”，下一步为“更新授权后重试”，动作提供“更新授权”和“重试”。
- “更新授权”复用单项权限失效治理链路，定位到当前 source 的授权控件。
- “重试”复用单项权限重试分流，支持普通写回、远端当前快照、覆盖远端、字段合并等权限失效重试。
- 远端冲突项显示“远端冲突”，动作提供“处理冲突”和“定位”，并复用单项冲突处理计划记录能力。
- 普通失败项显示“执行失败”，动作提供“重试”和“定位”，并复用单项远端写回执行 connector。
- 跳过项显示“已跳过”，动作提供“定位”，避免把非 ready 项强行执行。
- 选中失败队列行会定位到单项远端写回表，再回链到具体题图行。
- 失败队列表复用共享表格样式、动作容器和按钮 variant，保持与模板管理控件风格一致。
- 新增测试锁定“两条批量权限失败 -> 失败队列两条权限项 -> 更新授权 -> 重试一条 -> 队列收缩为一条”的动作桥链路。

- 指数退避、并发控制、限流和调度取消；
- 批量事务 manifest/artifact；
- 批量事务报告与 report drilldown；
- 远端批量回滚或本地补偿回滚；
- 已成功项跳过后的恢复/重放策略；
- 幂等窗口管理、重复提交防护中心；
- OAuth/SSO 登录、token 自动续期、签名 URL 自动续签；
- 组织、角色、题库权限申请或审批；
- 跨资料包素材主数据版本系统。
