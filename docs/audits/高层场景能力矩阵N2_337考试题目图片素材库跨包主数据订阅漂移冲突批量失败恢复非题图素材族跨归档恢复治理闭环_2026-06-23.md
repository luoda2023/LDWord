# 高层场景能力矩阵 N2.337 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复非题图素材族跨归档恢复治理闭环

## 1. 本轮定位

N2.336 已经把题目图片素材库在历史 Word 输出中的 `word/document.xml`、`word/_rels/document.xml.rels` 与 `word/media/*` 深修复推进到可执行首片。本轮 N2.337 承接它明确保留的缺口：签章、Logo、二维码、封面图、资质材料、签名图等非题目图片素材族，不能继续被题图素材库的恢复链路顺手带过。

本轮闭合的是“跨归档恢复治理 UI”：识别同一 `role/source/asset_id` 在多个 profile 中的本地文件可用性、缺失项、远端引用和可恢复候选，写入治理 manifest 与 profile metadata。它不伪装完成真实复制、Word XML 改写或回滚执行；这些留给下一步 `non-question asset family cross-archive recovery execution rollback connector UI`。

## 4. 场景边界

非题图素材族不是题目图片，也不是模板管理里的普通装饰图。它们属于场景资料/交付证据/组织身份的一部分：签章影响投标、合同、公文和证明材料；Logo 与封面影响品牌交付；二维码影响外部系统或校验入口；资质材料影响附件与证明链。

当前治理表只承诺“找到同族素材、判断缺失、给出可恢复候选、写入治理事实”。它不执行以下动作：

- 不直接复制缺失文件到其他 profile；
- 不改写历史 DOCX；
- 不修改 `document.xml`、header/footer relationships 或 `word/media/*`；
- 不执行回滚、二次补偿或远端写回；
- 不把公式、输出版本、水印等场景参数混入素材族恢复治理。

## 5. Word XML 视角

非题图素材族在 Word 内的落点更分散，不能沿用题目图片的单一正文图片视角。后续执行连接器至少要覆盖：

- 正文：签章、资质图片、二维码、封面图的 inline/anchor 引用；
- 页眉页脚：Logo、水印型图片、页眉横幅；
- relationships：`word/_rels/document.xml.rels`、`word/_rels/header*.xml.rels`、`word/_rels/footer*.xml.rels`；
- media：缺失媒体补写、孤儿媒体清理、重复媒体去重和回滚副本；
- 输出链路：学生版、教师版、答案版、正式版/内部版等多版本输出之间的素材一致性。

因此，本轮把“治理记录”先做成跨 profile 的事实源。下一轮执行连接器应从该事实源派生 copy/rewrite/rollback plan，而不是重新扫描一套不一致的素材口径。

## 6. 控件样式一致性约束

场景配置中的新增控件必须继续继承模板管理和素材管理的控件契约：

- 表格使用既有 `QTableWidget` QSS、表头、行高、选中态和 item 样式；
- 行动作按钮继续使用共享 button variant，不新增场景专用按钮语言；
- 数值输入继续使用统一输入框样式，单位、禁用态和摘要反馈与模板管理一致；
- 下拉选择继续使用 `StyledComboBox`；
- 开关继续使用共享 checkbox/toggle 契约；
- 如果场景页暴露缩进、段距、行距等覆盖项，左缩进/右缩进、段前/段后应同排，特殊缩进必须支持“无、首行、悬挂”的明确切换；
- `TableConfig.row_height_pt` 这一类残留参数不能含混存在：若属于固定版式套打，应进入 fixed-layout 场景能力；若无执行消费，应从通用模板模型退场。

## 7. 状态链路

- `governance_recovery_candidate_ready`：存在缺失本地文件，且同族素材在其他 profile 中有可用本地候选。
- `governance_source_required`：存在缺失本地文件，但没有可恢复候选，需要人工提供源文件或远端授权。
- `governance_snapshot_recorded`：当前同族素材没有缺失，记录快照和跨归档一致性事实。
- `non_question_asset_family_recovery_execution_required`：下一步进入执行连接器，生成真实 copy/rewrite/rollback plan。
- `non_question_asset_family_source_handoff_required`：下一步进入人工补源或远端授权链路。
- `non_question_asset_family_cross_archive_governance_verified`：治理快照可被报告、审计和后续执行消费。
