# 高层场景能力矩阵 N2.228 考试题目图片远端下载失败重试闭环

## 1. 本轮定位

N2.228 继续承接 V43 的 P0 高级考试素材库路线。N2.205-N2.227 已经把远端下载、鉴权、缓存刷新、共享缓存、失效治理和前台浏览逐步打通，但下载链路仍是单次请求：临时 503、网络抖动或短暂限流会直接进入失败诊断。

本轮解决的断点是：

```text
远端题图下载失败时没有重试，
执行报告只能看到最终失败，
不能证明系统是否尝试过恢复。
```

本轮只做运行时首片：显式配置 retry 后重试 HTTP/网络类临时失败，并写入尝试次数与结果状态。不做后台队列、不做并发调度、不做断点续传。

## 2. 新增配置语义

默认行为保持不变：未配置 retry 时仍只请求一次。

可通过 `AssetItem.metadata` 或 `MaterialExecutionContext.entity_data` 配置：

```text
download_retry_count
download_retries
remote_download_retry_count
remote_asset_download_retry_count
question_figure_download_retry_count
question_asset_download_retry_count
```

支持 camelCase 变体，最大重试次数上限为 5。

## 3. 重试范围

可重试失败：

- `network_error`
- `download_error`
- HTTP `408`
- HTTP `429`
- HTTP `500`
- HTTP `502`
- HTTP `503`
- HTTP `504`

不重试失败：

- unsupported scheme
- unsupported content type
- size limit exceeded
- empty response
- 304 without local cache
- 401/403/404 等明确权限或资源问题

## 4. 运行时证据

下载 payload / material manifest / index entry 新增：

```text
download_attempt_count
download_retry_count
download_retry_limit
download_retry_status
```

状态语义：

- `not_needed`：配置了 retry，但首次请求成功；
- `succeeded`：经历至少一次失败后重试成功；
- `exhausted`：重试次数用尽后仍失败。

失败诊断的 `remote_asset_items` 也透出 retry 字段，Workbench 问题项可以直接看到重试是否耗尽。

## 5. 报告与索引摘要

`remote_asset_cache` 摘要新增：

```text
download_retry_status_counts
```

资料包报告 `## Remote Asset Cache` 新增：

```text
Download retry statuses
```

这让成功重试能在 manifest / index / archive report 中留下可审计证据。

## 6. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote download retry bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

本轮把高级考试素材库从“远端下载失败只做诊断”推进到“临时失败可显式重试并可报告”。

## 7. 仍未闭合的边界

N2.228 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余缓存治理边界继续收窄为：

- 按题型、学科、来源、素材库版本筛选的批量治理；
- 跨运行、跨目录、跨 profile 的后台统一清理；
- 断点续传、后台队列、并发下载调度；
- 跨运行缓存命中率趋势面板；
- token 续期、签名 URL 更新、401/403 后重新授权；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图生成；
- 素材库版本、历史审阅、版权真实性和 AI 质量边界。
