# 高层场景能力矩阵 N2.282 考试题目图片素材库版本回滚 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.282 承接 N2.281 的题图素材库版本历史 UI。上一轮已经能记录和展示 `source / asset_id / alt_text` 的本地 metadata 变更，但历史记录仍只能看和定位，无法从历史记录恢复到上一个明确版本。

本轮只补“本地版本回滚 UI”闭环：用户可以在题图素材库版本历史表中对一条历史记录执行回滚，系统会进行当前版本冲突校验，恢复该历史记录涉及的字段，并追加回滚审计记录。它不宣称完成远端素材库写回、跨资料包主数据版本系统或素材库 API 同步。

## 2. 已闭合能力

- 版本历史表处理按钮从“定位”升级为“回滚”。
- 历史表行选择仍保留定位能力，会同步回到原题图行、素材库索引行和 metadata 编辑器。
- 回滚入口显式要求确认参数，避免测试和内部调用误触发。
- 回滚前会校验当前 metadata 是否仍等于该历史记录的 after 值。
- 如果当前版本已被后来修改，回滚会被拦截，并提示“版本已变更，无法直接回滚”。
- 回滚只恢复该历史记录 `changed_fields` 中声明的 `source / asset_id / alt_text` 字段。
- 回滚成功后会追加 `question_figure_library_metadata_rollback` 记录。
- 回滚审计记录保存回滚前后值、字段清单、题目标签、题号、素材条目 ID、变更摘要和 `rollback_from_changed_at`。
- 回滚后会刷新当前 archive、material context、题图明细表、素材库索引表、版本历史表和摘要状态。
- 回滚记录仍独立存放在 `asset_item_history`，不会进入运行时 `AssetItem.metadata`。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library version rollback UI bridge` evidence。
- 成熟度剩余 gap 从 `advanced question asset library version rollback UI` 细化为 `advanced question asset library remote writeback UI`。

## 3. 链路视角

```text
select version history row
  -> locate original question figure row
  -> click rollback
  -> read asset_item_history record index
  -> match current question_figure payload
  -> verify current metadata equals history after-values
  -> restore only changed source / asset_id / alt_text fields
  -> append rollback audit record
  -> persist current profile
  -> refresh material context and tables
```

这条链路补的是“本地版本可恢复”。N2.281 解决历史可见和可追溯；N2.282 解决从历史记录执行恢复、冲突守卫和回滚审计。

## 4. 场景矩阵影响

`exam_education` 与 `exam_teaching` 的高级题图素材库路线继续被拆清：

- 按题索引可见性由 N2.277 闭合；
- 单题 metadata 编辑由 N2.278 闭合；
- 高频 metadata 治理问题清单由 N2.279 闭合；
- 批量治理计划 UI 由 N2.280 闭合；
- 本地版本历史 UI 由 N2.281 闭合；
- 本地版本回滚 UI 由 N2.282 闭合；
- 后续 remaining gap 明确转为 `advanced question asset library remote writeback UI`。

这意味着后续不能再把“没有本地版本回滚入口、没有回滚冲突校验、没有回滚审计记录”重复计算为 L5 blocker。真正剩余的是把本地 archive 中的素材库 metadata 治理结果同步回远端素材库或跨资料包主数据。

## 5. 仍不宣称完成的边界

- 不做远端素材库写回。
- 不做素材库 API 登录、续期、签名 URL 或权限续签。
- 不做远端素材库更新后的冲突合并策略。
- 不做跨资料包素材主数据版本系统。
- 不做批量 metadata 自动修复。
- 不做素材 ID 合并、拆分、去重的完整裁决执行。
- 不做学校、学科、题型题库规则治理。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：本地题图素材 metadata 历史可以被安全回滚、持久化、审计、刷新，并保持运行时 metadata 干净。
