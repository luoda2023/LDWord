# 高层场景能力矩阵 N2.194 考试题目图片前台行选预览闭环

日期：2026-06-20

## 1. 目标

N2.193 已把多条 `question_figure` 做成前台明细表，用户可以看到每张图对应的题目、文件名、说明和状态。但仍有一个高频核对断点：

```text
用户看到“题2：question_2.png”，
但无法直接点这一行看图本身，
仍要回到文件系统或依赖单槽预览。
```

N2.194 闭合这段前台链路：

```text
question_figure detail table
-> row selection
-> row path in Qt.UserRole
-> existing image preview scaler
-> image status label
```

它不是逐题编辑器，也不是替换器；它只保证单题行选中后可以预览该题图。

## 2. 落地内容

### 2.1 表格行保存图片路径

`AssetsPanel._refresh_question_figure_items_table()` 在填充每个单元格时，会把当前行对应的本地图片路径写入 `Qt.UserRole`。

这样前台行显示仍只包含：

```text
题目 / 图片 / 说明 / 状态
```

但选择事件可以稳定拿到真实路径，不需要从文件名反查。

### 2.2 行选中触发预览

`question_figure_asset_items_table.itemSelectionChanged` 连接到 `_on_question_figure_item_selection_changed()`。

用户选中某一行时：

- 读取该行 `Qt.UserRole` 中的路径；
- 调用已有 `_set_image_preview(path, role="question_figure")`；
- 复用现有缩放逻辑、图片质量文案和图片状态标签；
- 不改写 `asset_items`、不影响运行时逐题映射。

### 2.3 成熟度证据

`scene_product_readiness` 已更新：

- `pack:exam_education` evidence 增加 `question asset frontstage row preview`；
- `family:exam_teaching` evidence 增加 `question asset frontstage row preview`；
- total gaps 仍为 49；
- remaining gap 仍是 `advanced question asset library UI` / `advanced asset library UI`。

保留 gap 的原因是：本轮只让明细行可预览，不提供前台逐题编辑、替换、缺项修复、远端素材解析或一题多图排序。

## 3. 与 V42 的关系

N2.194 是 V42 `QuestionAssetLibrary` 槽位的继续补强。它把 N2.193 的“可核对文本明细”推进为“可核对图像内容”：

```text
题图导入
-> 映射明细
-> 选中单题
-> 预览该题图片
```

这让用户不再只看文件名，而能在 AssetsPanel 内完成基础视觉核对。

## 4. 仍保留的边界

仍不承诺：

- 前台逐题编辑；
- 单题替换按钮或拖拽替换；
- 缺项修复入口；
- 远端 `asset_id` / `source` 解析；
- 一题多图或图组排序；
- 复杂学科图自动生成；
- AI 出题质量或素材质量判断。

这些继续属于 `advanced question asset library UI`、插件能力或 manual boundary。
