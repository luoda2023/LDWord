# 高层场景能力矩阵 N2.199 考试题目图片一题多图图组排序闭环

日期：2026-06-20

## 1. 定位

N2.198 已经闭合远端 `asset_id/source` 作为一等题图素材引用的链路。其后 `advanced question asset library UI` 仍保留一个高频缺口：

```text
同一道题可能有多张题图，需要稳定排序并一起渲染。
```

本轮 N2.199 闭合第一片图组能力：

```text
结构化 asset_items
-> 同题 question_figure + figure_order
-> AssetsPanel 明细表按题号/图序展示
-> Workbench 注入为 exam JSON figure list
-> exam renderer 按顺序插入 Word 图片
-> report/maturity evidence
```

这不是批量错图自动检测，也不是复杂学科图生成。本轮只保证同题多图不再被第二张静默跳过，并且图组顺序可追。

## 2. 已闭合链路

### 2.1 结构化素材输入

`EntityProfile.asset_items` 可表达同题多图：

```json
[
  {
    "item_id": "fig_q1_2",
    "role": "question_figure",
    "path": "question_1_figure_2.png",
    "metadata": {
      "question_id": "q1",
      "figure_order": "2",
      "alt_text": "第二张示意图"
    }
  },
  {
    "item_id": "fig_q1_1",
    "role": "question_figure",
    "path": "question_1_figure_1.png",
    "metadata": {
      "question_id": "q1",
      "figure_order": "1",
      "alt_text": "第一张示意图"
    }
  }
]
```

本轮优先锁定结构化 `asset_items` 事实源。CSV 平铺列名的同题多图扩展仍可在后续继续加，但不阻断底层图组能力。

### 2.2 前台明细表

AssetsPanel 的逐题题图明细表现在按题号和 `figure_order` 排序。若同一题有多张图，题目列显示：

```text
题1-图1
题1-图2
```

状态、说明和替换按钮继续复用既有题图明细表能力。

### 2.3 运行时注入

N2.198 前，运行时逻辑在同一道题已有第一张图后会因为 `_question_has_figure_path()` 跳过第二张同题素材。

N2.199 改为：

- 如果题源原本已有 figure，不覆盖；
- 如果第一张 figure 是本轮素材注入的，则同题后续素材可追加；
- 多张素材按 `figure_order` 排序；
- 最终注入为 `figure` list；
- 每个 figure payload 保留 `source`、`path`、`asset_id`、`alt`、`caption` 和 `figure_order`。

这样保持了“不要覆盖原始题源”的保守语义，同时打通素材库图组。

### 2.4 Word 渲染与报告

`exam_question_schema` 原本已经支持 `figure` list。本轮把运行时注入打通后，Word 输出中同一道题可按图序插入多张图片。

报告继续使用既有题图统计：

```text
assets=2/2, altText=2/2
```

## 5. 后续边界

N2.199 后，`advanced question asset library UI` 的剩余边界进一步收窄为：

- CSV/XLSX 平铺列名的一题多图导入语法；
- 批量自动匹配错图的检测与修复；
- 远端素材真实下载、鉴权、缓存和预览；
- 复杂学科图生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅与历史版本管理。

## 6. N2.200 追补

N2.200 已把 `CSV/XLSX 平铺列名的一题多图导入语法` 从剩余边界中移出：`questionFigure1Image1` / `questionFigure1Figure2` / `questionFigure1Image2AltText` 等列名可以导入为同一题的多张 `question_figure` 素材，并在 `asset_items` 中补齐 `question_index` 与 `figure_order`。

N2.199 的图组排序、前台明细表和运行时注入能力因此获得了表格导入入口。N2.201 又补上文件名题号错配预检。剩余边界继续聚焦在内容级错图识别、远端素材真实下载/鉴权/缓存/预览、复杂学科图或 AI 质量判断，以及更完整的素材库批量审阅与版本管理。
