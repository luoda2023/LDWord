# 高层场景能力矩阵 N2.307 考试题目图片素材库远端写回企业鉴权签名 URL 组织权限预检闭环

本轮闭合 N2.306 后的 `enterprise auth / signed URL / organization permission governance` 首片：把题目图片素材库远端写回中的企业鉴权、签名 URL 过期、组织/角色权限要求前移到 UI 预检、单项交接、单项执行和批量事务计划/执行链路。它不声明 OAuth/SSO 登录、token 自动续期、签名 URL 自动续签或组织权限申请系统已经完成；它承诺本地可判定的风险不再绕过前台治理直接写回远端。

## 已闭合内容

- 题图素材库远端写回表后新增“企业鉴权预检”表，列出风险、题目、范围、状态和处理入口。
- 预检表复用既有远端写回表格样式、按钮 variant 和 `_refresh_summary()` 刷新链路，保持与模板管理/场景配置控件样式一致。
- CSV/XLSX 题图元数据新增导入别名：`auth_mode`、`auth_type`、`enterprise_auth`、`auth_provider`、`signed_url_expires_at`、`writeback_expires_at`、`current_expires_at`、`organization_id`、`org_id`、`required_role`、`required_scope`、`permission_scope`、`permission_status` 等。
- 预检识别企业鉴权要求：当题图元数据声明 OAuth/SSO/enterprise/token/API key/cookie 等授权模式，而当前“远程素材授权”没有匹配来源、Header 和值时，显示“企业授权待补齐”。
- 预检识别签名 URL 过期：支持显式过期字段，也解析 `expires`、`expires_at`、`expiry`、`exp`、`X-Amz-Date` + `X-Amz-Expires` 等常见 URL 参数。
- 预检识别组织/角色/权限范围要求：当元数据声明组织、角色或 scope 且没有 `permission_status=approved/granted/authorized/ok` 等通过标记时，显示“组织权限待确认”。
- 预检行可“更新授权”并聚焦远程素材授权输入，也可“定位”到对应题图和远端写回行。
- 单项“生成交接”前重新预检，命中企业授权、签名 URL 或组织权限问题时阻断，不写入伪 handoff 记录。
- 单项“执行写回”前再次预检，避免 handoff 后 URL 过期或权限上下文变化时继续 POST。
- 批量事务 summary 将命中预检的问题归入 `blocked`，并在 plan item 中记录 `enterprise_auth_issue/status/next_step`。
- 批量执行循环逐项重跑预检，冻结计划后如果授权/URL/权限状态变化，仍不会绕过阻断直接执行。
- `scene_product_readiness` 在 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback enterprise auth signed URL organization permission preflight UI bridge` evidence。

## 仍不宣称完成

- OAuth/SSO 登录跳转、组织统一身份认证接入、token 自动续期。
- 签名 URL 自动续签、远端凭证刷新、短链刷新任务。
- 组织/角色/题库权限申请、审批、授权主数据同步。
- 企业审计日志、跨组织访问边界、外部权限系统回调。
- 跨资料包素材主数据版本系统。
