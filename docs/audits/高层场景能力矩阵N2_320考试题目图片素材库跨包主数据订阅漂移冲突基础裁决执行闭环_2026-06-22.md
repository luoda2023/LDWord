# 高层场景能力矩阵 N2.320 考试题目图片素材库跨包主数据订阅漂移冲突基础裁决执行闭环
日期：2026-06-22

## 本轮定位

N2.319 已经把跨包主数据订阅漂移冲突推进到字段级 decision plan：系统能从已审批的队列项生成每个 diff 字段的本地值、远端值、候选动作和推荐裁决方向。N2.320 继续补上下一段执行链路，但只覆盖基础裁决执行：接受远端与保留本地。它不把字段级人工合并、批量应用、后台任务、失败重试、回滚或历史 Word 输出追溯修复伪装成已完成。

当前承诺是：已生成并审批的订阅漂移裁决计划，可以在前台出现“执行裁决”入口；执行后，版本类主数据字段按计划接受远端，说明与引用字段按计划保留本地；执行结果同步写回受影响 profile 的题图 metadata，并产生可审计的执行记录。

## 已闭合内容

- 新增 `question_figure_asset_library_master_subscription_drift_decision_execution_table`，承接 N2.319 生成的裁决计划。
- 执行表从 `question_figure_library_cross_package_master_subscription_drift_conflict_decision_plan` 审计记录反推待执行项，且只展示 `planned`、尚未执行的记录。
- 表格展示主数据键、计划摘要、接受远端字段、保留本地字段、状态和处理动作。
- “执行裁决”生成 `question_figure_library_cross_package_master_subscription_drift_conflict_decision_execution` 审计记录。
- 执行记录包含 execution id、execution status、connector、plan id、changed fields、accept remote fields、keep local fields、executed items 与 next step。
- `asset_version`、`asset_etag`、`asset_updated_at` 按计划执行 `accept_remote`，写回远端值。
- `alt_text`、`reference` 按计划执行 `keep_local`，保留本地说明与本地素材引用。
- `reference` 在执行层按规范字段处理，并投射回现有资产元数据实际承载字段，例如 `download_url`、`asset_url`、`preview_url`、`thumbnail_url` 或 `cache_path`。
- metadata 写入 `master_subscription_drift_decision_execution_status`、执行 id、执行时间、plan id、变更字段、接受远端字段、保留本地字段和 next step。
- 已执行的计划不再重复出现在执行表中，避免同一 plan 重复执行。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 per-question asset library cross-package master subscription drift conflict decision execution UI evidence。
- 成熟度 gap 从 `advanced question asset library cross-package asset master data subscription drift conflict decision execution UI` 收敛为 `advanced question asset library cross-package asset master data subscription drift conflict field merge decision execution UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data subscription drift conflict field merge decision execution UI`。

## 边界说明

本轮后仍不声明以下能力完成：

- `field_merge` 的真实字段级交互与合并执行；
- alt text 与 reference 的人工逐字段来源选择；
- 多行批量裁决、批量执行、批量失败队列；
- 执行失败重试、回滚、二次补偿、后台 worker、SLA、优先级人工调整、提醒与重放；
- 跨 archive 持久化主数据中心；
- 历史 Word 输出追溯修复；
- 非题图素材族的订阅漂移冲突裁决执行。

因此，当前剩余的明确非本轮缺口不是“decision execution 整体未打通”，而是“field merge decision execution 未打通”。下一轮应聚焦字段级合并：为 `alt_text` 与 `reference` 提供本地/远端/手工合并选择，沉淀合并来源、合并值、字段级审计与失败退路。
