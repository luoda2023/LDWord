# 高层场景能力矩阵 N2.240 考试题目图片远端缓存当前资料包跨 Profile 任务中心 UI 闭环

日期：2026-06-21

## 本轮定位

N2.239 已经能在当前资料上下文里聚合共享缓存目录的清理任务，但范围仍以当前 profile 的 `asset_items` 为主。对批量生成资料包来说，多个 profile 可能引用不同共享缓存目录，也可能复用同一个共享缓存目录；如果只看当前 profile，前台任务视角仍会断开。

本轮闭合当前资料包内的跨 profile 前台任务中心首片。

## 已实现能力

- `question_figure_shared_cache_tasks_table` 从 7 列扩展为 8 列，新增“资料”列。
- 当前编辑中的 profile 使用编辑器实时 `asset_items`，避免未持久化编辑内容被漏掉。
- 其他 profile 使用 `EntityProfile.asset_items`、`asset_paths` 和 `asset_metadata` 解析出的资料项。
- 聚合当前 `EntityArchive.profiles` 中出现过的全部共享缓存目录。
- 同一个共享缓存目录被多个 profile 引用时，按目录去重读取一次 `cleanup_history.json`。
- “资料”列合并使用该共享目录的 profile 标签。
- 任务 tooltip 写入资料归属、目录、任务 id、失效索引候选/删除数和孤儿文件候选/删除数。
- 原有目录级 index 条目、metrics history、cleanup history、确认行仍按选中目录工作，不改变执行语义。

## 未伪装完成的边界

本轮仍不是完整后台任务中心，不承担以下能力：

- 跨资料包或全应用扫描。
- 后台定时清理。
- 后台队列、并发控制、取消、重试。
- 长任务断点续传。
- 真实素材库 API 登录、续期、签名和 UI 授权入口。

后续边界应继续表述为“跨资料包/后台定时清理、后台全局任务中心”，不再把当前资料包内的跨 profile 前台任务中心算作缺口。
