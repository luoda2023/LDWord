# 高层场景能力矩阵 N2.225 考试题目图片远端共享缓存目录浏览 UI 闭环

## 1. 本轮定位

N2.225 继续执行 V43 的 P0 高级考试素材库路线，承接 N2.222 的共享缓存目录摘要、N2.223 的单项显式失效和 N2.224 的运行级批量失效。

本轮解决的是前台可见性断点：

```text
共享缓存目录已经能在 material manifest / archive report 中留痕，
但 AssetsPanel 里仍只能逐题看远端/缓存状态，
不能按 shared_cache_dir 浏览本批题图命中的共享缓存目录。
```

本轮只实现当前 profile / 当前 material context 的轻量浏览摘要，不做后台目录扫描、不做删除按钮、不做跨运行统一清理。

## 2. 新增前台控件

AssetsPanel 的图片材料区域新增：

```text
question_figure_shared_cache_dirs_table
```

表格列为：

```text
共享缓存目录
题图
缓存状态
失效状态
```

显示规则：
- 只在当前题图素材中存在 `shared_cache_dir` / `sharedCacheDir` / `remote_cache_dir` / `cache_dir` 等共享缓存目录字段时显示；
- 按共享缓存目录聚合；
- 题图列显示该目录下当前 profile 的题图数量；
- 缓存状态列聚合 `cache_status`，缺省时按 `cache_path`、本地 path 或远端引用推断；
- 失效状态列聚合 `cache_invalidation_status` 和 `cache_invalidation_scope`。

示例：

```text
共享缓存目录: C:/cache/exam
题图: 2 张
缓存状态: 已下载=1，已复用=1
失效状态: 已失效=1；批量=1
```

## 3. 链路关系

本轮把 N2.221-N2.224 的运行链路前台化为：

```text
question_figure metadata.shared_cache_dir
-> AssetsPanel 当前 material context
-> question_figure_shared_cache_dirs_table
-> 按目录聚合题图数量、缓存状态、失效状态
-> 用户可在执行前确认本批题图命中了哪些共享缓存目录
```

这条链路与逐题表互补：
- `question_figure_asset_items_table` 继续负责逐题图片、说明、状态和替换；
- `question_figure_shared_cache_dirs_table` 负责按目录浏览共享缓存命中情况；
- 两者都消费同一套 `AssetItem.metadata`，不引入新的运行时字段。

## 5. 仍未闭合的边界

N2.225 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余缓存治理边界继续收窄为：

- 打开共享缓存目录、查看索引详情、按条目 drilldown；
- 按题型、学科、来源、素材库版本筛选的批量治理；
- 跨运行、跨目录、跨 profile 的后台统一清理；
- 后台失败重试、断点续传、并发下载队列；
- 跨运行缓存命中率趋势面板；
- token 续期、签名 URL 更新、401/403 后重新授权；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图生成；
- 素材库版本、历史审阅、版权/真实性/AI 质量边界。
