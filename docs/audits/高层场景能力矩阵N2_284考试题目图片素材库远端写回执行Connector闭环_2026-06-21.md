# 高层场景能力矩阵 N2.284 考试题目图片素材库远端写回执行 Connector 闭环

日期：2026-06-21

## 1. 本轮定位

N2.284 承接 N2.283 的题图素材库远端写回交接 UI。上一轮已经能把本地 metadata 治理结果形成交接清单和 `handoff_ready` 审计记录，但交接记录还不能进入可执行 connector。

本轮补“远端写回执行 connector”首片：当题图 metadata 提供 `writeback_url`，并且当前版本仍与来源历史记录一致时，AssetsPanel 可通过 HTTP JSON POST 执行写回，沿用远端素材授权 Header，并把成功或失败写入 `question_figure_library_remote_writeback_execution` 审计记录。

## 2. 已闭合能力

- CSV/XLSX 导入新增 `questionFigureNWritebackUrl` 等写回端点字段，进入题图 metadata 的 `writeback_url`。
- 远端写回交接表在已生成交接后会检查当前题图是否存在 `writeback_url`。
- 有交接、有端点、版本未变化时，状态显示为 `待执行写回`。
- 无端点时，状态显示为 `缺端点`，不误导为可执行。
- 写回执行成功后，状态显示为 `已执行`。
- 写回执行失败后，状态显示为 `执行失败`，并保留可重试入口。
- 执行前复用版本一致性校验，当前 metadata 已变化时阻止写回。
- 执行 connector 使用 `HTTP POST + application/json`。
- 执行请求沿用现有远端素材授权控件的 source-scoped Header。
- 写回 payload 包含题图角色、条目 ID、题号、当前 source、asset_id、变更字段和 metadata patch。
- 成功或失败都会生成 `question_figure_library_remote_writeback_execution` 审计记录。
- 执行审计记录包含 connector 类型、endpoint、HTTP 状态、响应摘要或错误原因、来源历史记录时间和交接记录时间。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback execution connector bridge` evidence。
- 成熟度剩余 gap 从 `advanced question asset library remote writeback execution connector` 细化为 `advanced question asset library remote writeback retry conflict governance`。

## 3. 链路视角

```text
metadata update or rollback
  -> remote writeback handoff record
  -> current metadata still matches history after-values
  -> metadata writeback_url exists
  -> source-scoped auth header
  -> HTTP JSON POST connector
  -> execution audit record
  -> refresh writeback table status
```

这条链路补的是“交接记录可执行”。N2.283 解决写回前的本地交接视图；N2.284 解决具备 endpoint 的交接记录可以真实发起一次受控写回，并留下执行证据。

## 4. 场景矩阵影响

`exam_education` 与 `exam_teaching` 的高级题图素材库路线继续收窄：

- 按题索引可见性由 N2.277 闭合；
- 单题 metadata 编辑由 N2.278 闭合；
- 高频 metadata 治理问题清单由 N2.279 闭合；
- 批量治理计划 UI 由 N2.280 闭合；
- 本地版本历史 UI 由 N2.281 闭合；
- 本地版本回滚 UI 由 N2.282 闭合；
- 远端写回交接 UI 由 N2.283 闭合；
- 远端写回执行 connector 首片由 N2.284 闭合；
- 后续 remaining gap 明确转为 `advanced question asset library remote writeback retry conflict governance`。

这意味着后续不能再把“没有 connector 执行入口、不能 POST endpoint、没有执行审计、不能带授权 Header”重复计算为 L5 blocker。真正剩余的是失败重试、幂等键、权限续期、远端版本冲突合并、批量事务和远端回滚。

## 5. 仍不宣称完成的边界

- 不做素材库登录态续期。
- 不做签名 URL 自动续签。
- 不做远端 409/412 等版本冲突合并 UI。
- 不做幂等键、重复提交防护和批量事务。
- 不做失败队列、指数退避、后台重试或断点续传。
- 不做远端回滚。
- 不做跨资料包素材主数据版本系统。
- 不做学校、学科、题型题库规则治理。
- 不做内容级错图识别。
- 不做复杂学科图或 AI 质量判断。

本轮只承诺：本地 `handoff_ready` 记录在具备 endpoint、版本未变且 Header 授权可用时，可以通过 HTTP JSON POST 执行写回，并形成成功/失败审计。
