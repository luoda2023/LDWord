# 高层场景能力矩阵 N2.308 考试题目图片素材库远端写回企业授权续期审批交接闭环

本轮闭合 N2.307 后的 `enterprise auth renewal approval execution` 首片：把企业授权、签名 URL、组织/角色权限预检项从“只提示/阻断”推进为“可生成续期或审批交接记录，并能对组织权限审批做前台确认”。它不声明 OAuth/SSO 续期 connector、签名 URL 自动刷新或外部权限回调已经完成；它承诺这些风险进入可审计的申请/审批链路，且组织权限确认能解除本地阻断。

## 已闭合内容

- 企业鉴权预检表新增交接动作：
  - 企业授权待补齐：显示“生成续期”；
  - 签名 URL 已过期：显示“生成续签”；
  - 组织权限待确认：显示“生成审批”。
- 生成交接后追加 `question_figure_library_remote_writeback_enterprise_auth_handoff` 历史记录。
- 交接记录保存题图、来源、素材 ID、原远端写回变更、issue category、issue、scope、next step 和 flow。
- 生成交接后预检表状态改为“续期申请已生成 / 续签申请已生成 / 审批申请已生成”，并提供“定位申请”。
- 组织权限审批申请生成后提供“确认审批”动作。
- 确认审批后追加 `question_figure_library_remote_writeback_enterprise_auth_approval` 历史记录，保存审批状态、交接 changed_at、权限 scope 和来源记录。
- 单项交接、单项执行和批量事务 summary 的预检判断会读取审批确认记录；已确认组织权限不再作为本地阻断项。
- 批量事务 summary 在组织审批确认后从 `blocked` 回到原本准备态，不需要用户手动改 CSV 元数据。
- 企业授权和签名 URL 仍保持阻断，直到用户补齐匹配授权或真实刷新 URL，避免把“生成申请”伪装成实际续期成功。
- `scene_product_readiness` 在 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback enterprise auth renewal approval handoff UI bridge` evidence。

## 缺口迁移

- `pack:exam_education` 的 remaining gap 从 `advanced question asset library remote writeback enterprise auth renewal approval execution UI` 收窄为 `advanced question asset library remote writeback enterprise auth connector signed URL refresh callback execution UI`。
- `family:exam_teaching` 的 remaining gap 从 `advanced asset library remote writeback enterprise auth renewal approval execution UI` 收窄为 `advanced asset library remote writeback enterprise auth connector signed URL refresh callback execution UI`。
- 新 gap 继续归属 `ui_control`、`runtime_execution`、`rule_governance`、`boundary_gate` 四个成熟度域。

## 仍不宣称完成

- OAuth/SSO 登录跳转、token 自动续期、企业身份平台回调。
- 签名 URL 自动续签、刷新 connector、短链刷新任务。
- 外部组织权限审批系统、组织权限回调、权限主数据同步。
- 企业审计日志与跨组织访问边界。
- 跨资料包素材主数据版本系统。
