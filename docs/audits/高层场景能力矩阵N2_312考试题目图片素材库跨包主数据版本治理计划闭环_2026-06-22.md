# 高层场景能力矩阵 N2.312 考试题目图片素材库跨包主数据版本治理计划闭环

日期：2026-06-22

## 本轮定位

N2.311 已经把外部权限审批回调接入执行、审计和预检退场链路。剩余缺口进入素材库更高层的主数据治理：同一个远端素材 `source + asset_id` 可能被不同资料包、不同 profile 复用，但各包携带的版本、ETag、更新时间、题图说明或 URL/缓存引用不一致。

N2.312 关闭跨资料包素材主数据版本治理的首片：前台可以基于整个 archive 的 profiles 聚合同一素材，识别跨包版本漂移或缺版本声明，并把治理计划写入所有受影响 profile 的 `asset_item_history`。它不声明已经完成选主、推广执行或真实主数据中心同步。

## 已闭合内容

- 题图素材库区域新增 `question_figure_asset_library_master_version_table`，展示主数据键、涉及资料包、版本摘要、差异字段、状态和处理动作；
- 以 `source + asset_id` 作为跨包主数据键，基于整个资料包 archive 的 profiles 聚合，不再局限于当前 profile；
- 支持导入跨包主数据字段：`libraryPackageId`、`packageId`、`materialPackageId`、`assetPackageId`、`libraryPackageName`、`packageName`、`assetVersion`、`libraryVersion`、`remoteVersion`、`assetEtag`、`remoteEtag`、`assetUpdatedAt`、`remoteUpdatedAt`、`lastModified` 等；
- 识别同一素材跨包的 `asset_version`、`asset_etag`、`asset_updated_at`、`alt_text`、URL/缓存引用差异；
- 当多个资料包复用同一素材但缺少版本/ETag/更新时间声明时，显示“待补版本声明”；
- “记录计划”动作会生成 `question_figure_library_cross_package_master_version_governance_plan` 审计记录；
- 治理计划写入所有受影响 profile 的 `asset_item_history`，包含 master key、资料包列表、profile 列表、差异字段、版本摘要、受影响题图条目和下一步；
- 重复点击同一主数据键不会重复生成治理计划；
- “定位”动作可跳转到首个受影响 profile 并定位对应题图素材；
- `scene_product_readiness` 在 `exam_education` 与 `exam_teaching` 新增 per-question asset library cross-package master version governance UI evidence；
- 成熟度 gap 从 `advanced question asset library cross-package asset master data version governance UI` 收敛为 `advanced question asset library cross-package asset master data version promotion execution UI`，家族口径同步收敛为 `advanced asset library cross-package asset master data version promotion execution UI`。

## 边界说明

本轮不声明以下能力完成：

- 自动选出主版本或可信主数据源；
- 把选定主版本推广写回所有资料包/profile；
- 跨包素材主数据中心或远端主数据服务；
- 主数据锁、审批、订阅、后台扫描和定时同步；
- 与远端素材库真实版本 API 的双向同步；
- 对历史 Word 输出文件进行跨包追溯修复。

当前“跨包主数据版本治理计划”只承诺：同一素材在多个资料包中的版本漂移或缺版本声明可见、可定位、可审计，并能把治理计划沉淀到所有受影响 profile。后续剩余缺口聚焦“选主 / 推广 / 执行”。
