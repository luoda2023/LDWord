# 高层场景能力矩阵 N2.247 考试题目图片远端全尺寸预览缩略图对比 UI 闭环

## 1. 本轮定位

N2.246 已让考试题图远端全尺寸预览具备缩放、100% 原始尺寸和适应窗口能力。V43 剩余边界中仍有“全尺寸对比查看/标注增强”，其中最基础、最高频的一段是：同一素材同时存在 `preview_url` / `fullPreviewUrl` 和 `thumbnail_url` 时，用户需要在大图查看器内确认缩略图与原图是否对应。

N2.247 关闭的是“同一题图原图与缩略图对比查看”首片，不扩展到多图横向比对、差异标注、批注或 AI 错图判断。

## 2. 已实现能力

- 题图明细表为每行额外记录缩略图对比引用：
  - 当前预览引用仍优先使用远端全尺寸预览 URL；
  - 当同条素材同时具备全尺寸预览 URL 和缩略图 URL 时，将缩略图 URL 写入 `Qt.UserRole + 3`；
  - 对比 source 和展示名同步写入 `Qt.UserRole + 4` / `Qt.UserRole + 5`。
- `AssetsPanel` 大图预览工具栏新增 `asset_full_image_preview_compare`。
- 对比按钮仅在当前大图预览存在可对比缩略图时启用。
- 点击对比按钮后，复用 source-scoped Header 授权下载缩略图，并在大图查看器右侧展开：
  - `asset_full_image_preview_compare_panel`
  - `asset_full_image_preview_compare_scroll`
  - `asset_full_image_preview_compare_image`
  - `asset_full_image_preview_compare_title`
- 状态栏展示 `已打开缩略图对比：<文件名>`，保留远端 URL 原始文件名。

## 3. 链路闭合

远端题图对比链路：

`questionFigure2ThumbnailUrl` + `questionFigure2FullPreviewUrl` -> 导入为 `thumbnail_url` + `preview_url` -> 题图表当前预览优先使用全尺寸预览 -> 表格行保存缩略图对比 URL -> 打开大图预览 -> 对比按钮启用 -> 点击后带授权 Header 下载缩略图 -> 右侧对比面板显示缩略图原始尺寸。

审计链路：

`scene_product_readiness` 中 `pack:exam_education` 与 `family:exam_teaching` 增加 `question asset remote full-preview compare UI bridge` evidence，并由 `tests/test_scene_product_maturity_upgrade_audit.py` 锁定。

## 4. 仍不宣称完成

- 真实素材库预览服务、签名预览 URL 续期、登录续期、授权续期。
- 后台队列、断点续传、并发下载调度。
- 多张全尺寸图横向对比、差异标注、批注、下载增强。
- 内容级错图识别、复杂学科图质量判断、AI 质量边界。

这些能力继续归入 `advanced question asset library UI` / `advanced asset library UI` 的后续产品化边界。
