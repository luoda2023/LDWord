# 高层场景能力矩阵 N2.334 考试题目图片素材库跨包主数据订阅漂移冲突批量失败恢复跨归档文件恢复中心 Word XML 关系媒体一致性闭环（2026-06-22）

## 1. 本轮定位

N2.333 已经把跨归档持久 worker 队列推进到前台 durable worker 监控、续跑判断和死信登记，但文件恢复仍停在“知道队列没有 DOCX 或等待 DOCX”的层面。本轮承接这个缺口，把恢复中心推进到 Word 文件结构视角：从 durable worker 监控记录向下追溯持久 worker 队列中的 DOCX targets，并扫描 `.docx` 包内的 `word/document.xml`、`word/_rels/document.xml.rels` 与 `word/media/*`，判断图片引用、关系目标和媒体文件是否一致。

本轮不声明真实修复 Word XML、重写 relationship 或自动生成缺失历史 DOCX。当前闭合的是“发现、记录、展示、审计、metadata 回写和成熟度缺口推进”，下一层才是历史 DOCX 生成接入与 Word media rewrite repair execution。

## 2. 新增产品能力

- 新增 `question_figure_asset_library_master_subscription_drift_batch_failure_recovery_file_recovery_center_table`，位于 durable worker 监控之后，显示批次、DOCX、XML 关系、媒体一致性、状态和处理动作。
- 新增恢复中心 action：`question_figure_library_cross_package_master_subscription_drift_conflict_batch_failure_recovery_cross_archive_file_recovery_center_word_xml_relationship_media_consistency`。
- 新增 artifact 类型：`question_figure_master_subscription_drift_batch_failure_recovery_cross_archive_file_recovery_center_word_xml_relationship_media_consistency`，默认写入 `artifacts/subscription_drift_file_recovery_centers`。
- 从持久 worker 队列记录解析 `subscription_drift_batch_failure_recovery_persistent_worker_queue_docx_targets` 或 `subscription_drift_batch_failure_recovery_word_media_rewrite_docx_targets`，并按最终扫描路径去重。
- 对真实 `.docx` 执行 Word 包扫描：提取 `r:embed` / `r:link` 引用、image relationship、关系指向的 media path、实际 `word/media/*` 文件，并输出 missing relationship、unreferenced relationship、missing media 与 orphan media。
- 无 DOCX 时明确记录 `blocked_missing_docx_targets`、`not_scanned` 和 `historical_word_docx_output_required`，避免把缺文件伪装成通过。
- 记录成功时写回题图素材 metadata：恢复中心状态、记录 id、Word XML 关系状态、媒体一致性状态、DOCX 目标数、已检查数、缺失关系数、孤儿媒体数、manifest 路径和 archive 信息。
- UI “定位记录”链路已接到上游 durable worker 监控行，不再出现按钮可见但 action 不被上游识别的断链。

## 3. Word XML 视角

本轮扫描的最小一致性模型是：

- `word/document.xml` 中的图片引用 id 必须能在 `word/_rels/document.xml.rels` 找到；
- image relationship 的 Target 归一化后必须能落到 `word/media/*`；
- `word/media/*` 中没有被 image relationship 引用的文件会被标记为 orphan media；
- 缺失 `document.xml` 或 rels 时进入 `xml_relationship_missing`；
- XML 解析失败、非法 docx、缺失 docx 分别有独立状态，而不是合并成通用失败。

这个视角比上一轮 durable worker 监控更深一层：上一轮只能说明“恢复批次是否有可执行目标”，本轮能说明“目标 Word 文件内部关系是否可信”。

## 4. 本轮边界

本轮仍不闭合：

- 历史 DOCX 缺失时的生成或接入策略；
- 对 `word/document.xml` 的图片引用自动改写；
- 对 `word/_rels/document.xml.rels` 的 relationship 自动修复；
- 对 `word/media/*` 的真实媒体补写、删除孤儿媒体或替换审计回滚；
- Word media rewrite 与题图替换审计、回滚审计、二次补偿 connector 的深度合流；
- 非题图素材族的同类跨归档文件恢复治理。

因此 readiness/maturity 的剩余缺口推进为：

- pack：`advanced question asset library cross-package asset master data subscription drift conflict batch failure recovery historical DOCX generation intake and Word media rewrite repair execution UI`
- family：`advanced asset library cross-package asset master data subscription drift conflict batch failure recovery historical DOCX generation intake and Word media rewrite repair execution UI`
