# 高层场景能力矩阵 N2.290 考试题目图片素材库远端写回字段合并裁决执行闭环

## 1. 背景

N2.288 闭合了“应用远端”，N2.289 闭合了“覆盖远端”。远端写回冲突仍剩下第三类高频裁决：不同字段采用不同事实源。例如保留本地的素材 ID，但采用远端当前的库来源和图片说明。

本轮只闭合题图 metadata 的 `source`、`asset_id`、`alt_text` 三个字段级合并，不把权限续期、失败队列、后台重试、批量事务或远端回滚伪装为完成。

## 2. 已闭合能力

- 远端快照成功后，远端写回表同一动作区提供“应用远端”“覆盖远端”“合并字段”三个裁决入口。
- “覆盖失败”“覆盖仍冲突”“合并失败”“合并仍冲突”状态仍保留三个裁决入口。
- “合并字段”入口弹出字段来源选择对话框，每个冲突字段可选择本地值或远端当前值。
- 对话框控件使用共享 `QComboBox` 输入样式和共享按钮 variant，继续保持与模板管理控件样式一致。
- 新增 `_execute_question_figure_library_remote_writeback_field_merge_decision_row`，执行前校验：
  - 已确认用户动作；
  - 来源历史记录仍存在；
  - 远端写回交接记录存在；
  - 远端当前快照为 `remote_current_snapshot_ready`；
  - 当前题图 metadata 仍等于来源历史 after 值；
  - 写回 endpoint 存在；
  - 尚无成功执行的终局裁决；
  - 每个冲突字段都明确选择本地或远端；
  - 字段合并至少同时包含一个本地字段和一个远端字段。
- 新增字段合并专用 POST payload：
  - `connector=question_figure_library_remote_writeback_conflict_decision`；
  - `conflict_decision=merge_fields`；
  - `metadata` 写入字段合并后的 source、asset_id、alt_text；
  - `remote_current` 写入远端快照值；
  - `field_sources` 写入每个字段采用本地或远端。
- 字段合并请求使用独立 `Idempotency-Key`，前缀为 `qfig-merge-`。
- 字段合并成功后追加 `question_figure_library_remote_writeback_conflict_decision` 审计记录：
  - `writeback_status=conflict_decision_applied`；
  - `conflict_resolution_status=applied`；
  - `conflict_resolution_action=merge_fields_writeback`；
  - `conflict_decision=merge_fields`；
  - `conflict_decision_applied_scope=local_and_remote_metadata`。
- 字段合并成功后，本地题图 metadata 同步为合并结果，远端通过二次 POST 写入同一合并结果。
- 字段合并成功后表格状态显示“已合并字段”，动作退回“定位”。
- 字段合并再次遇到 HTTP 409/412 时记录 `conflict_decision_remote_conflict`，状态显示“合并仍冲突”。
- 字段合并请求失败时记录 `conflict_decision_failed`，状态显示“合并失败”。
- 成功裁决后，重复执行应用远端、覆盖远端或字段合并都会被拦截为“远端冲突裁决已执行”。

## 3. 模型与成熟度变化

- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback field merge decision execution UI bridge` evidence。
- `pack:exam_education` 的 remaining gap 从 `advanced question asset library remote writeback field merge decision execution UI` 收窄为 `advanced question asset library remote writeback permission batch transaction governance UI`。
- `family:exam_teaching` 的 remaining gap 从 `advanced asset library remote writeback field merge decision execution UI` 收窄为 `advanced asset library remote writeback permission batch transaction governance UI`。
- `scene_product_maturity_upgrade_audit` 的显式 gap-domain mapping 已同步新 gap 名，仍归属 `ui_control`、`runtime_execution`、`rule_governance`、`boundary_gate`。

## 4. 仍不宣称完成

- 素材库登录态续期；
- 签名 URL 自动续签；
- 失败队列、指数退避、后台重试；
- 批量事务、幂等窗口管理、重复提交防护中心；
- 远端回滚；
- 跨资料包素材主数据版本系统。
