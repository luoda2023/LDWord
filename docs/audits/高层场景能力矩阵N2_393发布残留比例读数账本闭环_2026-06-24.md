# 高层场景能力矩阵 N2.393 发布残留比例读数账本闭环

## 目标

N2.393 处理 release gate 最后一行仍然容易被误读的残留比例。N2.382 已经解释了非满分 readiness 来源，N2.392 已经把 6 个 Blue/Boundary 成熟度保留项封装成 release envelope；本轮继续把最终发布摘要中的 `count_profiles=14/15`、`delivery_families=14/15`、`maturity_l5_blocked=6/27` 做成独立的 `release_residual_ratio_ledger`。

这不是把残留比例改成 100%。正确目标是让每一个非满分或 blocked 读数都能回答三个问题：

- 真实观察到的发布摘要读数是什么；
- 为什么它不是未完成缺口；
- 它在 readiness reconciliation、terminal release exception、boundary release envelope、dashboard、drilldown、release gate 和 CI 中分别由谁承接。

## 账本对象

N2.393 管理 3 条发布残留比例：

| Ratio | 观察读数 | 来源审计 | 发布解释 |
| --- | ---: | --- | --- |
| `count_profiles` | `14/15` | `scene_count_profile_audit` | `ip_patent_documents` 保持专业审查边界；`quick_formatting` 与 `import_ai_boundary` 保持显式 not-applicable count surface |
| `delivery_families` | `14/15` | `scene_delivery_preset_audit` | 专利交付归专业 handoff；import-AI 交付归 handoff/report 边界而非 final-DOCX 承诺 |
| `maturity_l5_blocked` | `6/27` | `scene_product_maturity_upgrade_audit` | 6 个 Blue/Boundary subject 保留在非 Green/L5，但每个 retained blocker 已有 N2.392 release envelope |

## 闭环链路

新增审计模块 `scene_release_residual_ratio_ledger_audit` 动态读取源审计的实际分子/分母。若未来 `14/15` 或 `6/27` 改变，而账本仍沿用旧解释，审计会失败；若某个 residual 消失，账本也必须同步删除对应 spec。

每一行必须同时满足：

- observed ratio 与期望发布读数一致；
- 对应 readiness reconciliation row 存在且已 reconciled；
- 对应 terminal release exception 存在且 governed；
- 对于 `maturity_l5_blocked`，6 个 release envelope 必须全部 `release_envelope_ready`；
- dashboard、drilldown、summary projection、release gate、workflow test、closure doc 均有投影。

## 产品口径

UI 可以继续展示 `14/15` 和 `6/27`，但不能把它们渲染成未解释失败。正确表达是：

- `Release residual ratios 3/3 published`；
- `CountProfile 14/15` 与 `DeliveryPreset 14/15` 是边界/不适用读数；
- `CountProfile 14/15` 与 `DeliveryPreset 14/15` 必须共享 `family:ip_patent_documents:IP plugin handoff` 与 `pack:import_ai_boundary:real OCR/PDF/LaTeX plugin integration` 这组 release envelope / retained-gap exit criteria，避免两个 14/15 被误解释成两条互不相干的缺口；
- `maturity_l5_blocked=6/27` 是受控边界保留项，已被 N2.392 release envelope 包住。

## 验收

- `scene_release_residual_ratio_ledger_audit` 返回 `3/3 published`、`0 issues`；
- release gate 输出 `residual_ratios=3/3`；
- dashboard 新增 `release_residual_ratios` 卡片；
- drilldown 新增 `Release residual ratio ledger`；
- `release_projection_surface_parity` 从 `11/11` 提升为 `12/12`；
- `release_closure_ledger` 从 `10/10` 回填为 `12/12`，补入 N2.392 与 N2.393；
- CI workflow 纳入 `tests/test_scene_release_residual_ratio_ledger_audit.py`。
