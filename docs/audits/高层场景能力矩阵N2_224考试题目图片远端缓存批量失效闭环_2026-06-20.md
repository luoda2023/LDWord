# 高层场景能力矩阵 N2.224 考试题目图片远端缓存批量失效闭环

## 1. 本轮定位

N2.224 继续执行 V43 的 P0 高级考试素材库路线，承接 N2.223 的单项显式失效。

本轮把“批量失效/统一清理”从纯边界声明推进为第一片可执行能力：

```text
一次运行可以声明本批次远端题图缓存全部不再可信，
运行时对所有 question_figure 远端缓存执行失效、索引摘除和重拉。
```

本轮不是完整缓存管理器，不提供跨目录后台扫描，也不提供 UI 勾选式目录清理。它只解决“本次运行内所有远端题图统一重拉”的链路。

## 2. 新增批量参数

`MaterialExecutionContext.entity_data` 新增批量失效开关识别：

```text
remote_asset_cache_invalidate_all / remoteAssetCacheInvalidateAll
question_figure_cache_invalidate_all / questionFigureCacheInvalidateAll
question_asset_cache_invalidate_all / questionAssetCacheInvalidateAll
cache_invalidate_all / cacheInvalidateAll
invalidate_all_remote_asset_cache / invalidateAllRemoteAssetCache
purge_all_remote_asset_cache / purgeAllRemoteAssetCache
clear_all_remote_asset_cache / clearAllRemoteAssetCache
```

真值沿用 N2.223 的布尔语义：

```text
1 / true / yes / y / on / force / forced / invalidate / invalidated / purge / clear / delete / always
```

单项题图 metadata 的 `cache_invalidate` 仍然优先；若单项未声明，但批量开关命中，则写入：

```text
cache_invalidation_reason=batch_manual
cache_invalidation_scope=batch
```

单项命中时继续写入：

```text
cache_invalidation_reason=manual
cache_invalidation_scope=item
```

## 3. 运行链路

运行时在 `_material_context_with_remote_question_asset_cache()` 入口先解析批量失效开关，然后逐个 `question_figure` 应用：

```text
entity_data.remote_asset_cache_invalidate_all=true
-> 每个远端 question_figure 获得 batch invalidation scope
-> 删除对应缓存目录内旧图片缓存
-> 从共享 index 或当前输出 index 摘除旧条目
-> 清空本轮旧 cache_path
-> refresh=True 重新下载
-> 写入新 cache_path / cache_status=downloaded / download_status=downloaded
-> 双写共享 index 与当前输出 index
```

安全边界继续沿用 N2.223：
- 不删除缓存目录外文件；
- 不删除 `index.json` 自身；
- 只删除支持图片后缀的缓存文件；
- 下载失败时不把已声明失效的旧 `cache_path` 当作有效回退。

## 4. Manifest / Report 输出

远端缓存 index entry 新增/延续：

```text
cache_invalidation_status
cache_invalidation_reason
cache_invalidation_scope
cache_invalidation_removed_count
cache_invalidation_index_removed_count
```

`remote_asset_cache` 摘要新增：

```text
cache_invalidation_scope_counts
```

资料包报告 `## Remote Asset Cache` 段新增可读计数：

```text
Invalidation statuses: removed=2
Invalidation scopes: batch=2
```

这样用户可以确认本轮不是逐条手工失效，而是运行级批量失效。

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cache batch invalidation bridge
```

覆盖对象：
- `pack:exam_education`
- `family:exam_teaching`

本轮把高级考试素材库从“单项缓存可显式失效”，推进到“本次运行内多题图缓存可统一失效重拉”。

## 6. 仍未闭合的边界

N2.224 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余缓存治理边界继续收窄为：

- 共享缓存目录浏览 UI；
- 按题型、学科、来源、素材库版本筛选的批量治理；
- 跨运行、跨目录、跨 profile 的后台统一清理；
- 后台失败重试、断点续传、并发下载队列；
- 跨运行缓存命中率趋势面板；
- token 续期、签名 URL 更新、401/403 后重新授权；
- 远端缩略图和下载前预览；
- 内容级错图识别、OCR/相似度对比、复杂学科图生成；
- 素材库版本、历史审阅、版权/真实性/AI 质量边界。
