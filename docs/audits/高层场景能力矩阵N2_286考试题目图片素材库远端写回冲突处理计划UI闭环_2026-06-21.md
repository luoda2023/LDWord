# 高层场景能力矩阵 N2.286 考试题目图片素材库远端写回冲突处理计划 UI 闭环

日期：2026-06-21

## 1. 本轮定位

N2.286 承接 N2.285 的“远端写回幂等、重试审计与冲突分类”。上一轮已经能把 HTTP 409/412 归类为 `remote_conflict`，但前台只停在“远端冲突 + 定位”，冲突没有进入可追踪的人工治理链路。

本轮补“冲突处理计划 UI”首片：远端冲突行出现“处理冲突”动作，点击后追加 `question_figure_library_remote_writeback_conflict_resolution` 审计记录，表格状态转为“冲突已记录”。它仍不做远端 diff 拉取或真实合并执行。

## 2. 已闭合能力

- 远端写回表识别 `remote_conflict` 后显示“处理冲突”按钮。
- “处理冲突”按钮只对远端冲突行开放。
- 点击后生成 `question_figure_library_remote_writeback_conflict_resolution` 审计记录。
- 冲突处理记录保存来源变更时间、冲突执行记录时间、endpoint、幂等键、retry attempt、HTTP 状态和错误摘要。
- 冲突处理记录声明 `conflict_resolution_status=manual_review_required`。
- 冲突处理记录声明 `conflict_resolution_action=open_remote_conflict_resolution`。
- 冲突处理记录声明可选裁决方向：覆盖远端、放弃本地、字段合并。
- 同一来源变更已记录冲突处理计划后不再重复追加。
- 远端写回表识别冲突处理记录后显示“冲突已记录”，处理动作退回“定位”。
- 当前 metadata 已偏离来源历史 after 值时，不允许记录冲突处理计划，避免旧版本误处理。
- `scene_product_readiness` 为 `pack:exam_education` 与 `family:exam_teaching` 新增 `question asset per-question asset library remote writeback conflict resolution plan UI bridge` evidence。
- 成熟度 gap 从 `advanced question asset library remote writeback conflict resolution UI` 收窄为 `advanced question asset library remote writeback conflict merge execution UI`。

## 3. 链路视角

```text
metadata update / rollback
  -> handoff_ready
  -> HTTP writeback execution
  -> HTTP 409/412 remote_conflict
  -> frontstage "处理冲突"
  -> conflict_resolution_planned audit
  -> table "冲突已记录"
  -> later remote diff / merge execution / permission renewal / batch transaction
```

这条链路补的是“冲突进入人工治理队列”的事实层。N2.285 负责识别远端冲突；N2.286 负责把冲突从只读状态推进为可记录、可复核、可继续治理的前台计划。

## 4. 场景矩阵影响

P0 高级考试素材库路线现在的远端写回链路为：

- N2.283：本地 metadata 治理结果生成远端写回交接。
- N2.284：具备 endpoint 的单项 handoff 可执行 HTTP JSON POST。
- N2.285：写回请求具备幂等键、retry attempt 审计和远端冲突分类。
- N2.286：远端冲突可生成前台人工处理计划并进入审计。

剩余 gap 不再是笼统的“冲突解决 UI”，而是更明确的 `advanced question asset library remote writeback conflict merge execution UI`。

## 5. 仍不宣称完成的边界

- 远端当前值拉取。
- 远端版本 diff 展示。
- 覆盖远端、放弃本地、字段合并的真正执行。
- 冲突合并后的二次写回 connector。
- 素材库登录态续期。
- 签名 URL 自动续签。
- 失败队列、指数退避和后台重试。
- 批量事务、幂等窗口管理和重复提交防护中心。
- 远端回滚。
- 跨资料包素材主数据版本系统。
