# 高层场景能力矩阵 N2.219 考试题目图片远端缓存资料包报告 Drilldown 闭环

## 1. 本轮定位

N2.219 继续执行 V43 的 P0 高级考试素材库路线，在 N2.218 已经让 `archive_report.md` 写入 `## Remote Asset Cache` 后，补齐前台产物浏览断点：

```text
资料包报告不应只是一个普通 markdown 文件路径。
当报告内已有 Remote Asset Cache 段时，最近运行面板需要能把它作为可直达锚点暴露出来。
```

本轮不是新增缓存下载能力，也不是全局缓存统计面板。它只把已存在的资料包报告段落接入 artifact drilldown 链路，让用户从执行结果直接定位到远端缓存摘要。

## 2. 新增产物类型

执行适配器新增 `material_package_report` 产物类型：

```text
material_package_paths["report"]
-> ArtifactItemState(kind="material_package_report")
-> path="archive_report.md"
-> fragment="remote-asset-cache"
-> detail="Remote Asset Cache"
```

普通资料包 zip 仍保留为 `material_package`，报告路径则独立为 `material_package_report`。这样最近运行面板可以把资料包文件和资料包报告分开展示，且报告项可以带锚点。

## 3. 前台入口

最近运行面板新增中文类型标签：

```text
material_package_report -> 资料包报告
```

当用户打开该产物时，路径文本会保留锚点：

```text
archive_report.md#remote-asset-cache
```

这条链路让 `Remote Asset Cache` 从报告内部段落升级为前台可见 drilldown 目标，满足 V43 “report/artifact 可验收”和“report -> target -> panel row/action 可回链”的要求。

## 4. 审计矩阵更新

`scene_report_artifact_drilldown_audit` 吸收 `material_package_report`：

- `artifact_state_model` 认得新的 artifact kind；
- `recent_run_artifact_browser` 认得新的 artifact kind；
- UI 证据包含 `QDesktopServices.openUrl` 与 `material_package_report`；
- 测试证据包含 `test_recent_run_panel_labels_material_package_report_anchor`；
- 审计计数更新为 `artifact_kind_count=11`、`test_evidence_count=14`，保持 0 issue。

## 5. 成熟度证据

`scene_product_readiness` 新增 evidence：

```text
question asset remote cache package report drilldown bridge
```

覆盖对象：

- `pack:exam_education`
- `family:exam_teaching`

这使高级考试素材库从“资料包报告可解释远端缓存状态”推进到“资料包报告中的远端缓存段可由前台产物入口直达”。

## 6. 仍未闭合的边界

N2.219 后，`advanced question asset library UI` / `advanced asset library UI` 的剩余边界继续收窄为：

- 真实素材库 API：登录、续期、签名 URL、远程查询下载 URL；
- UI 授权入口：401/403/过期/无权限/签名失效后的重新授权、token 刷新、权限申请或账号切换；
- 深层缓存治理：跨 profile 共享缓存索引、后台失败重试、批量失效、统一清理、全局命中率统计；
- 远端预览 UI：下载前缩略图、失败占位、尺寸展示、批量审阅；
- 内容级错图识别：图片内容、OCR、题干语义或图像相似度比对；
- 复杂学科图、几何图、公式图的生成或插件接管；
- AI 出题质量、素材质量、版权或真实性判断；
- 更完整的素材库批量审阅、历史版本、学科/题型标签和复用治理。
