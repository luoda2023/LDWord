# LDWord 用户使用说明

> 适用版本：main @ 668dd6d（2026-09-08）。
> 本手册覆盖从「提一句话需求」到「导出成品 Word」的完整操作步骤，以及写作过程中的编辑、润色、排版与导出设置。

---

## 一、快速上手：一句话到一份 Word

最快路径只需 **两次输入 + 一次确认**：

```
① 顶部选工作模式（如「工程文档版」）
② 左侧「共创写作」→ 输入一句话需求（如"写一份某某产业园项目的施工组织设计"）
③ AI 生成章节目录卡 → 直接在卡上核对/编辑目录
④ 点一次「确认目录，开始写正文」→ 之后全自动：
   逐章流式写作 → 排版复核校准 → 本地预检 → 生成 Word → 弹出成品卡
⑤ 点「打开文档」查看成品
```

中间**没有任何需要再次点按的步骤**（仅在成品会覆盖已有文件等必要闸门时才会停下来询问）。

## 二、界面总览

主窗口左侧是功能导航栏，从上到下：

| 面板 | 用途 |
| --- | --- |
| **共创写作** | 与 AI 对话，从需求到成稿的全流程主入口 |
| **排版装配** | 对已有 Word 文档做规范化排版（方案 → 模板 → 资料包 → 工作台） |
| **模板管理** | 管理格式模板：页面、标题、编号、表格、目录等版式规则 |
| **资料包** | 组织项目名称、公司名、图片、附件等素材 |
| **方案配置** | 配置当前工作模式下的处理方案 |
| **Markdown 编辑** | 右侧富文本编辑视图（写作时自动打开） |
| **工程范本库** | 工程阶段指南与范本 |
| **主题编辑器 / 偏好设置** | 界面主题与应用偏好 |

### 工作模式（窗口顶栏切换）

| 模式 | 适用文档 |
| --- | --- |
| 通用版 | 常规文档处理 |
| 试卷版 | 试卷及学生卷/答案卷交付 |
| **工程文档版** | 可研、施组、专项方案、交底、合同、结算、概算等 |
| 论文版 | 学位论文、课程论文、综述、开题 |
| 公文版 | 通知、请示、报告、批复、函、纪要 |

## 三、完整流程分步说明

### 第 1 步：选择工作模式

在窗口顶栏选择与你文档类型匹配的模式。模式决定了 AI 的写作规范、可用模板和交付规则。不确定时选「通用版」或「工程文档版」。

### 第 2 步：输入需求

进入左侧「共创写作」，在底部输入框用自然语言描述需求。**不需要固定句式**，AI 会理解语义，例如：

- 「写一份某某产业园项目的施工组织设计」
- 「帮我做一份污水处理厂技改项目的可行性研究报告，重点写工艺比选」
- 「根据附件里的招标文件，写一份投标文件的技术标部分」

**可附带材料**：把参考文档（docx/doc/wps/md）拖入或通过附件入口添加。首次发送带附件的需求时会弹出「材料发送授权」卡，同意后 AI 才能读取附件内容；勾选「记住我的选择」后不再重复询问（可在 偏好设置 → 材料发送授权 中重置）。

### 第 3 步：确认章节目录

AI 分析需求后，会直接弹出**章节目录确认卡**（无需再点计划卡）：

- **直接核对**：卡上按序号列出全部章节标题；
- **卡上编辑**：无需离开卡片即可 **改标题、删章、增章、拖动排序**；
- 有附件目录时以你的附件目录为准；行业内置指南（如工程六个阶段）会作为默认骨架。

确认无误后点 **「确认目录，开始写正文」**。确认后目录立即写入左侧章节目录列表，右侧 Markdown 编辑视图自动打开并停在第一章——不需要手动点开。

> 公文、试卷类需求会有相应的信息填写编辑器（文种/题目结构等），属于正常流程。

### 第 4 步：一条龙自动写作

确认目录后，系统自动完成以下全部环节：

1. **逐章流式写作** — 右侧编辑器与左侧对话区**实时打字机式**呈现每章文字与表格；表格**逐行成型**，不是写完才蹦出；左侧章节列表实时更新每章字数与状态；窗口右上角有红色「停止生成」按钮，点击即停（已写部分保留）。
2. **排版复核校准** — 全部章节写完后，自动按当前模板核对各级标题编号、表格结构并做安全修正，结果以卡片提示（哪些规则已检查、哪些有偏差已修正）。
3. **本地执行前检查（预检）** — 检查输出路径、资料完整性等；预检干净即自动继续，发现问题会弹卡说明原因并提供「重新检查」等操作。
4. **生成 Word 落盘** — 成品默认保存到 `文档\LDWord-Outputs\`（或你上次确认的输出目录），完成后弹出「文档已生成」成品卡，可直接打开文档或所在文件夹。

写作期间你随时可以：
- 在右侧编辑器**手动改任何内容**（编辑实时回写章节缓存，导出时以最新内容为准）；
- 用悬浮窗或对话区继续和 AI 交流。

### 第 5 步：写作中的编辑与 AI 润色

#### 右侧 Markdown 编辑器

- **格式工具栏**（编辑器顶部）：H1–H6、加粗/斜体/删除线/上下标/高亮、行内与块级公式、有序/无序列表、代码块、引用、链接、图片插入、表格选择器（拖拽选行列，支持自定义 N×M）；光标位置对应的格式按钮会高亮，状态栏显示当前块类型中文名（如「二级标题」）。
- **撤销/重做**：按钮带历史步数徽标，支持 Ctrl+Z / Ctrl+Y；仅真实内容变更计入撤销，光标移动不算。
- **图片**：直接**粘贴**、**拖入**（支持一次多张，拖入时编辑器出现"松开插入图片"提示）或用工具栏图片按钮插入；图片自动保存到工作台目录并以相对路径引用，重复图片按内容哈希去重。
- **右键菜单（表格）**：增删行列。
- **右键菜单（AI）**：
  - 选中文字 → 「AI 重新改写所选」「AI 润色优化」；
  - 光标放在某处 → 「AI 在光标处补充内容」（AI 承接上文续写）。
  - 执行时右下角弹出**分阶段等待浮层**，明确告知 AI 正在做什么：
    `AI 正在了解本章内容… → AI 正在撰写内容… → AI 正在应用到编辑器 → ✓ 完成`（Ctrl+Z 可撤销 AI 的改动）。

#### 右下角 AI 悬浮助手

编辑视图打开时，右下角常驻一个 **AI 悬浮图标**，点击弹出**可拖动的富文本悬浮对话框**。对话框里的对话与回复都按 Markdown 渲染（表格、标题、代码正常显示），输入直接走主会话——在悬浮窗里说「把第 2 章再润色一遍」即可直接驱动主流程。

#### 左侧章节目录列表

- 每章显示**字数、状态、评分**；
- 「第X篇/部分」标题会渲染为**可折叠分组**，点分组标题收起/展开其下各章；
- 每个分组提供 **「润色整篇」** 入口：AI 一次读取该篇下全部章节，逐章改写回写，保持标题与排版不变。

#### 左侧对话区（章节工作台）

- 每章写完都会沉淀为一条完整消息，可回看；
- 工作台编辑器内选中文字右键，同样可以「交给 AI 改写 / 润色 / 从光标处续写」。

### 第 6 步：导出 Word

**方式 A：一条龙自动落盘**（推荐）——确认目录后自动完成，成品在「文档已生成」卡上直接打开。

**方式 B：从 Markdown 编辑器手动导出**——适合你在编辑器里改完再出稿：

1. 点编辑器工具栏的导出按钮，选择保存位置与文件名；
2. 弹出「导出确认 · 页面设置」对话框，可设置：
   - **纸张/方向/分栏**：A4、A3；A3 横版分 2 栏适合超大版面；
   - **页边距**（勾选自定义后可逐边设置）、栏间距；
   - **图片质量**：压缩（推荐）/ 原图 / 强压缩；
   - **封面页**：可勾选生成封面，标题/副标题/日期自动从资料包项目名、文档类型等上下文带出（可手动修改）；
   - **页眉/页脚/页码**：可自定义文字，支持「第 X 页 共 Y 页」及每节重新编号；
   - 对话框实时显示**目标文件路径**与**预估总页数**；
3. 点「确定」完成导出，提示「导出完成」。

超长文档（数百页至上千页）按章节自动分节，每章独立分页；导出采用分批渲染，不会因文档过大而内存暴涨。

## 四、进阶说明

### AI 系统记忆

写作过程中 AI 会为整个项目维护一份**系统记忆**（全局背景 + 每章摘要），改写/续写任何章节前都会先读取，避免长文档"失忆"和前后重复。记忆文件默认与章节缓存同目录存放；可在 偏好设置 → AI 系统记忆位置 中改为「项目 / 源文档所在目录」，让记忆随项目文件夹一起保存。

### 流式显示速度

偏好设置中可切换流式写作的揭示速度（快 / 标准 / 慢），按个人阅读习惯调整。

### 撤销历史策略

- **保存 / 导出后是否清空撤销历史**可在 偏好设置 中配置（默认保留，可撤销到导出前）；
- **切换章节**时会重置编辑器撤销基线（跨章节撤销容易串内容）。

### 模板与排版规矩

各级标题（H1–H4）的字体、字号、加粗规则在模板中逐级定义，行业模板已按惯例预置（如工程类：黑体三号→小三→四号→宋体小四；公文按 GB/T 9704；论文按 GB/T 7713）。AI **边写边按这套规矩排版**，成稿后再由排版校准统一复核；你随时可以用编辑器工具栏手动微调。自建模板若缺某级标题样式，系统会自动派生递减字号兜底。

### 封面字段映射

资料包里的「项目名称 / 公司名称」等素材可映射为封面标题/副标题（导出对话框或素材编辑界面配置，按文档场景分别保存）。导出时若映射命中真实项目名，封面将优先使用，而不是退回文件名。

### 已生成的成品怎么改？

- 小改动：直接在右侧 Markdown 编辑器改，改完从编辑器重新导出 Word；
- 内容级修改：在对话区或悬浮窗告诉 AI（如「第三章换一个案例」「全文语气更正式」），AI 会带着系统记忆精准修改对应章节；
- 想换排版：在 模板管理 选择/调整模板后重新导出，无需重写正文。

## 五、常见问题

**Q：点「确认目录」后还能改目录吗？**
可以。写作开始前可以随时在确认卡上改；写作开始后也可以在对话区告诉 AI 增删章节，或直接在编辑器手动改。

**Q：停止生成会丢内容吗？**
不会。已流式写入的章节内容全部保留在章节缓存与对话记录中，中断章节会标记为中断状态，可单独重新生成。

**Q：写作时输入框为什么被锁定？**
逐章写作、预检、执行落盘期间为避免任务交叉，输入会暂时门禁；可点右上角红色「停止生成」结束当前任务后继续。悬浮窗被拒绝时输入会自动回填，不会丢字。

**Q：成品 Word 在哪里？**
默认 `文档\LDWord-Outputs\`，成品卡上也有「打开所在文件夹」按钮。

**Q：AI 能操作软件里的哪些功能？**
AI 每轮对话都携带一份完整的操作目录：目录生成、卡上编辑、逐章写作、重写/润色、套用模板、排版校准、导出预检、打开文档等都可以直接用自然语言驱动；只有覆盖文件等破坏性操作必须由你确认。

**Q：文档内容会上传吗？**
核心排版处理全部在本机完成；仅 AI 写作需要把你确认发送的需求与已授权的材料发给所配置的模型服务，文档不会自动上传。
