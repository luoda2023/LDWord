# 特殊标题与页眉页码范围联动

状态：已按本设计落地
日期：2026-07-31

## 1. 最终定义

“特殊标题”只有两类规则：

1. 完整标题：清除已有标题编号并去除首尾空白后，与用户输入全文相等。
2. 标题前缀：清除已有标题编号并去除首尾空白后，以用户输入开头。

默认值：

- 完整标题：`摘要`、`目录`、`参考文献`、`缩略语表`
- 标题前缀：`附录`、`附件`

每个逗号分隔项都是一条独立规则，也生成一个独立的页眉、页脚文字和页码范围选项。

以下行为明确禁止：

- 不把规则归入“摘要、目录、附录”等结构角色。
- 不合并多个输入项。
- 不为中文、英文或其他写法创建别名。
- 不因为输入了 `摘要` 而自动匹配 `Abstract`。
- 不把一个输入项展开为多个隐含选择器。
- 不从标题文字反推用户没有配置的规则。

同一栏内的重复项属于配置错误；同一文本也不能同时出现在“完整标题”和“标题前缀”中。

## 2. 匹配顺序

匹配使用用户输入的原始文本，区分大小写并保留内部空格，仅做以下清理：

1. 去除段落首尾空白。
2. 去除已存在的章、节或列表式标题编号。
3. 再次去除编号后产生的首尾空白。

随后按以下顺序匹配：

1. 完整标题优先。
2. 完整标题未命中时再匹配标题前缀。
3. 多个前缀同时命中时，最长前缀优先。
4. 长度相同则按用户输入顺序优先。

## 3. 范围定义

每次实际命中都创建一个范围：

- 起点：命中的标题段落。
- 终点：下一个特殊标题或普通一级标题之前。
- 文档结束前没有下一个一级标题时，以文档结束为终点。

同一规则可以在一个文档中命中多次；每次命中形成彼此独立、可以不连续的范围。

标题自身和标题后的内容共享该规则的范围选择器。标题编号、标题样式、页眉、页脚文字和页码计划读取同一份匹配结果，不再各自维护词表。

## 4. 联动选项

每条规则使用一个可逆的内部选择器：

```text
special-title:exact:<用户文本的 UTF-8 十六进制>
special-title:prefix:<用户文本的 UTF-8 十六进制>
```

这个编码只是稳定 ID，不是别名，也不参与文本匹配。界面始终显示用户输入原文，例如内部前缀选择器仍显示为“附录”。

规则变化与三个输出通道的联动如下：

| 用户操作 | 页眉隐藏范围 | 页脚文字隐藏范围 | 页码阶段范围 |
|---|---|---|---|
| 新增规则 | 新选项出现，默认不选中 | 新选项出现，默认不选中 | 每个阶段都可选择，默认不选中 |
| 删除规则 | 选项消失并清除旧引用 | 选项消失并清除旧引用 | 从所有阶段中清除旧引用 |
| 修改规则文字 | 选项文字与内部 ID 更新，原选择保留 | 同左 | 所有阶段中的原选择迁移到新 ID |
| 调整规则顺序 | 只调整选项显示顺序 | 同左 | 同左 |

页眉、页脚文字和页码是三个独立通道。一个规则在页眉中被选为隐藏范围，不会自动修改其页脚文字或页码设置。

## 5. 最终交互

标题面板只保留：

```text
特殊标题（不参与编号）

完整标题  [摘要, 目录, 参考文献, 缩略语表]
标题前缀  [附录, 附件]
样式来源  [沿用一级标题]
```

说明文字：

> 完整标题按全文匹配，标题前缀按开头匹配。每个逗号分隔项都是一条独立规则，并同步成为页眉、页脚文字和页码的独立范围选项。

不再显示“常用结构标题映射”、英文别名、结构角色或分类编辑器。

页眉、页脚文字和页码面板在“封面、其余正文”等基础范围之外，动态追加当前两栏中的每一个输入项。基础范围与特殊标题范围在界面上明确说明来源。

`声明页`、`授权书`、`说明页`不再是固定范围，也不再由内置标题词表猜测。用户需要控制这些内容时，应把文档中的实际标题加入“完整标题”或“标题前缀”；该输入项会原样成为一个独立范围选项。

## 6. 配置所有权

规则仅保存在：

```json
{
  "heading_model": {
    "non_numbered_title_texts": ["摘要", "目录", "参考文献", "缩略语表"],
    "non_numbered_prefixes": ["附录", "附件"]
  }
}
```

三个输出通道只保存自己选中的范围 ID：

```text
header.hidden_selectors
footer.hidden_selectors
page_number_plan.phases[*].selectors
```

配置中不增加 `section.roles`、`semantics_version` 或标题别名表。

## 7. 执行链路

```text
用户输入两类规则
  → 统一字面匹配器
  → 标题识别生成命中点和范围
  → 标题编号与样式读取命中点
  → 页眉、页脚文字与页码读取同一范围
```

标题规则编辑器负责同步维护三个输出通道里的引用。文档执行阶段不再根据标题含义重新分类。

## 8. 验收条件

- 输入 `摘要` 只匹配 `摘要`，不匹配 `Abstract` 或其他变体。
- 输入 `附录` 可匹配 `附录`、`附录 A`，但不自动匹配 `Appendix`。
- 完整规则 `附录 A` 与前缀规则 `附录` 同时命中时，完整规则优先。
- 前缀 `附` 与 `附录` 同时命中时，`附录` 优先。
- 两栏中的每一项在页眉、页脚文字和每个页码阶段中各出现一个选项。
- 新增规则不自动选中；删除规则不留下失效引用；修改文字保留已有选择。
- 用户删除 `目录` 后，相关动态选项和三个通道中的对应引用同时消失。
- 同一规则多次出现时生成多个不连续范围。
- 页眉、页脚文字和页码范围中不出现未经用户输入的“声明页、授权书、说明页”选项。
- 旧配置中的上述三个选择器在迁移时被清除；合法的特殊标题选择器原样保留。
- 模板中不存在结构角色映射、别名或隐式合并。
